# 电路拓扑收集 · 分类说明

本文件夹用于收集各类电路拓扑（原理图、结构图）。当前采用「**按功能分类为主、按拓扑结构归类为辅**」的两级体系。

## 一、一级分类（按功能）

| 序号 | 分类 | 说明 |
|------|------|------|
| 01 | 电源电路 | 线性稳压、开关电源、整流滤波、电池充放电管理 |
| 02 | 放大电路 | 运算放大、功率放大、音频放大、射频放大 |
| 03 | 振荡电路 | RC / LC / 晶体振荡器 |
| 04 | 滤波电路 | 低通 / 高通 / 带通 / 带阻 |
| 05 | 数字电路 | 组合逻辑、时序逻辑、单片机及嵌入式接口 |
| 06 | 转换电路 | ADC / DAC / 电平转换 |
| 07 | 驱动电路 | 电机驱动、LED 驱动、功率器件栅极驱动 |
| 08 | 传感器电路 | 各类传感器的信号调理与接口电路 |
| 09 | 通信电路 | 收发、调制解调、接口等 |
| 10 | 保护电路 | 过压 / 过流 / 过温 / ESD 及浪涌保护 |
| 11 | 变流电路 | 整流、逆变、变频 |
| 12 | 通用拓扑结构 | 不限定功能的纯连接结构（串联 / 并联 / 桥式 / 星型 / 网状） |

## 三、使用建议

1. 每张电路图存为图片（PNG/JPG）或 PDF，放入对应功能分类。
2. 同名电路若对应不同拓扑结构，可同时放入「通用拓扑结构」或功能分类下的结构子目录。
3. 需要扩充时，直接在某功能分类下新建子文件夹即可，保持编号前缀便于排序。

## 四、每个电路文件夹的说明文档

每个「最小子文件夹」（即不再含子文件夹的文件夹）内都有一份与该文件夹同名的 `.md` 说明文档，统一为 8 节结构：

1. **拓扑描述** —— 元件组成、连接方式、功能用途（纯文字，不画图）
2. **工作原理** —— 信号 / 能量如何流动
3. **关键计算公式** —— 核心设计公式 + 符号单位表
4. **元件调整影响** —— 增大/减小某个 R / C / L 对电路的影响
5. **典型参数示例** —— 具体数值代入计算的结果
6. **常见器件型号** —— 真实通用型号
7. **注意事项** —— 实际设计 / 使用注意点
8. **参考资料** —— 权威来源（教材 / 维基百科 / 官方应用笔记）

个别极生僻电路的公式如暂无法确定，文档中会标注「待补充」，后续可在仿真验证后补全。

## 五、公式查看方法（LaTeX）

文档中的公式使用 LaTeX 语法（`$...$` 行内、`$$...$$` 独立公式）。

- **VS Code**：内置预览不渲染数学公式，需安装扩展 **"Markdown Preview Enhanced"**（或 "Markdown+Math"），然后用命令 `Markdown Preview Enhanced: Open Preview to the Side` 打开预览即可渲染。
- **Typora / Obsidian**：原生支持，直接打开即可渲染。
- 未安装任何扩展时，公式会显示为 `$...$` / `$$...$$` 原始文本，但文字内容仍可正常阅读。
