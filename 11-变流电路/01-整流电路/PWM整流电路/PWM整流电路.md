# PWM 整流电路

## 拓扑描述
该电路由六只全控功率开关管 $T_1$~$T_6$（IGBT/MOSFET，各反并联快恢复续流二极管 $D_1$~$D_6$）、交流侧三相滤波电抗器 $L_a,L_b,L_c$（编号 L1~L3）与直流母线电容 $C_{dc}$（编号 C1）组成的三相全控桥有源整流网络。关键节点定义如下：三相交流输入节点 $a,b,c$（电网三相 $V_a,V_b,V_c$ 分别接滤波电抗器一端）；桥臂中点（开关节点）$M_a,M_b,M_c$（各相滤波电抗器另一端接对应相桥臂的上下两管连接点）；直流母线正节点 $P$（三个上管集电极 C/漏极 D 与 $C_{dc}$ 正端相连）；直流母线负节点 $N$（三个下管发射极 E/源极 S 与 $C_{dc}$ 负端相连），$P$、$N$ 即直流输出 $V_{dc}$ 端子。

各元件管脚连接（以 a 相为例，IGBT）：上管 $T_1$ 的集电极 C 接正节点 $P$、发射极 E 接开关节点 $M_a$、栅极 G 接 PWM 驱动信号；下管 $T_6$ 的集电极 C 接 $M_a$、发射极 E 接负节点 $N$、栅极 G 接 PWM 驱动信号；$T_1$、$T_6$ 各自反并联二极管 $D_1$、$D_6$ 的阳极接其发射极 E、阴极接其集电极 C；$b$、$c$ 两相由 $b$ 相上管 $T_3$/下管 $T_2$、$c$ 相上管 $T_5$/下管 $T_4$ 按相同方式构成（$T_3$、$T_5$ 为上管接 $P$，$T_2$、$T_4$ 为下管接 $N$）；滤波电抗器 $L_a$ 一端接电网 $a$ 相、另一端接 $M_a$，$L_b$、$L_c$ 同理接 $M_b$、$M_c$；直流母线电容 $C_{dc}$ 一端接 $P$、另一端接 $N$。

由此构成"三相全控桥 + 交流侧电感 + 直流侧电容"的 PWM 有源整流（AFE）组态，通过 PWM 控制交流电流实现单位功率因数与可调直流电压输出，并支持能量双向流动（可逆变回馈电网）。

## 工作原理
交流侧经滤波电抗器接入开关桥臂，控制电路以 PWM 方式驱动各开关管，使交流侧电流跟踪设定波形（通常与电压同相位以实现单位功率因数），同时把直流侧电压稳定在目标值。相比相控与不可控整流，它可实现低谐波、可调输出电压和再生回馈。

## 关键计算公式

- 直流侧平均电压（三相桥式，单位功率因数）：
$$V_{dc} = \frac{3\sqrt{2}}{\pi}\,V_{LL}\ (\text{基波近似})$$

- 调制比与直流电压关系：
$$V_{dc} \ge \frac{2\sqrt{2}}{\sqrt{3}}\,V_{LL(rms)}\ (\text{线电压})$$

- 交流侧电压方程（一相，稳态相量）：
$$V_{conv} = V_{grid} + j\omega L I$$

- 有功功率：
$$P = \frac{3}{2}V_d I_d\ (\text{dq 坐标系})$$

- 开关频率谐波主要集中在：
$$f_h = m f_{sw} \pm n f_{grid}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{dc}$ | 直流侧电压 | V |
| $V_{LL}$ | 交流线电压有效值 | V |
| $V_{grid}$ | 电网相电压 | V |
| $L$ | 交流滤波电感 | H |
| $I$ | 交流相电流 | A |
| $f_{sw}$ | 开关频率 | Hz |

## 元件调整影响
- **直流母线电压设定越高** → 控制裕量越大、电流控制能力越强，但开关与电容耐压要求升高。
- **滤波电感 $L$ 增大** → 电流纹波与谐波更小，但动态响应变慢、体积成本上升。
- **开关频率 $f_{sw}$ 提高** → 谐波减小、滤波器可缩小，但开关损耗增大。
- **直流电容 $C$ 增大** → 母线电压纹波小、抗扰强，但体积成本与上电浪涌增大。
- **调制比增大** → 输出电压提升，但接近上限时进入过调制、谐波增加。

## 典型参数示例
- 三相 PWM 整流，$V_{LL}=400\ \text{V}$：$V_{dc}\ge\dfrac{2\sqrt{2}}{\sqrt{3}}\times400\approx653\ \text{V}$，实际常取 700~800 V。
- 取 $L=2\ \text{mH}$、$f_{sw}=10\ \text{kHz}$、$I=10\ \text{A}$：电感基波压降 $j\omega LI=2\pi\times50\times0.002\times10\approx6.28\ \text{V}$（远小于 230 V 电网电压）。

## 常见器件型号
- IGBT 模块：英飞凌 FF 系列、三菱 CM 系列、富士 7MBR 系列。
- 功率 MOSFET：英飞凌 CoolMOS、华虹 / 安森美功率 MOSFET（按需选型）。
- 控制 DSP/MCU：TI TMS320F28379D、TMS320F28035。
- 驱动 IC：英飞凌 1ED、TI UCC 系列（按需选型）。

## 注意事项
- 交流侧滤波电感既要抑制纹波，又要保证足够的电流动态，需折中设计。
- 需通过锁相环（PLL）检测电网相位，保证同相控制以实现单位功率因数。
- 直流母线需预充电与软启动，防止上电浪涌损坏电容与开关。
- 开关管需设死区时间，防止桥臂直通短路。
