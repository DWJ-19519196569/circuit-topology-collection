# 半控整流电路

## 拓扑描述
由 **两只晶闸管（SCR）$T_1,T_2$ 与两只整流二极管 $D_1,D_2$** 组成的单相半控桥式结构（共阴极组为可控晶闸管、共阳极组为不可控二极管）。电路关键节点：**节点① 交流输入节点 $a,b$**（交流电源两端分别接两桥臂中点）；**节点② 直流输出正节点 $+$**（$T_1,T_2$ 的共阴极端，即直流正端）；**节点③ 直流输出负节点 $-$**（$D_1,D_2$ 的共阳极端，即直流负端）；**节点④ 负载/滤波节点**（负载与滤波电路跨接在 $+$ 与 $-$ 之间）。

各元件管脚连接：**$T_1$** 的阳极接交流节点 $a$、阴极接直流正节点 $+$、门极接触发电路；**$T_2$** 的阳极接交流节点 $b$、阴极接 $+$、门极接触发电路；**$D_1$** 的阳极接直流负节点 $-$、阴极接交流节点 $a$；**$D_2$** 的阳极接 $-$、阴极接交流节点 $b$；负载（或 $RL$ 负载 + 续流二极管）跨接在 $+$ 与 $-$ 之间。

由此构成"两只晶闸管共阴极组 + 两只二极管共阳极组"的单相半控桥整流组态，晶闸管控制开始导通时刻、二极管自然换流，输出直流电压可部分调节（延迟角 $\alpha$ 越大输出电压越低）。

## 工作原理
晶闸管在正向电压与门极触发信号同时满足时导通，延迟角 α 决定其开始导通的时刻；二极管则在对应半周自然导通。当延迟角 α 增大，晶闸管导通推迟，输出直流平均电压随之下降，从而实现有限范围的电压调节。

## 关键计算公式

- 单相半控桥输出平均电压（电阻负载）：
$$V_d = \frac{V_m}{\pi}(1+\cos\alpha)$$

- 角频率关系：
$$\omega = 2\pi f$$

- 输出平均电流（电阻负载）：
$$I_d = \frac{V_d}{R}$$

- 有效值电压：
$$V_{rms} = V_m\sqrt{\frac{1}{2\pi}\left(\pi-\alpha+\frac{\sin 2\alpha}{2}\right)}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_d$ | 输出平均电压 | V |
| $V_m$ | 输入交流峰值电压 | V |
| $V_{rms}$ | 输出电压有效值 | V |
| $\alpha$ | 触发延迟角 | rad |
| $I_d$ | 负载平均电流 | A |
| $f$ | 交流频率 | Hz |

## 元件调整影响
- **延迟角 α 增大** → 输出平均电压 $V_d$ 下降，可从接近全导通降到接近零。
- **α 减小** → 输出电压升高，功率因数与波形质量改善。
- **负载为感性时** → 输出电压调节范围受限，需加续流二极管防止失控。
- **换流重叠角越大** → 有效输出电压更低，纹波更大。
- **晶闸管耐压 / 电流额定越高** → 可整流的功率越大，但成本上升。

## 典型参数示例
- 单相 220 V、$V_m=220\sqrt2\approx311\ \text{V}$，$R=10\ \text{Ω}$。
- 取 $\alpha=\dfrac{\pi}{2}$：$V_d=\dfrac{311}{\pi}(1+\cos\frac{\pi}{2})=\dfrac{311}{\pi}\approx99\ \text{V}$，$I_d=\dfrac{99}{10}\approx9.9\ \text{A}$。
- 取 $\alpha=0$：$V_d=\dfrac{311}{\pi}(1+1)\approx198\ \text{V}$。

## 常见器件型号
- 晶闸管：BT151、BT169、TIC116、MCR100-6。
- 整流二极管：1N4007、1N5408、6A10。
- 续流二极管：常用快恢复二极管（如 FR107、MUR460）。
- 集成半控桥模块：常用按需选型。

## 注意事项
- 半控桥价廉、结构简单，但输出纹波与谐波较大，功率因数低。
- 感性负载必须并联续流二极管，否则可能发生失控导致输出异常。
- 触发电路需与交流电源同步，避免延迟角漂移。
- 晶闸管一旦导通无法靠门极关断，需等电流降至维持电流以下自然关断。
