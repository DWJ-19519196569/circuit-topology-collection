# 修正正弦波逆变电路

## 拓扑描述
由 **全桥开关桥（4 个开关器件 $T_1$~$T_4$，各反并联续流二极管，亦可用推挽）**、**输出滤波与升压变压器 $T$** 组成。电路关键节点：**节点① 直流母线正 $P$**；**节点② 直流母线负 $N$**；**节点③ 桥臂中点（开关节点）$M_1,M_2$**；**节点④ 输出节点**（变压器一次侧接 $M_1$、$M_2$，二次侧经滤波接负载）。

各元件管脚连接：**$T_1$** 的 C 接 $P$、E 接 $M_1$、G 接驱动；**$T_2$** 的 C 接 $M_1$、E 接 $N$、G 接驱动；**$T_3$** 的 C 接 $P$、E 接 $M_2$、G 接驱动；**$T_4$** 的 C 接 $M_2$、E 接 $N$、G 接驱动；各管反并联二极管阳极接 E、阴极接 C；**变压器一次侧** 一端接 $M_1$、另一端接 $M_2$，二次侧经输出电感/电容滤波后接负载。

由此构成"全桥开关桥 + 输出滤波与变压器"的修正正弦波逆变组态，通过在中电平与零电平间插入零电压区间，每半周输出"正电平—零电平—正电平"阶梯方波（以 $\pm V$ 与 $0$ 构成），使均方根值接近正弦波，广泛用于 UPS 与低成本移动电源逆变器。

## 工作原理
通过控制开关在上、下两只管交替工作并插入零电平区间，形成三级阶梯波形。虽然谐波含量高于纯正弦波，但对阻性负载（白炽灯、电阻性发热、部分电机）供电时，其有效值与基波能量接近正弦。

## 关键计算公式

- 修正正弦波有效值（幅值 $V_m$，导通角 $\alpha$ 定义阶梯宽度）：
$$V_{rms} = V_m \sqrt{\frac{\alpha}{\pi}}$$

- 输出电压基波幅值（阶梯波傅里叶展开）：
$$V_{o1} = \frac{4V_m}{\pi}\cos\left(\frac{\theta}{2}\right)$$

- 总谐波畸变率：
$$THD = \sqrt{\frac{V_{rms}^2 - V_{o1(rms)}^2}{V_{o1(rms)}^2}}$$

- 输出频率：
$$f_o = \frac{1}{T_s}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_m$ | 输出电压幅值 | V |
| $\alpha$ | 每周期导通角 | rad |
| $\theta$ | 零电压死区角 | rad |
| $V_{rms}$ | 输出电压有效值 | V |
| $THD$ | 总谐波畸变率 | — |
| $f_o$ | 输出频率 | Hz |

## 元件调整影响
- **零电平区间（死区角 $\theta$）↑** → 有效值下降、谐波成分改变，适当时可降低特定次谐波。
- **幅值 $V_m$ ↑** → 有效值与功率提高，器件耐压需同步提高。
- **开关频率 ↑** → 阶梯细分更接近正弦，但仍是「修正」波形、THD 不变性有限。
- **滤波电感/电容 ↑** → 输出波形平滑度改善，但体积与成本上升。

## 典型参数示例
- 取 $V_m = 311\ \text{V}$、阶梯导通角 $\alpha = \pi$（即方波）：$V_{rms} = 311\sqrt{1} = 311\ \text{V}$。
- 常用设计使修正波有效值等于市电 220 V，则 $V_m = 220 / \sqrt{\alpha/\pi}$ 反求峰值。

## 常见器件型号
- MOSFET：IRFP460、STW20NK50Z。
- 驱动/控制：EG8010、SG3525、TL494。
- 变压器：EE/ETD 铁氧体磁芯升压变压器。

## 注意事项
- 修正正弦波含高次谐波，对感性负载（电动机）会导致额外发热、噪声与效率下降。
- 精密测量仪器、带 PFC 或变压器电源的电子设备不宜用修正波供电。
- 输出峰值电压可能高于正弦波，需校验负载电压额定。
- 逆变器需有过载、短路与过温保护。
