# 正弦波逆变电路

## 拓扑描述
由 **全桥开关变换器（4 个开关器件 $T_1$~$T_4$，各反并联续流二极管）**、**SPWM 控制器**、**LC 输出滤波器（$L,C$）** 与 **直流母线电容 $C_{dc}$** 组成。电路关键节点：**节点① 直流母线正 $P$**；**节点② 直流母线负 $N$**；**节点③ 桥臂中点（开关节点）$M_1,M_2$**；**节点④ 输出节点 $V_{out}$**（滤波电感、滤波电容与负载公共点）。

各元件管脚连接：**$T_1$** 的 C 接 $P$、E 接 $M_1$、G 接 SPWM 驱动；**$T_2$** 的 C 接 $M_1$、E 接 $N$、G 接 SPWM 驱动；**$T_3$** 的 C 接 $P$、E 接 $M_2$、G 接 SPWM 驱动；**$T_4$** 的 C 接 $M_2$、E 接 $N$、G 接 SPWM 驱动；**$L$** 一端接 $M_1$、另一端接 $V_{out}$；**$C$** 一端接 $V_{out}$、另一端接 $M_2$（桥的另一中点/输出回线）；负载并联在 $V_{out}$ 与 $M_2$ 之间；**$C_{dc}$** 一端接 $P$、另一端接 $N$。

由此构成"全桥开关变换 + SPWM 调制 + LC 低通滤波"的正弦波逆变组态，桥臂输出占空比按正弦规律变化的 PWM 脉冲，经 LC 滤除高次谐波后得到与调制波同频的纯净正弦波，是高质量逆变电源（并网、UPS、变频器）的标准拓扑。

## 工作原理
通过正弦调制波与三角载波比较，生成占空比按正弦规律变化的 PWM 脉冲驱动开关桥。桥臂输出含基波与开关频率附近的高次谐波，LC 滤波器衰减高次谐波后，负载得到与调制波同频率的平滑正弦电压。

## 关键计算公式

- 输出基波电压幅值（SPWM）：
$$V_{o1} = m_a V_d$$

- 调制度：
$$m_a = \frac{V_{mod}}{V_{tri}}$$

- 载波比：
$$m_f = \frac{f_{tri}}{f_o}$$

- LC 滤波器截止频率：
$$f_c = \frac{1}{2\pi\sqrt{LC}}$$

- 滤波器特征阻抗：
$$Z_0 = \sqrt{\frac{L}{C}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_d$ | 直流母线电压 | V |
| $V_{o1}$ | 输出基波电压幅值 | V |
| $m_a$ | 调制度 | — |
| $m_f$ | 载波比（频率调制比） | — |
| $V_{mod}$ | 调制波幅值 | V |
| $V_{tri}$ | 载波幅值 | V |
| $f_{tri}$ | 载波频率 | Hz |
| $f_o$ | 输出基波频率 | Hz |
| $L,C$ | 滤波电感、电容 | H, F |

## 元件调整影响
- **$m_a$ ↑（≤1）** → 基波电压升高，线性区控制精度好，超过 1 进入过调制。
- **载波频率 $f_{tri}$ ↑** → 谐波频率升高、滤波更容易，但开关损耗增大。
- **滤波 $L$、$C$ ↑** → 截止频率下降、纹波减小，但体积成本上升、动态响应变慢。
- **$V_d$ ↑** → 输出电压能力提高，但器件耐压与母线电容成本上升。

## 典型参数示例
- 取 $V_d = 400\ \text{V}$、$m_a = 0.9$：基波幅值 $V_{o1} = 360\ \text{V}$，有效值约 $254\ \text{V}$。
- 取 $L = 1\ \text{mH}$、$C = 10\ \mu\text{F}$：$f_c = \dfrac{1}{2\pi\sqrt{10^{-3}\times10^{-5}}} \approx 1.59\ \text{kHz}$，远高于基波、低于载波。

## 常见器件型号
- IGBT：FGH40N60SFD、IRG4PC50F。
- MOSFET：IRFP460、STP40NF20。
- 控制 DSP：TMS320F28335、STM32F103（PWM 外设）。
- 驱动：IR2110、HCPL-3120。

## 注意事项
- LC 滤波器截止频率应远高于基波、远低于开关频率，避免落入谐振区。
- 死区时间会造成基波电压损失与波形畸变，需补偿。
- 阻性、感性、容性负载下滤波器谐振特性不同，需校验稳定性。
- 并网时需加同步锁相（PLL）与孤岛保护。
