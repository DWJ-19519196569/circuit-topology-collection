# 离网逆变电路

## 拓扑描述
由 **直流源（蓄电池/光伏）**、**桥式/推挽逆变器（以全桥 $T_1$~$T_4$ 为例，各反并联续流二极管）**、**升压变压器（工频机）或 DC–DC 升压（高频机）**、**正弦波/方波调制、输出滤波（$L,C$）与独立交流负载 $Z$** 组成。电路关键节点：**节点① 直流源母线正 $P$、负 $N$**；**节点② 桥臂中点（开关节点）$M_1,M_2$**；**节点③ 升压后母线/中间节点**（变压器或 DC-DC 升压输出）；**节点④ 输出节点 $V_{out}$**（滤波电感、电容与负载公共点）。

各元件管脚连接：前级 DC–DC 升压或工频变压器把电池/光伏直流升到所需母线；**$T_1$** 的 C 接 $P$、E 接 $M_1$、G 接调制驱动；**$T_2$** 的 C 接 $M_1$、E 接 $N$、G 接调制驱动；**$T_3$** 的 C 接 $P$、E 接 $M_2$、G 接调制驱动；**$T_4$** 的 C 接 $M_2$、E 接 $N$、G 接调制驱动；各管反并联二极管阳极接 E、阴极接 C；**$L$** 一端接 $M_1$、另一端接 $V_{out}$；**$C$** 一端接 $V_{out}$、另一端接 $M_2$；负载 $Z$ 并联在 $V_{out}$ 与 $M_2$ 之间。

由此构成"直流源 + 桥式/推挽逆变 + 升压与输出滤波"的离网逆变组态，不依赖电网，由本机振荡器决定输出频率、独立把直流转换为固定幅值与频率的交流电供给本地负载（须自行保证电压稳定与谐波抑制）。

## 工作原理
前级把电池直流升到所需母线电压，后级桥式逆变器用 SPWM（或方波/修正波）调制产生交流。输出电压和频率由本机振荡器决定，不跟踪电网，因此必须自行保证电压稳定与谐波抑制。

## 关键计算公式

- 输出功率：
$$P_{out} = V_{rms} \cdot I_{rms} \cdot \cos\varphi$$

- 直流输入功率：
$$P_{in} = V_{dc} \cdot I_{dc}$$

- 整机效率：
$$\eta = \frac{P_{out}}{P_{in}}$$

- 蓄电池放电时间：
$$t = \frac{C_{bat} \times V_{bat} \times DoD}{P_{out} / \eta}$$

- 输出频率（由振荡器）：
$$f = \frac{1}{T}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $P_{out}$ | 输出有功功率 | W |
| $V_{rms}$、$I_{rms}$ | 输出电压、电流有效值 | V、A |
| $\cos\varphi$ | 负载功率因数 | — |
| $V_{dc}$、$I_{dc}$ | 直流输入电压、电流 | V、A |
| $\eta$ | 效率 | — |
| $C_{bat}$ | 蓄电池容量 | Ah |
| $DoD$ | 放电深度 | — |
| $t$ | 供电持续时间 | h |

## 元件调整影响
- **蓄电池容量 $C_{bat}$ 增大** → 放电时间 $t$ 线性增大，续航更久，但体积、重量与成本上升。
- **放电深度 $DoD$ 增大** → 可用电量增加、单次续航变长，但会缩短电池循环寿命。
- **输出功率 $P_{out}$ 增大** → 直流输入功率 $P_{in} = P_{out}/\eta$ 增大、放电时间变短、器件电流应力上升。
- **效率 $\eta$ 提高** → 同等输出下直流输入功率下降，放电时间变长。
- 输出频率由本机振荡器周期 $T$ 决定，与电网无关，需保证振荡精度以稳定输出频率。

## 典型参数示例
- 取 $V_{rms} = 220\ \text{V}$、$I_{rms} = 5\ \text{A}$、$\cos\varphi = 0.9$：$P_{out} = 220\times5\times0.9 = 990\ \text{W}$。
- 取 $P_{out} = 1000\ \text{W}$、$\eta = 0.9$：$P_{in} = 1000/0.9 \approx 1111\ \text{W}$。
- 取 $C_{bat} = 100\ \text{Ah}$、$V_{bat} = 48\ \text{V}$、$DoD = 0.8$、$P_{out}=1000\ \text{W}$、$\eta=0.9$：
  $t = 100\times48\times0.8 / (1000/0.9) \approx 3.46\ \text{h}$。

## 常见器件型号
- 功率开关管：IRF3205、IRFP460、STP80NF70。
- 栅极驱动：IR2110、UCC21520。
- 控制器：SG3525（方波/推挽）、EG8010（纯正弦波 SPWM 专用）。

## 注意事项
- 输出电压、频率稳定完全靠自身，需良好反馈控制，负载突变时防止电压跌落。
- 感性/非线性负载（电机、整流型负载）瞬间启动电流大，需按冲击功率选额定值。
- 电池需配过放/过充保护与低压报警，DoD 不宜过大以保护寿命。
- 方波/修正波机型对部分电机与电子设备不适用，纯正弦波机型更通用。
