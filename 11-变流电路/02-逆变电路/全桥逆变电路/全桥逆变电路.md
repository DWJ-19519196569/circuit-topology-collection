# 全桥逆变电路

## 拓扑描述
由 **4 个开关器件 $T_1$~$T_4$（IGBT/MOSFET，各反并联续流二极管）** 组成两个桥臂，配合 **直流母线（电压 $V_d$，并联母线电容 $C_{dc}$）** 与 **负载 $Z$** 组成。电路关键节点：**节点① 直流母线正节点 $P$**；**节点② 直流母线负节点 $N$**；**节点③ 桥臂中点（开关节点）$M_1$**（左桥臂上下两管连接点）；**节点④ 桥臂中点（开关节点）$M_2$**（右桥臂上下两管连接点）；负载 $Z$ 跨接在 $M_1$ 与 $M_2$ 之间。

各元件管脚连接：**$T_1$** 的 C 接 $P$、E 接 $M_1$、G 接驱动信号，反并联二极管阳极接 E、阴极接 C；**$T_2$** 的 C 接 $M_1$、E 接 $N$、G 接驱动信号；**$T_3$** 的 C 接 $P$、E 接 $M_2$、G 接驱动信号；**$T_4$** 的 C 接 $M_2$、E 接 $N$、G 接驱动信号；**$C_{dc}$** 一端接 $P$、另一端接 $N$；负载 $Z$ 一端接 $M_1$、另一端接 $M_2$。

由此构成"两桥臂四管全桥 + 直流母线电容 + 负载跨接两桥臂中点"的单相电压型全桥逆变组态，对角两管 $T_1/T_4$ 与 $T_2/T_3$ 交替导通，使负载两端在 $\pm V_d$ 间切换、输出交变方波电压，功率大、可四象限运行。

## 工作原理
同一桥臂上下两管互补导通、对角两管同相位动作：T1/T4 导通时负载电压为 $+V_d$，T2/T3 导通时为 $-V_d$，负载两端电压在正负母线之间切换，经滤波或 PWM 调制后在负载上得到交流。

## 关键计算公式

- 输出基波电压峰值（方波调制）：
$$V_{o1} = \frac{4V_d}{\pi}$$

- 输出基波有效值：
$$V_{o1(rms)} = \frac{2\sqrt{2}}{\pi}V_d \approx 0.9 V_d$$

- 基波电压（正弦 PWM 调制，调制度 $m_a$）：
$$V_{o1} = m_a V_d$$

- 输出频率：
$$f_o = \frac{1}{T_s}$$

- 桥臂开关管承受的电压：
$$V_{sw} = V_d$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_d$ | 直流母线电压 | V |
| $V_{o1}$ | 输出基波电压幅值 | V |
| $m_a$ | 调制度（$0 \le m_a \le 1$） | — |
| $f_o$ | 输出频率 | Hz |
| $T_s$ | 输出周期 | s |

## 元件调整影响
- **$V_d$ ↑** → 输出基波电压升高，开关管耐压要求提高。
- **$m_a$ ↑** → 基波电压升高，谐波分布随调制方式变化。
- **开关频率 $f_s$ ↑** → 输出波形谐波减小、滤波器体积减小，但开关损耗增大。
- **死区时间 ↑** → 防止桥臂直通，但会引入波形畸变与基波压降。

## 典型参数示例
- 取 $V_d = 400\ \text{V}$、方波调制：基波有效值 $V_{o1(rms)} = 0.9 \times 400 = 360\ \text{V}$。
- 取 $V_d = 310\ \text{V}$、$m_a = 0.9$（SPWM）：基波幅值 $V_{o1} = 0.9 \times 310 = 279\ \text{V}$。

## 常见器件型号
- IGBT：IRG4PC50U、FGH40N60、IXYS IXGH 系列。
- MOSFET：IRFP460、STP75NF75。
- 驱动：IR2110 / IR2113 半桥驱动、HCPL-3120 光耦驱动。

## 注意事项
- 同一桥臂上下管严禁同时导通，必须设置死区时间防止直通短路。
- 母线需加大电容或低感母排，抑制开关瞬态电压尖峰。
- 续流二极管应选用快恢复或肖特基，降低反向恢复损耗。
- 大功率场合需加缓冲电路（RCD/RC）抑制 $dv/dt$ 与尖峰。
