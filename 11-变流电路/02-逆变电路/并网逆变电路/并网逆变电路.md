# 并网逆变电路

## 拓扑描述
由 **直流源（光伏/储能）**、**三相（或单相）桥式逆变器（6 只全控开关 $T_1$~$T_6$，各反并联二极管）**、**并网滤波电感 $L$（三相 $L_a,L_b,L_c$）**、**锁相环 PLL、电流/电压控制器**、**并网开关与电网** 组成。电路关键节点：**节点① 直流源母线正 $P$、负 $N$**；**节点② 桥臂中点（开关节点）$M_a,M_b,M_c$**；**节点③ 并网节点 $g_a,g_b,g_c$**（滤波电感另一端经并网开关接电网）；**节点④ 电网中性点 $GND$**。

各元件管脚连接：以 a 相桥臂为例，**$T_1$** 的 C 接 $P$、E 接 $M_a$、G 接驱动；**$T_4$** 的 C 接 $M_a$、E 接 $N$、G 接驱动；$b$、$c$ 相由 $T_3/T_6$、$T_5/T_2$ 按相同方式构成；各管反并联二极管阳极接 E、阴极接 C。**$L_a$** 一端接 $M_a$、另一端接并网节点 $g_a$（$L_b$、$L_c$ 同理）；并网开关串于 $g_a,g_b,g_c$ 与电网之间，PLL 与控制器分别采集电网电压/电流并输出驱动信号。

由此构成"三相桥式逆变器 + 并网滤波电感 + 锁相环控制"的并网逆变组态，把直流电能转换为与电网同频同相的正弦交流，以单位功率因数向电网馈送电流（且可按设定功率因数运行）。

## 工作原理
锁相环实时跟踪电网电压相位，控制器控制逆变器输出电流与电网电压同相（有功输出）或按设定功率因数运行。输出电流经 L 滤波后并入电网，通过调节桥臂电压矢量控制注入电流的幅值与相位。

## 关键计算公式

- 并网功率（三相）：
$$P = 3 \cdot \frac{\hat V_g \hat I_g}{2} \cos\varphi$$

- 单相并网功率：
$$P = V_{rms} I_{rms} \cos\varphi$$

- 滤波电感压降：
$$V_L = j\omega L I_g$$

- 并网电流纹波（近似）：
$$\Delta I_g = \frac{V_{dc}}{2 L f_{sw}} \cdot D(1-D)$$

- 功率因数：
$$PF = \cos\varphi$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $P$ | 馈入电网有功功率 | W |
| $\hat V_g$、$\hat I_g$ | 电网相电压、相电流幅值 | V、A |
| $\varphi$ | 电流与电压相位差 | rad |
| $L$ | 并网滤波电感 | H |
| $\omega$ | 电网角频率 | rad/s |
| $V_{dc}$ | 直流母线电压 | V |
| $PF$ | 功率因数 | — |

## 元件调整影响
- **滤波电感 $L$ 增大** → 并网电流纹波 $\Delta I_g$ 减小、波形更好，但电感压降 $V_L = j\omega L I_g$ 增大、体积与损耗上升。
- **直流母线电压 $V_{dc}$ 增大** → 桥臂可输出电压更高、电流控制裕量增大，但纹波同步增大、器件耐压需求上升。
- **开关频率 $f_{sw}$ 增大** → 纹波减小、滤波容易，但开关损耗上升。
- **相位差 $\varphi$ 增大** → 功率因数 $PF = \cos\varphi$ 下降，有功馈送减少、无功增大。
- 电网电压幅值/相位波动会改变 $V_L$ 与电流矢量，需锁相环及时跟踪以保证并网稳定。

## 典型参数示例
- 三相并网，取 $\hat V_g = 311\ \text{V}$、$\hat I_g = 10\ \text{A}$、$\cos\varphi = 1$：$P = 3 \times 311 \times 10 / 2 = 4665\ \text{W} \approx 4.67\ \text{kW}$。
- 单相并网，取 $V_{rms} = 220\ \text{V}$、$I_{rms} = 10\ \text{A}$、$\cos\varphi = 1$：$P = 220 \times 10 = 2200\ \text{W}$。
- 取 $L = 3\ \text{mH}$、$f = 50\ \text{Hz}$、$I_g = 10\ \text{A}$：$|V_L| = 2\pi\times50\times3\times10^{-3}\times10 \approx 9.42\ \text{V}$。

## 常见器件型号
- 功率开关管：IPD60R360P7、IKW40N65F5、IMW120R045M1（SiC MOSFET）。
- 栅极驱动：UCC21520、IR2136。
- 电流传感器：ACS758、LEM LA 系列霍尔传感器。

## 注意事项
- 必须通过锁相环与电网严格同频同相，相位偏差会导致功率因数下降甚至环流。
- 需满足孤岛保护、过欠压/过欠频保护与并网标准（如 IEEE 1547、GB/T 19939）。
- 并网电流要控制其总谐波畸变（THD），滤波电感设计须与载波频率匹配。
- 直流母线电压需高于电网相电压峰值，否则无法有效控制注入电流。
