# 半桥逆变电路

## 拓扑描述
由 **直流母线（电压 $V_{dc}$）**、**两只串联的功率开关管 $T_1,T_2$（各反并联续流二极管）**、**两只分压电容 $C_1,C_2$（构成中点 $O$）**、**驱动电路、输出滤波与负载 $Z$** 组成。电路关键节点：**节点① 直流母线正 $P$**；**节点② 直流母线负 $N$**；**节点③ 分压电容中点 $O$**（$C_1,C_2$ 公共点）；**节点④ 桥臂中点（开关节点）$M$**（$T_1,T_2$ 连接点）；负载 $Z$ 接在 $M$ 与 $O$ 之间。

各元件管脚连接：**$T_1$** 的 C 接 $P$、E 接 $M$、G 接驱动；**$T_2$** 的 C 接 $M$、E 接 $N$、G 接驱动；两管反并联二极管阳极接 E、阴极接 C；**$C_1$** 一端接 $P$、另一端接 $O$；**$C_2$** 一端接 $O$、另一端接 $N$；负载 $Z$ 一端接 $M$、另一端接 $O$（输出经滤波后接负载）。

由此构成"半桥两管串联 + 分压电容中点 + 负载跨接中点与开关节点"的半桥逆变组态，$T_1$、$T_2$ 交替导通使负载两端的电位在 $+V_{dc}/2$ 与 $-V_{dc}/2$ 之间切换，输出正负交替的方波交流电压。

## 工作原理
上管导通时负载接正母线，输出为正；下管导通时负载接负母线，输出为负。两管交替通断使负载两端得到双极性方波，其基波为正弦，可加滤波或调频调压后作为交流电源。

## 关键计算公式

- 输出方波幅值（直流母线中点分压）：
$$V_{out} = \pm \frac{V_{dc}}{2}$$

- 输出方波基波幅值（傅里叶展开）：
$$\hat V_{1} = \frac{2 V_{dc}}{\pi}$$

- 输出有效值（方波）：
$$V_{rms} = \frac{V_{dc}}{2}$$

- 每个开关管承受电压：
$$V_{DS} = V_{dc}$$

- 分压电容容值（纹波约束，近似）：
$$C = \frac{I_o}{4 f_{sw} \Delta V_C}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{dc}$ | 直流母线电压 | V |
| $V_{out}$ | 输出电压瞬时值 | V |
| $\hat V_1$ | 输出方波基波幅值 | V |
| $V_{rms}$ | 输出有效值 | V |
| $I_o$ | 输出电流 | A |
| $f_{sw}$ | 开关频率 | Hz |
| $\Delta V_C$ | 分压电容电压纹波 | V |

## 元件调整影响
- **直流母线电压 $V_{dc}$ 增大** → 输出幅值 $V_{out} = \pm V_{dc}/2$ 与基波 $\hat V_1$ 线性增大，同时每管耐压 $V_{DS} = V_{dc}$ 同步升高。
- **分压电容 C 增大** → 中点电压纹波 $\Delta V_C = I_o/(4 f_{sw} C)$ 减小、中点更稳定，但电容体积与成本上升。
- **开关频率 $f_{sw}$ 增大** → 分压电容纹波减小（容值需求下降），但开关损耗上升。
- **输出电流 $I_o$ 增大** → 分压电容纹波线性增大，中点电位漂移加剧。
- 与全桥相比，半桥输出摆幅只有母线一半，相同输出功率下电流加倍、管子电流应力更大。

## 典型参数示例
- 取 $V_{dc} = 300\ \text{V}$：输出方波幅值 $V_{out} = \pm 150\ \text{V}$，有效值 $V_{rms} = 150\ \text{V}$。
- 基波幅值 $\hat V_1 = 2 \times 300/\pi \approx 191\ \text{V}$。
- 取 $I_o = 2\ \text{A}$、$f_{sw} = 20\ \text{kHz}$、$\Delta V_C = 5\ \text{V}$：$C = 2/(4 \times 20\times10^{3} \times 5) = 5\ \mu\text{F}$。

## 常见器件型号
- 功率开关管：IRF840、STP12NM50、IPD60R280P7S。
- 栅极驱动（半桥）：IR2110、UCC21520、FAN7390。
- 分压电容：DC-Link 电解电容（如 450 V 系列）。

## 注意事项
- 两只开关管严禁同时导通，需设置足够死区时间防止直通短路。
- 分压电容中点电位在不对称负载下会漂移，必要时加中点平衡控制。
- 半桥输出电压摆幅为母线一半，驱动感性/变压器负载时注意偏磁。
- 输出为方波，谐波丰富，对波形敏感负载需加滤波后再供电。
