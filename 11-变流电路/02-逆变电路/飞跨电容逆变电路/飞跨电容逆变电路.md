# 飞跨电容逆变电路

## 拓扑描述
该电路由直流母线、每相多只串联功率开关管 $T_1$~$T_4$（编号 T1~T4，IGBT/MOSFET）、跨接在开关节点间的飞跨电容 $C_{FC}$（编号 C1）及驱动与控制器 IC1 组成。关键节点定义如下：直流母线正节点 $P$ 接最上端开关管 $T_1$ 的集电极 C/漏极 D；直流母线负节点 $N$ 接最下端开关管 $T_4$ 的发射极 E/源极 S；上、下桥臂中点节点 $M_1$、$M_2$ 是串联开关管 $T_1$ 与 $T_2$、$T_3$ 与 $T_4$ 的连接点，飞跨电容 $C_{FC}$ 跨接在这两个开关节点之间；输出节点 $V_{out}$ 是中间两管 $T_2$ 与 $T_3$ 的公共点，作为相输出端接负载。

各元件管脚连接（以三电平单相为例，IGBT）：上管 $T_1$ 的集电极 C 接正节点 $P$、发射极 E 接开关节点 $M_1$；管 $T_2$ 的集电极 C 接 $M_1$、发射极 E 接输出节点 $V_{out}$；管 $T_3$ 的集电极 C 接 $V_{out}$、发射极 E 接开关节点 $M_2$；下管 $T_4$ 的集电极 C 接 $M_2$、发射极 E 接负节点 $N$；各管栅极 G 分别接控制器 IC1 的对应驱动输出；飞跨电容 $C_{FC}$ 一端接开关节点 $M_1$、另一端接开关节点 $M_2$；负载/后级滤波一端接输出节点 $V_{out}$、另一端接母线中性点或负节点 $N$。

由此构成"多管串联 + 飞跨电容分压"的多电平逆变组态，飞跨电容作为浮动电压源把母线电压分为多个中间电位，使输出在多个电平间切换，同时降低各开关管的电压应力。

## 工作原理
飞跨电容被周期性充放电，维持在母线电压的某个分数值（如 $V_{dc}/2$），作为中间电平供开关节点接入。配合各开关管开合，输出得到三电平或多电平阶梯电压，开关管电压应力被降低。

## 关键计算公式

- 飞跨电容稳态电压（三电平 FC）：
$$V_{FC} = \frac{V_{dc}}{2}$$

- 每只开关管承受电压：
$$V_{DS} = \frac{V_{dc}}{2}$$

- 飞跨电容纹波电压（近似）：
$$\Delta V_{FC} = \frac{I_o}{C_{FC} f_{sw}}$$

- 输出电平数：
$$n = 2k + 1$$

- 开关管数量（每相，k 级）：
$$N_s = 2k$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{FC}$ | 飞跨电容稳态电压 | V |
| $V_{dc}$ | 直流母线电压 | V |
| $\Delta V_{FC}$ | 飞跨电容电压纹波 | V |
| $I_o$ | 输出电流 | A |
| $C_{FC}$ | 飞跨电容容值 | F |
| $f_{sw}$ | 开关频率 | Hz |
| $n$ | 输出电平数 | — |

## 元件调整影响
- **飞跨电容 $C_{FC}$ 增大** → 纹波 $\Delta V_{FC} = I_o/(C_{FC} f_{sw})$ 减小、中间电平更稳，但电容体积与成本上升。
- **飞跨电容 $C_{FC}$ 减小** → 中间电平波动加大，输出波形畸变、器件应力不稳。
- **开关频率 $f_{sw}$ 增大** → 飞跨电容纹波减小，可用更小电容，但开关损耗上升。
- **输出电流 $I_o$ 增大** → 飞跨电容纹波线性增大，需加大电容或提高开关频率。
- **串联级数增多** → 电平数 $n = 2k+1$ 增多、波形更好，但飞跨电容数量与电压平衡控制复杂度显著上升。

## 典型参数示例
- 三电平 FC 取 $V_{dc} = 400\ \text{V}$：$V_{FC} = 400/2 = 200\ \text{V}$，每管 $V_{DS} = 200\ \text{V}$。
- 取 $I_o = 5\ \text{A}$、$C_{FC} = 100\ \mu\text{F}$、$f_{sw} = 10\ \text{kHz}$：
  $\Delta V_{FC} = 5/(100\times10^{-6} \times 10\times10^{3}) = 5\ \text{V}$。
- 取 $k = 2$：电平数 $n = 2\times2+1 = 5$，每相开关管数 $N_s = 2\times2 = 4$。

## 常见器件型号
- 功率开关管：IRF540N、IRF840、IPD60R360P7。
- 飞跨电容：薄膜电容（低 ESR），如 EPCOS/TDK 薄膜系列、MLCC（小功率）。
- 栅极驱动：IR2110、UCC21520。

## 注意事项
- 必须对飞跨电容电压做主动平衡控制，否则中间电平漂移导致输出畸变与器件过压。
- 飞跨电容在启动/预充电阶段需先把电容充到稳定电平，防止初始冲击电流。
- 开关状态组合要避免飞跨电容被短接或过度放电，需严格的开关序列约束。
- 飞跨电容 ESR 与充放电环路寄生电感影响高频纹波，布局要短而紧凑。
