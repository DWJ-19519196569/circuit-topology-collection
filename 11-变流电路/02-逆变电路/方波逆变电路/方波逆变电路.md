# 方波逆变电路

## 拓扑描述
由 **直流源**、**桥式（全桥/半桥）或推挽功率开关管（以全桥 $T_1$~$T_4$ 为例，各反并联续流二极管）**、**驱动与振荡/控制电路**、**升压变压器 $T$**、**输出滤波与负载 $Z$** 组成。电路关键节点：**节点① 直流母线正 $P$**；**节点② 直流母线负 $N$**；**节点③ 桥臂中点（开关节点）$M_1,M_2$**；**节点④ 输出节点**（变压器一次侧接 $M_1$、$M_2$，二次侧经滤波接负载）。

各元件管脚连接：**$T_1$** 的 C 接 $P$、E 接 $M_1$、G 接振荡/控制输出；**$T_2$** 的 C 接 $M_1$、E 接 $N$、G 接振荡/控制输出；**$T_3$** 的 C 接 $P$、E 接 $M_2$、G 接振荡/控制输出；**$T_4$** 的 C 接 $M_2$、E 接 $N$、G 接振荡/控制输出；各管反并联二极管阳极接 E、阴极接 C；**变压器一次侧** 一端接 $M_1$、另一端接 $M_2$（推挽则为中心抽头接 $P$），二次侧经滤波电感/电容后接负载。

由此构成"桥式/推挽开关 + 升压变压器 + 方波控制"的方波逆变组态，开关管按固定频率交替通断使负载两端电压极性周期性反转，输出正负对称的方波交流电压，是结构最简单的一类逆变器。

## 工作原理
两对开关管（全桥）或两管（推挽）轮流导通，使变压器一次侧或负载两端电压极性周期性反转，产生方波交流。输出电压幅值由直流母线电压决定，频率由开关周期决定，主要用于对波形要求不高的阻性/感性负载。

## 关键计算公式

- 输出方波频率：
$$f = \frac{1}{T}$$

- 全桥方波峰值：
$$V_{out} = \pm V_{dc}$$

- 半桥方波峰值：
$$V_{out} = \pm \frac{V_{dc}}{2}$$

- 方波基波幅值（傅里叶）：
$$\hat V_1 = \frac{4 V_{dc}}{\pi}$$

- 方波有效值：
$$V_{rms} = V_{dc}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f$ | 输出方波频率 | Hz |
| $T$ | 开关周期 | s |
| $V_{dc}$ | 直流母线电压 | V |
| $V_{out}$ | 输出方波瞬时值 | V |
| $\hat V_1$ | 方波基波幅值 | V |
| $V_{rms}$ | 输出有效值 | V |

## 元件调整影响
- **直流母线电压 $V_{dc}$ 增大** → 全桥方波幅值 $V_{out} = \pm V_{dc}$ 与基波 $\hat V_1 = 4V_{dc}/\pi$ 线性增大，输出有效值 $V_{rms} = V_{dc}$ 同步升高。
- **开关周期 $T$ 缩短（频率升高）** → 输出频率 $f = 1/T$ 升高，变压器可做小，但开关损耗与磁性材料损耗上升。
- **拓扑选择（全桥 vs 半桥）** → 全桥输出摆幅为 $V_{dc}$，半桥为 $V_{dc}/2$，相同母线电压下全桥输出幅度翻倍。
- **升压变压器匝比增大** → 副边输出电压按匝比提高，用于把低压直流变为高压交流。
- 输出含大量奇次谐波，感性/容性负载对波形失真敏感，需滤波改善。

## 典型参数示例
- 取 $V_{dc} = 12\ \text{V}$（全桥）：$V_{out} = \pm 12\ \text{V}$，$V_{rms} = 12\ \text{V}$。
- 方波基波幅值 $\hat V_1 = 4\times12/\pi \approx 15.3\ \text{V}$。
- 取 $T = 20\ \text{ms}$：$f = 1/0.02 = 50\ \text{Hz}$。
- 通过 1:10 升压变压器，二次侧方波峰值达 $12\times10 = 120\ \text{V}$（对谐振/阻性负载近似）。

## 常见器件型号
- 全桥/推挽开关管：IRF3205、IRFP460、STP80NF70。
- 栅极驱动：IR2110、UCC21520、SG3525（推挽控制）。
- 升压变压器：按功率和频率定制的铁氧体/硅钢变压器。

## 注意事项
- 方波谐波丰富，对电机、精密设备等负载需加 LC 滤波或改用正弦调制。
- 推挽与全桥拓扑需防直通并设置死区时间，避免同一桥臂上下管同时导通。
- 变压器驱动时注意磁芯饱和与偏磁问题，需设计伏秒平衡。
- 阻性/感性负载下方波电流谐波会引入额外发热，需评估器件温升。
