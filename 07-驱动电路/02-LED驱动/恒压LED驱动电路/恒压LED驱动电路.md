# 恒压 LED 驱动电路

## 拓扑描述
由 **稳压源 / DC-DC 恒压变换器 $U_1$**、**限流电阻 $R$** 与 **LED 串（$n$ 颗 LED 串联，每颗正向压降 $V_F$）** 组成的驱动网络（亦可多组先串后并）。电路共有 3 个关键节点：**节点① 恒压输出正端 $V_{supply}$**（$U_1$ 输出正端与限流电阻 $R$ 上端相连）；**节点② LED 串上端节点**（$R$ 下端与第一颗 LED 阳极相连）；**节点③ 地 GND**（$U_1$ 输出负端与最后一颗 LED 阴极相连）。

各元件管脚连接：**$U_1$** 输出正端接节点①$V_{supply}$、输出负端接节点③地（输入与地脚接输入电源与节点③）；**限流电阻 $R$** 一端接节点①、另一端接节点②；**LED 串** 第一颗 LED 阳极接节点②、最后一颗 LED 阴极接节点③，中间各灯珠首尾依次串联；若先串后并，则每组 LED 串经各自的限流电阻 $R$ 接节点①、组内阴极接节点③。

由此构成"恒压源 + 限流电阻"的恒压驱动组态：$U_1$ 提供稳定输出电压，限流电阻 $R$ 吸收 $V_{supply}-nV_F$ 的压差并设定 LED 电流 $I_{LED}=(V_{supply}-nV_F)/R$，结构简单，但对 $V_F$ 与温度波动敏感、电流精度较差，适合指示灯、背光条等对电流一致性要求不高的场合。

## 工作原理
恒压源把输入电压稳定在设定值，LED 串两端压差被限流电阻吸收，由限流电阻决定流过 LED 的电流。负载变化时由稳压环路维持输出电压不变。

## 关键计算公式

- 限流电阻：
$$R = \frac{V_{supply} - nV_F}{I_{LED}}$$

- 限流电阻功耗：
$$P_R = I_{LED}^2 \times R = (V_{supply} - nV_F) I_{LED}$$

- 单颗 LED 功耗：
$$P_{LED} = V_F \times I_{LED}$$

- 总功耗 / 效率：
$$P_{total} = V_{supply} \times I_{LED}, \quad \eta = \frac{nV_F}{V_{supply}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{supply}$ | 恒压输出电压 | V |
| $n$ | 串联 LED 数量 | — |
| $V_F$ | 单颗 LED 正向压降 | V |
| $I_{LED}$ | LED 工作电流 | A |
| $R$ | 限流电阻 | Ω |
| $P_R$ | 限流电阻功耗 | W |
| $\eta$ | 效率 | — |

## 元件调整影响
- **限流电阻 R 增大** → 电流减小、亮度降低、电阻发热增大。
- **供电电压 $V_{supply}$ 升高** → 电流增大，限流电阻压降与功耗急剧上升，需重新计算 R。
- **串联 LED 数 n 增大** → 电阻压降减小、效率提高，但电压余量过低时电流对 $V_F$ 波动更敏感。
- **LED 并联数增多** → 总电流增大，且因 $V_F$ 差异导致各支路电流不均，应尽量串联。

## 典型参数示例
- 取 $V_{supply}=5\ \text{V}$、$n=1$、$V_F=2\ \text{V}$、$I_{LED}=20\ \text{mA}$：$R=(5-2)/0.02=150\ \Omega$，$P_R=0.02^2\times150=60\ \text{mW}$。
- 取 $V_{supply}=12\ \text{V}$、3 颗 LED（$V_F=3.2\ \text{V}$）、$I_{LED}=20\ \text{mA}$：$R=(12-9.6)/0.02=120\ \Omega$。

## 常见器件型号
- 恒压源：LM7805、LM2596（降压）、MP1584、XL6009（升压）。
- LED：5mm 直插 / 3528 / 5050 灯珠。

## 注意事项
- 必须串限流电阻，LED 是电流型器件，恒压直接驱动会过流损坏。
- 恒压方案电流精度差，$V_F$ 随温度和批次波动会带来亮度不均。
- 并联 LED 应采用「先串联成组、再并组」的方式减少分流不均。
- 限流电阻需按实际压差校核功耗，避免过热。
