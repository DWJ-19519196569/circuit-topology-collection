# LED 显示屏驱动电路

## 拓扑描述
由 **行扫描开关管（行选，以 P 沟道 MOSFET 计）$Q_1\sim Q_m$**、**列恒流驱动芯片 $U_1$（$n$ 列恒流通道）** 与 **LED 点阵（$m$ 行 $\times$ $n$ 列）** 组成的矩阵扫描驱动网络。电路共有 4 组关键节点：**节点① 电源正端 V+**（所有行选管 $Q_1\sim Q_m$ 的源极 S 与电源正极相连）；**节点② 各行母线（共 $m$ 个）**（第 $i$ 行行选管 $Q_i$ 的漏极 D 与该行全部 LED 阳极相连）；**节点③ 各列母线（共 $n$ 个）**（第 $j$ 列全部 LED 阴极与列恒流芯片 $U_1$ 第 $j$ 通道输入端相连）；**节点④ 地 GND**（列恒流芯片 $U_1$ 的电源负端/灌电流回路相连）。

各元件管脚连接：**行选管 $Q_i$** 的 S 接节点①电源正端、D 接节点②第 $i$ 行母线、G 接行译码器/行选驱动信号；**列恒流芯片 $U_1$** 第 $j$ 通道电流输入端接节点③第 $j$ 列母线、恒流输出经内部采样电阻接节点④地、基准/数据/时钟/使能脚送控制器；**LED 点阵**第 $i$ 行第 $j$ 列灯珠的阳极接第 $i$ 行母线（节点②）、阴极接第 $j$ 列母线（节点③）。

由此构成"行扫描 + 列恒流"的点阵扫描驱动组态：任意时刻仅选中一行（该行行选管导通），该行 LED 由列恒流通道按灰度数据提供恒定电流，逐行快速轮询并利用人眼视觉暂留完成整屏刷新，同时以 PWM 调制导通时长实现灰度与亮度控制。

## 工作原理
任意时刻仅选中一行，该行的 LED 按列数据由恒流源驱动导通；利用人眼视觉暂留效应快速轮询各行，使人眼看到完整的整屏画面。通过 PWM 调制导通时长实现灰度与亮度。

## 关键计算公式

- 单颗 LED 平均电流（占空比取均值）：
$$I_{avg} = I_{peak} \times D$$

- 整屏最大峰值电流（每行 N 列全亮）：
$$I_{row} = N \times I_{peak}$$

- 单帧扫描频率：
$$f_{frame} = \frac{f_{row}}{m}$$

- 单个 LED 功耗：
$$P_{LED} = V_F \times I_{avg}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I_{peak}$ | 单 LED 峰值电流 | A |
| $I_{avg}$ | 单 LED 平均电流 | A |
| $D$ | PWM 占空比 | — |
| $N$ | 每行点亮列数 | — |
| $I_{row}$ | 单行峰值电流 | A |
| $f_{frame}$ | 帧率 | Hz |
| $f_{row}$ | 行扫描频率 | Hz |
| $m$ | 扫描行数（1/m 扫描） | — |
| $V_F$ | LED 正向压降 | V |

## 元件调整影响
- **行数 m 增大** → 占空比 1/m 减小，LED 平均亮度下降，需提高峰值电流补偿。
- **峰值电流 $I_{peak}$ 增大** → 亮度提升，但 LED 发热与结温升高，存在烧毁风险。
- **扫描频率 $f_{row}$ 提高** → 画面闪烁减弱（越接近 ≥60 Hz 越好），但开关损耗增大。
- **灰度位数提高** → 灰阶更细腻，但刷新数据带宽与时钟频率需相应提高。

## 典型参数示例
- 16 行扫描（m=16）、帧率 $f_{frame}=60\ \text{Hz}$：$f_{row} = 16 \times 60 = 960\ \text{Hz}$。
- 单行全亮 64 列、$I_{peak}=20\ \text{mA}$：$I_{row} = 64 \times 0.02 = 1.28\ \text{A}$，平均每 LED $I_{avg}=20/16=1.25\ \text{mA}$。

## 常见器件型号
- 行扫描开关：74HC138 译码器 + 4953 PMOS 行管。
- 列驱动恒流芯片：MBI5024、MBI5026、SM16126、TLC5940、JS78。
- LED 点阵模块：1088AS（8×8）、8×8/16×16 点阵屏。

## 注意事项
- 行扫描占空比低时需按「峰值电流」校核 LED 规格，而非平均电流。
- 恒流通道精度与温度漂移直接影响显示均匀性，需选择匹配度高的驱动芯片。
- 大屏需分区供电、就近退耦，防止行电流突变引起电源纹波与地弹。
- 刷新率不足会导致画面闪烁与低亮度灰阶失真。
