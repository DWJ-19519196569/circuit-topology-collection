# PWM 调光电路

## 拓扑描述
由 **PWM 信号源（MCU 定时器/专用调光器）**、**开关管（以 N 沟道 MOSFET $Q_1$ 计，或使用恒流驱动芯片的调光/使能引脚）**、**限流/恒流环节** 与 **LED（串/并联负载）** 组成的亮度调节网络。电路共有 3 个关键节点：**节点① 电源正端 V+**（限流/恒流环节输入端或 LED 串阳极端）；**节点② 开关节点**（LED 串阴极端与 $Q_1$ 漏极 D 相连，为限流/恒流环节与开关管的公共节点）；**节点③ 地 GND**（$Q_1$ 源极 S 与电源负端相连）。另有 **节点④ PWM 信号节点**（PWM 源输出接 $Q_1$ 栅极 G 或恒流芯片调光使能脚）。

各元件管脚连接：**PWM 信号源** 输出接节点④PWM 信号节点；**$Q_1$** 的 G 接节点④PWM 信号节点、D 接节点②开关节点、S 接节点③地；**限流/恒流环节** 一端接节点①电源正端（或串于 LED 支路）、另一端接 LED 对应端；**LED** 阳极经限流/恒流环节接节点①、阴极接节点②开关节点（采用恒流芯片调光脚方案时由芯片内部开关控制 LED 支路）。

由此构成"PWM 通断调光"组态：PWM 方波控制 $Q_1$（或调光使能脚）通断，LED 在导通期间以额定（峰值）电流点亮、关断期间熄灭，改变占空比即改变人眼感知的平均亮度（$I_{avg}=I_{peak}\cdot D$），因导通电流恒定故 LED 色温基本不变，实现无级连续调光。

## 工作原理
在电路导通期间 LED 以额定（峰值）电流点亮，关断期间完全熄灭；调节高低电平的时间比例（占空比），即可改变人眼感知的平均亮度。由于导通电流恒定，LED 的光谱（颜色）几乎不随亮度漂移。

## 关键计算公式

- 平均电流：
$$I_{avg} = I_{peak} \times D$$

- 占空比：
$$D = \frac{t_{on}}{t_{on} + t_{off}} = \frac{t_{on}}{T}$$

- 调光分辨率（N 位定时器）：
$$R = \frac{1}{2^N}$$

- PWM 频率：
$$f_{PWM} = \frac{1}{T}$$

- 平均功耗：
$$P_{avg} = V_F \times I_{avg}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I_{peak}$ | 导通峰值电流 | A |
| $I_{avg}$ | 平均电流 | A |
| $D$ | 占空比 | — |
| $t_{on}$ | 导通时间 | s |
| $t_{off}$ | 关断时间 | s |
| $T$ | PWM 周期 | s |
| $f_{PWM}$ | PWM 频率 | Hz |
| $V_F$ | LED 正向压降 | V |

## 元件调整影响
- **占空比 D 增大** → 平均电流增大，LED 变亮。
- **PWM 频率降低** → 可能被人眼察觉闪烁，甚至与相机、频闪源产生拍频。
- **PWM 频率过高** → 开关损耗增大，调光线性度与对比度变差。
- **导通峰值电流增大** → 亮度上限提高，但需校核 LED 允许的峰值电流与结温。

## 典型参数示例
- 取 $I_{peak}=20\ \text{mA}$、$D=0.5$：$I_{avg} = 20 \times 0.5 = 10\ \text{mA}$。
- 16 位 PWM 定时器：调光分辨率 $R = 1/2^{16} \approx 1.53\times10^{-5}$（约 65536 级）。

## 常见器件型号
- PWM 发生器：任意带定时器的 MCU（STM32、ATmega328）。
- 恒流驱动带调光脚：MBI5024、TLC5940、PT4115（PWM 调光引脚）。
- 专用调光 IC：LM3409、AL8860。

## 注意事项
- PWM 频率通常取 200 Hz～10 kHz，避开人眼闪烁与音频可闻频段。
- 高频开关沿产生的 EMI 需通过布置短走线、加 RC 缓冲缓解。
- 高精度调光宜采用恒流源 + 模拟或混合调光，避免大占空比范围内的非线性。
- 数字电源上 PWM 突变电流会引入纹波，注意退耦与滤波。
