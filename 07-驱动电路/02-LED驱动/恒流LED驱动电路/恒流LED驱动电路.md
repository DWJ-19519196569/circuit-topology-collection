# 恒流 LED 驱动电路

## 拓扑描述
由 **基准电压源 $V_{ref}$**、**采样电阻 $R_{sense}$**、**误差放大器 $A_1$** 与 **调整管 $Q_1$（线性型，以 N 沟道 MOSFET/BJT 计）**（或专用恒流 IC）构成的闭环恒流网络。电路共有 4 个关键节点：**节点① 电源正端 $V_{in}$**（LED 串阳极）；**节点② LED 串下节点**（LED 串阴极与 $Q_1$ 漏极/集电极 C 相连）；**节点③ 采样节点**（$Q_1$ 源极/发射极 E、$R_{sense}$ 上端、$A_1$ 采样输入三者相连）；**节点④ 地 GND**（$R_{sense}$ 下端、$A_1$ 地、基准 $V_{ref}$ 负端相连）。

各元件管脚连接：**LED 串** 阳极接节点①电源正端、阴极接节点②LED 串下节点；**$Q_1$** 漏极/集电极 C 接节点②、源极/发射极 E 接节点③采样节点、栅极/基极 B 接 $A_1$ 输出；**$R_{sense}$** 一端接节点③、另一端接节点④地；**$A_1$** 的 IN− 接节点③采样节点、IN+ 接基准 $V_{ref}$、OUT 接 $Q_1$ 栅极/基极、V+ 接节点①（正电源）、V− 接节点④（地/负电源）；**基准 $V_{ref}$** 正端接 $A_1$ 的 IN+、负端接节点④地。

由此构成"闭环线性恒流"组态：$A_1$ 将采样电阻 $R_{sense}$ 上的压降 $V_{sense}=I_{LED}R_{sense}$ 与基准 $V_{ref}$ 比较，调节调整管 $Q_1$ 导通程度使 $I_{LED}=V_{ref}/R_{sense}$ 恒定，从而在电源电压与温度波动下保持 LED 电流稳定，避免亮度漂移或损坏。

## 工作原理
反馈回路检测采样电阻上的压降并与其内部的固定基准比较，偏差经误差放大器放大后控制调整管导通程度，从而把流过 LED 的电流稳定在设定值。电流设定值通常由采样电阻阻值决定。

## 关键计算公式

- 输出恒定电流（专用 IC）：
$$I_{LED} = \frac{V_{ref}}{R_{sense}}$$

- 采样电阻功耗：
$$P_{Rs} = I_{LED}^2 \times R_{sense}$$

- 采样电压：
$$V_{sense} = I_{LED} \times R_{sense}$$

- 线性型驱动管耗散（降压容余）：
$$P_{drop} = (V_{in} - V_F) \times I_{LED}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I_{LED}$ | 恒流输出电流 | A |
| $V_{ref}$ | IC 内部参考电压 | V |
| $R_{sense}$ | 采样电阻 | Ω |
| $V_{sense}$ | 采样电压 | V |
| $V_{in}$ | 输入电压 | V |
| $V_F$ | LED 总正向压降 | V |
| $P_{Rs}$ | 采样电阻功耗 | W |
| $P_{drop}$ | 调节管耗散 | W |

## 元件调整影响
- **采样电阻 $R_{sense}$ 减小** → 输出电流增大（$I_{LED}=V_{ref}/R_{sense}$）。
- **参考电压 $V_{ref}$ 越高** → 采样电阻压降越大，电流精度越高但采样损耗增大。
- **输入电压升高（线性型）** → 调节管压降与发热增大，需保证散热。
- **采样电阻精度/温漂提高** → 电流稳定性与一致性改善。

## 典型参数示例
- 取 $V_{ref}=0.2\ \text{V}$、目标 $I_{LED}=1\ \text{A}$：$R_{sense} = 0.2/1 = 0.2\ \Omega$，$P_{Rs}=1^2\times0.2=0.2\ \text{W}$。
- 取 $V_{ref}=0.1\ \text{V}$、$R_{sense}=0.05\ \Omega$：$I_{LED}=0.1/0.05=2\ \text{A}$。

## 常见器件型号
- 线性恒流 IC：LM317（恒流接法）、NCP3066、AL5809、CL2N3。
- 开关型恒流 IC：PT4115、LM3404、AL8860。
- 采样电阻：1206 / 2512 大功率低阻检流电阻（如 0.1 Ω 1%）。

## 注意事项
- 采样电阻需选用低温漂、功率充足的型号，否则电流漂移与发热影响精度。
- LED 串联数量需与输入电压范围匹配，保证调节管/开关管工作在线性可调范围。
- 开关型方案效率高，但需关注电感、续流二极管与纹波。
- LED 为电流器件，严禁直接用恒压源驱动而不限流。
