# MOSFET 低边栅极驱动电路

## 拓扑描述
由 **栅极驱动芯片 $U_1$**、**栅极电阻 $R_G$**、**栅源下拉电阻 $R_{GS}$（可选）**、**驱动电源 $V_{DD}$** 与 **低边 N 沟道功率 MOSFET $Q_1$（源极接地）** 组成。电路共有 4 个关键节点：**节点① 驱动输出节点**（$U_1$ 输出端与 $R_G$ 一端相连）；**节点② 栅极节点 G**（$R_G$ 另一端、$Q_1$ 栅极 G、$R_{GS}$ 上端三者相连）；**节点③ 源极节点/地 GND**（$Q_1$ 源极 S、$R_{GS}$ 下端、$U_1$ 地相连）；**节点④ 驱动电源 $V_{DD}$**（$U_1$ 电源脚）。

各元件管脚连接：**$U_1$** 输出端接节点①、电源脚接节点④$V_{DD}$、地脚接节点③源极节点/地；**$R_G$** 一端接节点①驱动输出节点、另一端接节点②栅极节点；**$R_{GS}$** 一端接节点②栅极节点、另一端接节点③地；**$Q_1$** 的 G 接节点②栅极节点、D 接功率负载/开关节点、S 接节点③源极节点（地）。

由此构成"低边驱动 + 栅极电阻 + 栅源下拉"的 N 沟道功率 MOSFET 驱动组态：$U_1$ 将 PWM 放大为大电流驱动，经 $R_G$ 对栅极电容充放电，使 $V_{GS}$ 越过/低于阈值 $V_{th}$ 控制 $Q_1$ 导通与关断，源极接地作低边开关，$R_{GS}$ 在驱动未上电时防止栅极浮空误开通。

## 工作原理
开通时驱动芯片对栅极电容充电，$V_{GS}$ 超过阈值电压 $V_{th}$ 后 MOSFET 进入线性区导通；关断时栅极放电，$V_{GS}$ 降到 $V_{th}$ 以下，沟道截止。栅极电阻限制充放电电流并优化开关波形。

## 关键计算公式

- 栅极峰值电流：
$$I_G = \frac{V_{DD}}{R_G}$$

- 栅极充电时间：
$$t_{on} \approx R_G\,C_{iss}\,\ln\left(\frac{V_{DD}}{V_{DD} - V_{GS}}\right)$$

- 栅极电荷：
$$Q_G = C_{iss}\,\Delta V_{GS}$$

- 驱动平均功耗：
$$P_{drv} = Q_G\,V_{DD}\,f_{sw}$$

- 开关时间近似：
$$t_{sw} \approx \frac{Q_G}{I_G}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_G$ | 栅极电阻 | Ω |
| $C_{iss}$ | 输入电容 | F |
| $Q_G$ | 栅极总电荷 | C |
| $V_{DD}$ | 驱动电源电压 | V |
| $V_{GS}$ | 栅源电压 | V |
| $V_{th}$ | 阈值电压 | V |
| $f_{sw}$ | 开关频率 | Hz |

## 元件调整影响
- **$R_G$ 增大** → 开关变慢、EMI 与振铃减小，但开关损耗增大。
- **$R_G$ 减小** → 开关加快、损耗降低，但振铃、过冲与 EMI 增大。
- **驱动电压过高** → 栅极氧化层击穿风险（勿超过 $V_{GS,max}$，通常 ±20 V）。
- $R_{GS}$ 下拉可在驱动未上电时防止栅极浮空引起的误开通。

## 典型参数示例
- 取 $V_{DD}=12\ \text{V}$、$R_G=10\ \Omega$：$I_G = 12/10 = 1.2\ \text{A}$（峰值）。
- 取 $Q_G=30\ \text{nC}$、$V_{DD}=12\ \text{V}$、$f_{sw}=100\ \text{kHz}$：
$$P_{drv} = 30\times10^{-9}\times12\times100\times10^{3} = 0.036\ \text{W}$$

## 常见器件型号
- 驱动芯片：TC4420、UCC27511、MIC4420、MC34152。
- N 沟道 MOSFET：IRFZ44N、IRLZ44N、Si2302、CSD18532。
- 逻辑电平 MOSFET：AO3400、IRLML2502。

## 注意事项
- 栅极走线短而宽，靠近 MOSFET，减小栅极环路寄生电感。
- 电源与地之间加去耦电容，驱动峰值电流较大需注意 PCB 杂散电感。
- 死区时间需正确设置，避免半桥上下管直通。
- 低压逻辑驱动较高阈值 MOSFET 时需电平移位或逻辑电平器件。
