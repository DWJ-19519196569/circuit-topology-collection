# 自举电路

## 拓扑描述
元件组成与节点定义：电路由**自举二极管 D**、**自举电容 C** 与**高侧驱动器供电引脚（VB/VS）** 组成，构成给悬浮高侧开关供电的浮动供电网络。电路共有 4 个关键节点：**节点① 低侧电源节点 $V_{CC}$**（连 D 阳极，与低压电源相连）；**节点② 自举上端节点 $V_B$**（连 D 阴极与 C 一端，接高侧驱动器电源脚 VB）；**节点③ 开关/浮动地节点 VS**（连 C 另一端与高侧驱动器浮动地脚 VS，即高侧 MOSFET 源极、半桥开关节点）；**节点④ 地节点**（低压电源地与下管源极）。

各元件管脚连接：D 阳极接节点①、阴极接节点②；C 一端接节点②、另一端接节点③；高侧驱动器的供电脚 VB 接节点②、浮动地脚 VS 接节点③，其输出脚接高侧 MOSFET 栅极；下管导通开关节点被拉到地，$V_{CC}$ 经 D 给 C 充电，节点② 抬高到约 $V_{CC}-V_F$ 之上。

由此构成"二极管 + 电容自举供电"的浮地电源组态，为悬浮的高侧开关提供高于源极的驱动电压：下管导通时充电，上管导通时由电容维持高侧驱动供电，实现高侧 MOSFET 可靠开通；100% 占空比或长期不开关时会失去自举能力。

## 工作原理
当下管导通、开关节点被拉到地时，VCC 经自举二极管对自举电容充电；下管关断、上管导通时，电容上的电荷维持高侧驱动供电，把栅极抬高到源极之上，实现高侧 MOSFET 的可靠开通。

## 关键计算公式

- 自举电容稳态电压：
$$V_{BS} = V_{CC} - V_F - V_{LS(on)}$$

- 自举电容最小取值：
$$C_{boot} \geq \frac{I_{Q,max}\cdot t_{on,max} + Q_g}{\Delta V_{BS}}$$

- 自举电容总电荷需求：
$$Q_{tot} = Q_g + Q_{LS} + I_{qbs}\cdot t_{on}$$

- 自举二极管反向电压：
$$V_{R} \geq V_{bus,max}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{BS}$ | 自举电容电压 | V |
| $V_F$ | 自举二极管正向压降 | V |
| $V_{LS(on)}$ | 下管导通压降 | V |
| $Q_g$ | 高侧栅极电荷 | C |
| $I_{qbs}$ | 高侧驱动静态电流 | A |
| $t_{on}$ | 高侧导通时间 | s |

## 元件调整影响
- **自举电容增大** → 电压跌落小、驱动稳定，但启动/恢复时间变长。
- **自举电容过小** → 高侧长导通时电压跌落，驱动不足。
- **自举二极管反向恢复慢** → 高频下损耗增大、引入噪声。
- **下管导通时间不足** → 自举电容无法充分充电，须保证足够充电时间。

## 典型参数示例
- 取 $V_{CC}=12\ \text{V}$、$V_F=0.6\ \text{V}$、$V_{LS(on)}=0.2\ \text{V}$：$V_{BS}=12-0.6-0.2=11.2\ \text{V}$。
- 取 $I_{Q,max}=1\ \text{mA}$、$t_{on,max}=50\ \mu\text{s}$、$Q_g=30\ \text{nC}$、$\Delta V_{BS}=0.5\ \text{V}$：$C_{boot}\geq\dfrac{1\times10^{-3}\times50\times10^{-6}+30\times10^{-9}}{0.5}=160\ \text{nF}$。

## 常见器件型号
- 自举二极管：UF4007、1N4148（小电流）、STTH 系列（快恢复）。
- 半桥驱动（带自举）:IR2110、IR2104、UCC27714。
- 自举电容：X7R 贴片电容（0.1~10 μF）。

## 注意事项
- 自举电容容量要按最长导通时间校核，保证电压跌落不超限。
- 自举二极管须为快恢复型，反向耐压 ≥ 母线电压。
- 100% 占空比或长期不开关时将失去自举能力，需额外充电电路或隔离电源。
- 初次上电时需先导通下管为自举电容充电。
