# 弛张振荡器

## 拓扑描述
以典型的**运放施密特触发器 + RC 积分充放电**为代表性实现，本电路由**一个运算放大器 $A_1$（构成施密特迟滞比较器）**、**正反馈电阻 $R_1$**、**接地分压电阻 $R_2$** 与**定时电阻 $R$、定时电容 $C$** 组成。电路共有 5 个关键节点：**节点① 输出节点**（$A_1$ 的输出端 OUT 与 $R_1$ 一端、$R$ 一端相连）；**节点② 同相输入节点**（$A_1$ 的同相输入 IN+ 与 $R_1$ 另一端、$R_2$ 上端相连，由分压决定迟滞门限）；**节点③ 反相（电容）节点**（$A_1$ 的反相输入 IN− 与 $R$ 另一端、$C$ 上端相连）；**节点④ 地节点 GND**（$R_2$ 下端、$C$ 下端、电源负极相连）；**节点⑤ 电源节点**（$A_1$ 的正电源脚 V+ 接 $+V_{CC}$、负电源脚 V− 接 $-V_{EE}$）。

各元件管脚连接：**$A_1$** 的 IN+ 接同相输入节点②、IN− 接反相节点③、OUT 接输出节点①、V+ 接正电源 $+V_{CC}$、V− 接负电源 $-V_{EE}$；**$R_1$** 一端接输出节点①、另一端接同相输入节点②；**$R_2$** 一端接同相输入节点②、另一端接地节点④；**$R$** 一端接输出节点①、另一端接反相节点③；**$C$** 一端接反相节点③、另一端接地节点④。

由此构成"输出经 $R$ 对 $C$ 充放电、$R_1$/$R_2$ 分压设定迟滞门限"的运放施密特弛张振荡器组态，电容在上、下门限之间反复翻转，输出近似方波（兼三角波），频率 $f=\frac{1}{4RC}\cdot\frac{R_1}{R_2}$。

## 工作原理
电容充电到上门限时开关翻转，改路放电；放至下门限时再次翻转，周而复始，形成自由振荡。迟滞特性决定两个翻转门限，充放电 RC 时间常数决定周期，产生锯齿或方波输出。

## 关键计算公式

- 施密特触发器门限（由电阻分压决定）：
$$V_{TH+} = \frac{R_2}{R_1+R_2}V_{CC},\qquad V_{TH-} = -\frac{R_2}{R_1+R_2}V_{CC}$$

- 三角波 / 方波振荡器频率：
$$f = \frac{1}{4 R C}\cdot\frac{R_1}{R_2}$$

- 一般 RC 充放电电压规律：
$$V(t) = V_{\infty} - (V_{\infty}-V_0)e^{-t/RC}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{TH+}$ / $V_{TH-}$ | 上 / 下翻转门限 | V |
| $R_1$ / $R_2$ | 迟滞分压电阻 | Ω |
| $R$ / $C$ | 定时电阻 / 电容 | Ω / F |
| $f$ | 振荡频率 | Hz |
| $V(t)$ | 电容电压 | V |

## 元件调整影响
- **$R$ 或 $C$ 增大** → 充放电变慢、频率下降。
- **迟滞比 $R_2/R_1$ 增大** → 门限范围变大、频率下降、三角波幅度增大。
- **$R_2/R_1$ 减小** → 门限变窄、频率升高。
- **电源电压 $V_{CC}$ 增大** → 输出幅度增大（门限随比例变化）。

## 典型参数示例
- 运放弛张振荡器取 $R_1=10\ \text{kΩ}$、$R_2=10\ \text{kΩ}$、$R=10\ \text{kΩ}$、$C=10\ \text{nF}$：$f=\dfrac{1}{4\times10^4\times10^{-8}}\cdot\dfrac{10}{10}=2.5\ \text{kHz}$。

## 常见器件型号
- 运放（施密特）：TL072、LM358、LM311 比较器。
- UJT：2N2646；555：NE555。

## 注意事项
- 门限由迟滞分压决定，电源波动会影响频率与幅度稳定性。
- 输出近三角波需恒流源充放电，否则指数波非线性明显。
- 频率随温度与器件容差漂移，需精确时改用晶体振荡。
