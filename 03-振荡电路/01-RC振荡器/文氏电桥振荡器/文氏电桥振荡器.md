# 文氏电桥振荡器

## 拓扑描述
本电路由**一个同相运算放大器 $A_1$** 与**文氏电桥选频网络**组成，电桥由**串联阻抗臂（$R_1$ 与 $C_1$ 串联）**与**并联阻抗臂（$R_2$ 与 $C_2$ 并联）**构成带通网络接到同相端作正反馈，另由**反馈电阻 $R_f$、接地电阻 $R_g$** 与**串入稳幅元件（灯泡/JFET）** 构成负反馈决定增益。电路共有 5 个关键节点：**节点① 输出节点**（$A_1$ 的输出端 OUT 与 $R_1$ 一端、$R_f$ 一端相连）；**节点② 串联臂中间节点**（$R_1$ 另一端与 $C_1$ 一端相连）；**节点③ 同相输入节点（电桥分压点）**（$C_1$ 另一端、$R_2$ 上端、$C_2$ 上端与 $A_1$ 的同相输入端 IN+ 相连）；**节点④ 反相输入节点**（$A_1$ 的反相输入端 IN− 与 $R_f$ 另一端、$R_g$ 上端相连）；**节点⑤ 地节点 GND**（$R_2$ 下端、$C_2$ 下端、$R_g$ 下端相连）。

各元件管脚连接：**$A_1$** 的同相输入端 IN+ 接同相输入节点③、反相输入端 IN− 接反相输入节点④、OUT 接输出节点①、正电源脚 V+ 接 $+V_{CC}$、负电源脚 V− 接 $-V_{EE}$；**$R_1$** 一端接输出节点①、另一端接串联臂中间节点②；**$C_1$** 一端接串联臂中间节点②、另一端接同相输入节点③；**$R_2$** 一端接同相输入节点③、另一端接地节点⑤；**$C_2$** 一端接同相输入节点③、另一端接地节点⑤；**$R_f$** 一端接输出节点①、另一端接反相输入节点④；**$R_g$** 一端接反相输入节点④、另一端接地节点⑤（$R_g$ 处可串入灯泡/JFET 稳幅元件）。

由此构成"文氏电桥正反馈选频、$R_f$/$R_g$ 负反馈决定增益（$A_v=1+R_f/R_g=3$）、$R_g$ 串稳幅元件自动稳幅"的文氏电桥振荡器组态，在 $f_0=1/(2\pi RC)$ 处相移为零、衰减 1/3，环路增益等于 1，输出低失真正弦波。

## 工作原理
文氏网络在谐振频率 $f_0$ 处相移为零且衰减 1/3，同相放大器增益设为 3 使环路增益等于 1，实现等幅正弦振荡。负反馈中引入正温度系数灯泡 / 二极管 / JFET 自动稳幅，把增益锁定在刚好维持振荡的水平，降低失真。

## 关键计算公式

- 振荡频率（R、C 相等时）：
$$f_0 = \frac{1}{2\pi RC}$$

- 文氏网络在 $f_0$ 处反馈系数：
$$\beta = \frac{1}{3}$$

- 起振所需同相增益：
$$A_v = 1 + \frac{R_f}{R_g} = 3$$

- 负反馈电阻关系：
$$R_f = 2 R_g$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ / $C$ | 电桥定时电阻 / 电容 | Ω / F |
| $f_0$ | 振荡频率 | Hz |
| $\beta$ | 反馈系数 | （无量纲） |
| $R_f$ / $R_g$ | 反馈 / 接地电阻 | Ω |
| $A_v$ | 同相放大增益 | （无量纲） |

## 元件调整影响
- **$R$ 或 $C$ 增大** → $f_0$ 下降。
- **$R_f/R_g$ 略大于 2** → 起振更快，但失真增大。
- **$R_f/R_g$ 小于 2** → 环路增益不足，可能不起振。
- **稳幅元件（灯泡/JFET）特性变化** → 影响振幅稳定性与失真。

## 典型参数示例
- 取 $R=10\ \text{kΩ}$、$C=10\ \text{nF}$：$f_0=\dfrac{1}{2\pi\times10^4\times10^{-8}}\approx 1.59\ \text{kHz}$。
- 为满足 $A_v=3$，取 $R_g=10\ \text{kΩ}$，则 $R_f=20\ \text{kΩ}$。

## 常见器件型号
- 运放：NE5532、TL072、OPA2134；稳幅 JFET：J113、BF245；也可用微型白炽灯稳幅。

## 注意事项
- 增益必须精确等于 3 并配合自动稳幅，否则失真大或停振。
- 双联可变电阻/电容实现频率连续可调，元件需同步匹配。
- 稳幅环节（灯丝 / JFET）的响应决定振幅建立时间与残波失真。
