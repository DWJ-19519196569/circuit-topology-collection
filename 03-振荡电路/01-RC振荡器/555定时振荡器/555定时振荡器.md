# 555 定时振荡器

## 拓扑描述
本电路由**一片 555 定时器芯片 $U_1$** 与**外接电阻 $R_1$、$R_2$** 及**定时电容 $C$** 组成无稳态（Astable）多谐振荡器。电路共有 6 个关键节点：**节点① 电源节点 $V_{CC}$**（电源正端、$R_1$ 上端、$U_1$ 的电源脚 VCC(8) 与复位脚 RESET(4) 相连）；**节点② 放电节点**（$R_1$ 下端、$R_2$ 上端与 $U_1$ 的放电脚 DIS(7) 相连）；**节点③ 阈值/触发节点**（$R_2$ 下端、$C$ 上端与 $U_1$ 的阈值脚 THRES(6)、触发脚 TRIG(2) 相连）；**节点④ 输出节点**（$U_1$ 的输出脚 OUT(3)，作为方波输出送往负载）；**节点⑤ 地节点 GND**（$C$ 下端、$U_1$ 的地脚 GND(1) 与电源负极相连）；**节点⑥ 控制电压节点**（$U_1$ 的控制电压脚 CV(5) 经去耦电容 $C_c$ 接地）。

各元件管脚连接：**$U_1$** 的 VCC(8) 与 RESET(4) 接电源节点①、DIS(7) 接放电节点②、THRES(6) 与 TRIG(2) 接阈值/触发节点③、OUT(3) 接输出节点④、GND(1) 接地节点⑤、CV(5) 接控制电压节点⑥（并接 $C_c$ 到地）；**$R_1$** 一端接电源节点①、另一端接放电节点②；**$R_2$** 一端接放电节点②、另一端接阈值/触发节点③；**$C$** 一端接阈值/触发节点③、另一端接地节点⑤；**$C_c$** 一端接控制电压节点⑥、另一端接地节点⑤。

由此构成"$C$ 经 $R_1$+$R_2$ 充电至 $2V_{CC}/3$、再经 $R_2$ 放电至 $V_{CC}/3$"的 555 无稳态多谐振荡器组态，在输出端产生方波，频率 $f=1.44/((R_1+2R_2)C)$，高电平时间 $t_H=0.693(R_1+R_2)C$ 长于低电平时间 $t_L=0.693R_2C$。

## 工作原理
上电后 $C$ 经 $R_1+R_2$ 充电，电压升至 $2V_{CC}/3$ 时内部比较器翻转、放电管导通，$C$ 经 $R_2$ 放电至 $V_{CC}/3$ 时再次翻转，如此循环在输出端产生方波。充电时间常数比放电大，故高电平长于低电平。

## 关键计算公式

- 高电平时间：
$$t_H = 0.693 (R_1 + R_2) C$$

- 低电平时间：
$$t_L = 0.693 R_2 C$$

- 振荡周期与频率：
$$T = t_H + t_L = 0.693 (R_1 + 2R_2) C$$

$$f = \frac{1}{T} = \frac{1.44}{(R_1 + 2R_2) C}$$

- 占空比：
$$D = \frac{t_H}{T} = \frac{R_1 + R_2}{R_1 + 2R_2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_1$ / $R_2$ | 充电 / 放电电阻 | Ω |
| $C$ | 定时电容 | F |
| $t_H$ / $t_L$ | 高 / 低电平时间 | s |
| $T$ / $f$ | 周期 / 频率 | s / Hz |
| $D$ | 占空比 | （无量纲） |

## 元件调整影响
- **$R_1$ 或 $R_2$ 增大** → 频率下降。
- **$C$ 增大** → 频率下降，周期成比例增大。
- **$R_1$ 相对 $R_2$ 增大** → 占空比上升（高电平占比增大）。
- **$R_1$ 减小（占空比趋近 50%）** → 波形趋于对称方波。

## 典型参数示例
- 取 $R_1=1\ \text{kΩ}$、$R_2=10\ \text{kΩ}$、$C=1\ \mu\text{F}$：$f=\dfrac{1.44}{(1000+20000)\times10^{-6}}\approx 68.6\ \text{Hz}$。
- 占空比 $D=\dfrac{1000+10000}{1000+20000}\approx 52.4\%$。

## 常见器件型号
- 555 芯片：NE555、LM555、TLC555 / LMC555（CMOS，低功耗）、ICM7555。
- 电容：C0G/NP0 或聚酯电容（定时稳定）。

## 注意事项
- 定时电容宜选温度稳定性好的 C0G / 聚酯，避免电解电容 ESR 与漏电影响定时。
- 占空比无法低于 50% 的标准接法，需 < 50% 时可加二极管旁路充电路径。
- CMOS 555 静态功耗低、频率上限较高，适合高阻定时网络。
