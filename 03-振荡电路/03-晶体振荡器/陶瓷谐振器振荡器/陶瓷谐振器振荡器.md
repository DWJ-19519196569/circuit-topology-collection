# 陶瓷谐振器振荡器

## 拓扑描述
陶瓷谐振器振荡器由压电陶瓷谐振器 $X_1$（两端镀电极、内建负载电容）、反相放大器 $U_1$（CMOS 反相器或晶体管）、负载电容 $C_1$、$C_2$ 及反馈电阻 $R_f$ 组成。节点定义如下：反相器输入节点 $N_{in}$ 接陶瓷片一端与 $C_1$、$R_f$；反相器输出节点 $N_{out}$ 接陶瓷片另一端与 $C_2$、$R_f$；谐振器第一端节点 $N_{x1}$ 接 $N_{in}$、第二端节点 $N_{x2}$ 接 $N_{out}$；地节点 GND 汇集 $C_1$、$C_2$ 接地端与 $U_1$ 电源地。

各元件管脚连接：反相放大器 $U_1$ 的 IN 接 $N_{in}$、OUT 接 $N_{out}$、VDD/VSS 接电源与地；陶瓷谐振器 $X_1$ 两引脚一端接 $N_{x1}$（即 $N_{in}$）、另一端接 $N_{x2}$（即 $N_{out}$）；负载电容 $C_1$ 一端接 $N_{in}$、另一端接 GND；负载电容 $C_2$ 一端接 $N_{out}$、另一端接 GND；反馈电阻 $R_f$ 一端接 $N_{in}$、另一端接 $N_{out}$，为反相器提供直流偏置。

该电路为与皮尔斯振荡器同构的陶瓷谐振器振荡器，陶瓷片替代石英晶体，$C_1$/$C_2$ 构成负载电容，Q 值低于石英故稳定度较低，常用于低成本时钟。

## 工作原理
陶瓷谐振器在谐振频率附近呈现类似晶体的电抗特性，与负载电容构成选频网络，配合反相放大的正反馈维持振荡。其等效电感因陶瓷材料 Q 值低于石英而产生振荡，频率稳定度约 $10^{-3}\sim10^{-4}$ 量级，低于石英晶振。

## 关键计算公式

- 负载电容：
$$C_L = \frac{C_1 C_2}{C_1 + C_2} + C_s$$

- 并联谐振频率：
$$f_p = f_s\sqrt{1 + \frac{C_m}{C_0 + C_L}}$$

- 频率容差（稳定度范围）：
$$\frac{\Delta f}{f_0} \approx 10^{-3} \sim 10^{-4}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_1, C_2$ | 负载电容 | F |
| $C_L$ | 总负载电容 | F |
| $C_s$ | 杂散电容 | F |
| $C_0$ | 谐振器静电容 | F |
| $C_m$ | 谐振器动态电容 | F |
| $f_s$ | 串联谐振频率 | Hz |
| $f_p$ | 并联谐振频率 | Hz |
| $f_0$ | 标称频率 | Hz |

## 元件调整影响
- **$C_1$、$C_2$ 增大** → $C_L$ 增大、频率被拉低，起振更稳但偏慢。
- **$C_1$、$C_2$ 减小** → $C_L$ 减小、频率升高，起振裕度下降。
- **选用内置负载电容的谐振器** → 可省略外接电容，简化电路。
- **温度升高** → 频率温度系数（$10^{-5}\sim10^{-4}$/℃）明显大于晶振，漂移更大。

## 典型参数示例
- 取 $C_0 = 15\ \text{pF}$、$C_m = 0.5\ \text{pF}$、$C_L = 30\ \text{pF}$：并联谐振 $f_p = f_s\sqrt{1 + 0.5/(15+30)} \approx f_s(1 + 5.5\times10^{-3})$，即比 $f_s$ 高约 0.55 %。
- 标称 $f_0 = 4\ \text{MHz}$、稳定度 $3\times10^{-4}$：频率偏差约 $\Delta f = 4\times10^6 \times 3\times10^{-4} = 1.2\ \text{kHz}$。

## 常见器件型号
- 谐振器：CSTCE、ZTT 系列（Murata）陶瓷谐振器。
- 反相器：74HCU04、74HC1GU04。
- 常用：按需选型（低成本 MCU 时基、IR 遥控载波）。

## 注意事项
- 频率稳定度和精度低于石英晶振，不适合高精度时基。
- 内置负载电容的谐振器无需外接电容，但需核对器件规格。
- 陶瓷材料压电耦合强，机械应力与焊接热可能引起频率偏移。
