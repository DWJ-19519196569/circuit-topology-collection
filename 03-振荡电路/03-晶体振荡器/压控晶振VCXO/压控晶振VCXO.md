# 压控晶振 VCXO

## 拓扑描述
压控晶振由石英晶体 $X_1$、振荡放大器 $A_1$、变容二极管 $D_1$、耦合电容 $C_c$、隔离/回路电阻 $R_v$ 及负载电容组成。节点定义如下：振荡输入节点 $N_{in}$ 与振荡输出节点 $N_{out}$ 为 $A_1$ 的两端，晶体跨接其间；晶体负载节点 $N_x$ 为晶体一端与变容管/耦合电容的连接点；控制电压节点 $N_{ctrl}$ 为输入控制电压 $V_c$ 经 $R_v$ 的引入点；地节点 GND 汇集变容管阳极/冷端与回路电容的接地端。

各元件管脚连接：晶体 $X_1$ 的两引脚一端接 $N_{in}$、另一端接 $N_x$；振荡放大器 $A_1$ 的 IN 接 $N_{in}$、OUT 接 $N_{out}$、V+/V− 接电源；变容二极管 $D_1$ 的阴极接 $N_x$（或经耦合电容到晶体端）、阳极接 GND；耦合电容 $C_c$ 一端接 $N_x$、另一端接 $D_1$ 阴极（或直接串入支路）；隔离电阻 $R_v$ 一端接 $N_{ctrl}$、另一端接 $D_1$ 阴极，把 $V_c$ 反偏加到变容管上改变结电容。

该电路为晶体振荡器加变容二极管负载牵引结构，控制电压 $V_c$ 改变 $D_1$ 结电容从而微调晶体谐振频率，实现电压控制的频率牵引。

## 工作原理
变容管结电容随反偏电压增大而减小，该电容与晶体共同决定振荡频率（负载电容牵引效应）。调节控制电压即可在晶体串联/并联谐振之间小范围内连续改变输出频率，实现压控牵引。

## 关键计算公式

- 结电容—偏压关系（突变结近似）：
$$C_j = \frac{C_{j0}}{\left(1 + \dfrac{V_R}{V_{bi}}\right)^{m}}$$

- 牵引频率范围（近似）：
$$\frac{\Delta f}{f_0} \approx \frac{C_m}{2(C_0 + C_L)}\cdot\frac{\Delta C_L}{C_L}$$

> 近似前提：该式适用于小 $\Delta C_L$（负载电容变化远小于 $C_0+C_L$）、忽略晶体静电容 $C_0$ 随负载的变化、忽略晶体与回路寄生参数的一阶近似。大范围牵引或 $\Delta C_L$ 较大时需用完整表达式并按实际电路校正。

- 压控灵敏度（牵引率）：
$$K_v = \frac{\Delta f}{\Delta V_c}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_j$ | 变容管结电容 | F |
| $C_{j0}$ | 零偏结电容 | F |
| $V_R$ | 反向偏压 | V |
| $V_{bi}$ | 内建电位 | V |
| $m$ | 结电容梯度因子 | 无量纲 |
| $C_m$ | 晶体动态电容 | F |
| $C_0$ | 晶体静电容 | F |
| $C_L$ | 负载电容 | F |
| $\Delta C_L$ | 负载电容变化 | F |
| $f_0$ | 标称频率 | Hz |
| $\Delta f$ | 频率偏移 | Hz |
| $V_c$ | 控制电压 | V |
| $K_v$ | 压控灵敏度 | Hz/V |

## 元件调整影响
- **控制电压 $V_c$ 增大** → 结电容减小，牵引频率升高（或依接法相反）。
- **变容管电容变化比 ($C_{max}/C_{min}$) 增大** → 压控牵引范围变宽。
- **串联耦合电容减小** → 限制了变容管对回路的耦合，牵引范围收窄。
- **晶体 Q 值、负载电容 $C_L$ 增大** → 牵引灵敏度下降，可调范围变窄但频率更稳。

## 典型参数示例
- 取 $C_m = 10\ \text{fF}$、$C_L = 20\ \text{pF}$、$\Delta C_L = 2\ \text{pF}$：$\Delta f/f_0 \approx 10\times10^{-15}/(2\times20\times10^{-12})\times(2/20) \approx 2.5\times10^{-5}$，即约 25 ppm。
- 牵引率 $K_v = 5\ \text{ppm/V}$、$f_0=20\ \text{MHz}$：每伏电压改变频率 $\Delta f = 20\times10^6\times5\times10^{-6}=100\ \text{Hz}$。

## 常见器件型号
- 变容二极管：BB910、BB131、1SV264。
- 熟称 VCXO，常见频率 12.8 / 19.44 / 155.52 MHz。
- 常用：按需选型（PLL、电信网同步）。

## 注意事项
- 牵引范围通常仅百 ppm 级，不能用于大幅调谐。
- 控制电压纹波会直接转化为频率抖动（相位噪声），需滤除。
- 变容管非线性会在大牵引时引入失真，PLL 应用需关注线性度。
