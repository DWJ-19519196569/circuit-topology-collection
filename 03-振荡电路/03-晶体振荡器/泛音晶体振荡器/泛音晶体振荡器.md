# 泛音晶体振荡器

## 拓扑描述
泛音晶体振荡器由石英晶体 $X_1$（工作于奇次泛音）、放大管 $Q_1$（BJT/FET/门电路）及 LC 调谐网络的电感 $L$、电容 $C_t$ 组成。节点定义如下：集电极/输出节点 $N_C$ 接调谐网络与反馈；基极/输入节点 $N_B$ 接晶体反馈端；发射极/源极节点 $N_E$ 接交流地；调谐节点 $N_{tank}$ 为 $L$、$C_t$ 谐振回路的公共端；电源节点 $V_{CC}$ 为回路供电端；地节点 GND 汇集电容冷端与发射极回路。

各元件管脚连接：$Q_1$ 的 B 接 $N_B$，C 接 $N_C$，E 接 $N_E$（FET 对应 G/D/S）；晶体 $X_1$ 两引脚一端接 $N_B$、另一端接 $N_C$（跨接在输入输出之间）；调谐电感 $L$ 一端接 $N_C$、另一端接 $V_{CC}$（或经射频扼流圈）；调谐电容 $C_t$ 一端接 $N_C$、另一端接 GND，与 $L$ 构成谐振在目标泛音 $f_{tank}=1/(2\pi\sqrt{LC_t})$ 的选频回路。

该电路为晶体工作于奇次泛音的三点式/皮尔斯类振荡器，LC 网络调谐于目标泛音以抑制基频与其他泛音，使晶体在选定泛音上稳定振荡。

## 工作原理
晶体的机电谐振除基频外还存在于奇次泛音（约 3、5、7…倍基频，略低于整数倍）。LC 调谐网络调谐在目标泛音附近，只让该泛音频率满足正反馈相位与增益条件，抑制基频与其他泛音，使晶体在选定泛音上持续振荡，得到比基频高数倍的稳定频率。

## 关键计算公式

- 泛音频率（近似，略低于整数倍）：
$$f_n \approx n f_1 \quad (n=3,5,7,\dots)$$

- 调谐回路谐振频率（选频于目标泛音）：
$$f_{tank} = \frac{1}{2\pi\sqrt{LC}}$$

- 晶体串联谐振频率：
$$f_s = \frac{1}{2\pi\sqrt{L_1 C_1}}$$

- 并联谐振频率：
$$f_p = f_s\left(1 + \frac{C_1}{2C_0}\right)$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_1$ | 晶体基频 | Hz |
| $f_n$ | 第 n 次泛音频率 | Hz |
| $n$ | 泛音次数（3,5,7…） | （无量纲） |
| $L_1$ / $C_1$ | 晶体动态电感 / 电容 | H / F |
| $C_0$ | 晶体静态电容 | F |
| $f_{tank}$ | 调谐回路谐振频率 | Hz |

## 元件调整影响
- **调谐回路 $L$、$C$ 调偏** → 选频错误，可能锁定到基频或错误泛音。
- **回路 $Q$ 不足** → 基频抑制不够，易错振在基频。
- **晶体泛音次数 $n$ 增大** → 频率升高，但起振更难、需更高 Q 选频。
- **负载电容变化** → 并联谐振频率微调，影响实际振荡频率。

## 典型参数示例
- 基频 $f_1=20\ \text{MHz}$ 的晶体工作于 3 次泛音：$f_3\approx60\ \text{MHz}$（实际略低于 60 MHz）。
- 取 $L=0.5\ \mu\text{H}$、$C=10\ \text{pF}$ 选频：$f_{tank}=\dfrac{1}{2\pi\sqrt{0.5\times10^{-6}\times10\times10^{-11}}}\approx 71\ \text{MHz}$（需按目标泛音调）。

## 常见器件型号
- 泛音晶体：标准 3 次 / 5 次泛音晶振（如 30~150 MHz 范围）；放大管：2SC1674、BFR93A、J310。

## 注意事项
- 必须有高 Q 选频回路抑制基频，否则晶体优先在基频起振。
- 泛音频率并非基频整数倍（略低），标称值以晶体规格为准。
- 泛音晶振负载电容、驱动电平需匹配，过驱动会损坏晶体或激励错误模式。
