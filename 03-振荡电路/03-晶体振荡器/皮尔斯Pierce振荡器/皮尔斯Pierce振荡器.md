# 皮尔斯 Pierce 振荡器

## 拓扑描述
皮尔斯振荡器由石英晶体 $X_1$、反相放大器 $U_1$（CMOS 反相器或晶体管）、负载电容 $C_1$、$C_2$ 及反馈电阻 $R_f$ 组成。节点定义如下：反相器输入节点 $N_{in}$ 接晶体一端与 $C_1$、$R_f$；反相器输出节点 $N_{out}$ 接晶体另一端与 $C_2$、$R_f$；晶体第一端节点 $N_{x1}$ 接 $N_{in}$、第二端节点 $N_{x2}$ 接 $N_{out}$；地节点 GND 汇集 $C_1$、$C_2$ 的接地端与 $U_1$ 的电源地。

各元件管脚连接：反相放大器 $U_1$ 的 IN 接 $N_{in}$、OUT 接 $N_{out}$、VDD/VSS 接电源与地；晶体 $X_1$ 两引脚一端接 $N_{x1}$（即 $N_{in}$）、另一端接 $N_{x2}$（即 $N_{out}$）；负载电容 $C_1$ 一端接 $N_{in}$、另一端接 GND；负载电容 $C_2$ 一端接 $N_{out}$、另一端接 GND；反馈电阻 $R_f$ 一端接 $N_{in}$、另一端接 $N_{out}$，为反相器提供直流偏置使其工作在线性放大区。

该电路为反相器加晶体的并联谐振振荡器，$R_f$ 提供直流自偏置、$C_1$/$C_2$ 构成负载电容 $C_L$，是数字系统最常用的晶振拓扑。

## 工作原理
反相器提供 180° 相移，晶体与两个负载电容在谐振附近再提供约 180° 相移，二者相加满足正反馈相位条件；$R_f$ 提供直流偏置使门电路工作在线性区，晶体的选频特性使其仅在谐振频率处维持振荡。

## 关键计算公式

- 负载电容（晶体看到的总负载）：
$$C_L = \frac{C_1 C_2}{C_1 + C_2} + C_s$$

- 振荡频率（并联谐振，含牵引）：
$$f_{osc} = f_s\sqrt{1 + \frac{C_m}{C_0 + C_L}}$$

- 反馈电阻典型经验值：
$$R_f \approx 1\ \text{MΩ}\ \text{（数百 kΩ ~ 数 MΩ）}$$

- 增益裕度（起振条件经验式，适用于 CMOS）：
$$g_m \gg \omega^2 R_s (C_0 + C_L)^2$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_1, C_2$ | 负载电容 | F |
| $C_L$ | 总负载电容 | F |
| $C_s$ | 杂散/引脚电容 | F |
| $C_0$ | 晶体静电容 | F |
| $C_m$ | 晶体动态串联电容 | F |
| $f_s$ | 串联谐振频率 | Hz |
| $f_{osc}$ | 实际振荡频率 | Hz |
| $g_m$ | 反相器等效跨导 | S |
| $R_s$ | 晶体等效串联电阻 | Ω |
| $R_f$ | 反馈偏置电阻 | Ω |

## 元件调整影响
- **$C_1$、$C_2$ 增大** → $C_L$ 增大、频率被拉低，起振变慢但更稳。
- **$C_1$、$C_2$ 减小** → $C_L$ 减小、频率升高，但容易因增益裕度不足而停振。
- **$R_f$ 过大** → 偏置时间常数太大，启动慢；**过小** → 降低等效增益，可能不起振。
- **负载电容偏离晶体标称 $C_L$** → 频率偏离标称值，需按晶体规格匹配。

## 典型参数示例
- 取常见 MCU 外围：$C_1 = C_2 = 22\ \text{pF}$，忽略杂散：$C_L = 11\ \text{pF}$（匹配标称 $C_L=8\sim12\ \text{pF}$ 的晶振）。
- 取 $R_f = 1\ \text{MΩ}$、晶体 16 MHz 典型负载 $C_L=12\ \text{pF}$，可稳定起振于 16 MHz 附近。

## 常见器件型号
- 反相器：74HC1GU04、74HCU04，或 MCU 内置振荡输入级。
- 晶振：16 MHz、25 MHz SMD 3225 / HC-49S 无源晶振。
- 常用：按 CPU 时钟规格选型。

## 注意事项
- 负载电容必须匹配晶体标称 $C_L$，否则频率偏移、甚至不起振。
- CMOS 反相器需用无缓冲（U 系列）器件才能可靠放大；有缓冲品可能直接饱和。
- 反馈电阻用于保证偏置，取值过大启动慢、过小损耗增益，需权衡。
