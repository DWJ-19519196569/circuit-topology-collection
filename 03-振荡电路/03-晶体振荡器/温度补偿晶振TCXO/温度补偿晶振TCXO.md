# 温度补偿晶振 TCXO

## 拓扑描述
温度补偿晶振由石英晶体 $X_1$、振荡放大器 $A_1$、温度传感器 $S_t$、补偿网络 $A_2$（模拟或数字查表）及变容二极管 $D_1$ 组成。节点定义如下：振荡输入节点 $N_{in}$ 与输出节点 $N_{out}$ 为 $A_1$ 两端，晶体跨接其间；晶体负载节点 $N_x$ 为晶体一端与变容管的连接点；温度传感输出节点 $N_{sen}$ 为 $S_t$ 输出；补偿电压节点 $N_{comp}$ 为 $A_2$ 输出、驱动变容管；控制/牵引节点 $N_{cvar}$ 为 $D_1$ 阴极接入点；地节点 GND 汇集变容管阳极与回路接地端。

各元件管脚连接：晶体 $X_1$ 两引脚一端接 $N_{in}$、另一端接 $N_x$；振荡放大器 $A_1$ 的 IN 接 $N_{in}$、OUT 接 $N_{out}$、V+/V− 接电源；温度传感器 $S_t$ 感温端位于晶体附近、输出端接 $N_{sen}$；补偿网络 $A_2$ 的 IN 接 $N_{sen}$、OUT 接 $N_{comp}$；变容二极管 $D_1$ 的阴极接 $N_{cvar}$（经耦合电容/隔离电阻接入回路，与 $N_x$ 相连）、阳极接 GND，用 $N_{comp}$ 的反偏电压改变结电容，抵消晶体的频率—温度漂移。

该电路为晶体振荡器加温度传感与压控补偿闭环，$S_t$ 测温度、$A_2$ 生成补偿电压驱动 $D_1$ 微调负载电容，实现宽温区频率补偿。

## 工作原理
晶体的 $f-T$ 曲线近似二次抛物线，TCXO 用温度传感器得到温度量，通过补偿电路改变变容二极管电容，使振荡频率随温度的变化被反向抵消，最终在全温度范围内获得较平坦的频率—温度特性。

## 关键计算公式

- 频率—温度近似（晶体 AT 切三次曲线）：
$$\frac{\Delta f}{f_0} = a(T-T_0) + b(T-T_0)^2 + c(T-T_0)^3$$

- 变容管牵引灵敏度：
$$\frac{\Delta f}{f_0} \approx \frac{C_m}{2(C_0 + C_L)^2}\Delta C_L$$

- 压控牵引率（用于补偿量核算）：
$$\text{牵引率} = \frac{\Delta f / f_0}{\Delta V_c}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_0$ | 标称频率 | Hz |
| $\Delta f$ | 频率偏移 | Hz |
| $T$ | 温度 | K（或 ℃） |
| $T_0$ | 参考温度 | K（或 ℃） |
| $a,b,c$ | 温度系数 | 无量纲（或 1/K 幂次） |
| $C_m$ | 晶体动态电容 | F |
| $C_0$ | 晶体静电容 | F |
| $C_L$ | 负载电容 | F |
| $\Delta C_L$ | 补偿导致的电容变化 | F |
| $V_c$ | 补偿控制电压 | V |

## 元件调整影响
- **变容管电容变化范围增大** → 可补偿更大的频率偏差，但相位噪声可能变差。
- **补偿曲线与晶体 $f-T$ 曲线失配** → 温度补偿不足或过补偿，稳定度下降。
- **温度传感器精度提高** → 补偿更准，全温度频率平坦度更好。
- **数字查表（DTCXO）替代模拟补偿** → 可拟合高阶曲线，温度稳定度进一步提升。

## 典型参数示例
- 标称 $f_0 = 26\ \text{MHz}$、温度稳定度 $\pm0.5\ \text{ppm}$（$-30\sim+85\ \text{℃}$）：最大频率偏差 $\Delta f = 26\times10^6 \times 0.5\times10^{-6} = 13\ \text{Hz}$。
- 未补偿晶体温度系数约 $1\ \text{ppm/℃}$，全温 $115\ \text{℃}$ 变化将漂移 115 ppm，而 TCXO 将其压缩到约 0.5 ppm。

## 常见器件型号
- 熟称：TCXO、DTCXO（数字温补），常见频率 19.2 / 26 / 38.4 MHz。
- 常用：按需选型（GNSS、手机、无线模块内置 TCXO）。

## 注意事项
- 精度介于普通晶振与 OCXO 之间，功耗远低于 OCXO。
- 补偿需针对具体晶体批次标定，更换晶体后需重新校准。
- 快速温度突变时补偿存在热滞后，可能瞬时超差。
