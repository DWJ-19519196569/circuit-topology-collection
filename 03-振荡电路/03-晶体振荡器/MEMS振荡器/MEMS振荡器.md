# MEMS 振荡器

## 拓扑描述
MEMS 振荡器由 MEMS 谐振器 $X_1$（硅微机械谐振结构）、驱动放大器 $A_1$（跨阻/维持放大器）、检测电路 $A_2$、移相网络及输出整形分频级组成。节点定义如下：驱动节点 $N_{drv}$ 为 $A_1$ 输出、激励谐振器的激励端；检测节点 $N_{sen}$ 为谐振器振动输出/检测端，进入 $A_2$；反馈节点 $N_{fb}$ 为经过移相网络后的反馈信号回到 $A_1$ 输入端；输出节点 $N_{out}$ 为整形/分频后的方波时钟输出；电源节点 $V_{DD}$ 与地节点 GND 为各放大级供电基准。

各元件管脚连接：MEMS 谐振器 $X_1$ 的激励端接 $N_{drv}$、检测端接 $N_{sen}$；驱动放大器 $A_1$ 的 IN+ 接 $N_{fb}$、OUT 接 $N_{drv}$、V+/V− 接 $V_{DD}$/GND；检测电路 $A_2$ 的 IN 接 $N_{sen}$、OUT 经移相网络接到 $N_{fb}$；反馈环路从 $N_{sen}$ 经移相与限幅再回到 $A_1$ 输入构成正反馈；输出整形/分频级的输入接 $N_{sen}$ 或 $N_{fb}$，输出接 $N_{out}$。

该电路为闭环维持放大器驱动的 MEMS 机械谐振振荡，谐振器高 Q 选频、移相网络保证相位条件，整形分频后输出方波时钟。

## 工作原理
驱动电路激励 MEMS 谐振器在其机械谐振频率处振动，检测电路把振动转换为电信号并经移相放大维持正反馈，形成稳定振荡；后续分频 / 抖动整形网络把基准频率分频或倍频到所需时钟输出。谐振器高 Q 特性保证频率稳定。

## 关键计算公式

- 谐振器机械谐振频率（近似）：
$$f_0 = \frac{1}{2\pi}\sqrt{\frac{k_{eff}}{m_{eff}}}$$

- 品质因数：
$$Q = \frac{f_0}{\Delta f}$$

- 频率牵引（受负载 / 电压影响）：
$$f_{shift} = f_0 \cdot K_{pull}$$

- 输出分频关系：
$$f_{out} = \frac{f_0}{N}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $k_{eff}$ | 等效刚度 | N/m |
| $m_{eff}$ | 等效质量 | kg |
| $f_0$ | 谐振频率 | Hz |
| $\Delta f$ | 谐振峰 -3 dB 带宽 | Hz |
| $Q$ | 品质因数 | （无量纲） |
| $N$ | 分频比 | （无量纲） |

## 元件调整影响
- **谐振器尺寸 / 刚度变化** → 谐振频率改变（由工艺与材料决定，不可外部调）。
- **驱动增益增大** → 起振更可靠，但可能激励非线性振动。
- **直流偏置电压改变** → 静电力导致频率牵引，影响输出频率。
- **分频比 $N$ 改变** → 输出频率成反比改变（可编程）。

## 典型参数示例
- 取谐振器 $f_0=125\ \text{MHz}$、$Q=10000$：$\Delta f=\dfrac{125\times10^6}{10^4}=12.5\ \text{kHz}$。
- 经 $N=5$ 分频输出 $f_{out}=25\ \text{MHz}$。

## 常见器件型号
- 集成 MEMS 振荡器：SiTime SiT8008、SiT15xx 系列、Discera DSC（现 Micrel/Microchip）系列。

## 注意事项
- MEMS 振荡器相位抖动 / 相位噪声与石英晶体不同，选型需核对抖动与频率稳定度规格。
- 输出频率可编程且抗冲击优于石英，但长期老化与温漂指标需查具体型号。
- 高要求模拟 / 射频时钟时需评估其相位噪声是否满足指标。
