# 科皮兹晶体振荡器

## 拓扑描述
科皮兹晶体振荡器由晶体管 $Q_1$（或运放 $A_1$）、石英晶体 $X_1$ 及电容 $C_1$、$C_2$ 组成。节点定义如下：基极（或运放同相输入）节点 $N_B$ 接晶体一端与反馈支路；集电极（或运放输出）节点 $N_C$ 接晶体另一端与 $C_1$ 上端；发射极节点 $N_E$ 接 $C_2$ 与反馈的交流地；电容分压中点节点 $N_{mid}$ 为 $C_1$、$C_2$ 串联点，回馈到发射极（或运放反相端）；电源节点 $V_{CC}$ 为回路供电端；地节点 GND 汇集电容冷端与发射极回路。

各元件管脚连接：$Q_1$ 的 B 接 $N_B$、C 接 $N_C$、E 接 $N_E$（运放时 IN+ 接 $N_B$、OUT 接 $N_C$、IN− 接 $N_E$）；晶体 $X_1$ 两引脚一端接 $N_B$、另一端接 $N_C$；电容 $C_1$ 一端接 $N_C$、另一端接 $N_{mid}$；电容 $C_2$ 一端接 $N_{mid}$、另一端接 $N_E$；反馈从 $N_{mid}$（$C_1$、$C_2$ 分压点）回馈到 $N_E$ 构成正反馈，晶体在串联与并联谐振间呈感性，与 $C_1$、$C_2$ 决定振荡频率。

该电路为 Colpitts 拓扑的晶体实现，晶体作感性元件与 $C_1$、$C_2$ 电容三点式谐振，负载电容 $C_L=C_1C_2/(C_1+C_2)$，产生高稳定正弦振荡。

## 工作原理
晶体在串联谐振与并联谐振之间呈现电感性，与 $C_1$、$C_2$ 一起构成谐振回路并移相，配合放大级的正反馈满足相位与幅度条件，电路在此晶体等效电感与负载电容决定的频率上起振。

## 关键计算公式

- 负载电容：
$$C_L = \frac{C_1 C_2}{C_1 + C_2} + C_s$$

- 振荡频率（含负载电容牵引）：
$$f = f_s\left(1 + \frac{C_1}{2(C_L + C_0)}\right)$$

- 纯并联谐振频率：
$$f_p = f_s\sqrt{1 + \frac{C_1}{C_0}}$$

- 起振条件（环路增益）：
$$g_m > \omega^2 C_1 C_2 \, R_s$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_1, C_2$ | 分压电容 | F |
| $C_L$ | 负载电容 | F |
| $C_s$ | 杂散电容 | F |
| $C_0$ | 晶体静电容 | F |
| $C_1$（晶体） | 晶体动态（串联）电容 | F |
| $f_s$ | 晶体串联谐振频率 | Hz |
| $f_p$ | 并联谐振频率 | Hz |
| $g_m$ | 跨导 | S |
| $R_s$ | 晶体等效串联电阻 | Ω |

## 元件调整影响
- **$C_1$、$C_2$ 增大** → 负载电容 $C_L$ 增大，振荡频率被牵引偏低。
- **$C_1$、$C_2$ 减小** → $C_L$ 减小，频率升高，但起振裕度下降。
- **$g_m$（偏置电流）减小** → 环路增益下降，可能停振或难起振。
- **负载电容偏离晶体标称 $C_L$** → 频率偏离标称值，需按晶体规格匹配。

## 典型参数示例
- 取晶体 $C_0 = 7\ \text{pF}$、动态电容 $C_1 = 10\ \text{fF}$、$C_L = 20\ \text{pF}$：由牵引公式 $f \approx f_s(1 + 10\times10^{-15}/(2\times27\times10^{-12})) \approx f_s(1 + 1.85\times10^{-4})$，即比 $f_s$ 高约 185 ppm。
- 取 $C_1 = C_2 = 30\ \text{pF}$、忽略杂散：$C_L \approx 15\ \text{pF}$。

## 常见器件型号
- 晶振：HC-49S、SMD 3225 无源晶振。
- 晶体管：2N3904、BC547；运放可用单门反相器 74HC1GU04（皮尔斯变体）。
- 常用：按需选型。

## 注意事项
- 负载电容必须匹配晶体标称 $C_L$，否则频率明显偏移。
- 无源晶体需要外加放大级提供增益，驱动能力有限，适合逻辑与基准时基。
- PCB 走线与寄生电容（$C_s$）会影响实际频率，布局需紧凑。
