# 调谐振荡器

## 拓扑描述
调谐振荡器由放大管 $Q_1$（BJT 或 FET）、可调电感 $L$（或固定电感加可变电容 $C_{var}$）、调谐电容 $C_t$ 及反馈分压/抽头元件组成。节点定义如下：集电极/漏极节点 $N_C$ 接谐振回路一端；基极/栅极节点 $N_B$ 接反馈端；发射极/源极节点 $N_E$ 接交流地；谐振节点 $N_{tank}$ 为并联 LC 回路的公共端；调谐节点 $N_{tune}$ 为可变电容/抽头引出的反馈点；电源节点 $V_{CC}$ 为回路供电端；地节点 GND 汇集电容冷端与发射极回路。

各元件管脚连接：$Q_1$ 的 B 接 $N_B$，C 接 $N_C$，E 接 $N_E$（FET 对应 G/D/S）；调谐电感 $L$（或抽头电感）一端接 $N_C$、另一端接 $N_E$，抽头或经电容分压引出反馈到 $N_B$；可变电容 $C_{var}$ 一端接 $N_C$、另一端接 $N_E$ 与 $L$ 并联构成可调谐振回路；反馈支路从电感抽头 $N_{tune}$ 或电容分压点经耦合电容接 $N_B$，构成正反馈。

该电路为可变频率 LC 振荡器（VFO），通过改变 $C_{var}$ 或 $L$ 连续调谐输出频率，$f_0=1/(2\pi\sqrt{LC})$，反馈取自抽头/分压点满足相位条件。

## 工作原理
LC 回路在谐振频率处阻抗最大且相移为零，配合适当的反馈接法形成正反馈，环路增益在该频率满足起振条件而其他频率被抑制，从而输出正弦波；改变回路电容或电感即可连续调谐输出频率。

## 关键计算公式

- 振荡（谐振）频率：
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 可变电容调谐频率比：
$$\frac{f_{max}}{f_{min}} = \sqrt{\frac{C_{max} + C_{stray}}{C_{min} + C_{stray}}}$$

- 谐振回路品质因数：
$$Q = \frac{R_p}{\omega_0 L} = \omega_0 R_p C$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L$ / $C$ | 谐振电感 / 电容 | H / F |
| $f_0$ | 振荡频率 | Hz |
| $C_{max}$ / $C_{min}$ | 可调电容最大 / 最小值 | F |
| $C_{stray}$ | 寄生电容 | F |
| $R_p$ | 回路等效并联电阻 | Ω |
| $Q$ | 品质因数 | （无量纲） |

## 元件调整影响
- **$L$ 或 $C$ 增大** → $f_0$ 下降。
- **调谐电容范围增大** → 频率覆盖范围增宽。
- **$Q$ 增大** → 频谱更纯、频率稳定度与相位噪声更好。
- **寄生电容影响增大** → 频率覆盖比受压缩、调谐非线性。

## 典型参数示例
- 取 $L=10\ \mu\text{H}$、$C=10\sim100\ \text{pF}$：$f_{min}=\dfrac{1}{2\pi\sqrt{10^{-5}\times100\times10^{-12}}}\approx 5.03\ \text{MHz}$，$f_{max}\approx 15.9\ \text{MHz}$，覆盖比约 3.16。
- 若 $C_{stray}=5\ \text{pF}$，覆盖比变为 $\sqrt{\dfrac{100+5}{10+5}}\approx 2.65$。

## 常见器件型号
- 晶体管：2SC1674、2N3904、J310（FET）；可变电容：MV104（变容二极管）、空气可变电容。

## 注意事项
- 调谐范围与寄生电容直接相关，布局要减小杂散电容与引线电感。
- 变容二极管调谐需控制偏压范围，避免非线性与相位噪声恶化。
- 机械可变电容易受振动微扰，精密场合采用锁相环锁定。
