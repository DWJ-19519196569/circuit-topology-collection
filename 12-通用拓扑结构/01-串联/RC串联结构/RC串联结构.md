# RC 串联结构

## 拓扑描述
由 **一个电阻 $R$** 与 **一个电容 $C$** 串联构成的两端网络，无任何分支与分路。电路共有 3 个关键节点：**节点① 输入节点**（信号源 $V_{in}$ 的正端与 $R$ 的一端相连）；**节点② 中间节点**（$R$ 的另一端与 $C$ 的一端相连，是分压/滤波的抽头点）；**节点③ 输出节点**（$C$ 的另一端与信号源的负端/地相连，作为参考端）。

各元件管脚连接：**$R$** 一端接输入节点、另一端接中间节点；**$C$** 一端接中间节点、另一端接输出节点；**信号源 $V_{in}$** 正端接输入节点、负端接输出节点（地）。输出可在中间节点与输出节点之间取（即 $C$ 两端，为低通），也可在输入节点与中间节点之间取（即 $R$ 两端，为高通）。

由此构成"信号经 $R$、$C$ 串联、输出取自 $C$ 两端（低通）或 $R$ 两端（高通）"的一阶 RC 分压/滤波组态，是高通滤波、低通滤波、微分与积分电路共同的拓扑基础。

## 工作原理
流过 R 与 C 的电流相同，输入电压按阻抗大小在 R 与 C 上分压；电容容抗 $X_C = \frac{1}{\omega C}$ 随频率变化，使两端分压比例随频率改变，从而体现滤波或相位移动行为。

## 关键计算公式

- 总阻抗（相量形式）：
$$Z = R + \frac{1}{j\omega C} = R - j\frac{1}{\omega C}$$

- 阻抗模：
$$|Z| = \sqrt{R^2 + \left(\frac{1}{\omega C}\right)^2}$$

- 串联电流：
$$I = \frac{V_{\mathrm{in}}}{Z}$$

- 输出取自电容两端（低通，即分压式）：
$$V_{\mathrm{out}} = V_{\mathrm{in}}\cdot\frac{1/(j\omega C)}{R + 1/(j\omega C)} = \frac{V_{\mathrm{in}}}{1 + j\omega RC}$$

- 输出取自电阻两端（高通形式）：
$$V_{\mathrm{out}} = V_{\mathrm{in}}\cdot\frac{R}{R + 1/(j\omega C)}$$

- 时间常数：
$$\tau = RC$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 电阻 | Ω |
| $C$ | 电容 | F |
| $Z$ | 总阻抗 | Ω |
| $I$ | 串联电流 | A |
| $V_{\mathrm{in}},V_{\mathrm{out}}$ | 输入、输出电压 | V |
| $\tau$ | 时间常数 | s |

## 元件调整影响
- **R↑ 或 C↑** → 时间常数 $\tau$ 增大，充放电变慢，相应的截止频率 $f_c=\frac{1}{2\pi RC}$ 下降。
- **R↓ 或 C↓** → $\tau$ 减小，响应加快，截止频率升高。
- 输出位置不同行为相反：取自 C 两端为低通，取自 R 两端为高通，但 $\tau$ 与截止频率均只由 $RC$ 决定。
- 该结构无放大能力，增益恒 ≤ 1，且前后级负载会影响等效 R/C，测量时需计入源内阻与负载阻抗。

## 典型参数示例
- 取 $R=1\ \text{kΩ}$、$C=1\ \mu\text{F}$：$\tau = 1000 \times 1\times10^{-6} = 1\ \text{ms}$；低通截止频率 $f_c=\dfrac{1}{2\pi\times 10^{-3}}\approx 159\ \text{Hz}$。
- 取 $R=10\ \text{kΩ}$、$C=10\ \text{nF}$：$\tau = 0.1\ \text{ms}$，$f_c\approx 1.59\ \text{kHz}$。

## 常见器件型号
- 电阻：0805 / 0603 贴片电阻、1% 金属膜电阻。
- 电容：C0G/NP0（高频稳定）、X7R（去耦）、电解电容（低频大容量）。

## 注意事项
- 有输出位置即有滤波类型的区别：C 两端低通、R 两端高通，设计前先明确取哪一端。
- 实际源内阻与负载电阻会与 R 串/并联，改变等效 $RC$ 与截止频率，需一并计入。
- 电容耐压需高于可能出现的峰值电压；高频下注意电容 ESL 与电阻寄生电感影响。
