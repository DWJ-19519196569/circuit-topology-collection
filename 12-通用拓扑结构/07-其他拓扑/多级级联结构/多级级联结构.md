# 多级级联结构

## 拓扑描述
由 **多个放大级（或其他功能级）$A_1, A_2, \dots, A_n$** 首尾依次串联组成的链路结构，前一级的输出作为后一级的输入。电路共有 $n+1$ 个关键节点：**节点① 输入节点**（信号源与第一级 $A_1$ 输入端相连）；**节点②…节点n（级间节点）**（前一级输出与后一级输入相连处）；**节点$n+1$ 输出节点**（末级 $A_n$ 输出端，作为总输出）。

各元件管脚连接：**$A_1$** 输入端接输入节点、输出端接第一个级间节点；**$A_2$** 输入端接第一个级间节点、输出端接第二个级间节点；依此类推，**$A_n$** 输入端接第 $n-1$ 个级间节点、输出端接总输出节点。信号逐级传递，各级增益相乘叠加。

由此构成"多个功能单元首尾串联、前级输出驱动后级输入"的多级级联组态，用于获得单级无法达到的总增益、总衰减或总体滤波特性，是放大、滤波、信号链的基本组织方式。

## 工作原理
信号逐级传递，每一级的输出电压作为下一级的输入电压，各级增益（衰减）相乘叠加，从而以小的单元级实现大的整体增益或陡峭的频率响应。

## 关键计算公式

总电压增益（各级相乘）：
$$A_{total} = A_1 \times A_2 \times \cdots \times A_N$$

总增益（分贝形式）：
$$A_{total}\ (\text{dB}) = 20\lg|A_1| + 20\lg|A_2| + \cdots + 20\lg|A_N|$$

总带宽（各级带宽不相同时近似）：
$$\frac{1}{BW_{total}} \approx \sqrt{\left(\frac{1}{BW_1}\right)^2 + \left(\frac{1}{BW_2}\right)^2 + \cdots}$$

总噪声系数（Friis 公式）：
$$F_{total} = F_1 + \frac{F_2-1}{G_1} + \frac{F_3-1}{G_1G_2} + \cdots$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $A_i$ | 各级电压增益 | 无量纲 |
| $A_{total}$ | 总增益 | 无量纲 |
| $BW$ | 带宽 | Hz |
| $F$ | 噪声系数 | 无量纲 |
| $G_i$ | 各级功率增益 | 无量纲 |

## 元件调整影响
- **增加级数 N↑** → 总增益增大，但总带宽变窄、噪声与功耗上升。
- **前级增益↑** → 总增益上升，且对总噪声系数改善最明显。
- **任一级增益↓** → 总增益等比例下降。
- **各级阻抗失配** → 级间耦合损耗增大，需做阻抗匹配。

## 典型参数示例
- 三级各增益 10、20、5 倍：$A_{total}=10\times20\times5=1000$ 倍（60 dB）。
- 用 dB 表示：$20\lg10 + 20\lg20 + 20\lg5 = 20+26+14=60\ \text{dB}$。

## 常见器件型号
- 运放：LM358、NE5532、OPA2134、TL072。
- 晶体管：2N3904、2N2222、S8050。

## 注意事项
- 级联越多带宽越窄（增益带宽乘积受限制），需折衷增益与带宽。
- 前级噪声对整机噪声起主导作用，前级应选低噪声器件。
- 各级需设置合适的直流偏置并防止级间直流耦合漂移。
