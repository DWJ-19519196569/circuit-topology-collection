# 一阶高通滤波电路

## 拓扑描述
由 **一个电容 $C$** 与 **一个电阻 $R$** 组成的最简单一阶无源高通网络。电路共有 3 个关键节点：**节点① 输入节点**（信号源 $V_{in}$ 正端与 $C$ 的一端相连）；**节点② 输出节点**（$C$ 的另一端与 $R$ 的一端相连，作为输出 $V_{out}$，即电阻两端电压）；**节点③ 地节点 GND**（$R$ 的另一端接地）。

各元件管脚连接：**$C$** 一端接输入节点、另一端接输出节点；**$R$** 一端接输出节点、另一端接 GND。

由此构成"电容串联在信号通路、电阻并联到地、输出取自电阻两端"的一阶无源 RC 高通组态，低频被 $C$ 阻隔、高频经 $C$ 传至输出，阻断直流而通过交流，阻带以 $-20$ dB/十倍频下降；如需增益可再接运放构成一阶有源高通。

## 工作原理
电容容抗随频率升高而减小：低频被电容阻隔、高频顺利通过，输出电压按分压关系随频率上升而增大，形成一阶高通特性。

## 关键计算公式

- 截止频率（-3 dB 点）：
$$f_c = \frac{1}{2\pi RC}$$

- 时间常数：
$$\tau = RC$$

- 传递函数：
$$H(j\omega) = \frac{j\omega RC}{1 + j\omega RC}$$

- 有源形式（带增益 K）：
$$H(s) = \frac{K\, sRC}{1 + sRC}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 电阻 | Ω |
| $C$ | 电容 | F |
| $f_c$ | 截止频率 | Hz |
| $\omega$ | 角频率 | rad/s |
| $\tau$ | 时间常数 | s |
| $K$ | 高频增益 | 无量纲 |

## 元件调整影响
- **R、C 增大** → $f_c$ 降低。
- **R、C 减小** → $f_c$ 升高。
- **负载电阻并联 R** → 等效电阻减小、$f_c$ 升高。
- **运放增益 K 调整** → 只改变通带幅度，不改变 $f_c$。

## 典型参数示例
- 取 $R=10\ \text{kΩ}$、$C=100\ \text{nF}$：$f_c=\dfrac{1}{2\pi\times10^4\times100\times10^{-9}}\approx159\ \text{Hz}$。
- 取 $R=1\ \text{kΩ}$、$C=1\ \mu\text{F}$：$f_c\approx159\ \text{Hz}$。

## 常见器件型号
- 电阻：0805/0603 贴片、1% 金属膜电阻。
- 电容：C0G/NP0、薄膜电容。
- 运放：LM358、TL072。

## 注意事项
- 增益恒 ≤ 1（无源），有源方可提供增益。
- 输出无直流分量，用于交流耦合。
- 负载会抬高实际 $f_c$，需加缓冲。
