# 有源带阻滤波电路

## 拓扑描述
本电路由 **运放 A、无源双 T 网络（电阻 $R$、电容 $C$，如 $R_1$、$R_2$、$R_3$ 与 $C_1$、$C_2$、$C_3$）以及正反馈分压电阻 $R_a$、$R_b$** 组成的有源带阻滤波器。关键节点命名如下：输入节点 $N_{in}$ 为双 T 网络输入端，输出节点 $N_{out}$ 为运放输出端 OUT，地节点 $GND$ 为公共参考；中间节点 $N_1$、$N_2$ 分别为两条 T 形支路的中点；运放同相端 IN+、反相端 IN− 分别经相应路径接反馈网络与分压网络；分压节点 $N_{k}$ 位于 $R_b$ 与 $R_a$ 的连接点，提供少量正反馈。

各元件管脚连接：双 T 网络中 R–R–C 支路由电阻 $R_1$、$R_2$ 串联、其中点经电容 $C_3$ 接地，C–C–R 支路由电容 $C_1$、$C_2$ 串联、其中点经电阻 $R_3$ 接地；双 T 网络的输入与输出分别接 $N_{in}$ 与运放反相端 IN−（作为负反馈支路），使运放输出经双 T 网络折回反相端。正反馈分压支路中，电阻 $R_b$ 一端接运放输出节点 $N_{out}$、另一端接分压节点 $N_k$，电阻 $R_a$ 一端接 $N_k$、另一端接地节点 $GND$，$N_k$ 再接到运放同相端 IN+，由此把一小部分输出同相引回，补偿无源损耗以提升 Q 值；运放 V+、V− 分别接正负电源轨。

组态上，这是以双 T 网络作负反馈支路、并通过电阻分压引入少量正反馈的有源二阶带阻组态，具有更窄阻带与可调品质因数的陷波特性。

## 工作原理
双 T 网络在陷波频率产生传输零点；运放提供的增益与正反馈补偿了无源网络的损耗，使阻带显著收窄（Q 值提高）。信号在陷波点被深度衰减，其余频段经运放缓冲后低阻输出，带载能力强于无源结构。

## 关键计算公式

- 陷波中心频率（双 T 型，$R_1=R_2=R$、$C_1=C_2=C$）：
$$f_0 = \frac{1}{2\pi RC}$$

- 品质因数（正反馈系数 $k$）：
$$Q = \frac{1}{4(1-k)}$$

- 正反馈分压系数：
$$k = \frac{R_b}{R_a + R_b}$$

- 幅频响应（二阶带阻）：
$$|H(j\omega)| = \frac{\left|\omega_0^2 - \omega^2\right|}{\sqrt{(\omega_0^2 - \omega^2)^2 + \left(\frac{\omega_0\omega}{Q}\right)^2}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 双 T 网络电阻 | Ω |
| $C$ | 双 T 网络电容 | F |
| $f_0$ | 陷波中心频率 | Hz |
| $Q$ | 品质因数 | — |
| $k$ | 正反馈分压系数 | — |

## 元件调整影响
- **R 增大 或 C 增大** → $f_0$ 降低。
- **k 增大** → Q 值升高，阻带变窄变深。
- **k 过大（→1）** → 环路增益逼近 1，易自激振荡。
- 运放开环增益与带宽需远高于 $f_0$，否则影响陷波性能。

## 典型参数示例
- 若需 $f_0 = 60\ \text{Hz}$、$Q = 20$：取 $C = 100\ \text{nF}$，则 $R = \dfrac{1}{2\pi \times 60 \times 100\times10^{-9}} \approx 26.5\ \text{kΩ}$；由 $Q=\frac{1}{4(1-k)}$ 得 $k = 1-\frac{1}{80} = 0.9875$，据此确定正反馈分压电阻比 $\frac{R_b}{R_a+R_b}=0.9875$。

## 常见器件型号
- 运放：TL072、OPA227、OP07、LM358（按噪声 / 带宽选择）。
- 集成状态变量滤波器：UAF42、LMF100。
- 精密阻容：0.1% 金属膜电阻、C0G/NP0 或聚丙烯电容。

## 注意事项
- 高 Q 时正反馈易导致自激，需限制 k 并校核相位裕度。
- 元件需精密匹配以保证陷波深度。
- 双电源供电或偏置处理需保证运放在整个信号摆幅内线性工作。
