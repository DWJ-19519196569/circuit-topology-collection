# 无源带阻滤波电路（双 T 陷波）

## 拓扑描述
本电路由 **四只电阻 $R_1$、$R_2$、$R_3$、$R_4$（R-R-C 支路用 $R_1$、$R_2$，中点接地电阻为 $R_3$；C-C-R 支路用 $R_4$）与三只电容 $C_1$、$C_2$、$C_3$** 组成的无源双 T 形网络。两条 T 形支路并联：一条为 R–R–C（$R_1$、$R_2$ 串联，中点经 $C_3$ 接地），另一条为 C–C–R（$C_1$、$C_2$ 串联，中点经 $R_3$ 接地）。关键节点命名如下：输入节点 $N_{in}$ 为两条 T 形支路的公共输入端，输出节点 $N_{out}$ 为两条 T 形支路的公共输出端，地节点 $GND$ 为 $C_3$ 与 $R_3$ 的下端公共参考；中间节点 $N_1$ 为 $R_1$ 与 $R_2$ 的串联中点，复接 $C_3$ 上端；中间节点 $N_2$ 为 $C_1$ 与 $C_2$ 的串联中点，复接 $R_3$ 上端。

各元件管脚连接：电阻 $R_1$ 一端接输入节点 $N_{in}$，另一端接中间节点 $N_1$；电阻 $R_2$ 一端接 $N_1$，另一端接输出节点 $N_{out}$；电容 $C_3$ 一端接 $N_1$，另一端接地节点 $GND$；电容 $C_1$ 一端接 $N_{in}$，另一端接中间节点 $N_2$；电容 $C_2$ 一端接 $N_2$，另一端接 $N_{out}$；电阻 $R_3$ 一端接 $N_2$，另一端接 $GND$。为了精确平衡，通常取 $R_1=R_2=R$、$C_1=C_2=C$，中点接地元件取 $C_3=2C$、$R_3=R/2$（或反之对应 $R_4$），以保证两条支路在陷波频率处输入输出之间提供等幅反相的两条并联通路。

组态上，这是一个无运放、纯阻容并联双 T 的二阶带阻组态，在特定频率处对信号衰减最大（陷波）、其余频率几乎无衰减通过，用于抑制单一干扰频率。

## 工作原理
在陷波频率处，两条 T 形支路产生幅度相等、相位相反的信号，在输出端相互抵消，使输出趋近于零；偏离该频率时两支路不再抵消，信号基本无衰减通过。陷波深度取决于两支路元件的匹配精度。

## 关键计算公式

- 陷波中心频率（取 $R_1=R_2=R$，$C_1=C_2=C$）：
$$f_0 = \frac{1}{2\pi RC}$$

- 角频率形式：
$$\omega_0 = \frac{1}{RC}$$

- 传递函数（理想平衡双 T 网络）：
$$H(s) = \frac{s^2 + \omega_0^2}{s^2 + 4\omega_0 s + \omega_0^2}$$

- 品质因数（无源双 T，$R_3 = R/2$ 时为临界状态）：
$$Q = \frac{f_0}{\Delta f_{-3dB}}$$

- 衰减零点条件（要求精确匹配）：
$$R_1 C_1 + R_2 C_2 = R C$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 双 T 网络电阻 | Ω |
| $C$ | 双 T 网络电容 | F |
| $f_0$ | 陷波中心频率 | Hz |
| $\omega_0$ | 陷波角频率 | rad/s |
| $Q$ | 品质因数 | — |
| $\Delta f$ | -3 dB 阻带带宽 | Hz |

## 元件调整影响
- **R 增大 或 C 增大** → $f_0$ 降低，陷波点向低频移动。
- **两支路元件失配** → 陷波深度变浅，零点被破坏。
- **中点电阻 R/2 偏大或偏小** → 影响 Q 值，偏离最优值时阻带变宽。
- 无源结构 Q 值较低（通常 <0.5），阻带较宽，需高 Q 时改用有源双 T 或专门陷波器。

## 典型参数示例
- 抑制 50 Hz 工频干扰：取 $R = 31.8\ \text{kΩ}$、$C = 100\ \text{nF}$，则 $f_0 = \dfrac{1}{2\pi \times 31.8\times10^{3} \times 100\times10^{-9}} \approx 50\ \text{Hz}$。
- 抑制 1 kHz 干扰：取 $R = 15.9\ \text{kΩ}$、$C = 10\ \text{nF}$，则 $f_0 \approx 1\ \text{kHz}$。

## 常见器件型号
- 电阻：1% 金属膜电阻、精密贴片电阻（匹配精度直接决定陷波深度）。
- 电容：C0G/NP0、1% 精密聚苯乙烯或聚丙烯电容。
- 专用陷波 IC：UAF42、LTC1050（配外部网络）、集成状态变量滤波器。

## 注意事项
- 陷波深度对元件匹配极其敏感，R、C 需成对精密匹配（0.1%~1%）。
- 无源双 T 增益恒 ≤ 1，且带载能力差，实际常加运放缓冲或采用有源结构。
- $f_0$ 附近的相位变化剧烈，可能影响反馈环路稳定性。
