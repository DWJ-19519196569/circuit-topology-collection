# 陷波器 Notch 电路

## 拓扑描述
本电路为专门抑制极窄频带、其余频率基本无衰减通过的带阻（陷波）滤波器，常见实现有双 T 型（无源或加运放整形）、带通加求和器以及状态变量正交陷波三种，含运放 A、电阻 $R$（含分压反馈电阻 $R_a$、$R_b$）与电容 $C$ 等元件。关键节点命名如下：输入节点 $N_{in}$ 为信号入口，输出节点 $N_{out}$ 为陷波后的信号出口，地节点 $GND$ 为公共参考；中间节点 $N_{m}$ 为双 T 网络的中部连接点，分压节点 $N_k$ 为 $R_a$ 与 $R_b$ 的连接点，用于提供正反馈；带通加求和器方式中还有带通输出节点 $N_{bp}$ 接入求和器的某一输入端。

各元件管脚连接：双 T 型中，第一条 T 支路由两只等值电阻 $R$ 串联、中点经一只电容接地，第二条 T 支路由两只等值电容 $C$ 串联、中点经一只电阻接地，两支路在 $N_{in}$ 与 $N_{out}$ 之间并联；加运放整形时，运放 A 的反相端 IN− 接双 T 输出、同相端 IN+ 经分压节点 $N_k$（由 $R_b$ 上接输出、$R_a$ 下接地构成）引入正反馈，运放 OUT 接 $N_{out}$。带通加求和器方式中，带通滤波器输出 $N_{bp}$ 与原始输入 $N_{in}$ 分别接求和器（运算放大器反相求和输入）两端，使两者相减得到陷波输出；状态变量正交陷波用积分与求和网络合成正交信号形成零点，运放 V+、V− 分别接正负电源轨。

组态上，这是通过对消式传输零点或负反馈实现的有源窄带带阻组态，可获得高 Q 值与可调陷波频率，用于去除电源工频、传感器工频串扰等单一强干扰信号。

## 工作原理
电路在陷波频率通过对消或负反馈产生一个传输零点，使该频率信号被大幅衰减；远离陷波频率时增益恢复为近乎平坦。有源结构（如双 T 加正反馈）可在不放大噪声的前提下显著提升 Q 值，形成一个极窄的衰减槽。

## 关键计算公式

- 陷波中心频率（双 T 型，$R_1=R_2=R$、$C_1=C_2=C$）：
$$f_0 = \frac{1}{2\pi RC}$$

- 有源双 T 的品质因数（引入正反馈系数 $k$）：
$$Q = \frac{1}{4(1-k)}$$

- 正反馈支路分压系数：
$$k = \frac{R_{b}}{R_a + R_b}$$

- 传递函数（二阶陷波）：
$$H(s) = \frac{s^2 + \omega_0^2}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 双 T 网络电阻 | Ω |
| $C$ | 双 T 网络电容 | F |
| $f_0$ | 陷波中心频率 | Hz |
| $Q$ | 品质因数 | — |
| $k$ | 正反馈分压系数 | — |

## 元件调整影响
- **R 增大 或 C 增大** → $f_0$ 降低。
- **k 增大（接近 1）** → Q 值升高，陷波变窄变深；但 k 过大时可能自激振荡。
- **元件失配** → 陷波深度下降，衰减零点被破坏。
- 有源结构的 Q 值远高于无源双 T，可实现很窄的陷波频带。

## 典型参数示例
- 若需 $f_0 = 50\ \text{Hz}$、$Q = 10$：取 $C = 100\ \text{nF}$，则 $R = \dfrac{1}{2\pi \times 50 \times 100\times10^{-9}} \approx 31.8\ \text{kΩ}$；由 $Q=\frac{1}{4(1-k)}$ 得 $k = 1 - \frac{1}{40} = 0.975$，据此取反馈分压电阻比。

## 常见器件型号
- 运放：OP07、LM358、TL072、OPA227（低噪声）。
- 专用滤波器 / 状态变量 IC：UAF42、LMF100。
- 精密阻容：0.1% 金属膜电阻、C0G 或聚苯乙烯电容。

## 注意事项
- 元件匹配精度决定陷波深度，需精密配对的 R、C。
- 高 Q 有源陷波器的正反馈易引发自激，需限制 k 值并做好相位裕度。
- 陷波频率处相位陡变，可能影响闭环系统稳定性，需评估环路相位。
