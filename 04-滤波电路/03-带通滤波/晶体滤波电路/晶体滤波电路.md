# 晶体滤波电路

## 拓扑描述
由 **多只石英晶体 $X_1$、$X_2$、…** 与 **若干耦合/匹配阻容元件** 组成的窄带带通滤波器，多以梯形（ladder）或格形（lattice）网络连接，晶体作为高 Q 谐振器。以梯形为例：**节点① 输入节点**（信号源 $V_{in}$ 正端与第一只串联晶体 $X_1$ 的一端相连）；**节点② 中间节点**（$X_1$ 另一端与第一只并联晶体 $X_2$ 的一端相连）；**节点③ 输出节点**（末级串联晶体的另一端作为输出 $V_{out}$）；**节点④ 地节点 GND**（各并联晶体的公共端接地）。

各端口管脚连接：串联晶体接在相邻两个节点之间（$X_1$ 接输入节点与中间节点，下一级串联晶体接中间节点与再下一级节点），并联晶体接在某一节点与 GND 之间，如此逐级构成梯形；输入、输出端各经匹配阻抗网络与晶体网络相接。每只晶体为双端谐振元件，等效为动态电感 $L_1$、动态电容 $C_1$、等效串联电阻 $R_1$ 与静电容 $C_0$。

由此构成"石英晶体按串联/并联交替排列的窄带谐振梯形"拓扑，中心频率由晶体的串联谐振 $f_s$ 与并联谐振 $f_p$ 决定，只让匹配频率附近通过、其余频率被强烈抑制，选择性远优于 LC，带宽仅 kHz 级。

## 工作原理
石英晶体在串联谐振与并联谐振之间呈现极窄的谐振区间，Q 值可达 $10^4\sim10^6$。晶体网络只让与晶体谐振频率匹配的信号通过，偏离该频率的信号被强烈抑制，从而获得极窄的带通与陡峭的阻带。

## 关键计算公式

- 晶体串联谐振频率：
$$f_s = \frac{1}{2\pi\sqrt{L_1 C_1}}$$

- 并联谐振频率：
$$f_p = f_s\sqrt{1 + \frac{C_1}{C_0}}$$

- 晶体品质因数：
$$Q = \frac{2\pi f_s L_1}{R_1}$$

- 通带宽度（由晶体间耦合决定，经验式）：
$$BW \propto \frac{k}{Q}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L_1$ | 晶体动态电感 | H |
| $C_1$ | 晶体动态电容 | F |
| $C_0$ | 晶体静电容 | F |
| $R_1$ | 晶体等效串联电阻 | Ω |
| $f_s$ | 串联谐振频率 | Hz |
| $f_p$ | 并联谐振频率 | Hz |
| $Q$ | 品质因数 | 无量纲 |
| $k$ | 耦合系数 | 无量纲 |

## 元件调整影响
- **晶体静电容 $C_0$ 增大** → $f_p$ 与 $f_s$ 间隔变小，可调带宽变窄。
- **增加级联晶体数量** → 阻带衰减更陡、带外抑制更强。
- **耦合电容/阻抗改变** → 通带宽度变化，进而影响插入损耗。
- **负载不匹配** → 通带纹波增大、插入损耗增加。

## 典型参数示例
- 取 $f_s=10\ \text{MHz}$、$C_1=10\ \text{fF}$、$C_0=5\ \text{pF}$：$f_p = 10\times10^6\sqrt{1+10\times10^{-15}/5\times10^{-12}}\approx10\times10^6(1+1\times10^{-6})$，即 $f_p$ 比 $f_s$ 高约 10 Hz。
- 晶体 Q 值：$L_1=25\ \text{mH}$、$R_1=10\ \Omega$，$Q=2\pi\times10\times10^6\times25\times10^{-3}/10\approx1.57\times10^5$。

## 常见器件型号
- 石英晶体：AT 切 / 滤波级晶体。
- 常用：按需选型（通信 IF 滤波用晶体，如 10.7 MHz）。

## 注意事项
- 晶体滤波器带宽很窄（通常 kHz 级），不适合宽带选频。
- 需良好阻抗匹配与屏蔽，避免杂散耦合。
- 晶体参数离散，需筛选配对，批量一致性重要。
