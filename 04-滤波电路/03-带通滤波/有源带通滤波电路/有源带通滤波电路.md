# 有源带通滤波电路

## 拓扑描述
本电路由 **运放 A 与阻容网络（电阻 $R_1$、$R_2$、$R_3$、电容 $C_1$、$C_2$）** 组成的二阶有源带通滤波器，典型结构有 MFB 型与 Sallen-Key 型两种。关键节点命名如下：输入节点 $N_{in}$ 承接输入信号，地节点 $GND$ 为公共参考，输出节点 $N_{out}$ 由运放输出端 OUT（或缓冲输出）提供；反相（或同相）输入节点 $N_{in\pm}$ 为运放的输入端，中间节点 $N_{m}$ 为阻容网络内部连接点。以 MFB 型为例，信号自 $N_{in}$ 经 $R_1$ 注入运放反相端，$R_2$、$R_3$ 与 $C_1$、$C_2$ 组成反馈选频网络，Sallen-Key 型则同相端接 RC 网络、输出经分压反馈至反相端。

各元件管脚连接（以 MFB 带通为例）：电阻 $R_1$ 一端接输入节点 $N_{in}$，另一端接运放反相端节点 $N_{in-}$；电容 $C_2$ 一端接 $N_{in-}$，另一端接输出节点 $N_{out}$；电阻 $R_3$ 一端接 $N_{in-}$，另一端接中间节点 $N_{m}$；电容 $C_1$ 一端接 $N_{m}$，另一端接地节点 $GND$；电阻 $R_2$ 一端接 $N_{m}$，另一端接输出节点 $N_{out}$；运放 A 的 IN− 接 $N_{in-}$、IN+ 接地、OUT 接 $N_{out}$、V+ 与 V− 接正负电源轨。Sallen-Key 型中，$R_1$ 与 $C_1$ 在输入端构成串联 RC，$R_2$ 与 $C_2$ 并接于 $N_m$ 与地之间，运放同相端 IN+ 接 $N_m$、输出经分压电阻回接 IN−。

组态上，这是一个用单运放加 RC 网络实现的二阶有源带通组态，利用大电阻小电容避免电感，用于音频选频、调制解调与测量。

## 工作原理
RC 网络只在中心频率附近提供必要的反馈与选频特性，运放放大该频带信号并抑制两侧频率，形成带通响应。相比无源 LC，有源带通可用大电阻小电容实现低频选频，且无需电感。

## 关键计算公式

### Sallen-Key 式带通（二阶）

- 中心频率：
$$f_0 = \frac{1}{2\pi\sqrt{R_1 R_2 C_1 C_2}}$$

- 品质因数（简化，增益相关）：
$$Q \approx \frac{1}{3 - K}\quad(K\text{ 为带内增益})$$

- 带宽：
$$BW = \frac{f_0}{Q}$$

### 多重反馈（MFB）带通

- 中心频率：
$$f_0 = \frac{1}{2\pi C}\sqrt{\frac{R_1 + R_3}{R_1 R_2 R_3}}\quad(C_1=C_2=C)$$

- 中心增益：
$$G_0 = -\frac{R_2}{2R_1}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_1, R_2, R_3$ | 阻容/反馈电阻 | Ω |
| $C_1, C_2, C$ | 选频电容 | F |
| $f_0$ | 中心频率 | Hz |
| $Q$ | 品质因数 | 无量纲 |
| $BW$ | 带宽 | Hz |
| $K, G_0$ | 中心增益 | 无量纲 |

## 元件调整影响
- **C 增大** → $f_0$ 降低。
- **$R_2$ 增大（MFB）** → $f_0$ 降低、增益增大、Q 升高。
- **增益 K 增大（Sallen-Key）** → Q 升高、带宽变窄。
- **运放带宽不足** → 高频带通特性偏离。

## 典型参数示例
- MFB 带通、$C=10\ \text{nF}$、$R_1=R_3=10\ \text{kΩ}$、$R_2=100\ \text{kΩ}$：$f_0=\dfrac{1}{2\pi\times10\times10^{-9}}\sqrt{\dfrac{2\times10^4}{10^4\times10^5\times10^4}}\approx712\ \text{Hz}$，$G_0=-100\text{k}/(2\times10\text{k})=-5$。
- 目标 $Q=10$、$f_0=1\ \text{kHz}$：$BW=100\ \text{Hz}$。

## 常见器件型号
- 运放：TL072、LM358、NE5532、OPA2134。
- 电阻/电容：1% 金属膜电阻、C0G/NP0 电容。
- 常用：按需选型。

## 注意事项
- 有源带通无需电感，适合低频选频。
- 高 Q 设计对元件容差敏感。
- Sallen-Key 带通增益受 Q 限制，设计需注意稳定性。
