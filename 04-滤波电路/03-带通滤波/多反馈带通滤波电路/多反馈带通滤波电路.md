# 多反馈带通滤波电路

## 拓扑描述
本电路由 **一个运放 A、三个电阻 $R_1$、$R_2$、$R_3$、两个电容 $C_1$、$C_2$** 组成，构成二阶多重反馈（MFB）有源带通滤波器。关键节点命名如下：输入节点 $N_{in}$ 承接输入信号，地节点 $GND$ 为公共参考，输出节点 $N_{out}$ 由运放输出端 OUT 提供；中间节点 $N_{in-}$ 即运放反相输入端 IN−，其上汇聚电阻 $R_1$、$R_3$、电容 $C_2$ 与运放 IN− 等端子；中间节点 $N_{fb}$ 位于 $R_2$ 与 $C_1$ 的连接点，复接电容 $C_1$、$C_2$ 与 $R_3$ 各一端；运放同相输入端 IN+ 直接接地节点 $GND$，正负电源端 V+、V− 分别接正负电源轨。

各元件管脚连接：电阻 $R_1$ 一端接输入节点 $N_{in}$，另一端接运放反相端节点 $N_{in-}$；电容 $C_2$ 一端接 $N_{in-}$，另一端接运放输出节点 $N_{out}$，构成反相端到输出的反馈电容；电阻 $R_3$ 一端接 $N_{in-}$，另一端接中间节点 $N_{fb}$；电容 $C_1$ 一端接 $N_{fb}$，另一端接地节点 $GND$；电阻 $R_2$ 一端接 $N_{fb}$，另一端接运放输出节点 $N_{out}$；运放 A 的 IN− 接 $N_{in-}$、IN+ 接 $GND$、OUT 接 $N_{out}$、V+ 与 V− 分别接正、负电源轨，其中 $R_2$ 与 $C_1$、$R_3$ 构成从输出经中间节点 $N_{fb}$ 折回反相端的双重反馈（多重反馈）路径。

组态上，这是一个单运放、经 $R_1$ 串联输入至反相端并带双重反馈的二阶带通组态，输出与输入反相，用于音频与窄带选频。

## 工作原理
MFB 网络在中心频率处呈现最大反馈与选频增益，偏离中心频率时阻容网络衰减信号，从而只让中心频率附近一段频带通过，形成带通特性。输出与输入反相。

## 关键计算公式

- 中心（谐振）频率（取 $C_1=C_2=C$）：
$$f_0 = \frac{1}{2\pi C}\sqrt{\frac{R_1 + R_3}{R_1 R_2 R_3}}$$

- 品质因数：
$$Q = \frac{1}{2}\sqrt{\frac{R_2(R_1 + R_3)}{R_1 R_3}}$$

- 带宽：
$$BW = \frac{f_0}{Q}$$

- 中心增益（输出反相）：
$$G_0 = -\frac{R_2}{2R_1}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_1, R_2, R_3$ | 阻容/反馈电阻 | Ω |
| $C_1, C_2$ | 选频电容 | F |
| $f_0$ | 中心频率 | Hz |
| $Q$ | 品质因数 | 无量纲 |
| $BW$ | 带宽 | Hz |
| $G_0$ | 中心增益 | 无量纲 |

## 元件调整影响
- **$C_1$、$C_2$ 增大** → $f_0$ 降低。
- **$R_2$ 增大** → Q 升高、带宽变窄、中心增益增大。
- **$R_1$ 增大** → 输入阻抗增大，但中心增益降低。
- **$R_3$ 增大** → 对 $f_0$ 与增益有综合影响，需整体核算。

## 典型参数示例
- 取 $R_1=R_3=10\ \text{kΩ}$、$R_2=100\ \text{kΩ}$、$C=10\ \text{nF}$：$f_0=\dfrac{1}{2\pi\times10\times10^{-9}}\sqrt{\dfrac{2\times10^4}{10^4\times10^5\times10^4}}\approx712\ \text{Hz}$，$Q=\dfrac{1}{2}\sqrt{\dfrac{100\times10^3\times2\times10^4}{10^4\times10^4}}\approx2.24$，$G_0=-100\text{k}/(2\times10\text{k})=-5$。
- 由此 $BW \approx 712\ \text{Hz}/2.24 \approx 318\ \text{Hz}$。

## 常见器件型号
- 运放：TL072、LM358、NE5532、OPA2134。
- 电阻/电容：1% 金属膜电阻、C0G/NP0 电容。
- 常用：按需选型。

## 注意事项
- MFB 带通输出反相，且 Q 与增益耦合（$G_0=-R_2/2R_1$），设计需联立求解元件值。
- 高 Q 对元件容差与温度敏感。
- 上述公式取 $C_1=C_2=C$ 的简化形式，若两电容不等需用完整表达式。
