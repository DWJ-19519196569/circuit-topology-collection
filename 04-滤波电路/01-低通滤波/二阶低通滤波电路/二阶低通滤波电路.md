# 二阶低通滤波电路

## 拓扑描述
由 **一个运算放大器 A1**、**两个电阻 $R_1$、$R_2$**、**两个电容 $C_1$、$C_2$** 与 **增益设定电阻 $R_f$、$R_g$** 组成的有源二阶低通滤波器（Sallen-Key 结构）。电路共有 6 个关键节点：**节点① 输入节点**（信号源 $V_{in}$ 正端与 $R_1$ 一端相连）；**节点② 中间节点 A**（$R_1$ 另一端、$R_2$ 一端与 $C_1$ 一端三者相连）；**节点③ 同相输入端节点**（$R_2$ 另一端、$C_2$ 一端与 A1 的同相输入端 IN+ 三者相连）；**节点④ 输出节点**（A1 的输出端 OUT、$C_1$ 另一端与 $R_f$ 一端相连，作为输出 $V_{out}$）；**节点⑤ 反相输入端节点**（A1 的反相输入端 IN−、$R_f$ 另一端与 $R_g$ 一端相连）；**节点⑥ 地节点 GND**（$C_2$ 另一端与 $R_g$ 另一端接地）。

各元件管脚连接：**$R_1$** 一端接输入节点、另一端接中间节点 A；**$R_2$** 一端接中间节点 A、另一端接同相输入端节点；**$C_1$** 一端接中间节点 A、另一端接输出节点（跨接反馈）；**$C_2$** 一端接同相输入端节点、另一端接 GND；**$R_f$** 一端接输出节点、另一端接反相输入端节点；**$R_g$** 一端接反相输入端节点、另一端接 GND；**A1** 的 IN+ 接同相输入端节点、IN− 接反相输入端节点、OUT 接输出节点、正电源脚 V+ 接 +VCC、负电源脚 V− 接 −VEE。

由此构成"$C_1$ 跨接输出与节点 A、$R_2$–$C_2$ 接同相端到地、$R_f/R_g$ 设定增益 $K=1+R_f/R_g$"的 Sallen-Key 二阶有源低通组态，具有两个极点、阻带以 $-40$ dB/十倍频下降，品质因数 $Q=1/(3-K)$；若将阻容网络改接为反相端的多重反馈网络即为 MFB 结构。

## 工作原理
两级 RC 网络使信号随频率升高产生更大衰减与相移，运放在通带内提供增益、在阻带内使输出快速跌落，形成二极点响应的低通特性。Sallen-Key 用正反馈提升 Q 值，MFB 用负反馈网络实现。

## 关键计算公式

### Sallen-Key 结构

- 截止频率：
$$f_c = \frac{1}{2\pi\sqrt{R_1 R_2 C_1 C_2}}$$

- 品质因数（取 $R_1=R_2=R$）：
$$Q = \frac{\sqrt{C_1 C_2}}{C_1 + C_2}\cdot\frac{1}{2 - K}\quad (K=1+R_f/R_g)$$

- 传递函数：
$$H(s) = \frac{K\omega_c^2}{s^2 + \frac{\omega_c}{Q}s + \omega_c^2}$$

### MFB 结构（传递函数形式）

- 低通传递函数：
$$H(s) = \frac{-1/(R_1 R_2 C_1 C_2)}{s^2 + s\frac{1}{C_1}\left(\frac{1}{R_1}+\frac{1}{R_2}+\frac{1}{R_3}\right) + \frac{1}{R_2 R_3 C_1 C_2}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_1, R_2, R_3$ | 阻容网络电阻 | Ω |
| $C_1, C_2$ | 阻容网络电容 | F |
| $R_f, R_g$ | 增益设定电阻 | Ω |
| $K$ | 直流增益 | 无量纲 |
| $Q$ | 品质因数 | 无量纲 |
| $f_c$ | 截止频率 | Hz |
| $\omega_c$ | 截止角频率（$\omega_c=2\pi f_c$） | rad/s |

## 元件调整影响
- **R、C 增大** → $f_c$ 下降，通带变窄。
- **$K$（增益）增大** → $Q$ 升高，$f_c$ 附近出现峰值甚至振荡。
- **$R_f/R_g$ 增大** → 增益升高同时 Q 升高，可能过冲。
- **元件容差（尤其 C 的容差）增大** → 实际 $f_c$ 与 $Q$ 偏离设计值。

## 典型参数示例
- Sallen-Key 取 $R_1=R_2=10\ \text{kΩ}$、$C_1=C_2=10\ \text{nF}$：$f_c = \dfrac{1}{2\pi\times10^4\times10^{-8}} \approx 1.59\ \text{kHz}$，$Q=\frac{1}{2-K}$，$K=1$ 时 $Q=1$。
- Butterworth 设计（$Q=0.707$）：由 $Q=1/(2-K)$ 得 $K\approx0.586$；实际取 $K=1$ 则不满足 Butterworth，需按元件比调整。

## 常见器件型号
- 运放：TL072、LM358（通用）、OPA2134（音频）、NE5532。
- 电阻/电容：1% 金属膜电阻、C0G/NP0 电容。
- 常用：按需选型。

## 注意事项
- 二阶滤波对元件匹配与容差敏感，高 Q 设计需 1% 以上精度元件。
- Sallen-Key 的 Q 受增益限制，增益过高会自激。
- 无源二阶 LC 亦常见，但带载能力差，有源结构可同时提供增益与阻抗隔离。
