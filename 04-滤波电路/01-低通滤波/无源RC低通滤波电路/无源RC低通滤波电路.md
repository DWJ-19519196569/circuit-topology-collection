# 无源 RC 低通滤波电路

## 拓扑描述
由 **一个电阻 $R$** 与 **一个电容 $C$** 组成的一阶无源滤波网络。电路共有 3 个关键节点：**节点① 输入节点**（信号源 $V_{in}$ 正端与 $R$ 的上端相连）；**节点② 输出节点**（$R$ 的下端与 $C$ 的上端相连，作为输出 $V_{out}$，即电容两端电压）；**节点③ 地节点 GND**（$C$ 的下端接地）。

各元件管脚连接：**$R$** 一端（上端）接输入节点、另一端（下端）接输出节点；**$C$** 一端（上端）接输出节点、另一端（下端）接 GND。

由此构成"$R$ 与 $C$ 串联分压、输出取自电容两端"的一阶无源 RC 低通组态，低频信号经 $R$ 传至输出、高频信号被 $C$ 旁路到地，阻带以 $-20$ dB/十倍频下降，是最基本的低通滤波电路。

## 工作原理
电容的容抗为 $X_C = \frac{1}{\omega C}$，随频率升高而减小。低频时容抗远大于 R，输出接近输入；高频时容抗变小，把信号分流到地，输出被衰减。该电路只有一阶，阻带以 **-20 dB/十倍频** 的斜率下降。

## 关键计算公式

- 截止频率（-3 dB 点）：
$$f_c = \frac{1}{2\pi RC}$$

- 角频率形式：
$$\omega_c = \frac{1}{RC}$$

- 传递函数：
$$H(j\omega) = \frac{1}{1 + j\omega RC}$$

- 幅频响应：
$$|H(\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}}$$

- 相频响应：
$$\phi(\omega) = -\arctan(\omega RC)$$

- 时间常数：
$$\tau = RC$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 电阻 | Ω |
| $C$ | 电容 | F |
| $f_c$ | 截止频率 | Hz |
| $\omega$ | 角频率（$\omega = 2\pi f$） | rad/s |
| $\tau$ | 时间常数 | s |

## 元件调整影响
- **R 增大 或 C 增大** → $f_c$ 降低，更多高频被滤除，电路响应变慢（$\tau$ 增大）。
- **R 减小 或 C 减小** → $f_c$ 升高，通过频带变宽。
- 想得到某一截止频率时，可固定 C 调 R，或固定 R 调 C，二者乘积决定 $f_c$。
- 该电路无放大能力（增益恒 ≤ 1），且带载时输出会被负载电阻影响，实际使用常在后级加运放缓冲。

## 典型参数示例
- 取 $R=1\ \text{kΩ}$、$C=100\ \text{nF}$：$f_c = \dfrac{1}{2\pi \times 1000 \times 100\times10^{-9}} \approx 1.59\ \text{kHz}$。
- 取 $R=10\ \text{kΩ}$、$C=1\ \mu\text{F}$：$f_c \approx 15.9\ \text{Hz}$（用于音频 / 直流滤波）。

## 常见器件型号
- 电阻：0805 / 0603 贴片电阻、1% 金属膜电阻。
- 电容：C0G/NP0（高频稳定）、X7R（去耦）、电解电容（低频大容量）。
- 后级缓冲运放：LM358、TL072、OPA2134。

## 注意事项
- 无放大能力，增益恒 ≤ 1。
- 带载时截止频率受负载电阻影响，实际常加运放跟随器缓冲。
- 电容耐压需高于信号峰值；高频场合考虑电容 ESL 与电阻寄生电感。
