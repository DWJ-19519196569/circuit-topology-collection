# 椭圆滤波器（Cauer 滤波器）

## 拓扑描述
本电路为在通带和阻带都允许等幅纹波、从而在给定阶数下获得最陡过渡带的滤波器逼近类型（又称考尔 Cauer 滤波器），元件组成为 **无源 RLC 阶梯网络（电感 $L$、电容 $C$、电阻 $R$）或有源运放 A + RC 网络**，其传递函数在有限频率处含传输零点。关键节点命名如下：输入节点 $N_{in}$ 为信号入口，输出节点 $N_{out}$ 为信号出口，地节点 $GND$ 为公共参考；无源实现时各中间节点 $N_1$、$N_2$、…、$N_n$ 为阶梯网络中串联元件与并联元件（含构成有限零点的并联 LC 谐振支路）的交点；有源实现时节点 $N_{in-}$、$N_{in+}$ 为各节运放输入端。

各元件管脚连接（以含有限零点的无源 RLC 阶梯低通为例）：每级串联元件（电感 $L$ 或电阻 $R$）一端接上一级节点、另一端接本级节点 $N_i$；并联电容 $C$ 一端接 $N_i$、另一端接地节点 $GND$；为产生阻带深陷波点，在并联分支中把电容 $C$ 与电感 $L$ 先串联成谐振支路后再并接到地，使该谐振频率处出现传输零点，各级依次级联、输入端接 $N_{in}$、末端接输出节点 $N_{out}$。有源实现时，按椭圆函数综合的表系数把有限零点分配到各运放 + RC 节的 IN+/IN− 与 OUT 之间的网络中，逐级串联实现高阶椭圆响应。

组态上，这是借助雅可比椭圆函数同时放置极点与有限传输零点的滤波器组态，适用于对过渡带陡峭度要求极高的场合。

## 工作原理
利用雅可比椭圆函数同时放置极点与有限传输零点，使通带和阻带都呈等纹波特性。有限零点使阻带在某些频率处出现深陷波，从而以相同阶数获得比切比雪夫更陡的过渡带，代价是通带、阻带纹波与较差的相位 / 群延迟特性。

## 关键计算公式

- n 阶椭圆低通幅度平方响应（$R_n$ 为 n 阶有理切比雪夫函数）：
$$|H(j\omega)|^2 = \frac{1}{1 + \varepsilon^2 R_n^2\!\left(\frac{\omega}{\omega_c}\right)}$$

- 纹波因子（通带纹波 $\delta$，dB）：
$$\varepsilon = \sqrt{10^{\delta/10}-1}$$

- 选择性因子（$k$ 由通带 / 阻带边缘频率定义）：
$$k = \frac{\omega_c}{\omega_s} = \frac{f_c}{f_s}$$

- 阶数估算（依赖模 $k$ 与椭圆积分，工程上查表）：
$$n \approx \frac{K(k)K(\sqrt{1-k_1^2})}{K(k_1)K(\sqrt{1-k^2})}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $n$ | 滤波器阶数 | — |
| $\omega_c$ | 通带边缘角频率 | rad/s |
| $\omega_s$ | 阻带边缘角频率 | rad/s |
| $\varepsilon$ | 纹波因子 | — |
| $k, k_1$ | 选择性 / 纹波相关模数 | — |
| $K(\cdot)$ | 第一类完全椭圆积分 | — |

## 元件调整影响
- **阶数 n 增大** → 过渡带进一步变陡，但纹波增多、相位失真加剧、电路复杂。
- **通带纹波减小** → 选择性略降；**阻带纹波增大** → 过渡带更陡。
- 有限传输零点位置由元件值决定，改变 R、L、C 会移动零点与截止频率。
- 对元件容差最敏感，失配易破坏等纹波特性。

## 典型参数示例
- 设计椭圆低通时若通带纹波 $\delta = 0.1\ \text{dB}$，则 $\varepsilon = \sqrt{10^{0.01}-1} \approx 0.153$，其极点与零点位置需按椭圆积分表或滤波器综合软件（如 MATLAB）确定。

## 常见器件型号
- 运放：TL072、OPA227。
- 集成有源滤波 IC：LTC1064、LMF100（按配置）。
- 阻容（无源实现）：高 Q 电感、1% 电阻、精密电容。

## 注意事项
- 通带与阻带均有纹波，不适合对幅度平坦度要求高的应用。
- 群延迟变化剧烈，宽带脉冲 / 数字信号会有明显失真。
- 设计依赖椭圆积分与查表，工程上常用 MATLAB / ADI、TI 滤波器设计工具辅助。
