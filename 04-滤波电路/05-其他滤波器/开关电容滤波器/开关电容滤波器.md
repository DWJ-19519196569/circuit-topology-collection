# 开关电容滤波器

## 拓扑描述
本电路由 **运放 A、受时钟控制的 MOS 开关 S1、S2、…、以及电容 $C$（开关转移电容）与反馈电容 $C_f$** 组成的开关电容（SC）滤波器，用开关电容等效电阻替代传统有源 RC 滤波器中的电阻。关键节点命名如下：输入节点 $N_{in}$ 为信号入口，输出节点 $N_{out}$ 为运放输出端 OUT，地节点 $GND$ 为公共参考；开关中间节点 $N_{s}$ 为开关 S1 与 S2 交替切换时电容 $C$ 的浮空端点；运放反相端节点 $N_{in-}$（虚地）为反馈电容 $C_f$ 与开关支路的汇聚点；时钟端 $N_{clk}$ 接入 $f_{clk}$ 时钟信号。

各元件管脚连接：开关电容支路中，输入开关 S1 一端接输入节点 $N_{in}$、另一端接开关中间节点 $N_s$，转移电容 $C$ 一端接 $N_s$、另一端在 S2 切换下轮流接地或接反相端，输出开关 S2 一端接 $N_s$、另一端接运放反相端节点 $N_{in-}$，两开关的栅极（控制端）均由时钟 $N_{clk}$ 的非交叠两相驱动；反馈电容 $C_f$ 一端接 $N_{in-}$、另一端接运放输出节点 $N_{out}$；运放 A 的 IN+ 接地节点 $GND$、IN− 接 $N_{in-}$、OUT 接 $N_{out}$、V+ 与 V− 接正负电源轨。开关以频率 $f_{clk}$ 周期性地把电荷从输入搬移到反馈电容上，等效电阻 $R_{eq}=1/(f_{clk}C)$。

组态上，这是以开关电容等效电阻和片内电容比例设定时间常数、受时钟程控的集成滤波器组态，成功用时钟频率正比地设定截止/中心频率。

## 工作原理
开关以时钟频率 $f_{clk}$ 交替导通，电容每个周期被充电或转移电荷，形成平均电流，等效为一个阻值为 $R_{eq}=1/(f_{clk}C)$ 的电阻。滤波器的截止频率 / 中心频率与时钟频率成正比，因此可通过改变时钟来程控调节滤波器特性。

## 关键计算公式

- 开关电容等效电阻：
$$R_{eq} = \frac{1}{f_{clk}\, C}$$

- 由等效电阻构成的 RC 时间常数：
$$\tau = R_{eq} C_f = \frac{C_f}{f_{clk}\, C}$$

- 常见低通截止频率（与电容比成正比）：
$$f_c \propto f_{clk} \cdot \frac{C}{C_f}$$

- 采样定理要求（时钟频率应远高于信号带宽）：
$$f_{clk} \gg 2 f_{signal}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_{eq}$ | 开关电容等效电阻 | Ω |
| $f_{clk}$ | 时钟频率 | Hz |
| $C$ | 开关电容（被开关转移电荷的电容） | F |
| $C_f$ | 反馈 / 积分电容 | F |
| $\tau$ | 时间常数 | s |

## 元件调整影响
- **时钟频率 $f_{clk}$ 升高** → 等效电阻减小，滤波器截止 / 中心频率升高。
- **电容比 $C/C_f$ 增大** → 截止频率**升高**（时间常数减小），与 $f_c \propto f_{clk}\cdot\dfrac{C}{C_f}$ 一致。
- 滤波器特性主要由电容比和时钟决定，对绝对电容值不敏感，工艺一致性好。
- 时钟或开关会引入开关噪声与混叠，需在前后加抗混叠 / 平滑滤波。

## 典型参数示例
- 设 $f_{clk} = 100\ \text{kHz}$、$C = 1\ \text{pF}$，则 $R_{eq} = \dfrac{1}{10^5 \times 10^{-12}} = 10\ \text{MΩ}$。再取 $C_f = 10\ \text{pF}$，时间常数 $\tau = \dfrac{10\ \text{pF}}{10^5 \times 1\ \text{pF}} = 10^{-4}\ \text{s}$，对应截止频率 $f_c = \dfrac{1}{2\pi\tau} \approx 1.59\ \text{kHz}$。

## 常见器件型号
- 集成开关电容滤波 IC：LTC1064、MAX291/MAX296、LTC1068、MF10（国家半导体）。
- 通用运放 + 模拟开关组合：如 CD4066、ADG 系列开关 + 电容。

## 注意事项
- 属采样系统，需满足采样定理，并在输入前加抗混叠低通、输出后加平滑滤波。
- 时钟馈通与开关电荷注入会引入噪声与直流失调，需选低电荷注入开关或补偿。
- 时钟频率需稳定，否则滤波器特性随之漂移。
