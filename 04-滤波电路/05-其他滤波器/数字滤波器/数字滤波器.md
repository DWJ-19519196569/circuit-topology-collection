# 数字滤波器

## 拓扑描述
本电路并非由 R、C、L 等模拟元件搭建，而是以 **加法器、乘法器（系数 $b_k$、$a_k$）与单位延迟单元 $z^{-1}$** 组成的离散时间运算结构，按拓扑分为 FIR 与 IIR（IIR 可展开为直接 I 型、直接 II 型、级联型、并联型）。关键节点命名如下：输入采样节点 $N_{in}$ 接收输入序列 $x[n]$，输出节点 $N_{out}$ 给出输出序列 $y[n]$，各延迟节点 $N_{d1}$、$N_{d2}$、… 为每个单位延迟单元 $z^{-1}$ 的输出端，即历史采样值的存储或连线点；求和节点 $N_{\Sigma}$ 为各乘加结果的汇聚处。

各支路连接：每个前馈支路把输入采样 $x[n]$（或其延迟版本）经乘法器乘以前馈系数 $b_k$ 后送入求和节点 $N_{\Sigma}$；每个反馈支路把输出延迟节点 $N_{di}$ 的信号经乘法器乘以反馈系数 $a_k$ 后反相（负）送入 $N_{\Sigma}$；单位延迟单元 $z^{-1}$ 的输入端接某一采样序列、输出端接下一个延迟节点，把信号推迟一个采样周期。例如直接 II 型中，输入 $x[n]$ 先进入求和节点，输出按其差分方程经反馈与前馈两条支路分别实现极点和零点，最终从 $N_{out}$ 输出 $y[n]$。

组态上，这是以递推差分方程组合当前与历史采样值、由系数决定零极点位置的数字滤波器组态，用于微处理器、DSP 或 FPGA 中对离散数字信号做滤波。

## 工作原理
数字滤波器通过递归或非递归地组合当前与历史采样值、乘以相应系数得到输出，用离散差分方程实现对频率的选择性。单位延迟 $z^{-1}$ 表示将信号推迟一个采样周期，系数决定零极点位置，从而决定滤波特性。

## 关键计算公式

- 通用差分方程（IIR）：
$$y[n] = \sum_{k=0}^{M} b_k\, x[n-k] - \sum_{k=1}^{N} a_k\, y[n-k]$$

- FIR 形式（$a_k=0$）：
$$y[n] = \sum_{k=0}^{M} b_k\, x[n-k]$$

- 传递函数（z 域）：
$$H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}$$

- 采样频率与奈奎斯特限制：
$$f_s > 2 f_{max}$$

- 归一化角频率：
$$\omega = 2\pi \frac{f}{f_s}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $x[n]$ | 输入序列 | — |
| $y[n]$ | 输出序列 | — |
| $b_k$ | 前馈（零点）系数 | — |
| $a_k$ | 反馈（极点）系数 | — |
| $M, N$ | 滤波器阶数相关项数 | — |
| $f_s$ | 采样频率 | Hz |
| $f_{max}$ | 信号最高频率 | Hz |

## 元件调整影响
- **增大阶数** → 阻带更陡、过渡带更窄，但运算量与延迟增大。
- **系数精度（字长）降低** → 量化噪声增大，IIR 极点可能偏移甚至不稳定。
- **采样频率 $f_s$ 升高** → 可用带宽增大、混叠风险降低，但运算量与功耗上升。
- 系数决定零极点位置：调整系数即改变通带 / 阻带和截止频率。

## 典型参数示例
- 一阶 IIR 低通：$y[n] = a\,y[n-1] + (1-a)\,x[n]$。取 $a=0.9$、$f_s=1\ \text{kHz}$ 时，其 -3 dB 截止频率约 $f_c \approx \dfrac{1-a}{2\pi\,T_s}$，代入 $T_s=1\ \text{ms}$ 得 $f_c \approx \dfrac{0.1}{2\pi\times10^{-3}} \approx 15.9\ \text{Hz}$。

## 常见器件型号
- DSP：TMS320 系列、ADSP-21xx 系列。
- FPGA：Xilinx / Intel FPGA（结合 IP 核或手写 FIR/IIR）。
- 单片机：STM32（Cortex-M，含 CMSIS-DSP 库）、ADI Blackfin。

## 注意事项
- 采样前需加模拟抗混叠低通滤波器。
- IIR 结构量化误差可能造成不稳定，需校核极点是否在单位圆内。
- 设计时注意系数定标，避免定点运算溢出。
