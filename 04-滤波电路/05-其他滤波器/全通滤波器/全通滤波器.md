# 全通滤波器

## 拓扑描述
本电路由 **运放 A、电阻 $R_1$、$R_2$ 与电容 $C_1$、$C_2$** 组成的一阶（或多级级联的高阶）全通滤波器。关键节点命名如下：输入节点 $N_{in}$ 为信号入口，输出节点 $N_{out}$ 为运放输出端 OUT，地节点 $GND$ 为公共参考；中间节点 $N_{a}$ 为 $R_1$ 与 $C_1$ 构成的一条 RC 支路的中点（接运放同相端），中间节点 $N_{b}$ 为 $R_2$ 与 $C_2$ 构成的另一条 RC 支路的中点（接运放反相端），两条 RC 支路的另一端分别接输入与地。

各元件管脚连接：运放同相支路中，电阻 $R_1$ 一端接输入节点 $N_{in}$、另一端接中间节点 $N_a$，电容 $C_1$ 一端接 $N_a$、另一端接地节点 $GND$，$N_a$ 同时接到运放同相端 IN+；运放反相支路中，电容 $C_2$ 一端接输入节点 $N_{in}$、另一端接中间节点 $N_b$，电阻 $R_2$ 一端接 $N_b$、另一端接地节点 $GND$，$N_b$ 同时接到运放反相端 IN−；运放 A 的 OUT 接输出节点 $N_{out}$，V+、V− 接正负电源轨，通常取 $R_1=R_2=R$、$C_1=C_2=C$ 以保证幅度恒为 1。

组态上，这是同相端与反相端各接一路互补 RC 网络的单运放全通组态，幅度恒为 1、仅随频率改变相位，用于相位校正、延迟均衡与移相。

## 工作原理
电路在输入与输出之间提供随频率变化的相移，但幅度在所有频率保持不变。一阶全通在 $\omega\to0$ 时相移趋近 0，在 $\omega\to\infty$ 时相移趋近 $-180^\circ$，在特征频率处相移 $-90^\circ$，从而实现对特定频段的相位调整而不衰减信号幅度。

## 关键计算公式

- 一阶全通传递函数：
$$H(s) = \frac{1 - sRC}{1 + sRC}$$

- 相频响应：
$$\phi(\omega) = -2\arctan(\omega RC)$$

- 相位转折（$-90^\circ$）频率：
$$\omega_0 = \frac{1}{RC}$$

- 群延迟：
$$\tau_g(\omega) = \frac{2RC}{1 + (\omega RC)^2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 电阻 | Ω |
| $C$ | 电容 | F |
| $\omega_0$ | 相位转折角频率 | rad/s |
| $\phi$ | 相移 | rad |
| $\tau_g$ | 群延迟 | s |

## 元件调整影响
- **R 或 C 增大** → 相位转折频率 $\omega_0$ 降低，相移发生的频段下移。
- **R、C 失配**（相对运放两输入端不精确匹配）→ 幅度响应出现起伏，不再恒为 1。
- 级联多个全通节可叠加相移，用于实现更大范围的相位 / 延迟补偿。
- 幅度恒为 1，改变元件不改变增益，只改变相位特性。

## 典型参数示例
- 取 $R=10\ \text{kΩ}$、$C=15.9\ \text{nF}$：$\omega_0 = \dfrac{1}{10^4\times15.9\times10^{-9}} \approx 6280\ \text{rad/s}$，即 $f_0\approx 1\ \text{kHz}$。在 $f_0$ 处相移 $\phi = -2\arctan(1) = -90^\circ$。

## 常见器件型号
- 运放：TL072、OPA227、LM358（按频率与噪声选择）。
- 精密阻容：1% 金属膜电阻、C0G/NP0 电容。

## 注意事项
- 幅度响应平坦依靠两路 RC 的精确匹配，需选精密元件。
- 全通不提供幅度选择性，仅用于相位 / 延迟补偿，不能用作选频滤波。
- 高频时运放带宽与寄生电容会使幅度响应偏离平坦，需评估。
