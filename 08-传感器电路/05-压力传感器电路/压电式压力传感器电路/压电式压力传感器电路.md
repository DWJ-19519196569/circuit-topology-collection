# 压电式压力传感器电路

## 拓扑描述
元件组成与节点定义：电路由**压电材料（石英、PZT）传感器 Y1**（等效为电荷源与传感器电容 $C_s$）、**积分电容 $C_f$**、**反馈电阻 $R_f$** 与**电荷放大器（跨阻型）运算放大器 U1** 组成，也可只接高输入阻抗电压放大器。电路共有 5 个关键节点：**节点① 传感器输出节点**（连 Y1 一端与 U1 的 IN− 脚）；**节点② 地节点 GND**（连 Y1 另一端与 U1 的 IN+ 脚、$C_f$/$R_f$ 下端）；**节点③ 反馈节点**（连 $C_f$、$R_f$ 上端与 U1 的 OUT 脚）；**节点④ 输出节点 $V_{out}$**（连 U1 的 OUT 脚）；**节点⑤ 电源节点**（连 U1 的 V+、V− 供电脚）。

各元件管脚连接：Y1 一端接节点①、另一端接节点②，受压时在节点①产生与压力变化率成正比的电荷；U1 的 IN− 接节点①、IN+ 接节点②、OUT 接节点③与④、V+ / V− 接节点⑤；$C_f$ 一端接节点①、另一端接节点③；$R_f$ 一端接节点①、另一端接节点③，与 $C_f$ 并联跨接在 IN− 与 OUT 之间构成电荷—电压转换。运放输入偏置电流极小，把注入的电荷积分到 $C_f$ 上，输出 $V_{out}=-Q/C_f$。

由此构成"压电电荷源 + 电荷放大器（$C_f$/$R_f$ 反馈积分）"的压电压力测量组态，适用于动态压力（冲击、振动、声压）测量，不能测静态/准静态压力。

## 工作原理
压力作用于压电晶体产生电荷 $Q = d_{33} \cdot F$，电荷放大器利用反馈电容 C_f 将电荷转换为电压 $V_{out} = -Q / C_f$，从而得到与压力成正比的电压输出。

## 关键计算公式

- 压电电荷：
$$Q = d_{33} \cdot F$$

- 电荷放大器输出：
$$V_{out} = -\frac{Q}{C_f}$$

- 传感器开路电压：
$$V_s = \frac{Q}{C_s}$$

- 电荷放大器下限截止频率：
$$f_l = \frac{1}{2\pi R_f C_f}$$

- 压力（受力面积 A 均布）：
$$F = P \cdot A$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $Q$ | 产生的电荷 | C |
| $d_{33}$ | 压电电荷常数 | C/N |
| $F$ | 作用力 | N |
| $C_f$ | 反馈电容 | F |
| $C_s$ | 传感器电容 | F |
| $R_f$ | 反馈电阻 | Ω |
| $P$ | 压力 | Pa |

## 元件调整影响
- **C_f ↓** → 电荷放大器增益增大、输出电压升高。
- **R_f ↓** → 下限截止频率升高，低频响应变差、时间常数减小。
- **R_f ↑ / C_f ↑** → 低频响应改善（下限频率降低），但漂移与噪声增加。
- 压电材料电荷常数越大，灵敏度越高。

## 典型参数示例
- 取 $d_{33}=4\ \text{pC/N}$、$F=100\ \text{N}$：$Q=4\times10^{-12}\times100=0.4\ \text{nC}$。
- 电荷放大器 $C_f=100\ \text{pF}$：$V_{out}=\dfrac{0.4\times10^{-9}}{100\times10^{-12}}=4\ \text{V}$。
- $R_f=10\ \text{MΩ}$、$C_f=100\ \text{pF}$ 时下限频率：$f_l=\dfrac{1}{2\pi\times10^{7}\times10^{-10}}\approx159\ \text{Hz}$。

## 常见器件型号
- 压电传感器：PCB Piezotronics、Kistler 系列、蜂鸣片（低成本声压）。
- 电荷放大器运放：OPA128、LMC6081（低偏流）。

## 注意事项
- 压电式**不能测量静态/准静态压力**，仅适用于动态或冲击测量。
- 需极高输入阻抗（GΩ 级）的电荷放大器，电缆也会贡献电容影响灵敏度。
- 反馈电阻决定低频响应，选用超低偏流运放以减小漂移。
- 电缆移动、振动会引入噪声，宜用低噪声专用电缆并固定。
