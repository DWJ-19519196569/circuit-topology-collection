# 开关型霍尔电路

## 拓扑描述
由 **开关型霍尔传感器 $H_1$**（内部集成霍尔元件、放大器与施密特触发器，集电极开路输出）与 **上拉电阻 $R_P$** 组成，输出送 MCU。电路共有 3 个关键节点：**节点① 电源节点**（$H_1$ 的 VCC 脚与 $R_P$ 的上端一起接 +VCC）；**节点② 接地节点**（$H_1$ 的 GND 脚接地）；**节点③ 输出节点**（$H_1$ 的 OUT 脚、$R_P$ 的下端与 MCU 输入相连，作为数字输出）。

各元件管脚连接：**$H_1$** 的 VCC 接节点①、GND 接节点②、OUT（集电极开路）接节点③；**$R_P$** 一端接节点①、另一端接节点③；**MCU** 输入接节点③。当外磁场超过动作阈值 $B_{OP}$ 时内部比较器经迟滞翻转、OUT 拉低/抬升，越过释放阈值 $B_{RP}$ 时恢复。

由此构成"开关型（数字迟滞输出）+ 集电极开路带上拉"的霍尔测量组态，磁场过/欠动作点产生数字开关电平，配合 $R_P$（$R_P=\frac{V_{CC}-V_{OL}}{I_{sink}}$）可测速与限位。

## 工作原理
磁场由弱变强越过动作点 $B_{OP}$ 时，内部比较器经施密特迟滞翻转，输出电平改变；磁场回落越过释放点 $B_{RP}$ 时恢复。迟滞 $B_{HYS}=B_{OP}-B_{RP}$ 保证输出不抖动。

## 关键计算公式

- 迟滞宽度：
$$B_{HYS} = B_{OP} - B_{RP}$$

- 上拉电阻选择：
$$R_{P} = \frac{V_{CC} - V_{OL}}{I_{sink}}$$

- 转速换算（m 为每转磁极数）：
$$n = \frac{60 f}{m}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $B_{OP}$ | 动作磁感应强度 | T |
| $B_{RP}$ | 释放磁感应强度 | T |
| $B_{HYS}$ | 迟滞宽度 | T |
| $R_P$ | 上拉电阻 | Ω |
| $I_{sink}$ | 输出灌电流 | A |
| $f$ | 输出脉冲频率 | Hz |
| $n$ | 转速 | r/min |

## 元件调整影响
- **上拉电阻 R_P ↓** → 输出上升沿更快、驱动能力更强，但灌电流与功耗增大。
- **上拉电阻 R_P ↑** → 功耗降低，但信号沿变缓、抗干扰变差。
- **磁铁强度/距离** → 决定磁场是否可靠越过动作点，磁铁太远则不动作。
- 迟滞由器件内部决定，固定不可调。

## 典型参数示例
- 取 $V_{CC}=5\ \text{V}$、$V_{OL}=0.2\ \text{V}$、$I_{sink}=4\ \text{mA}$：$R_P = \dfrac{5-0.2}{4\times10^{-3}} = 1.2\ \text{kΩ}$（常用 1~10 kΩ）。
- 转盘 4 个磁极、输出频率 $f=100\ \text{Hz}$：$n = \dfrac{60\times100}{4}=1500\ \text{r/min}$。

## 常见器件型号
- 开关型霍尔：SS411A、A3144、OH3144、SS41F、US1881（带锁存）。

## 注意事项
- 区分单极、双极（锁存）开关型：锁存型输出状态保持到反向磁场出现。
- 集电极开路输出必须外接上拉电阻才能得到高电平。
- 注意磁场极性与安装方向，磁铁与器件距离需保证磁场越过动作点。
- 输出为数字信号，适合测速、限位，不适合模拟定位。
