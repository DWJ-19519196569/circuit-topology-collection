# 光电池检测电路

## 拓扑描述
由 **光电池（光伏电池，作为光生电流源）**、**运算放大器 A1**、**反馈电阻 $R_f$** 与并联的 **反馈电容 $C_f$** 组成跨阻放大器（TIA），或改用 **采样电阻**。电路共有 3 个关键节点：**节点① 虚地节点**（光电池一端、A1 的反相输入端 IN−、$R_f$ 一端与 $C_f$ 一端相连）；**节点② 接地节点**（光电池另一端与 A1 的同相输入端 IN+ 接地 GND）；**节点③ 输出节点**（A1 的输出端 OUT 与 $R_f$、$C_f$ 的另一端相连，作为 $V_{out}$）。

各元件管脚连接：**光电池**两端分别接节点①、节点②；**A1** 的 IN− 接节点①、IN+ 接节点②、OUT 接节点③、正电源 V+ 接 +VCC、负电源 V− 接 −VEE；**$R_f$** 一端接节点①、另一端接节点③；**$C_f$** 一端接节点①、另一端接节点③。

由此构成"光电池（零偏近短路）+ 跨阻放大"组态，输入节点被钳在虚地使光电池工作于短路点，光生电流 $I_{ph}$ 全部流过 $R_f$，输出 $V_{out}=-I_{ph}R_f$，用于测光强或光伏功率。

## 工作原理
光电池的短路电流近似与入射光照度成正比。短路工作点下线性最好，故后级用跨阻放大器把输入节点钳在虚地（≈0 V），将光生电流 $I_{ph}$ 全部流过反馈电阻 $R_f$，转为输出电压 $V_{out} = -I_{ph} R_f$。

## 关键计算公式

- 输出电压（跨阻放大）：
$$V_{out} = -I_{ph} R_f$$

- 光生电流（短路电流）：
$$I_{ph} = S R \cdot E$$

- 带宽（跨阻放大器）：
$$f_c = \frac{1}{2\pi R_f C_f}$$

- 最大输出功率（光伏电池匹配负载）：
$$P_{max} = I_{mp} V_{mp}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{out}$ | 输出电压 | V |
| $I_{ph}$ | 光生电流 | A |
| $R_f$ | 反馈电阻 | Ω |
| $S R$ | 光谱响应度 | A/W |
| $E$ | 入射光功率 | W |
| $C_f$ | 反馈电容（相位补偿） | F |
| $P_{max}$ | 最大输出功率 | W |
| $I_{mp}$、$V_{mp}$ | 最大功率点电流、电压 | A、V |

## 元件调整影响
- **反馈电阻 $R_f$ 增大** → 输出电压 $V_{out} = -I_{ph} R_f$ 线性增大、灵敏度提高，但带宽 $f_c = 1/(2\pi R_f C_f)$ 降低、噪声与失调放大加剧。
- **反馈电容 $C_f$ 增大** → 相位裕度增加、稳定性变好，但带宽下降、响应变慢。
- **入射光功率 $E$ 增大** → 光生电流 $I_{ph} = SR \cdot E$ 线性增大，若超出运放输出摆幅则进入饱和。
- **运放输入偏置电流增大** → 对微小光电流引入更大误差，弱光检测需选低输入偏置运放。
- 反馈电阻换自感较小的薄膜/贴片电阻可减小并联寄生电容，避免高频自激。

## 典型参数示例
- 取 $SR = 0.5\ \text{A/W}$、$E = 1\ \text{mW}$：$I_{ph} = 0.5 \times 10^{-3} = 0.5\ \text{mA}$。
- 取 $I_{ph} = 0.5\ \text{mA}$、$R_f = 10\ \text{kΩ}$：$V_{out} = -0.5\times10^{-3} \times 10\times10^{3} = -5\ \text{V}$。
- 取 $R_f = 10\ \text{kΩ}$、$C_f = 10\ \text{pF}$：$f_c = 1/(2\pi \times 10^4 \times 10^{-11}) \approx 1.59\ \text{MHz}$。

## 常见器件型号
- 运算放大器（TIA）：OPA335、LTC6228、ADA4610、OPA2156。
- 光电池/光电二极管：BPW34、S2386、OSD15-5T。
- 反馈电阻：高精度薄膜电阻（如 0.1%、低 TCR 贴片）。

## 注意事项
- 跨阻放大输入节点被钳在虚地，必须保证光电池工作于短路/近短路点以获得最佳线性。
- 电源去耦与反馈电容要就近布局，防止跨阻放大自激振荡。
- 遮光、屏蔽与 PCB 漏电流会影响微弱光电流的测量精度。
- 运放输出摆幅与供电决定最大可测光强，超出后应减小 $R_f$ 或提高供电电压。
