# 红外对射检测电路

## 拓扑描述
由 **红外发射管（IR LED）$D_{LED}$** 与 **限流电阻 $R$** 组成发射链路，以及 **红外接收管（光电二极管/三极管）$Q_{rec}$**、**负载电阻 $R_L$** 与 **比较器** 组成接收链路。发射链共有 3 个关键节点：**节点① 发射电源节点**（+VCC 与 $R$ 的上端相连）；**节点② LED 阳极节点**（$R$ 的下端与 $D_{LED}$ 的阳极相连）；**节点③ 发射地节点**（$D_{LED}$ 的阴极接地 GND）。接收链共有 3 个关键节点：**节点④ 接收电源节点**（+VCC 与 $R_L$ 的上端相连）；**节点⑤ 接收输出节点**（$R_L$ 的下端、接收管的集电极/阴极与比较器输入相连，作为 $V_{out}$）；**节点⑥ 接收地节点**（接收管的发射极/阳极接地 GND）。

各元件管脚连接：发射端 **$R$** 一端接节点①、另一端接节点②，**$D_{LED}$** 阳极接节点②、阴极接节点③；接收端 **$R_L$** 一端接节点④、另一端接节点⑤，**$Q_{rec}$**（光电三极管）集电极 C 接节点⑤、发射极 E 接节点⑥（若为光电二极管则阳极接节点⑥、阴极接节点⑤），**比较器**输入接节点⑤。

由此构成"红外发射限流驱动 + 红外接收经 $R_L$ 成压 + 比较器阈值"的对射式开关组态，物体遮挡光路时接收信号骤降、比较器翻转输出，用于计数、报警与接近检测。

## 工作原理
红外 LED 发射的红外光被接收管接收，接收管产生光电流并在负载电阻上形成电压；当物体遮断光路时接收信号骤降，比较器与阈值比较后翻转输出，从而判断有无物体。

## 关键计算公式

- 红外 LED 限流：
$$I_{LED} = \frac{V_{CC} - V_F}{R}$$

- 占空比与平均电流（调制发射）：
$$I_{avg} = I_{LED} \cdot D$$

- 接收端输出电压：
$$V_{out} = I_p \cdot R_L$$

- 脉冲调制频率（抗环境光干扰常用 38 kHz）：
$$f_{mod} = \frac{1}{T}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I_{LED}$ | 发光管电流 | A |
| $V_{CC}$ | 电源电压 | V |
| $V_F$ | 红外管正向压降 | V |
| $R$ | 限流电阻 | Ω |
| $D$ | 占空比 | — |
| $R_L$ | 接收负载电阻 | Ω |

## 元件调整影响
- **R ↓** → I_LED 增大，发射更强、检测距离变远，但勿超过峰值电流。
- **R ↑** → 功耗降低，但检测距离变近。
- **调制频率/占空比调整** → 影响抗干扰能力与平均功耗。
- **接收负载 R_L ↑** → 灵敏度增大，但响应变慢、易误触发。

## 典型参数示例
- 取 $V_{CC}=5\ \text{V}$、$V_F=1.2\ \text{V}$、目标 $I_{LED}=20\ \text{mA}$：$R = \dfrac{5-1.2}{20\times10^{-3}} = 190\ \Omega$（取 200 Ω 标准值）。
- 调制发射占空比 $D=0.5$ 时：$I_{avg} = 20\times0.5 = 10\ \text{mA}$。

## 常见器件型号
- 红外发射管：TSAL6200（950 nm）、IR333。
- 接收头：VS1838B、HS0038（38 kHz 一体化接收头）。
- 比较器：LM393。

## 注意事项
- 采用 38 kHz 调制可有效抑制阳光、白炽灯等环境光干扰。
- 对射式响应快、距离远但对准要求高；易受高温物体红外辐射误触发。
- 发射管需限流，脉冲调制时注意峰值电流不超过器件额定值。
- 镜头脏污或误对准会导致灵敏度下降。
