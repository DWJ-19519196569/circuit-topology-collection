# MEMS加速度计电路

## 拓扑描述
由 **MEMS 电容式加速度传感内核**（一个微机械质量块—弹簧结构，质量块随加速度位移，带动一对差分检测电容）与 **片上信号调理与接口电路**（C/V 转换、放大、ADC 与 SPI/I²C 接口逻辑，作为一个单片集成电路芯片实现）组成。电路共有 6 个关键节点：**节点① 供电节点 VDD**（芯片供电脚 VCC/VDD 与片外去耦电容一端相连）；**节点② 地节点 GND**（芯片地脚 GND/VSS、去耦电容另一端与系统地相连）；**节点③ I²C 数据节点 SDA**（芯片 SDA/SDI 脚与一片外上拉电阻下端相连，为主控双向数据线）；**节点④ I²C 时钟节点 SCL**（芯片 SCL/SPC 脚与另一片外上拉电阻下端相连，为主控时钟线）；**节点⑤ 地址/数据输出节点 SDO/ALT**（芯片 SDO/ALT 脚，I²C 时接 VDD 或 GND 决定从机地址，SPI 时作为数据输出 MISO）；**节点⑥ 片选与中断节点**（芯片 CS 片选脚与 INT1/INT2 中断输出脚）。

各元件管脚连接：**MEMS 差分电容传感元件**的两条电容臂一端接固定电位、另一端各自作为 C/V 转换的传感桥臂；**片上调理电路**把该电容变化经 C/V 转换、放大与 ADC 数字化后，再经接口输出；**去耦电容**一端接供电节点 VDD、另一端接地节点 GND；芯片 **VCC/VDD** 接供电节点 VDD、**GND/VSS** 接地节点 GND、**SDA/SDI** 接 I²C 数据节点 SDA、**SCL/SPC** 接 I²C 时钟节点 SCL、**SDO/ALT** 接地址/数据输出节点 SDO/ALT、**CS** 接片选与中断节点中的片选端、**INT1/INT2** 接该节点的中断输出端；两片 **上拉电阻**上端接供电节点 VDD、下端分别接 SDA 与 SCL 数据/时钟线上；模拟输出型的 **Vout** 模拟输出脚接主控 ADC 输入。

由此构成"MEMS 电容式加速度传感内核 + 片上 C/V 转换、放大与 ADC + SPI/I²C 数字接口"的集成传感与数字输出组态，输出与加速度成比例的数字量；模拟输出型则经 Vout 输出与加速度成比例的模拟电压。

## 工作原理
加速度 → 质量块受惯性力偏移 → 差分电容间隙变化 → 片上调理电路将电容变化转为电压并数字化，输出与加速度成比例的数值。

## 关键计算公式

- 牛顿第二定律：
$$F = m a$$

- 电容检测位移（平面电容）：
$$\Delta C \propto \frac{\Delta x}{d}$$

- 灵敏度与输出：
$$V_{out} = S \cdot a$$

- 量程与分辨率（LSB）：
$$a_{res} = \frac{2\,Range}{2^{N}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $m$ | 质量块质量 | kg |
| $a$ | 加速度 | m/s² |
| $\Delta C$ | 电容变化 | F |
| $S$ | 灵敏度 | V/(m/s²) 或 LSB/g |
| $Range$ | 量程（±g） | g |
| $N$ | ADC 位数 | bit |

## 元件调整影响
- **量程配置 ↑** → 可测更大加速度，但每 LSB 分辨率变差。
- **输出数据率 ODR ↑** → 响应更快，但功耗与噪声增大。
- **去耦电容不足** → 电源噪声耦合到测量，加速度噪声增大。
- 模拟输出型的滤波电容影响带宽与噪声。

## 典型参数示例
- 量程 $\pm2g$、14 位有效分辨率：$a_{res}=\dfrac{2\times2}{2^{14}}\approx0.244\ \text{mg/LSB}$。
- 灵敏度 $S=1000\ \text{LSB/g}$ 时，读数 $a=1g$ 对应 1000 LSB。

## 常见器件型号
- MEMS 加速度计：ADXL345、LIS3DH、MPU6050（含陀螺）、BMI160。

## 注意事项
- 加速度计输出包含重力分量 g，静态倾角测量需区分重力与运动加速度。
- 放置位置尽量靠近目标测量点，机械谐振频率需高于测量带宽。
- 输出含噪声与零偏，需校准零偏与比例因子。
- 注意 PCB 应力传导与温漂对零偏的影响。
