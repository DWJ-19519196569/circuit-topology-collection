# 射频小信号放大电路

## 拓扑描述
以典型的**单管共射射频小信号放大级**为代表性实现，本电路由**一个射频小信号晶体管 $Q_1$（BJT，亦可为 FET）**、**输入匹配网络（串联耦合电容 $C_{in}$ 与并联电感 $L_1$）**、**输出匹配网络（并联电感 $L_2$ 与输出耦合电容 $C_{out}$）**、**基极偏置分压电阻 $R_1$、$R_2$**、**发射极电阻 $R_E$ 与旁路电容 $C_E$** 以及 **集电极电源扼流圈 $L_c$** 组成，工作在线性区（小信号模型）。电路共有 8 个关键节点：**节点① 输入节点**（信号源正端与 $C_{in}$ 一端相连）；**节点② 基极节点**（$C_{in}$ 另一端、$L_1$ 一端、$R_1$ 下端、$R_2$ 上端与 $Q_1$ 的基极 B 相连）；**节点③ 发射极节点**（$Q_1$ 的发射极 E、$R_E$ 上端、$C_E$ 上端相连）；**节点④ 集电极节点**（$Q_1$ 的集电极 C、$L_c$ 下端、$L_2$ 一端、$C_{out}$ 一端相连）；**节点⑤ 输出节点**（$C_{out}$ 另一端，送往负载）；**节点⑥ 电源节点 $+V_{CC}$**（$R_1$ 上端、$L_c$ 上端相连）；**节点⑦ 地节点 GND**（$L_1$ 另一端、$R_2$ 下端、$R_E$ 下端、$C_E$ 下端相连）。

各元件管脚连接：**$Q_1$** 的基极 B 接基极节点②、发射极 E 接发射极节点③、集电极 C 接集电极节点④；**$C_{in}$** 一端接输入节点①、另一端接基极节点②；**$L_1$** 一端接基极节点②、另一端接地节点⑦；**$R_1$** 一端接电源节点⑥、另一端接基极节点②；**$R_2$** 一端接基极节点②、另一端接地节点⑦；**$R_E$** 一端接发射极节点③、另一端接地节点⑦；**$C_E$** 一端接发射极节点③、另一端接地节点⑦；**$L_c$** 一端接电源节点⑥、另一端接集电极节点④；**$L_2$** 一端接集电极节点④、另一端接地节点⑦；**$C_{out}$** 一端接集电极节点④、另一端接输出节点⑤。

由此构成"信号经 $C_{in}$、$L_1$ 输入匹配耦合到基极、$Q_1$ 共射放大、集电极经输出匹配（$L_2$、$C_{out}$）向负载转移最大功率"的小信号射频放大组态，偏置网络建立合适静态工作点使其在线性区提供稳定增益且保持良好线性与低噪声。

## 工作原理
偏置网络给晶体管建立合适静态工作点，使其工作在线性放大区；交流信号经匹配网络耦合进入基极/栅极放大，再由输出匹配网络把放大后的信号以最大功率转移到负载。小信号下可用器件 S 参数或 h 参数模型设计。

## 关键计算公式

- 电压增益（BJT 共射，带负载）：
$$A_v = -g_m (R_C \parallel R_L)$$

- 跨导（BJT）：
$$g_m = \frac{I_C}{V_T},\qquad V_T \approx 26\ \text{mV（室温）}$$

- 功率增益（用 S 参数，匹配时）：
$$G_p = |S_{21}|^2$$

- 输入 / 输出反射与驻波：
$$VSWR = \frac{1+|\Gamma|}{1-|\Gamma|}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $A_v$ | 电压增益 | （无量纲） |
| $g_m$ | 跨导 | S |
| $I_C$ | 集电极静态电流 | A |
| $V_T$ | 热电压 | V |
| $R_C$ / $R_L$ | 集电极 / 负载电阻 | Ω |
| $S_{21}$ | 正向传输参数 | （无量纲） |
| $\Gamma$ | 反射系数 | （无量纲） |

## 元件调整影响
- **$I_C$ 增大** → $g_m$ 增大、增益升高，线性度与功耗上升。
- **$R_C$ 增大** → 增益升高，但输出摆幅减小、易进入饱和。
- **匹配网络失配** → 反射增大，$|S_{21}|$ 有效增益下降。
- **偏置分压电阻失配** → 工作点漂移，影响增益与线性。

## 典型参数示例
- 取 $I_C=5\ \text{mA}$：$g_m=\dfrac{5\times10^{-3}}{0.026}\approx 192\ \text{mS}$；取 $R_C=1\ \text{kΩ}$、$R_L\gg R_C$：$|A_v|\approx 192\times10^{-3}\times1000 = 192$（约 45.7 dB）。
- 若器件 $|S_{21}|^2=100$（20 dB），匹配良好时 $G_p=20\ \text{dB}$。

## 常见器件型号
- 晶体管：2SC3356、BFP640、BFR93A、2N3904（低频）。
- 集成 MMIC：MAR-6、SGA-6789、ABA52563。

## 注意事项
- 小信号假定线性，输入过强会压缩增益产生谐波与互调。
- 偏置去耦需良好，避免电源纹波串入射频通路。
- 匹配设计依赖器件 S 参数，需在目标频点核算稳定性。
