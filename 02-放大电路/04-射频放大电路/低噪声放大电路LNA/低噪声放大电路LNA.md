# 低噪声放大电路 LNA

## 拓扑描述
以典型的**单管共射（或共源）低噪声放大级**为代表性实现，本电路由**一个低噪声放大晶体管 $Q_1$（BJT，亦可为 HEMT/pHEMT/MOSFET）**、**输入匹配网络（串联电感 $L_1$ 与并联电容 $C_1$）**、**输出匹配网络（串联电感 $L_2$ 与输出耦合电容 $C_{out}$）** 与 **直流偏置网络（基极偏置电阻 $R_1$、$R_2$，发射极电阻 $R_E$、旁路电容 $C_E$，以及电源扼流圈 $L_c$）** 组成。电路共有 8 个关键节点：**节点① 输入节点**（天线接收到的信号源正端与 $L_1$ 一端相连）；**节点② 基极（噪声匹配）节点**（$L_1$ 另一端、$C_1$ 上端、$R_1$ 下端、$R_2$ 上端与 $Q_1$ 的基极 B 相连，此节点被匹配到最佳噪声源阻抗 $Z_{opt}$）；**节点③ 发射极节点**（$Q_1$ 的发射极 E、$R_E$ 上端、$C_E$ 上端相连）；**节点④ 集电极节点**（$Q_1$ 的集电极 C、$L_c$ 下端、$L_2$ 一端相连）；**节点⑤ 输出中间节点**（$L_2$ 另一端、$C_{out}$ 一端相连）；**节点⑥ 输出节点**（$C_{out}$ 另一端，送往混频/中放）；**节点⑦ 电源节点 $+V_{CC}$**（$R_1$ 上端、$L_c$ 上端相连）；**节点⑧ 地节点 GND**（$C_1$ 下端、$R_2$ 下端、$R_E$ 下端、$C_E$ 下端相连）。

各元件管脚连接：**$Q_1$** 的基极 B 接基极节点②、发射极 E 接发射极节点③、集电极 C 接集电极节点④；**$L_1$** 一端接输入节点①、另一端接基极节点②；**$C_1$** 一端接基极节点②、另一端接地节点⑧；**$R_1$** 一端接电源节点⑦、另一端接基极节点②；**$R_2$** 一端接基极节点②、另一端接地节点⑧；**$R_E$** 一端接发射极节点③、另一端接地节点⑧；**$C_E$** 一端接发射极节点③、另一端接地节点⑧；**$L_c$** 一端接电源节点⑦、另一端接集电极节点④；**$L_2$** 一端接集电极节点④、另一端接输出中间节点⑤；**$C_{out}$** 一端接输出中间节点⑤、另一端接输出节点⑥。

由此构成"输入经 $L_1$、$C_1$ 噪声匹配到 $Z_{opt}$、$Q_1$ 共射放大、输出经 $L_2$、$C_{out}$ 匹配到负载"的低噪声放大组态，前级低噪声与后级增益共同把整条接收链的噪声系数（Friis 公式）降到最低。

## 工作原理
天线接收的微弱信号经输入匹配网络送入有源器件放大。噪声匹配使有源器件工作在噪声系数最小的源阻抗下，先放大后接混频/中放，从而按 Friis 公式降低整条接收链的噪声系数，保证弱信号接收灵敏度。

## 关键计算公式

- 噪声系数（NF）：
$$F = \frac{SNR_{in}}{SNR_{out}},\qquad NF = 10\log_{10} F$$

- 级联系统噪声系数（Friis 公式）：
$$F_{total} = F_1 + \frac{F_2 - 1}{G_1} + \frac{F_3 - 1}{G_1 G_2} + \cdots$$

- 最佳噪声源阻抗匹配条件：$Z_S = Z_{opt}$（器件最佳噪声源阻抗），对应最小噪声系数 $F_{min}$。

- 功率增益（匹配时）：
$$G_p = \frac{P_{out}}{P_{in}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $F$ | 噪声系数 | （无量纲） |
| $NF$ | 噪声系数（dB） | dB |
| $F_1, F_2, \dots$ | 各级噪声系数 | （无量纲） |
| $G_1, G_2, \dots$ | 各级功率增益 | （无量纲） |
| $Z_{opt}$ | 最佳噪声源阻抗 | Ω |
| $P_{in}$ / $P_{out}$ | 输入 / 输出功率 | W |

## 元件调整影响
- **输入匹配更接近 $Z_{opt}$** → 噪声系数下降，但增益与驻波需权衡。
- **有源器件工作电流减小** → 噪声降低但增益与线性度下降。
- **偏置电流增大** → 线性度（IIP3）改善但功耗与噪声可能上升。
- **级联中 LNA 增益增大** → 后续级噪声贡献被稀释，系统 NF 降低。

## 典型参数示例
- 取 LNA 增益 $G_1=20\ \text{dB}$（100 倍）、$F_1=1.5\ \text{dB}$（约 1.41），后级混频 $F_2=10\ \text{dB}$（10）：$F_{total}=1.41+\dfrac{10-1}{100}=1.5\ \to\ NF_{total}\approx 1.76\ \text{dB}$。
- 若去掉 LNA（$F_1=10$ 直连混频），$NF=10\ \text{dB}$，可见 LNA 把整机 NF 从 10 dB 降到 1.76 dB。

## 常见器件型号
- 晶体管：2SC3356 / 2SC5551（BJT）、ATF-54143、BFP640、NE3512S02（HEMT）。
- 集成 LNA：BGU8x 系列（如 BGU8062）、SKY67151。

## 注意事项
- 输入匹配必须折中噪声匹配与功率匹配，二者难以同时最优。
- 前级 LNA 的增益与噪声直接决定整机灵敏度，布局需良好接地与屏蔽。
- 强输入下需有保护与线性度考虑，避免 LNA 饱和或损坏。
