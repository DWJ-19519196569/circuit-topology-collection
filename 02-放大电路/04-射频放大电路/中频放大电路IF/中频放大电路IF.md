# 中频放大电路 IF

## 拓扑描述
以典型的**单管共射调谐放大级 + 并联 LC 选频回路**为代表性实现，本电路由**一个放大晶体管 $Q_1$（BJT）**、**输入耦合电容 $C_{in}$**、**基极偏置分压电阻 $R_1$、$R_2$**、**发射极电阻 $R_E$ 与旁路电容 $C_E$**、**集电极并联选频回路（电感 $L_p$ 与电容 $C_p$ 并联）** 与 **输出耦合电容 $C_{out}$** 组成。电路共有 7 个关键节点：**节点① 输入节点**（上一级混频输出的信号源正端与 $C_{in}$ 上端相连）；**节点② 基极节点**（$C_{in}$ 下端、$R_1$ 下端、$R_2$ 上端与 $Q_1$ 的基极 B 四者相连）；**节点③ 发射极节点**（$Q_1$ 的发射极 E、$R_E$ 上端、$C_E$ 上端三者相连）；**节点④ 集电极/谐振节点**（$Q_1$ 的集电极 C、$L_p$ 上端、$C_p$ 上端、$C_{out}$ 一端相连）；**节点⑤ 输出节点**（$C_{out}$ 另一端，作为中频输出 $V_{out}$ 送往检波/解调）；**节点⑥ 电源节点 $+V_{CC}$**（$R_1$ 上端、$L_p$ 下端、$C_p$ 下端相连）；**节点⑦ 地节点 GND**（$R_2$ 下端、$R_E$ 下端、$C_E$ 下端相连）。

各元件管脚连接：**$Q_1$** 的基极 B 接基极节点②、发射极 E 接发射极节点③、集电极 C 接集电极节点④；**$C_{in}$** 一端接输入节点①、另一端接基极节点②；**$R_1$** 一端接电源节点⑥、另一端接基极节点②；**$R_2$** 一端接基极节点②、另一端接地节点⑦；**$R_E$** 一端接发射极节点③、另一端接地节点⑦；**$C_E$** 一端接发射极节点③、另一端接地节点⑦；**$L_p$** 一端接集电极节点④、另一端接电源节点⑥；**$C_p$** 一端接集电极节点④、另一端接电源节点⑥；**$C_{out}$** 一端接集电极节点④、另一端接输出节点⑤。

由此构成"信号经 $C_{in}$ 耦合到基极、集电极并联 LC 回路在固定中频谐振选频、$C_{out}$ 耦合输出"的单管共射单调谐中频放大组态，谐振点增益最大，实现窄带高选择性中频放大；多级实现时需保持各级调谐一致并做好级间去耦与屏蔽，防止中频自激。

## 工作原理
混频输出的中频信号经谐振回路选频，仅让中频附近窄带信号通过并放大，抑制镜像频率与邻道干扰；回路中心频率固定，增益在谐振点最大，获得窄带高选择性放大，之后送给检波 / 解调。

## 关键计算公式

- LC 谐振频率：
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 谐振回路品质因数：
$$Q = \frac{f_0}{BW} = \frac{R_{p}}{\omega_0 L} = \omega_0 R_p C$$

- 谐振增益（单管共射）：
$$A_v = -g_m R_p$$

- 带通带宽（-3 dB）：
$$BW = \frac{f_0}{Q}$$

- 多级矩形系数（选择性）：
$$k = \frac{BW_{60dB}}{BW_{3dB}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_0$ | 中频谐振频率 | Hz |
| $L$ / $C$ | 谐振电感 / 电容 | H / F |
| $Q$ | 品质因数 | （无量纲） |
| $R_p$ | 谐振回路等效并联电阻 | Ω |
| $g_m$ | 跨导 | S |
| $BW$ | 带宽 | Hz |

## 元件调整影响
- **$L$、$C$ 增大** → $f_0$ 下降，中频偏移。
- **$Q$ 增大（回路损耗减小）** → 带宽变窄、选择性提高、增益升高。
- **$R_p$ 减小（负载过重）** → $Q$ 与增益下降、带宽展宽。
- **级联级数增多** → 总增益与选择性上升、矩形系数接近理想，但易自激。

## 典型参数示例
- 取 $L=100\ \mu\text{H}$、$C=10\ \text{pF}$：$f_0=\dfrac{1}{2\pi\sqrt{100\times10^{-6}\times10\times10^{-12}}}\approx 5.03\ \text{MHz}$。
- 若 $Q=50$，则 $BW=\dfrac{5.03\times10^{6}}{50}\approx 100\ \text{kHz}$。

## 常见器件型号
- 中放芯片：TA7640AP、MC1350、NE592、TL026C。
- 陶瓷 / 晶体滤波器：455 kHz、10.7 MHz 标准件；晶体管：2SC1674、2N2222。

## 注意事项
- 中频滤波器带宽需匹配信号带宽，过窄削信号、过宽引入邻道干扰。
- 多级中放需级间去耦与屏蔽，防止中频自激。
- 谐振回路 Q 与负载阻抗相互牵制，需统筹增益、带宽与选择性。
