# C 类功率放大电路

## 拓扑描述
由 **一只功率放大晶体管 $Q$**（NPN）、**并联 LC 谐振回路**（电感 $L$、电容 $C$，作负载/选频网络）、**射频扼流圈 RFC**、**深截止偏置网络**（$R_{b1}$、$R_{b2}$ 或自生偏置）与 **负载 $R_L$** 组成，采用 **单电源 $V_{CC}$** 供电。电路共有 6 个关键节点：**节点① 输入节点**（输入射频信号 $V_{in}$ 经耦合接 $Q$ 的基极 B，偏置到深截止）；**节点② 地节点**（$Q$ 的发射极 E、$R_L$ 的下端、偏置网络接地端接 GND）；**节点③ 集电极节点**（$Q$ 的集电极 C、$L$ 的一端、$C$ 的一端相连）；**节点④ 谐振回路上端节点**（$L$ 的另一端与 $C$ 的另一端相连）；**节点⑤ 电源节点**（RFC 的一端接 +VCC，另一端接谐振回路上端节点）；**节点⑥ 输出节点**（并联谐振回路经耦合（变压器次级或电容分压）接 $R_L$ 的上端）。

各元件管脚连接：**$Q$** 的 B 接输入节点、C 接集电极节点、E 接地节点；**$L$** 一端接集电极节点、另一端接谐振回路上端节点；**$C$** 一端接集电极节点、另一端接谐振回路上端节点（$L$ 与 $C$ 并联成选频回路）；**RFC** 一端接电源节点、另一端接谐振回路上端节点；**$R_L$** 一端接输出节点、另一端接地节点。管子被偏置在深度截止区，导通角（半导通角）$\theta_c$ 远小于 90°，集电极电流为窄脉冲。

由此构成"晶体管深偏置截止、集电极电流为窄脉冲、经 LC 并联谐振回路选频后还原出基波正弦"的单管丙类（C 类）射频功放组态，效率随导通角减小而升高、理论极限趋近 100%，但非线性强，仅适合恒包络信号（如 FM、FSK）。

## 工作原理
静态时管子截止，输入射频信号仅在其正峰值附近把管子拉到导通，产生一连串窄电流脉冲；并联谐振回路在载波频率谐振，把这些脉冲中的基波分量选出、滤掉谐波，在负载上重建近似正弦输出。

## 关键计算公式

- 导通角 $\theta_c$ 定义：指晶体管在一个信号周期内导通对应的电角度（弧度制）；设管子正向导通角 $2\theta_c$（半导通角为 $\theta_c$），即仅当输入信号相位落入 $[-\theta_c,\ \theta_c]$ 时管子导通。C 类典型 $\theta_c$ 约 30°~60°（远小于 90°）。

- 导通角与效率关系（效率 $\eta$ 是导通角 $\theta_c$ 的函数，随导通角变化）：
$$\eta = \frac{2\theta_c - \sin(2\theta_c)}{4\left(\sin\theta_c - \theta_c\cos\theta_c\right)}$$

> 注：效率随导通角 $\theta_c$ 变化，需按实际导通角计算。

- C 类效率随导通角减小而升高，理论极限（$\theta_c \to 0$）：
$$\eta_{max} \to 100\%$$

- 输出功率（基波分量）：
$$P_o = \frac{V_{om} I_{1}}{2}$$

- 谐振频率（并联 LC 回路）：
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 回路有载品质因数：
$$Q_L = \frac{R_L}{\omega_0 L} = \omega_0 R_L C$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $\theta_c$ | 导通角（半导通角） | rad |
| $V_{om}$ | 输出基波电压峰值 | V |
| $I_1$ | 输出基波电流峰值 | A |
| $L$、$C$ | 谐振回路电感、电容 | H、F |
| $f_0$ | 谐振（载波）频率 | Hz |
| $Q_L$ | 有载品质因数 | — |

## 元件调整影响
- **导通角 $\theta_c$ ↓（偏置更深）** → 效率升高，但输出功率与增益下降。
- **导通角 $\theta_c$ ↑** → 输出功率增大、线性变好，但趋于 AB/B 类、效率下降。
- **$L$、$C$ 偏离谐振** → 输出减小、谐波增大、波形变差。
- **$Q_L$ ↑** → 谐波抑制好、波形纯，但带宽变窄且回路损耗增加。
- 谐振回路电容耐压须高于集电极电压摆幅。

## 典型参数示例
- 取导通角 $\theta_c=90^\circ=\pi/2$：代入效率式得 $\eta \approx 78.5\%$（与 B 类相同）；取 $\theta_c=60^\circ$ 时效率可超过 85%。
- 取 $L=1\ \mu\text{H}$、$C=25\ \text{pF}$：$f_0=\dfrac{1}{2\pi\sqrt{1\times10^{-6}\times25\times10^{-12}}}\approx 31.8\ \text{MHz}$。

## 常见器件型号
- 射频功率管：2N3866、2N2219、MRF4427、2SC1971。
- 双极射频管：BFQ19、BD135（较低频段）。
- LDMOS 射频管可按 C 类偏置使用于发射末级。

## 注意事项
- 只适合恒包络信号（FM、FSK），不能放大 AM 或宽带信号（会严重非线性失真）。
- 输入需足够驱动摆幅以克服深偏置。
- 谐振回路元件须高频低损耗，注意温漂引起的失谐。
- 输出需加滤波器抑制谐波，满足频谱规范。
