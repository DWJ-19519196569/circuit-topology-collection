# OCL 功率放大电路

## 拓扑描述
由 **一对互补对称的功率三极管**（上管 $Q_1$ 为 NPN、下管 $Q_2$ 为 PNP，亦可用互补 MOSFET）与 **负载电阻 $R_L$**（扬声器）组成，采用 **正、负双电源 ±VCC** 供电。电路共有 5 个关键节点：**节点① 输出节点（中点）**（$Q_1$ 的发射极 E、$Q_2$ 的发射极 E 与 $R_L$ 的上端三者相连）；**节点② 地节点**（$R_L$ 的下端接 GND）；**节点③ 正电源节点**（$Q_1$ 的集电极 C 接 +VCC）；**节点④ 负电源节点**（$Q_2$ 的集电极 C 接 −VCC）；**节点⑤ 输入驱动节点**（$Q_1$ 的基极 B 与 $Q_2$ 的基极 B 相连并接输入信号 $V_{in}$）。

各元件管脚连接：**$Q_1$（NPN）** 的 B 接输入驱动节点、C 接正电源节点、E 接输出节点；**$Q_2$（PNP）** 的 B 接输入驱动节点、C 接负电源节点、E 接输出节点；**$R_L$** 一端接输出节点、另一端接地节点。负载直接跨接在两管发射极中点与地之间，输出中点静态直流电位为 0 V，故无需输出耦合电容。

由此构成"双电源供电、两管发射极并接输出中点、负载接中点与地之间"的互补对称乙类（或甲乙类）推挽功放组态，两管轮流导通完成全周期功率放大，效率高、低频特性好。

## 工作原理
正半周时 NPN 管导通、PNP 管截止，电流从 +VCC 经 NPN 管流向负载；负半周时 PNP 管导通、NPN 管截止，电流从地经负载流向 −VCC。两管交替工作，负载上得到完整的正弦电流信号，实现功率放大。

## 关键计算公式

- 最大不失真输出功率（忽略管压降）：
$$P_{o\max} = \frac{V_{CC}^2}{2 R_L}$$

- 考虑管饱和压降 $V_{CE(sat)}$ 时的输出功率：
$$P_o = \frac{(V_{CC} - V_{CE(sat)})^2}{2 R_L}$$

- 输出峰值电流：
$$I_{o\max} = \frac{V_{CC}}{R_L}$$

- 理想（乙类）最大效率：
$$\eta_{\max} = \frac{\pi}{4} \approx 78.5\%$$

- 最大集电极耗散功率（每管）：
$$P_{C\max} \approx 0.2\, P_{o\max}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{CC}$ | 单边电源电压（±VCC） | V |
| $R_L$ | 负载电阻（扬声器阻抗） | Ω |
| $P_{o\max}$ | 最大不失真输出功率 | W |
| $V_{CE(sat)}$ | 功率管饱和压降 | V |
| $I_{o\max}$ | 输出峰值电流 | A |
| $\eta$ | 效率 | — |

## 元件调整影响
- **VCC ↑** → 最大输出功率 $P_{o\max}$ 按平方增大，但需校核管耐压与散热。
- **RL ↓** → 输出电流和输出功率增大，但对功率管电流能力与散热要求更高。
- **静态偏置电流 ↑** → 交越失真减小、由乙类趋近甲乙类，但静态功耗上升。
- 双电源不对称会使输出中点电位偏离 0 V，需保证正负电源对称。

## 典型参数示例
- 设 $V_{CC}=24\ \text{V}$、$R_L=8\ \Omega$：$P_{o\max}=\dfrac{24^2}{2\times8}=36\ \text{W}$。
- 设 $V_{CC}=12\ \text{V}$、$R_L=4\ \Omega$：$P_{o\max}=\dfrac{12^2}{2\times4}=18\ \text{W}$。

## 常见器件型号
- 功率对管：TIP41C/TIP42C、2SC5200/2SA1943、MJL3281A/MJL1302A。
- 集成功率 OCL：TDA2030A、LM1875、TDA7294。

## 注意事项
- 开机瞬间若无输出继电器保护，直流冲击可能损坏扬声器，需加延时保护。
- 中点直流偏移过大时需加直流伺服或电容负反馈消除。
- 功率管需足够散热器，双管热耦合可减小温漂引起的交越失真。
