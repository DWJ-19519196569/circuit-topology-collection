# 跨阻放大电路 TIA

## 拓扑描述
由 **一个运算放大器 A1**、**反馈电阻 $R_f$** 与 **反馈补偿电容 $C_f$**（$R_f$ 与 $C_f$ 并联）组成。电路关键节点：**电流输入节点（虚地）**（电流源 $I_{in}$ 的输出端、$R_f$ 左端、$C_f$ 左端、A1 的 IN− 相连）；**同相输入端节点**（A1 的 IN+ 直接接地 GND）；**输出节点**（A1 的 OUT、$R_f$ 右端、$C_f$ 右端相连，作为输出 $V_{out}$）。

各元件管脚连接：**$R_f$** 与 **$C_f$** 并联，两端分别接电流输入节点与输出节点；**A1** 的 IN− 接电流输入节点、IN+ 接地 GND、OUT 接输出节点、V+ 接 +VCC、V− 接 −VEE（单电源时 V− 接地）。

由此构成跨阻（电流－电压转换）组态：输入电流直接注入反相端（虚地），全部流过 $R_f$，输出 $V_{out}=-I_{in}R_f$。

## 工作原理
运放负反馈使反相输入端维持在虚地电位（约 0 V），输入电流全部流过 $R_f$，从而在输出端产生 $V_{out} = -I_{in} R_f$ 的电压。电流信号被直接"跨阻"转换为电压，输入阻抗极低，适合驱动容性电流源。

## 关键计算公式

- 跨阻增益（理想）：
$$V_{out} = -I_{in} \cdot R_f$$

- 跨阻（transimpedance）：
$$Z_T = \frac{V_{out}}{I_{in}} = -R_f$$

- 与光电二极管电容 $C_d$ 相关的带宽：
$$f_{-3dB} = \frac{1}{2\pi R_f C_f}$$

- 稳定补偿电容估算：
$$C_f = \sqrt{\frac{C_d}{2\pi R_f \cdot GBW}}$$

- 闭环噪声增益：
$$A_{CL} = 1 + \frac{R_f}{R_d}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_f$ | 反馈电阻（跨阻增益） | Ω |
| $C_f$ | 反馈补偿电容 | F |
| $C_d$ | 输入（光电二极管）结电容 | F |
| $GBW$ | 运放增益带宽积 | Hz |
| $I_{in}$ | 输入电流 | A |
| $V_{out}$ | 输出电压 | V |

## 元件调整影响
- **$R_f$ 增大** → 跨阻增益增大，但带宽下降、噪声与失调电压放大也增大。
- **$C_f$ 增大** → 带宽（$f_{-3dB}$）下降，但稳定性提高、可消除振铃。
- **$C_d$ 增大** → 需要更大的 $C_f$ 才能稳定，同时可用带宽下降。
- 选用 **GBW 更高的运放** → 可在同样增益下获得更宽带宽。

## 典型参数示例
- 取 $R_f = 10\ \text{kΩ}$，输入电流 $I_{in}=1\ \mu\text{A}$：$V_{out} = 1\times10^{-6} \times 10\times10^{3} = 10\ \text{mV}$。
- 取 $R_f = 1\ \text{MΩ}$、$C_f = 1\ \text{pF}$：$f_{-3dB} = \dfrac{1}{2\pi \times 10^{6} \times 10^{-12}} \approx 159\ \text{kHz}$。

## 常见器件型号
- 运放：OPA656、OPA657、OPA380、ADA4530-1（fA 级输入偏置，用于光电检测）。
- 反馈电阻：金属膜 / 精密薄膜电阻（1 MΩ ~ 10 GΩ）。

## 注意事项
- 高增益 TIA 需选用**低输入偏置电流（FET/CMOS 输入）**运放，否则偏置电流被 $R_f$ 放大造成失调。
- $R_f$ 大时反馈电容 $C_f$ 不可或缺，否则易自激振荡。
- 布局要短路径、大接地平面，避免光电二极管引线寄生电容与寄生反馈。
