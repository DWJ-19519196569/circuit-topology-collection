# 反相放大电路

## 拓扑描述
由 **一个运算放大器 A1**、**输入电阻 $R_1$**、**反馈电阻 $R_f$** 与 **平衡电阻 $R_2$** 组成。电路共有 4 个关键节点：**节点① 输入节点**（信号源 $V_{in}$ 的正端与 $R_1$ 上端相连）；**节点② 反相输入端节点（虚地）**（$R_1$ 下端、$R_f$ 左端、A1 的反相输入端 IN− 三者相连）；**节点③ 同相输入端节点**（A1 的同相输入端 IN+ 与 $R_2$ 上端相连）；**节点④ 输出节点**（A1 的输出端 OUT 与 $R_f$ 右端相连，作为电路输出 $V_{out}$）。

各元件管脚连接：**$R_1$** 一端接输入节点、另一端接反相输入端节点；**$R_f$** 一端接反相输入端节点、另一端接输出节点；**$R_2$** 一端接同相输入端节点、另一端接地 GND；**A1** 的 IN− 接反相输入端节点、IN+ 接同相输入端节点、OUT 接输出节点、正电源脚 V+ 接 +VCC、负电源脚 V− 接 −VEE（单电源时 V− 接地）。

由此构成"输入经 $R_1$ 到反相端、$R_f$ 跨接输出与反相端、同相端经 $R_2$ 接地"的反相放大组态，输出与输入反相，闭环增益为 $-R_f/R_1$。

## 工作原理
利用运放"虚短、虚断"：反相端电位被虚短拉到 0（虚地），输入电流 $I = \frac{V_{in}}{R_1}$ 全部经 $R_f$ 流向输出端，故 $V_{out} = -I R_f = -V_{in}\frac{R_f}{R_1}$，实现反相放大。

## 关键计算公式

- 电压增益（闭环）：
$$A_v = \frac{V_{out}}{V_{in}} = -\frac{R_f}{R_1}$$

- 输出电压：
$$V_{out} = -V_{in}\frac{R_f}{R_1}$$

- 输入电阻：
$$R_{in} = R_1$$

- 同相端平衡电阻（减小输入偏置电流引起的失调）：
$$R_2 = R_1 \parallel R_f = \frac{R_1 R_f}{R_1 + R_f}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_1$ | 输入电阻 | Ω |
| $R_f$ | 反馈电阻 | Ω |
| $R_2$ | 平衡电阻 | Ω |
| $A_v$ | 电压增益 | 倍（V/V） |
| $V_{in}$、$V_{out}$ | 输入 / 输出电压 | V |

## 元件调整影响
- **$R_f$ 增大 或 $R_1$ 减小** → 增益 $|A_v|$ 增大。
- **$R_1$ 决定输入阻抗**：$R_1$ 越大输入阻抗越高，但同等增益下 $R_f$ 也要更大，热噪声与失调会增大。
- 增益受运放**增益带宽积（GBW）**限制：信号频率越高，可获得的闭环增益越低。
- 输出摆幅不能超过运放电源电压范围，增益设置过大时会发生削波失真。

## 典型参数示例
- 取 $R_1=10\ \text{kΩ}$、$R_f=100\ \text{kΩ}$：$A_v = -10$。
- 取 $R_1=R_f=10\ \text{kΩ}$：$A_v = -1$（反相器）。
- 平衡电阻 $R_2 = 10\text{k} \parallel 100\text{k} \approx 9.1\ \text{kΩ}$。

## 常见器件型号
- 通用运放：LM358、LM324、TL072、TL084。
- 音频运放：NE5532、OPA2134。
- 精密运放：OP07、OPA2277。
- 电阻：1% 金属膜 / 薄膜电阻。

## 注意事项
- 反相输入阻抗较低（等于 $R_1$），前级需有足够驱动能力。
- 需接平衡电阻 $R_2$ 以减小输入偏置电流引起的失调。
- 增益受运放增益带宽积（GBW）与摆率限制，高频 / 大摆幅时易失真。
- 双电源运放需提供正负电源，单电源工作时需加直流偏置。
