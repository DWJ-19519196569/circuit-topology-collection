# 微分电路

## 拓扑描述
由 **一个运算放大器 A1**、**输入电容 $C$** 与 **反馈电阻 $R_f$** 组成（实际常再串入输入稳定电阻 $R_{in}$ 与反馈补偿电容 $C_f$）。电路共有 4 个关键节点：**输入节点**（信号源 $V_{in}$ 正端与 $C$ 左端相连）；**反相端节点（虚地）**（$C$ 右端、$R_f$ 左端、A1 的 IN− 相连）；**同相输入端节点**（A1 的 IN+ 直接接地 GND）；**输出节点**（A1 的 OUT 与 $R_f$ 右端相连，作为输出 $V_{out}$）。

各元件管脚连接：**$C$** 一端接输入节点、另一端接反相端节点；**$R_f$** 一端接反相端节点、另一端接输出节点；**A1** 的 IN− 接反相端节点、IN+ 接地 GND、OUT 接输出节点、V+ 接 +VCC、V− 接 −VEE（单电源时 V− 接地）。

由此构成反相微分组态：输入经 $C$ 耦合到反相端、$R_f$ 跨接输出与反相端，输出正比于输入电压的时间导数，用于提取信号变化率（边沿检测）。

## 工作原理
流过电容的电流 $i = C\,dV_{in}/dt$ 全部流过 $R_f$，在输出端产生 $V_{out} = -R_f C\,dV_{in}/dt$。输入变化越快，输出越大；输入恒定（直流）时电容阻断电流、输出为零。

## 关键计算公式

- 理想微分输出：
$$V_{out} = -R_f C \frac{dV_{in}}{dt}$$

- 频率响应（角频率域）：
$$H(j\omega) = -j\omega R_f C$$

- 相位（理想）：
$$\phi = -90^\circ$$

- 增益随频率（幅度）：
$$|V_{out}/V_{in}| = \omega R_f C$$

- 稳定补偿（限制高频增益）：
$$R_{in} C = R_f C_f$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C$ | 输入耦合电容 | F |
| $R_f$ | 反馈电阻 | Ω |
| $t$ | 时间 | s |
| $R_{in}$ | 输入稳定电阻 | Ω |
| $C_f$ | 反馈补偿电容 | F |

## 元件调整影响
- **$R_f$ 或 $C$ 增大** → 微分项系数 $R_f C$ 增大，同样变化率的输出幅度增大。
- **$R_f C$ 过大** → 高频增益过高，噪声被严重放大，甚至自激振荡。
- **输入串小电阻 $R_{in}$ 增大** → 高频增益被限制在 $R_f/R_{in}$，稳定性变好。
- **反馈并小电容 $C_f$ 增大** → 进一步压低高频，改善稳定性。

## 典型参数示例
- 取 $R_f=100\ \text{kΩ}$、$C=1\ \mu\text{F}$，输入斜率 $dV/dt = 1\ \text{V/ms}$：$V_{out} = -10^{5}\times10^{-6}\times10^{3} = -100\ \text{V}$（已超供电，实际受输出摆幅限制）。
- 常用微分量级：$R_f=100\ \text{kΩ}$、$C=10\ \text{nF}$，输入 $1\ \text{V/ms}$ 时 $V_{out}=-1\ \text{V}$。

## 常见器件型号
- 运放：LM358、TL072、OPA2277。
- 电容：C0G/NP0 或聚酯薄膜电容（低漏电、稳定）。

## 注意事项
- 纯理想微分电路对高频噪声极其敏感，实际必须加 $R_{in}$、$C_f$ 限制高频增益。
- 输出易受运放摆率、增益带宽积限制；输入突变时输出可能饱和。
- 电容漏电与运放输入偏置电流会造成直流漂移。
