# 限幅压缩电路

## 拓扑描述
限幅压缩电路由运放 $A_1$（增益受控级）、检波二极管 $D_1$、$D_2$、滤波/积分电容 $C_f$、时间常数电阻 $R_t$、增益设定电阻 $R_f$、$R_g$ 及阈值设定电位器 $P_t$ 组成。节点定义如下：输入节点 $N_{in}$ 接输入信号并分成两路；主通道输入节点 $N_{in1}$ 进入受控级；检波输入节点 $N_{det}$ 进入整流网络；包络/控制电压节点 $N_{ctl}$ 为整流滤波后的直流电平；门限节点 $N_{th}$ 为 $P_t$ 设定的阈值；输出节点 $N_{out}$ 为主通道输出；地节点 GND 汇集各支路冷端。

各元件管脚连接：运放 $A_1$ 的 IN− 经 $R_g$ 接 $N_{in1}$，IN+ 接 GND，OUT 接 $N_{out}$，V+、V− 分接正负电源，控制端接 $N_{ctl}$；反馈电阻 $R_f$ 一端接 $N_{out}$，另一端接 $N_-$；二极管 $D_1$ 阳极接 $N_{det}$、阴极接 $N_{ctl}$，$D_2$ 提供对称整流或倍压支路，阳极/阴极与 $D_1$ 反向并接于 $N_{det}$ 与 $N_{ctl}$ 之间；滤波电容 $C_f$ 一端接 $N_{ctl}$，另一端接 GND；时间常数电阻 $R_t$ 一端接 $N_{ctl}$、另一端接 GND（或构成充放电斜率）；电位器 $P_t$ 一端接参考电源、另一端接 GND、滑动端接 $N_{th}$，使 $N_{ctl}$ 超过 $N_{th}$ 后输出驱动压控增益。

该电路为"检波—滤波—压控增益"反馈型压缩器结构，$N_{ctl}$ 随电平升高而增大并反向压低 $A_1$ 增益，实现对动态范围的压缩与限幅。

## 工作原理
信号电平升高时，检波网络产生的控制电压增大，减小主通道增益，输出增幅被压缩；电平回落时增益恢复。检波采用对数规律近似 dB 压缩，实现对动态范围的压缩或对过载的硬限幅。

## 关键计算公式

- 压缩比（超过阈值后输入输出变化之比）：
$$R = \frac{\Delta L_{in}}{\Delta L_{out}} \quad \text{（单位 dB/dB）}$$

- 增益缩减量：
$$GR = L_{in} - L_{out} \quad \text{（} L_{in} > L_{th} \text{）}$$

其中压缩后输出电平满足 $L_{out} = L_{th} + \dfrac{L_{in} - L_{th}}{R}$，代入可写为 $GR = (L_{in} - L_{th})\left(1 - \dfrac{1}{R}\right)$。

- 检波时间常数（决定启动/恢复速度）：
$$\tau = RC$$

$$t_{attack} \approx 2.2 R_a C,\qquad t_{release} \approx 2.2 R_r C$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R$ | 压缩比 | （无量纲，dB/dB） |
| $L_{in}$ / $L_{out}$ | 输入 / 输出电平 | dB |
| $L_{th}$ | 阈值电平 | dB |
| $RC$ | 检波时间常数 | s |
| $t_{attack}$ / $t_{release}$ | 启动 / 恢复时间 | s |

## 元件调整影响
- **阈值设定电阻比 ⟶ 阈值升高** → 压缩介入输出电平更高。
- **检波电容 C 增大** → 启动、恢复时间变长，响应变慢，压缩更平稳。
- **检波电阻减小** → 恢复加快，可能引入低频失真（泵浦效应）。
- **压缩比设定电阻比增大** → 压缩越狠，极限趋于限幅。
- **增益控制范围（如 VCA 控制斜率）增大** → 最大压缩量增大。

## 典型参数示例
- 取阈值 $L_{th}=-20\ \text{dB}$、压缩比 $R=4:1$，输入 $L_{in}=0\ \text{dB}$：输出 $L_{out} = -20 + \dfrac{0-(-20)}{4} = -15\ \text{dB}$，增益缩减 $GR = L_{in} - L_{out} = 0 - (-15) = 15\ \text{dB}$。
- 取 $R_a=10\ \text{kΩ}$、$C=10\ \mu\text{F}$：$t_{attack}\approx 2.2\times 10^4\times 10^{-5}=0.22\ \text{s}$。

## 常见器件型号
- 运放：NE5532、TL072、OPA2134。
- 压控放大器（VCA）：THAT 2180 / 2181、SSM2164。
- 检波二极管：1N4148、1N914；JFET 变阻：J113、BF245。

## 注意事项
- 启动/恢复时间过短会产生低频“泵浦”失真；过长则电平波动明显。
- 检波需采用对数 / RMS 检波以匹配听觉响度，峰值检波适用于限幅保护。
- 非线性增益控制会引入谐波失真，音频用 VCA 需关注 THD 指标。
