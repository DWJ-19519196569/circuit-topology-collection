# 图示均衡电路 EQ

## 拓扑描述
图示均衡电路以单段"运放 $A_1$＋回旋器等效电感"的带通型为例，由运放 $A_1$、负反馈电阻 $R_f$、输入电阻 $R_i$、回旋器电容 $C_1$、回旋器电阻 $R_2$、$R_3$、$R_4$ 与频段调节电位器 $P_1$ 组成；多段时各段并联在公共母线上。节点定义如下：输入节点 $N_{in}$ 接信号源及 $R_i$；运放反相输入节点 $N_-$ 汇集 $R_i$ 与反馈支路；输出节点 $N_{out}$ 为运放输出；电位器中点节点 $N_p$ 为 $P_1$ 的滑动端；回旋器等效电感连接节点 $N_g$ 为运放 $A_1$ 与回旋器相连处；地节点 GND 汇集各电阻冷端与回旋器接地端。

各元件管脚连接：运放 $A_1$ 的 IN− 接 $N_-$，IN+ 接 GND，OUT 接 $N_{out}$，V+、V− 分接正负电源；输入电阻 $R_i$ 一端接 $N_{in}$，另一端接 $N_-$；反馈电阻 $R_f$ 一端接 $N_{out}$，另一端接 $N_-$；电位器 $P_1$ 一端接 $N_{out}$、另一端接 $N_-$、滑动端接 $N_p$；回旋器中电容 $C_1$ 一端接 $N_g$，另一端接 GND；电阻 $R_2$ 一端接 $N_g$、另一端接运放 $A_1$ 的输出（作为回旋器的同相正反馈电阻）；电阻 $R_3$、$R_4$ 构成分压把 $N_{out}$ 的电压反馈到 $N_g$ 与 $GND$，使回旋器呈现等效电感 $L_{eq}=R_1 R_2 C$。

该段拓扑为运放加回旋器模拟电感的带通谐振段，$P_1$ 在 $N_{out}$ 与 $N_-$ 之间滑动即改变该频段的提升/衰减量；多段并接叠加即构成图示均衡器。

## 工作原理
每个频段是一个中心频率固定的带通滤波/谐振网络，电位器改变该频段在带通内的提升或衰减量，其余频率基本不受影响。所有频段叠加后，用户可通过电位器位置直观看出曲线的形状，实现对频响的分段整形。

## 关键计算公式

- 各段中心频率（等比排列，相邻比为 $k$）：
$$f_{n+1} = k \cdot f_n$$

- 回旋器等效电感：
$$L_{eq} = R_1 R_2 C$$

- 谐振中心频率：
$$f_0 = \frac{1}{2\pi \sqrt{L_{eq} C}} = \frac{1}{2\pi C\sqrt{R_1 R_2}}$$

- 品质因数：
$$Q = \frac{f_0}{BW}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_0$ | 谐振中心频率 | Hz |
| $L_{eq}$ | 回旋器等效电感 | H |
| $R_1, R_2$ | 回旋器电阻 | Ω |
| $C$ | 谐振电容 | F |
| $Q$ | 品质因数 | — |
| $BW$ | 频段带宽 | Hz |

## 元件调整影响
- **R1 或 R2 ↑** → 等效电感增大，中心频率 $f_0$ 下降。
- **C ↑** → 中心频率下降，各段频率整体下移。
- **Q ↑** → 该段影响频带变窄，相邻频段重叠减小、调节更精细。
- 电位器处于中点时该段增益为 0 dB，两端分别对应最大提升与最大衰减。

## 典型参数示例
- 10 段图示均衡相邻频率比 $k=\sqrt[10]{\dfrac{20000}{31.25}}\approx2$（约按倍频程 31.25 Hz~20 kHz 排列）。
- 设 $R_1=R_2=10\ \text{kΩ}$、$C=100\ \text{nF}$：$f_0=\dfrac{1}{2\pi\times100\times10^{-9}\times\sqrt{10^4\times10^4}}\approx159\ \text{Hz}$。

## 常见器件型号
- 运放：NE5532、TL072、OPA2134、BA3812（专用图示均衡 IC）。
- DSP 数字均衡：ADAU1701、TI TAS5508。

## 注意事项
- 多段级联时注意相位叠加与噪声积累，应用低噪声运放。
- 回旋器受运放带宽限制，高频段 Q 与增益易偏差，需留裕量。
- 极端提升可能导致削波，需留足输出余量或加限幅。
