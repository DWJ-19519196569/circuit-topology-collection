# 音调控制电路

## 拓扑描述
由 **一个运算放大器 $A_1$**（或多个运放级）与 **RC 频率整形网络** 组成，低音段由 **电阻 $R_L$、电容 $C_L$** 与 **低音电位器 $P_L$** 构成 shelving（搁架式）网络，高音段由 **电阻 $R_H$、电容 $C_H$** 与 **高音电位器 $P_H$** 构成；另含 **输入电阻 $R_{in}$** 与 **反馈电阻 $R_f$**。电路共有 6 个关键节点：**节点① 输入节点**（输入信号 $V_{in}$ 经输入网络接入 $A_1$ 反相端）；**节点② 反相输入端节点（求和点）**（$A_1$ 的 IN− 与 $R_{in}$ 一端、$R_f$ 一端、低音网络一端、高音网络一端相连）；**节点③ 同相输入端节点**（$A_1$ 的 IN+ 接 GND 或参考电位）；**节点④ 输出节点**（$A_1$ 的 OUT 与 $R_f$ 另一端、低音网络另一端、高音网络另一端相连）；**节点⑤ 低音网络中间节点**（$R_L$、$C_L$、$P_L$ 构成的低音 shelving 分支内部两端）；**节点⑥ 地节点**（网络接地端与电位器滑臂参考端接 GND）。

各元件管脚连接：**$A_1$** 的 IN− 接反相输入端节点、IN+ 接同相输入端节点、OUT 接输出节点、V+ 接 +VCC、V− 接 −VEE；**$R_{in}$** 一端接输入节点、另一端接反相输入端节点；**$R_f$** 一端接反相输入端节点、另一端接输出节点；**$R_L$** 一端接反相输入端节点、另一端接低音网络中间节点；**$C_L$** 一端接低音网络中间节点、另一端接输出节点（与 $P_L$ 滑臂一起调节低音提升/衰减）；**$R_H$** 一端接反相输入端节点、另一端接高音网络中间节点；**$C_H$** 一端接高音网络中间节点、另一端接输出节点（与 $P_H$ 滑臂一起调节高音提升/衰减）；**$P_L$**、**$P_H$** 的一端与滑臂分别接对应网络节点、另一端接输出节点或地。

由此构成"运放负反馈环内接入低音 $R_L$-$C_L$ 与高音 $R_H$-$C_H$ 频率整形网络、电位器改变反馈量与输入分压"的有源音调控制组态，低音段由大时间常数的 RC 网络决定转折频率、高音段由小时间常数网络决定，对低频（bass）与高频（treble）幅度做可调提升或衰减，是均衡器（EQ）的基本单元。

## 工作原理
低频段由大时间常数的 RC 网络决定转折频率，高音段由小时间常数网络决定。当电位器滑臂移动时，反馈量与输入分压随之改变，使某频段增益被提升或衰减，而其他频段保持接近 0 dB，形成 shelving（搁架式）或 peaking（峰值式）响应。

## 关键计算公式

- 低音转折频率：
$$f_L = \frac{1}{2\pi R_L C_L}$$

- 高音转折频率：
$$f_H = \frac{1}{2\pi R_H C_H}$$

- 搁架滤波器传递函数（低通架）：
$$H(s) = \frac{1 + s/\omega_z}{1 + s/\omega_p}$$

- 最大提升增益（低频段）：
$$A_{bass,max} = 1 + \frac{R_{f}}{R_{in}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_L$ / $f_H$ | 低音 / 高音转折频率 | Hz |
| $R_L$ / $C_L$ | 低音段电阻 / 电容 | Ω / F |
| $R_H$ / $C_H$ | 高音段电阻 / 电容 | Ω / F |
| $\omega_z$ / $\omega_p$ | 零点 / 极点角频率 | rad/s |
| $A_{bass,max}$ | 低音最大提升增益 | （无量纲） |

## 元件调整影响
- **$C_L$ 增大** → 低音转折频率下降，低音增强范围下移。
- **$R_L$ 增大** → 低音转折频率下降。
- **$C_H$ 增大** → 高音转折频率下降，高频增强提前介入。
- **反馈比 $R_f/R_{in}$ 增大** → 最大提升/衰减量增大，调节范围变宽。
- 电位器滑臂平移改变零点与极点位置，从而改变提升斜率与频段范围。

## 典型参数示例
- 低音段取 $R_L=47\ \text{kΩ}$、$C_L=33\ \text{nF}$：$f_L = \dfrac{1}{2\pi\times 47000\times 33\times10^{-9}}\approx 103\ \text{Hz}$。
- 高音段取 $R_H=10\ \text{kΩ}$、$C_H=4.7\ \text{nF}$：$f_H \approx 3.4\ \text{kHz}$。

## 常见器件型号
- 运放：NE5532、TL072、OPA2134、LM4562。
- 电位器：B 型对数单联/双联电位器；电容：薄膜电容（WIMA、Poly）。

## 注意事项
- 使用对数（A 型）或线性（B 型）电位器需匹配电路设计，否则调节手感与范围不符。
- 级联多段 EQ 时相邻频段的重叠会影响整体响应，需统筹各段转折频率。
- 高提升量会带来噪声与相位畸变，实际 ≥ ±12 dB 时需关注稳定性与失真。
