# 线路放大电路

## 拓扑描述
由 **一个运算放大器 $A_1$**、**输入电阻 $R_{in}$（对地）**、**反馈电阻 $R_f$**、**接地增益电阻 $R_g$**、**输入隔直电容 $C_{in}$**、**输出隔直电容 $C_{out}$** 与 **下级负载 $R_L$** 组成，构成标准同相（或反相）放大电路，高阻信号源多用同相接法。电路共有 6 个关键节点：**节点① 输入节点**（信号源 $V_{in}$ 的正端经 $C_{in}$ 接节点②，$V_{in}$ 负端接 GND）；**节点② 同相输入端节点**（$C_{in}$ 的另一端、$R_{in}$ 的一端与 $A_1$ 的 IN+ 相连）；**节点③ 反相输入端节点**（$A_1$ 的 IN− 与 $R_f$ 一端、$R_g$ 上端相连）；**节点④ 输出节点**（$A_1$ 的 OUT 与 $R_f$ 另一端、$C_{out}$ 一端相连）；**节点⑤ 输出耦合节点**（$C_{out}$ 的另一端与下级负载 $R_L$ 上端相连，作为输出 $V_{out}$）；**节点⑥ 地节点**（$R_{in}$ 下端、$R_g$ 下端、$R_L$ 下端与 $V_{in}$ 负端接 GND）。

各元件管脚连接：**$A_1$** 的 IN+ 接同相输入端节点、IN− 接反相输入端节点、OUT 接输出节点、V+ 接 +VCC、V− 接 −VEE（单电源时接地）；**$C_{in}$** 一端接输入节点、另一端接同相输入端节点；**$R_{in}$** 一端接同相输入端节点、另一端接地节点；**$R_f$** 一端接反相输入端节点、另一端接输出节点；**$R_g$** 一端接反相输入端节点、另一端接地节点；**$C_{out}$** 一端接输出节点、另一端接输出耦合节点；**$R_L$** 一端接输出耦合节点、另一端接地节点。

由此构成"信号经 $C_{in}$ 送入同相端、$R_f$ 与 $R_g$ 构成负反馈、输出经 $C_{out}$ 隔直送往下级"的同相放大缓冲组态，增益约为 $1+R_f/R_g$，输出阻抗低，兼具阻抗变换与隔离作用，把约 −10 dBV~+4 dBu 的线路电平放大到下一级所需电平。

## 工作原理
信号经输入电阻进入运放，运放通过负反馈维持虚短/虚断，以固定增益放大信号。增益由两个电阻比值决定，运放的深度负反馈同时把输出阻抗压到很低，便于长线驱动后级负载。

## 关键计算公式

- 同相放大增益：
$$A_v = 1 + \frac{R_f}{R_i}$$

- 反相放大增益：
$$A_v = -\frac{R_f}{R_i}$$

- 输入耦合高通截止频率：
$$f_c = \frac{1}{2\pi R_{in} C_{in}}$$

- 增益带宽积限制的上限频率：
$$f_{max} = \frac{GBW}{A_v}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $A_v$ | 电压增益 | （无量纲） |
| $R_i$ | 输入电阻 | Ω |
| $R_f$ | 反馈电阻 | Ω |
| $C_{in}$ | 输入耦合电容 | F |
| $f_c$ | 高通截止频率 | Hz |
| $GBW$ | 增益带宽积 | Hz |

## 元件调整影响
- **$R_f$ 增大** → 增益升高、带宽下降。
- **$R_i$ 增大** → 同相增益下降、反相输入阻抗升高。
- **$C_{in}$ 增大** → 低频耦合截止频率降低，低频响应更深。
- **$R_{in}$ 增大** → 输入阻抗升高，但热噪声与偏置失调放大增大。

## 典型参数示例
- 同相接法取 $R_f=10\ \text{kΩ}$、$R_i=2\ \text{kΩ}$：$A_v = 1 + \dfrac{10000}{2000} = 6$（约 15.6 dB）。
- 取 $R_{in}=47\ \text{kΩ}$、$C_{in}=1\ \mu\text{F}$：$f_c = \dfrac{1}{2\pi\times 47000\times 10^{-6}}\approx 3.4\ \text{Hz}$。

## 常见器件型号
- 运放：NE5532、OPA2134、LM4562、TL072。
- 输入 / 输出耦合电容：铝电解或薄膜电容（WIMA、Nichicon）。

## 注意事项
- 增益电阻取值过大会引入热噪声，音频级常在 1 kΩ~100 kΩ 之间折中。
- 输入、输出需隔直耦合以防直流偏置进入后级；隔直电容影响低频响应。
- 输入级偏置电流会在较大输入电阻上产生失调，双极型运放宜加等值平衡电阻。
