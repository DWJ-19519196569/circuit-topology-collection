# 参数均衡电路

## 拓扑描述
参数均衡电路（以状态变量型 SVF 为例）由运放 $A_1$、$A_2$、$A_3$（或等效的多个运放级）、定值电阻 $R_1$、$R_2$、$R_3$、积分电容 $C_1$、$C_2$，以及三只电位器 $P_f$（中心频率）、$P_Q$（品质因数）、$P_G$（增益）构成。节点定义如下：输入节点 $N_{in}$ 接信号源与 $P_G$ 的一端；中间求和节点 $N_s$ 汇集 $P_G$ 滑动端、$P_Q$ 反馈支路与 $A_3$ 输出反馈；带通积分节点 $N_{bp}$ 为 $A_1$ 的输出端；低通积分节点 $N_{lp}$ 为 $A_2$ 的输出端；反相输出节点 $N_{out}$ 为末级 $A_3$ 的输出，经 $R_3$ 回馈到 $N_s$；地节点 GND 汇集各电阻分压支路的冷端与各运放电源地。

各元件管脚连接：运放 $A_1$ 的 IN− 接 $N_s$ 与 $R_1$，IN+ 接地，OUT 接 $N_{bp}$ 并经 $C_1$ 反馈回 IN−；运放 $A_2$ 的 IN− 经 $R_2$ 接 $N_{bp}$，IN+ 接地，OUT 接 $N_{lp}$ 并经 $C_2$ 反馈回 IN−；运放 $A_3$ 的 IN− 汇集 $N_{bp}$、$N_{lp}$ 与 $P_Q$ 反馈，IN+ 接地，OUT 接 $N_{out}$；各运放的 V+、V− 分别接正负电源。电位器 $P_f$ 用于设定积分器时间常数（中心频率），$P_Q$ 跨接在 $N_{bp}$ 与 $N_s$ 之间调节阻尼，$P_G$ 决定输入到 $N_s$ 的增益比例。

该电路为三运放状态变量（SVF）拓扑，通过两级积分与求和反馈实现中心频率、增益与 Q 三者独立可调的有源带通/带阻均衡。

## 工作原理
运放配合 RC 网络形成一个中心频率 $f_0$ 可调的带通/带阻网络，通过反馈比例决定对该频带的提升或衰减。调节“增益”电位器改变反馈量，从而改变谐振峰值幅值；调节“Q”电位器改变带宽，使同一中心频率下影响频率范围可宽可窄。

## 关键计算公式

- 中心频率（状态变量型，典型）：
$$f_0 = \frac{1}{2\pi RC}$$

> 说明：此式适用于状态变量型（SVF）积分器结构；其他拓扑（如模拟电感/gyrator 型）中心频率表达式不同，需按实际电路确定。

- 品质因数：
$$Q = \frac{f_0}{BW}\quad(\text{BW 为 -3 dB 带宽})$$

- 带宽：
$$BW = \frac{f_0}{Q}$$

- 增益（提升/衰减幅度，状态变量型）：
$$A_V = 1 + \frac{R_g}{R}$$

- 传递函数（通用二阶带通形式）：
$$H(s) = \frac{s\,\dfrac{\omega_0}{Q}}{s^2 + s\,\dfrac{\omega_0}{Q} + \omega_0^2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_0$ | 中心频率 | Hz |
| $\omega_0$ | 中心角频率（$2\pi f_0$） | rad/s |
| $Q$ | 品质因数 | — |
| $BW$ | -3 dB 带宽 | Hz |
| $R, C$ | 定时电阻、电容 | Ω、F |
| $A_V$ | 增益 | — |

## 元件调整影响
- **R 或 C ↑** → 中心频率 $f_0$ 下降。
- **Q ↑** → 带宽变窄，只影响更窄的一段频带，谐振峰更尖锐。
- **增益电位器 ↑** → 提升量增大（正增益），反相则变为衰减。
- 定时元件成组改变可移动中心频率，需保持各端点匹配以保证对称响应。

## 典型参数示例
- 设 $R=10\ \text{kΩ}$、$C=10\ \text{nF}$：$f_0=\dfrac{1}{2\pi\times10^4\times10\times10^{-9}}\approx1.59\ \text{kHz}$。
- 设 $f_0=1\ \text{kHz}$、$Q=2$：$BW=\dfrac{1000}{2}=500\ \text{Hz}$。

## 常见器件型号
- 运放：NE5532、TL072、OPA2134、SSM2164（VCA 控制）。
- 数字参数均衡常用 DSP：ADAU1701、ADAU1452。

## 注意事项
- 高 Q 值时电路易振荡，需留相位裕量与合适阻尼。
- 定时元件精度决定中心频率精度，需选用精度一致的电阻电容。
- 音频场合注意噪声与失真，选用低噪声运放。
