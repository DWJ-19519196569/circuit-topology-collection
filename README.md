# 电路拓扑收集

> 一个系统化的**电路拓扑知识库**，按功能与拓扑结构两级分类，收集常见电路的原理、计算公式、典型参数与器件选型，面向电子工程学习与设计参考。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)

## 📖 项目简介

本仓库收集各类电路拓扑（原理图、结构图），采用「**按功能分类为主、按拓扑结构归类为辅**」的两级体系，覆盖从电源、放大、振荡到数字、通信、保护、变流等 12 大类别、数百个电路单元。

每个「最小电路单元」都配有一份统一的 **8 节结构** 说明文档，便于快速查阅与对照学习。

## 📚 每个电路文档的 8 节结构

每个最小电路单元的说明文档统一为以下 8 节：

1. **拓扑描述** —— 元件组成、连接方式、功能用途
2. **工作原理** —— 信号 / 能量如何流动
3. **关键计算公式** —— 核心设计公式 + 符号单位表
4. **元件调整影响** —— 增大/减小某个 R / C / L 对电路的影响
5. **典型参数示例** —— 具体数值代入计算的结果
6. **常见器件型号** —— 真实通用型号
7. **注意事项** —— 实际设计 / 使用注意点
8. **参考资料** —— 权威来源（教材 / 维基百科 / 官方应用笔记）

个别极生僻电路的公式如暂无法确定，文档中会标注「待补充」，后续可在仿真验证后补全。

## 🧮 公式查看方法（LaTeX）

文档中的公式使用 LaTeX 语法（`$...$` 行内、`$$...$$` 独立公式）：

- **VS Code**：安装扩展 **"Markdown Preview Enhanced"**（或 "Markdown+Math"），然后用命令 `Markdown Preview Enhanced: Open Preview to the Side` 打开预览即可渲染。
- **Typora / Obsidian**：原生支持，直接打开即可渲染。
- 未安装任何扩展时，公式会显示为 `$...$` / `$$...$$` 原始文本，但文字内容仍可正常阅读。

## 🧭 使用建议

1. 每张电路图存为图片（PNG/JPG）或 PDF，放入对应功能分类。
2. 同名电路若对应不同拓扑结构，可同时放入「通用拓扑结构」或功能分类下的结构子目录。
3. 需要扩充时，直接在某功能分类下新建子文件夹即可，保持编号前缀便于排序。
