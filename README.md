# 电路拓扑收集

一个系统化的电路拓扑知识库：按「功能分类为主、拓扑结构归类为辅」的两级体系组织，收录 **483 份电路单元说明文档**，内容涵盖原理、关键计算公式、典型参数与器件选型，面向电子工程的学习与设计参考。

> 📄 本仓库文档为 **Word（.docx）** 格式；芯片手册等 PDF 资料属于本地资产，**未入库**（`.gitignore` 已忽略 `*.pdf`）。

---

## 📖 项目简介

- **两级分类**：一级按功能（电源、放大、振荡、滤波、数字、转换、驱动、传感器、通信、保护、变流、通用拓扑）划分；二级按具体拓扑结构划分。
- **最小电路单元**：每个「不再含子文件夹」的目录内，都有一份与目录同名的 `.docx` 说明文档。
- **统一结构**：每份文档固定为 8 节，便于快速查阅与横向对照。
- **覆盖范围**：12 大类、60 个二级子类、483 份文档。

## 📚 每份文档的 8 节结构

1. **拓扑描述** —— 元件组成、连接方式、功能用途
2. **工作原理** —— 信号 / 能量如何流动
3. **关键计算公式** —— 核心设计公式 + 符号单位表
4. **元件调整影响** —— 增大 / 减小某个 R、C、L 对电路的影响
5. **典型参数示例** —— 具体数值代入计算的结果
6. **常见器件型号** —— 真实通用型号
7. **注意事项** —— 实际设计与使用注意点
8. **参考资料** —— 权威来源（教材 / 维基百科 / 官方应用笔记）

> 个别生僻电路的公式若暂无法确定，文档中会标注「待补充」，可在仿真验证后补全。

## 🧭 使用建议

- 需要扩充时，直接在对应功能分类下新建「编号-名称」子文件夹，保持编号前缀便于排序。
- 同名电路若对应不同拓扑结构，可同时放入「通用拓扑结构」或功能分类下的结构子目录。
- 快速定位电路：先看 `电路索引.docx`，再按「一级功能 → 二级拓扑」进入对应目录。
