# 或非门电路（NOR 门）

## 拓扑描述
由**一个二输入或门 A1** 与**一个非门 A2** 级联组成，实现"先或后非"。电路共有 4 个关键节点：**节点① 输入节点 A**（外部输入信号 $A$ 与 A1 的 A 端相连）；**节点② 输入节点 B**（外部输入信号 $B$ 与 A1 的 B 端相连）；**节点③ 中间节点 S**（A1 的输出 Y 与 A2 的 A 端相连，携带 $A+B$）；**节点④ 输出节点 Y**（A2 的输出 Y 作为电路输出，携带 $\overline{A+B}$）。

各门管脚连接：**A1（或门）** 的 A 端接输入节点 A、B 端接输入节点 B、输出 Y 端接中间节点 S，正电源脚 VDD 接 $+V_{DD}$、接地脚 GND 接 GND；**A2（非门）** 的 A 端（输入端）接中间节点 S、输出 Y 端接输出节点 Y，正电源脚 VDD 接 $+V_{DD}$、接地脚 GND 接 GND。在 CMOS 实现中，A1 与 A2 合并为"两个 PMOS 串联、两个 NMOS 并联"的互补结构，即任一 NMOS 导通即把输出拉低，仅当所有输入为 0 时才由并联 PMOS 把输出拉高，此时只有一个 VDD 与一个 GND。

由此构成"或门输出再经非门取反"的二输入或非组态，输出 $Y=\overline{A+B}$，仅当所有输入都为 0 时输出为 1，其余输入组合输出为 0；由于 NOR 也是通用逻辑门，仅用或非门即可搭建任意逻辑功能。

## 工作原理
当任一输入为高电平 1 时输出为低电平 0，仅当所有输入都为 0 时输出才为 1。CMOS 中，任一 NMOS 导通即可把输出拉低，所有 PMOS 同时导通才把输出拉高，从而实现或非逻辑。

## 关键计算公式

- 二输入或非逻辑：
$$Y = \overline{A + B}$$

- 德摩根等价形式：
$$Y = \bar{A}\cdot\bar{B}$$

- n 输入或非：
$$Y = \overline{A_1 + A_2 + \cdots + A_n}$$

- 用 NOR 门表示非：
$$\bar{A} = \overline{A + A}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $A, B$ | 输入 | — |
| $Y$ | 输出 | — |

## 元件调整影响
- 属基本逻辑门，无模拟调整参数；驱动能力、速度取决于工艺与电源电压。
- 增大晶体管宽长比可提高驱动电流、加快翻转，但功耗与面积增大。
- 提高电源电压可加快速度，但功耗上升，需在 VDD 允许范围内。

## 典型参数示例
- 二输入真值表：当 $A=0,B=0$ 时 $Y=\overline{0+0}=1$；当 $A=1,B=0$ 时 $Y=\overline{1+0}=0$；$A=1,B=1$ 时 $Y=0$。

## 常见器件型号
- 74HC02（四 2 输入 NOR 门）、74LS02、CD4001（四 2 输入 NOR 门）、74HC27（三输入）。
- 可编程阵列：GAL22V10 等（可配置为实现 NOR 逻辑）。

## 注意事项
- 未使用输入端应按逻辑接 VDD 或 GND，避免悬空引起噪声与功耗问题。
- CMOS 输出摆幅接近满电源，TTL 输入阈值不同，混用时注意电平匹配。
- 高速翻转时注意去耦电容，降低开关噪声。
