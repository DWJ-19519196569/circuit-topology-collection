# 数值运算电路

## 拓扑描述
以**四个全加器 FA0~FA3** 与**四个异或门 X0~X3** 构成一个 4 位加减运算器（减法用补码加），作为包含加减乘除及逻辑运算的数值运算电路的代表性核心。电路共有 11 个关键节点：**节点①~④ 输入节点 $A_0\sim A_3$**（被加/被减数各位）；**节点⑤~⑧ 输入节点 $B_0\sim B_3$**（加/减数各位）；**节点⑨ 加减控制节点 M**（接各异或门另一输入端及最低位进位输入 $C_0$）；**节点⑩ 进位链节点 $C_0\sim C_3$**（各级进位/借位）；**节点⑪ 输出节点 $S_0\sim S_3$ 与进位输出 $C_4$**。

各单元管脚连接：**X_i（异或门）** 的一个输入端接 $B_i$、另一个输入端接加减控制节点 M，输出 Y 端接 FA_i 的 B 端；**FA_i（全加器）** 的 A 端接 $A_i$、B 端接 X_i 的输出、进位输入端 $C_i$ 接上一级进位输出（最低位接节点 M），和位输出端接 $S_i$、进位输出端接下一级进位（最高位作 $C_4$）。各单元正电源脚 VDD 接 $+V_{DD}$、接地脚 GND 接 GND。

由此构成"共用一组加法器，由异或门与进位输入切换加/减"的数值运算组态，加法直接逐位相加、减法按补码 $A-B=A+\bar B+1$ 完成；乘法用移位—加法阵列、除法用移位—减迭代、逻辑运算为逐位与/或/异或，是 ALU 与数字信号处理、数据通路的基础。

## 工作原理
减法通过把减数取补码后与被减数相加完成；乘法按“移位 + 累加”逐位完成部分积累加；除法用“移位 + 减 / 比较”反复迭代。逻辑运算是逐位并行处理，不涉及进位传递，速度最快。

## 关键计算公式

- n 位补码减法（$A-B$，用补码加）：
$$A - B = A + (-B) = A + \bar{B} + 1$$

- 无符号乘法（部分积累加）：
$$A \times B = \sum_{i=0}^{n-1} A \cdot b_i \cdot 2^i$$

- 二进制除法（移位—减）：
$$A = Q \times B + R, \qquad 0 \le R < B$$

- 逻辑运算逐位：
$$(A \text{ op } B)_i = A_i \text{ op } B_i$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $A, B$ | 运算操作数 | — |
| $\bar{B}$ | B 的按位取反 | — |
| $b_i$ | B 的第 i 位 | — |
| $Q, R$ | 商、余数 | — |

## 元件调整影响
- 字长增大 → 运算范围增大，但面积、延迟、功耗上升。
- 加法进位链越短（超前进位）→ 速度越快、逻辑越多。
- 乘法阵列规模随位宽平方增长，Booth 可减少加数项、降低面积。

## 典型参数示例
- 4 位补码减法：$A=0101_2(5)$，$B=0011_2(3)$。$\bar{B}=1100$，$A+\bar{B}+1 = 0101+1100+0001 = 0010_2 = 2$，即 $5-3=2$。
- 无符号乘法 $3\times5$：$0011 \times 0101 = 00001111_2 = 15$。

## 常见器件型号
- 74HC283（4 位全加器，用于加 / 减）、74LS181（4 位 ALU）、74LS182（超前进位发生器）。
- 乘法器 / MAC：TMS320 系列 DSP、FPGA 的硬核乘法器。

## 注意事项
- 减法用补码需统一字长并正确对待符号位，注意溢出检测。
- 乘法结果位宽翻倍，存储与寄存器需预留足够位宽。
- 组合乘 / 除器面积大、延迟高，高速场合宜加流水或时序实现。
