# 算术逻辑单元（ALU）

## 拓扑描述
由**一个算术单元 U1**（加法器/减法器）、**一个逻辑单元 U2**（与、或、异或、移位）、**一个功能选择译码器 D1** 与**一个输出多路选择器 U3**（MUX）构成算术逻辑单元（ALU）。电路共有 8 个关键节点：**节点① 操作数输入节点 A**（多位数据，并接 U1、U2 的 A 输入）；**节点② 操作数输入节点 B**（多位数据，并接 U1、U2 的 B 输入）；**节点③ 进位输入节点 $C_{in}$**（接 U1 的进位输入）；**节点④ 功能选择节点 S**（接 D1）；**节点⑤ 算术结果节点 R_A**（U1 的输出 Y）；**节点⑥ 逻辑结果节点 R_L**（U2 的输出 Y）；**节点⑦ 输出节点 R**（U3 的输出 Y，选 R_A 或 R_L）；**节点⑧ 标志节点**（零 Z、负 N、溢出 V、进位 $C_{out}$）。

各单元管脚连接：**U1** 的 A、B 数据脚分别接操作数节点 A、B，进位输入脚接进位输入节点 $C_{in}$，计算结果输出脚接算术结果节点 R_A，标志输出脚接标志节点（进位 $C_{out}$、溢出 V 等）；**U2** 的 A、B 数据脚分别接操作数节点 A、B，逻辑结果输出脚接逻辑结果节点 R_L；**D1** 的功能选择脚接功能选择节点 S，译码输出的选通信号接 U3 的选择端；**U3** 的多路数据输入分别接算术结果节点 R_A 与逻辑结果节点 R_L，输出脚接输出节点 R。各单元正电源脚 VDD 接 $+V_{DD}$、接地脚 GND 接 GND。

由此构成"功能选择码经译码后由多路选择器挑选算术或逻辑结果"的 ALU 组态，输出 $R=A\ \mathrm{op}\ B$（加减运算用补码 $R=A+B+C_{in}$ 或 $A+\bar B+1$，逻辑运算逐位进行），同时输出零、负、溢出、进位等标志供后续控制与跳转判断使用；典型器件如 74LS181。

## 工作原理
功能选择码通过译码控制内部多路选择器，把 A、B 送入对应的算术或逻辑运算路径，得到结果；加减由加法器实现（减法用补码加），逻辑运算逐位并行完成。结果连同状态标志一并输出，供后续控制与跳转判断使用。

## 关键计算公式

- 算术运算（加 / 减，减法用补码）：
$$R = A + B + C_{in} \quad \text{或} \quad R = A + \bar{B} + 1$$

- 逻辑运算（逐位）：
$$R = A \text{ AND/OR/XOR } B$$

- 进位 / 借位标志：
$$C_{out} = \text{最高位进位}$$

- 溢出标志（有符号数同符号相加符号翻转）：
$$V = C_{n} \oplus C_{n-1}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $A, B$ | 两个操作数 | — |
| $C_{in}, C_{out}$ | 进位输入 / 输出 | — |
| $R$ | 运算结果 | — |
| $V$ | 溢出标志 | — |

## 元件调整影响
- 功能选择码位数决定支持的操作种类，扩展选择码可增加功能。
- 采用超前进位 / 并行前缀结构可提升加法速度，降低 ALU 关键路径延迟。
- 位宽增大 → 运算范围增大，但面积与延迟上升。

## 典型参数示例
- 8 位 ALU 执行减法 $7-3$：$A=00000111$，$\bar{B}+1 = \overline{00000011}+1 = 11111101$，$R = 00000111 + 11111101 = 00000100_2 = 4$，零标志 Z=0、进位标志反映借位。

## 常见器件型号
- 74LS181（4 位 ALU）、74HC181、74LS382（4 位 ALU）。
- CPU 结构参考：MC68000、8086、以及 FPGA 中可综合的 ALU IP 核。

## 注意事项
- 功能选择码与数据需稳定在建立 / 保持时间内，避免运算出错。
- 减法 / 比较的结果标志（进位、零、符号、溢出）含义随器件而定，需核对。
- 高速设计中 ALU 常是时序关键路径，可加流水寄存器提升频率。
