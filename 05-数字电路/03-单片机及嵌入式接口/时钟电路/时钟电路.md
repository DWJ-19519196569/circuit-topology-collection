# 时钟电路

## 拓扑描述
向单片机等数字器件提供稳定系统时钟的电路，常见结构有 **晶振（Crystal）Y1 + 两个负载电容** 的皮尔斯振荡器、**陶瓷谐振器**，以及只需外接电阻电容的 **RC 振荡器**。晶振两脚分接两个对地负载电容，再接入芯片的 XTAL1/XTAL2 引脚，构成并联谐振回路。电路共有 4 个关键节点：**节点① XTAL1 引脚节点**（晶振一脚、C1 上端与 MCU 的 XTAL1 相连）；**节点② XTAL2 引脚节点**（晶振另一脚、C2 上端与 MCU 的 XTAL2 相连）；**节点③ 地节点 GND**（C1、C2 下端与 MCU 地）；**节点④ 电源节点 $+V_{DD}$**（芯片振荡电路供电）。

各元件管脚连接：**晶振 Y1** 一脚接节点①、另一脚接节点②；**负载电容 C1** 一端接节点①、另一端接节点③（GND）；**负载电容 C2** 一端接节点②、另一端接节点③（GND）；**MCU** 的 XTAL1 脚接节点①、XTAL2 脚接节点②、地脚 GND 接节点③、正电源脚 VCC 接节点④。两个负载电容通常取相等值，且需满足 $C_L=\frac{C_1C_2}{C_1+C_2}+C_{stray}$ 与晶振标称负载电容匹配，其中 $C_{stray}$ 为走线与引脚寄生电容（约 $3\sim5\ \text{pF}$）。芯片内部的反相放大器作为负阻跨接在节点①、② 之间，抵消晶振损耗以维持振荡。

由此构成晶振在串联谐振频率附近呈感性、与 C1/C2 构成并联谐振回路的皮尔斯振荡组态，经芯片内部整形与分频，为 CPU、定时器、通信外设提供统一系统时钟。

## 工作原理
晶振作为极高 Q 值的压电谐振器件，在串联谐振频率附近呈现感性，与负载电容构成并联谐振并维持振荡。芯片内部的反相放大器提供负阻以抵消晶振的损耗，使振荡持续；信号再经内部整形与分频得到所需的系统时钟。

## 关键计算公式

- 负载电容（两电容串联）：
$$C_L = \frac{C_1 C_2}{C_1 + C_2} + C_{stray}$$

- 皮尔斯振荡器增益裕度（负阻条件）：
$$g_m \geq \frac{q_{crit}}{ESR},\quad q_{crit} = 4\,ESR\,(2\pi f)^2\left(C_0 + C_L\right)^2$$

- 谐振频率（若有外部串联或并联电容微调）：
$$f = f_s\left(1 + \frac{C_1'}{2\,(C_0 + C_L)}\right)$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_1,\ C_2$ | 两个负载电容 | F |
| $C_L$ | 等效负载电容 | F |
| $C_0$ | 晶振并联（静态）电容 | F |
| $C_{stray}$ | 布线及引脚寄生电容 | F |
| $ESR$ | 晶振等效串联电阻 | Ω |
| $f_s$ | 晶振串联谐振频率 | Hz |
| $g_m$ | 振荡器跨导 | S |

## 元件调整影响
- **负载电容 $C_1$、$C_2$ 增大** → $C_L$ 增大，起振更稳定，但实际振荡频率略微拉低、起振时间变长。
- **负载电容过小** → 起振困难、波形畸变，甚至不起振。
- **ESR 过大（晶振老化/误选型）** → 损耗增大，相位裕度不足，振荡不稳定或停振。
- 两个负载电容通常取相等，且应包含 PCB 走线与引脚寄生电容（约 3~5 pF）的影响。

## 典型参数示例
- 12 MHz 晶振，$C_1 = C_2 = 22\ \text{pF}$，寄生电容 $C_{stray} = 5\ \text{pF}$：
$$C_L = \frac{22 \times 22}{22 + 22} + 5 = 11 + 5 = 16\ \text{pF}$$
- 典型 32.768 kHz 表晶负载电容为 12.5 pF，配 $C_1 = C_2 \approx 15\ \text{pF}$。

## 常见器件型号
- 晶振：HC-49S、5032 贴片晶振、3225 贴片晶振。
- 表晶：32.768 kHz 圆柱晶振（如 3×8 mm）。
- 陶瓷谐振器：村田（Murata）CSTCE/CSTCR 系列。
- 负载电容：C0G/NP0 贴片电容（精度 ±5%）。

## 注意事项
- 晶振及负载电容应尽量靠近芯片引脚，走线短而对称，远离大电流开关走线。
- 负载电容值须与晶振标称 $C_L$ 匹配，实际 $C_L$ 包含 PCB 寄生电容，需按数据手册微调。
- 晶振周围做地隔离环（guard ring），避免数字噪声串扰。
- 上电后应校验起振时间与频率精度，必要时加匹配电阻或减小 $C_L$。
