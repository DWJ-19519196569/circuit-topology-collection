# OLED 显示接口电路

## 拓扑描述
由 **OLED 显示模组 U1**（内含 SSD1306/SSD1315 驱动芯片）与 **主机 MCU** 组成，通过 I²C 或 SPI 总线连接。若采用 I²C 接口，电路共有 5 个关键节点：**节点① 时钟线 SCL**（MCU 的 SCL 脚、模组 SCL 脚与上拉电阻三者相连）；**节点② 数据线 SDA**（MCU 的 SDA 脚、模组 SDA 脚与上拉电阻三者相连）；**节点③ 上拉电源端**（两支上拉电阻接 $+V_{DD}$ 的一端）；**节点④ 电源节点**（MCU 供电与模组 VCC）；**节点⑤ 地节点 GND**。若采用 SPI 接口，则改用 **SCLK、MOSI、CS、DC**（可选 RES）四根信号线，另配电源与地。

各元件管脚连接（I²C 模式）：**主机 MCU** 的 SCL 脚接节点①、SDA 脚接节点②、正电源脚 VCC 接节点④ 的 $+V_{DD}$、地脚 GND 接节点⑤；**OLED 模组（SSD1306）** 的 SCL 脚接节点①、SDA 脚接节点②、VCC 脚接节点④、GND 脚接节点⑤；**两支上拉电阻 $R_{pu}$**（常用 $4.7\ \text{kΩ}$）一端均接节点③ 的 $+V_{DD}$，另一端分别接节点①（SCL）与节点②（SDA），为开漏总线提供高电平。若改为 SPI 模式，则 **MCU** 的 SCK 脚接模组 SCLK、MOSI 脚接模组 MOSI、GPIO 接模组 CS 与 DC、GPIO 或复位脚接模组 RES，模组 VCC/GND 同样接节点④/⑤。

由此构成 MCU 经 I²C（或 SPI）总线向 OLED 驱动芯片写入命令与数据、由芯片刷新 GDDRAM 显存并驱动点阵显示的组态，用于显示字符与图形。

## 工作原理
MCU 通过总线向驱动芯片发送命令字节与数据字节；驱动芯片把收到的数据写入内部 GDDRAM 显存，再由其内部时序逻辑逐行刷新 OLED 像素，从而在屏幕上呈现文字与图像。

## 关键计算公式

- I²C 上拉电阻取值范围（保证上升沿斜率与驱动能力）：
$$R_{min} = \frac{V_{DD} - V_{OL}}{I_{OL}},\qquad R_{max} = \frac{t_r}{0.8473\, C_b}$$

- I²C 时钟（标准/快速模式）：
$$f_{SCL} \le 400\ \text{kHz}$$

- 一帧刷新所需时间（N 为帧字节数）：
$$t_{frame} = \frac{N \times 8}{f_{SCL}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_{min}$ | 上拉电阻下限 | Ω |
| $R_{max}$ | 上拉电阻上限 | Ω |
| $V_{DD}$ | 电源电压 | V |
| $V_{OL}$ | 输出低电平 | V |
| $I_{OL}$ | 输出低电平灌电流 | A |
| $t_r$ | 信号上升时间 | s |
| $C_b$ | 总线寄生电容 | F |
| $f_{SCL}$ | 串行时钟频率 | Hz |

## 元件调整影响
- **上拉电阻 R↑** → 上升沿变慢（$t_r$ 增大），高速模式下可能无法满足时序。
- **上拉电阻 R↓** → 低电平灌电流增大，功耗上升，过小可能超过器件 $I_{OL}$ 承受能力。
- **总线寄生电容 C↑** → 上升时间增大，可用最大时钟频率下降。
- **$f_{SCL}$↑** → 刷新更快，但对走线、上拉和主机时序要求更苛刻。

## 典型参数示例
- 取 $V_{DD}=3.3\ \text{V}$、$V_{OL}=0.4\ \text{V}$、$I_{OL}=3\ \text{mA}$：$R_{min}=\dfrac{3.3-0.4}{3\times10^{-3}}\approx 967\ \text{Ω}$，工程上常用 $4.7\ \text{kΩ}$ 上拉。
- 128×64 单色 OLED，一帧 $N=1024$ 字节，$f_{SCL}=400\ \text{kHz}$：$t_{frame}=\dfrac{1024\times8}{400\times10^3}\approx 20.5\ \text{ms}$。

## 常见器件型号
- 驱动芯片：SSD1306、SSD1315、SH1106。
- 模组：0.96 英寸 128×64 OLED（I²C/SPI 版）。
- 上拉/外设电平：常用 4.7 kΩ 上拉；电平转换可用 TXS0102（I²C 3.3 V↔5 V）。

## 注意事项
- OLED 模组工作电压多为 3.3 V，接 5 V 系统需确认容忍电平或加电平转换。
- I²C 的 SDA/SCL 必须接上拉电阻，否则总线无法输出高电平。
- 首次初始化需按驱动芯片手册发送完整的上电指令序列。
- 长时间静态高亮显示会加速 OLED 老化，建议加入屏保或移位显示。
