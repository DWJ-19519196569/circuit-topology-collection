# 矩阵键盘电路

## 拓扑描述
由 **m 行 × n 列的按键阵列** 组成，每根行线与每根列线的交叉处接一个 **按键开关 S$_{ij}$**，行线与列线分别接到 MCU 的若干 GPIO 口，行线通常接 **上拉电阻**。电路共有 $m+n$ 个关键节点：**行线节点 ROW$_1\!\sim\!$ROW$_m$**（MCU 的 m 个 GPIO 口与各按键一端）；**列线节点 COL$_1\!\sim\!$COL$_n$**（MCU 的 n 个 GPIO 口与各按键另一端）；每个按键 S$_{ij}$ 跨接在行线 ROW$_i$ 与列线 COL$_j$ 之间。

各元件管脚连接：**每个按键 S$_{ij}$** 一脚接行线 ROW$_i$、另一脚接列线 COL$_j$；**MCU** 用 m 个 GPIO 分别接行线 ROW$_1\!\sim\!$ROW$_m$、用 n 个 GPIO 分别接列线 COL$_1\!\sim\!$COL$_n$，电源脚 VDD 接 $+V_{DD}$、地脚 GND 接 GND；**行线上拉电阻**（每行一支，也可用 MCU 内部上拉）一端接 $+V_{DD}$、另一端接各自的行线 ROW$_i$，把行线拉高。扫描时 MCU 依次把某一行置低、其余行保持为高，再读取所有列电平，若某列读到低即判定该行列交叉处的按键被按下，配合消抖解析出唯一键值。

由此构成"m 行 n 列按键交叉阵列、行/列线分接 GPIO、行加上拉、逐行扫描+消抖读键"的矩阵键盘组态，用 $m+n$ 个 I/O 支持 $m\times n$ 个按键，相比独立按键大幅节省引脚。

## 工作原理
采用逐行（或逐列）扫描：MCU 依次把某一行置为低电平、其余行保持高电平，然后读取所有列的电平，若某列读到低电平即表示该行列交叉处的按键被按下，配合消抖后解析出唯一键值。

## 关键计算公式

- 所需 I/O 数量与可支持按键数：
$$N_{key} = m \times n \quad(\text{占用 } m + n \text{ 个 I/O})$$

- 扫描一轮所需时间（$t_{row}$ 为单行检测耗时）：
$$t_{scan} = m \times t_{row}$$

- 行上拉电阻静态电流：
$$I = \frac{V_{DD}}{R_{pull}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $m$ | 行数 | — |
| $n$ | 列数 | — |
| $N_{key}$ | 按键总数 | — |
| $t_{scan}$ | 扫描一轮时间 | s |
| $t_{row}$ | 单行检测时间 | s |
| $R_{pull}$ | 行上拉电阻 | Ω |
| $V_{DD}$ | 电源电压 | V |
| $I$ | 静态电流 | A |

## 元件调整影响
- **矩阵规模 m、n 增大** → 可支持更多按键，但扫描周期变长、软件开销增大。
- **扫描频率提高** → 按键响应更及时，但易误触发，需配合合理消抖。
- **上拉电阻 R↑** → 省电，但边沿变缓、抗干扰变弱。
- **无二极管时多键同按** → 可能产生“鬼键”串扰，需软件防护或加二极管。

## 典型参数示例
- 4×4 矩阵：$N_{key}=4\times4=16$ 个按键，仅占用 $4+4=8$ 个 I/O。
- 单行检测 $t_{row}=1\ \text{ms}$、$m=4$：$t_{scan}=4\times1=4\ \text{ms}$。

## 常见器件型号
- 按键：6×6 轻触开关、机械按键。
- 隔离二极管（防鬼键）：1N4148。
- MCU：STM32F1、STC89C52 等 GPIO。

## 注意事项
- 扫描与消抖要结合，通常连续两次/多次采样一致才确认按键。
- 多键同时按下会产生“鬼键”，需在按键串接二极管或软件屏蔽。
- 行线接上拉电阻；若 MCU 支持内部上拉可省去外部电阻。
- 注意扫描时引脚方向的切换，防止多个输出同时占线造成电平冲突。
