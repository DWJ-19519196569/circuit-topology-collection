# I2C 接口电路

## 拓扑描述
I2C（Inter-Integrated Circuit，两线式串行总线）接口电路由 **SCL 串行时钟线** 与 **SDA 串行数据线** 两条开漏（Open-Drain）信号线组成，每条线经一个 **上拉电阻 Rp** 接正电源，多个器件（主机与从机）并联在同一对线上。电路共有 5 个关键节点：**节点① 时钟线 SCL**（主机 SCL、各从机 SCL 与 SCL 上拉电阻三者相连）；**节点② 数据线 SDA**（主机 SDA、各从机 SDA 与 SDA 上拉电阻三者相连）；**节点③ 上拉电源端**（两支上拉电阻接 $+V_{DD}$ 的一端）；**节点④ 电源节点 $+V_{DD}$**；**节点⑤ 地节点 GND**。

各元件管脚连接：**主机** 的 SCL 脚接节点①、SDA 脚接节点②、电源脚 VCC 接节点④、地脚 GND 接节点⑤；**各从机** 的 SCL 脚接节点①、SDA 脚接节点②、电源脚 VCC 接节点④、地脚 GND 接节点⑤；**两支上拉电阻 $R_p$** 一端均接节点③ 的 $+V_{DD}$，另一端分别接节点①（SCL）与节点②（SDA），为开漏总线提供高电平。总线上拉电阻取值满足 $R_{p\min}=\frac{V_{DD}-V_{OL\max}}{I_{OL}}$ 与 $R_{p\max}=\frac{t_r}{0.8473\,C_b}$，上升时间 $t_r=0.8473\,R_p C_b$。总线空闲时两线均被上拉为高电平，主机在节点① 的 SCL 上产生时钟，器件按起始/停止条件与每字节应答（ACK）位完成寻址与传输；标准速率 100 kbps、快速 400 kbps、快速+ 1 Mbps、高速 3.4 Mbps。

由此构成"两条开漏信号线 SCL/SDA 各配上拉电阻、多主机多从机并联共享、以起止条件加应答寻址"的 I²C 组态，用于板内传感器、EEPROM、PMIC 等短距低速通信。

## 工作原理
主机在 SCL 上产生时钟，在 SDA 上通过开漏下拉/释放驱动高低电平：器件拉低 SDA 表示逻辑 0，释放后由上拉电阻拉回高电平表示逻辑 1。总线空闲时两线均为高电平；起始/停止条件与每字节后的应答（ACK）位完成寻址与数据传输。开漏结构允许多器件共享总线而不冲突。

## 关键计算公式

- 上拉电阻下限（保证驱动能力，$C_b$ 为总线电容，$V_{OL\max}=0.4$ V）：
$$R_{p\min} = \frac{V_{DD} - V_{OL\max}}{I_{OL}}$$

- 上拉电阻上限（保证上升沿时间内充电）：
$$R_{p\max} = \frac{t_r}{0.8473\, C_b}$$

- 总线上升时间（标准 $t_r$ 上限 300 ns / 快速 300 ns / 高速 120 ns）：
$$t_r = 0.8473\, R_p C_b$$

- 位速率与时钟周期的关系：
$$f = \frac{1}{t_{SCL}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{DD}$ | 电源电压（1.8/3.3/5 V） | V |
| $V_{OL}$ | 低电平输出电压 | V |
| $I_{OL}$ | 输出灌电流 | A |
| $R_p$ | 上拉电阻 | Ω |
| $C_b$ | 总线等效电容 | F |
| $t_r$ | 上升时间 | s |
| $f$ | 位速率 | Hz |

## 元件调整影响
- **Rp ↑** → 上升时间变长、总线变慢，但功耗降低；过大则无法在速率要求内完成上升。
- **Rp ↓** → 上升加快、支持更高速率，但灌电流与功耗增大，过小可能低于 $R_{p\min}$。
- **总线电容 Cb ↑**（器件多、走线长）→ 上升时间增大，需减小 Rp 或降低速率。
- **VDD 电平不匹配** 时各器件逻辑阈值不同，需电平转换避免误判。

## 典型参数示例
- 设 $V_{DD}=3.3\ \text{V}$、$I_{OL}=3\ \text{mA}$：$R_{p\min}=\dfrac{3.3-0.4}{0.003}\approx967\ \Omega$。
- 设 $t_r=300\ \text{ns}$（快速模式）、$C_b=200\ \text{pF}$：$R_{p\max}=\dfrac{300\times10^{-9}}{0.8473\times200\times10^{-12}}\approx1.77\ \text{kΩ}$。

## 常见器件型号
- I2C 电平转换/缓冲：TCA9517、PCA9306、LTC4316。
- 上拉电阻：4.7 kΩ（标准）、2.2 kΩ（快速模式）。
- 常见 I2C 从机：AT24C02（EEPROM）、PCF8574（IO 扩展）。

## 注意事项
- 上拉电阻必须接同一电源轨，走线长或器件多时适当降低阻值。
- 需加入起始/停止、应答与器件地址正确时序；7 位地址最多 112 个地址，10 位扩址。
- 与 5 V/3.3 V/1.8 V 器件混合时使用电平转换，避免逻辑阈值不匹配。
