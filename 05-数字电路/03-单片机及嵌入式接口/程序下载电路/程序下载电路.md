# 程序下载电路

## 拓扑描述
由 **目标 MCU 的编程接口引脚**（如 ISP、UART 引导、SWD、JTAG）与 **下载器/上位机** 连接而成，通常配 **电平转换器**、**复位控制电路** 与必要的 **上拉电阻**，或经 **USB 转串口芯片**（如 CH340、CP2102）与 PC 相连。电路共有 4 类关键节点：**节点① 通信信号线**（SWD 的 SWDIO/SWCLK、UART ISP 的 TXD/RXD、SPI/ISP 的 SCK/MOSI/MISO、JTAG 的 TCK/TMS/TDI/TDO）；**节点② 复位控制线**（下载器 nRESET 与 MCU 复位脚）；**节点③ 电源节点**（供电 $+V_{DD}$ 与目标 VDD）；**节点④ 地节点 GND**。

各元件管脚连接：**目标 MCU** 的编程接口脚接节点① 对应信号线、复位脚 NRST 接节点②、电源脚 VDD 接节点③、地脚 GND 接节点④；**下载器（ST-Link、J-Link 等）** 的对应信号脚接节点①、nRESET 脚接节点②、VCC 与 GND 分别接节点③、④；**USB 转串口芯片（CH340/CP2102）** 的 USB 侧 D+/D− 接 PC，TTL 侧 TXD/RXD 接节点① 的 UART ISP 引脚；**电平转换器（TXS0102 等）** 在 TTL 与目标电平之间翻译信号并接入节点① 的数据线；节点① 上按需加 **上拉电阻** $R_{pull}\approx\frac{V_{DD}}{I_{pull}}$ 保证空闲电平。下载时按 MCU 规定的引导/调试协议经节点① 通信，并由节点② 配合复位进入编程/引导模式，写入固件并校验。

由此构成"下载器/上位机经编程接口（SWD、UART ISP、JTAG 等）按协议写入固件并配合复位"的程序下载组态，用于把程序烧录进 MCU 的 Flash 或外部存储器。

## 工作原理
下载器按 MCU 规定的编程协议（ISP 命令、引导程序或调试接口时序）与芯片通信，先进入编程/引导模式（常配合复位），再逐块写入目标存储并校验，完成后复位进入正常运行。

## 关键计算公式

- 编程时钟周期：
$$t_{prog} = \frac{1}{f_{prog}}$$

- 总烧录时间（N 字节、速率 B）：
$$t_{total} = \frac{N \times 8}{B}$$

- 上拉电阻选择（同 UART/调试接口）：
$$R_{pull} \approx \frac{V_{DD}}{I_{pull}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_{prog}$ | 编程/下载时钟频率 | Hz |
| $t_{prog}$ | 时钟周期 | s |
| $N$ | 程序字节数 | — |
| $B$ | 下载速率 | bit/s |
| $R_{pull}$ | 上拉电阻 | Ω |
| $V_{DD}$ | 电源电压 | V |
| $I_{pull}$ | 上拉电流 | A |

## 元件调整影响
- **下载速率/时钟↑** → 烧录更快，但对线缆质量、时序余量要求更高。
- **上拉电阻 R↑** → 功耗小，但边沿变慢，高速下载可能失败。
- **上拉电阻 R↓** → 边沿陡、抗干扰好，但功耗增大。
- **线缆长度↑** → 信号衰减，需降低下载速率以保证可靠。

## 典型参数示例
- 取 $f_{prog}=4\ \text{MHz}$（SWD）：$t_{prog}=\dfrac{1}{4\times10^6}=250\ \text{ns}$。
- 烧录 $N=64\ \text{kB}$ 程序、串口下载速率 $B=115200$ bps：$t_{total}=\dfrac{65536\times8}{115200}\approx4.55\ \text{s}$。

## 常见器件型号
- 下载器：ST-Link/V2、J-Link、USB 转串口 CH340/CP2102、USBAsp。
- 目标：STM32（SWD）、STC（UART ISP）、AVR（ISP）。
- 电平匹配：74LVC245、TXS0102。

## 注意事项
- 需按芯片手册配置正确的引导/编程模式脚位与复位时序。
- 下载接口引脚若被复用，需保留可供调试器访问的连线。
- 供电电压与接口电平需匹配，防止损坏下载器或 MCU。
- 下载线尽量短且接好 GND，必要时降低时序频率。
