# FIFO 先入先出电路

## 拓扑描述
由**双端口存储阵列 $M$**（$2^n$ 个字、每字 $m$ 位）、**写指针寄存器 $W_P$**、**读指针寄存器 $R_P$**（各为 $n$ 位计数器）、**地址译码器**、**读写控制逻辑**与**满/空标志生成逻辑**组成。电路共 9 个关键节点：**节点① 写数据输入节点 $D_{in}$**（外部写入数据，接存储阵列的数据写入端）；**节点② 读数据输出节点 $D_{out}$**（存储阵列的数据读出端，作为电路输出）；**节点③ 写时钟节点 $WCLK$**（接写指针与写控制逻辑）；**节点④ 读时钟节点 $RCLK$**（接读指针与读控制逻辑）；**节点⑤ 写使能节点 $WEN$**（接写指针与写控制）；**节点⑥ 读使能节点 $REN$**（接读指针与读控制）；**节点⑦ 复位节点 $RST$**（接两个指针清零端）；**节点⑧ 满标志节点 $FULL$**；**节点⑨ 空标志节点 $EMPTY$**（由标志生成逻辑输出）。

各单元管脚连接：**存储阵列 $M$** 的写数据脚接 $D_{in}$、读数据脚接 $D_{out}$、写地址脚 $A_w$ 接写指针 $W_P$ 的输出、读地址脚 $A_r$ 接读指针 $R_P$ 的输出；**写指针 $W_P$** 的时钟脚接 $WCLK$、使能脚接 $WEN$、清零脚接 $RST$，其 $n$ 位输出 $A_w$ 接存储阵列写地址脚；**读指针 $R_P$** 的时钟脚接 $RCLK$、使能脚接 $REN$、清零脚接 $RST$，其 $n$ 位输出 $A_r$ 接存储阵列读地址脚；**读写控制逻辑** 接收 $WEN$、$REN$ 产生读写控制信号；**标志生成逻辑** 同时接入 $W_P$ 与 $R_P$ 的输出并比较，产生 $FULL$ 与 $EMPTY$；各单元 $V_{DD}$ 接 $+V_{CC}$、$GND$ 接地。

由此构成"双端口指针式 RAM 缓冲"组态，写入口地址与读出口地址独立推进，数据按写入顺序从队头读出，并由指针差值产生满/空标志，实现先入先出功能。

## 工作原理
写操作使写指针递增并写入数据；读操作使读指针递增并读出数据。两个指针之差即当前队列中的有效数据个数，指针相撞时产生“空”或“满”标志。异步 FIFO 用格雷码指针跨时钟域同步，避免亚稳态。

## 关键计算公式

- 占用深度（当前数据量）：
$$N_{\text{used}} = (W_{\text{ptr}} - R_{\text{ptr}}) \bmod 2^n$$

- 空标志条件：
$$W_{\text{ptr}} = R_{\text{ptr}}$$

- 满标志条件：
$$(W_{\text{ptr}} + 1) \bmod 2^n = R_{\text{ptr}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $W_{\text{ptr}}$ | 写指针 | — |
| $R_{\text{ptr}}$ | 读指针 | — |
| $n$ | 指针/地址比特数 | — |
| $N_{\text{used}}$ | 已占用深度 | — |

## 元件调整影响
- **深度（地址位数 n）增大** → 可缓存更多数据，但存储面积与指针比较逻辑增大。
- **写速率大于读速率持续过久** → FIFO 会写满，数据溢出丢失。
- **读写时钟不同步** → 须用格雷码指针与双触发器同步，否则满/空标志出错。
- **标志产生滞后** → 空/满标志通常滞后一拍，控制逻辑需预留余量。

## 典型参数示例
- 一个 256 深、8 bit 宽的 FIFO：$n=8$，总容量 $2^8=256$ 个字。若写指针=100、读指针=80，则 $N_{\text{used}}=(100-80)=20$ 个字。
- 异步 FIFO 常用于 50 MHz 写域到 25 MHz 读域的跨时钟数据缓冲。

## 常见器件型号
- 常用：按需选型（FIFO 多以 IP 核或 FPGA 资源实现，如 Xilinx/Intel FIFO IP）。
- 独立芯片：IDT72V 系列、SN74V 系列同步 FIFO（具体型号按深度/宽度选型）。

## 注意事项
- 依据读写速率差估算最小 FIFO 深度，防止溢出或读空。
- 异步 FIFO 必须用格雷码指针，避免多位指针同时翻转导致同步错误。
- 满/空标志需提前使用（如空标志在“几乎空”时预判），避免一拍延迟出错。
