# T 触发器电路

## 拓扑描述
由**一个 JK 触发器 $FF$**将 $J$、$K$ 两输入短接后得到（也可在 SR 锁存器基础上加反馈构成），是单输入边沿触发的时序单元。电路共 5 个关键节点：**节点① 翻转控制输入节点 $T$**（外部控制输入，同时接到 $FF$ 的 $J$、$K$ 脚）；**节点② 时钟节点 $CLK$**（接 $FF$ 的时钟脚）；**节点③ 输出节点 $Q$**（$FF$ 的输出端，作为电路输出）；**节点④ 反相输出节点 $\overline Q$**（$FF$ 的互补输出脚）；**节点⑤ 电源/地节点**（$V_{DD}$ 与 $GND$）。

各单元管脚连接：**$FF$**（JK 触发器）的 $J$ 脚与 $K$ 脚并接后接翻转控制节点 $T$，时钟脚 $CLK$ 接时钟节点 $CLK$，输出脚 $Q$ 接输出节点 $Q$、互补脚 $\overline Q$ 接反相输出节点 $\overline Q$，正电源脚 $V_{DD}$ 接 $+V_{CC}$、地脚 $GND$ 接地。$T=1$ 时等价于 $J=K=1$，每个时钟有效边沿翻转一次，输出频率为时钟的一半；$T=0$ 时 $J=K=0$，输出保持。

由此构成"单输入翻转（toggle）触发器"组态，$T=1$ 时每时钟翻转、$T=0$ 时保持，常用作计数与二分频。

## 工作原理
时钟边沿到来时，若 $T=0$ 输出保持；若 $T=1$ 输出翻转。翻转本质是 JK 触发器的 $J=K=1$ 情形。把 T 恒接高电平，输出即每时钟翻转一次，形成二分频器。

## 关键计算公式

- 特征方程：
$$Q^{n+1} = T \oplus Q^n = T\,\overline{Q^n} + \overline{T}\,Q^n$$

- 二分频（T 恒为 1）：
$$Q^{n+1} = \overline{Q^n}$$

- 输出频率与时钟频率关系：
$$f_Q = \frac{f_{\text{CLK}}}{2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $T$ | 翻转控制输入 | — |
| $Q^n$ | 现态 | — |
| $Q^{n+1}$ | 次态 | — |
| $f_Q$ | 输出频率 | Hz |
| $f_{\text{CLK}}$ | 时钟频率 | Hz |

## 元件调整影响
- **T 恒接高** → 每时钟翻转，构造二分频 / 二进制计数器。
- **T 接低** → 输出保持，电路等效于静态寄存器。
- **时钟频率升高** → 受触发器传播延迟制约，最高分频频率有限。
- **多级 T 触发器级联** → 输出依次二分频，构成二进制计数器的高低位。

## 典型参数示例
- 二分频：$T=1$，输入时钟 $4~\text{MHz}$，则输出 $f_Q = \frac{4~\text{MHz}}{2}=2~\text{MHz}$。
- 特征方程验证：$Q^n=0, T=1$，则 $Q^{n+1}=1\oplus 0 = 1$，完成翻转。

## 常见器件型号
- 常用：按需选型（独立 T 触发器较少，多用 JK 触发器 J、K 短接实现）。
- 基础实现：74HC73 / 74HC76（JK 触发器接成 T 触发器）、CD4027。

## 注意事项
- T 触发器与 JK 触发器关系密切，常用 JK 触发器短接 J、K 实现。
- 用于计数/分频时注意多级级联的时钟方向（同步/异步）。
- 确保 T 与时钟满足建立/保持时间。
