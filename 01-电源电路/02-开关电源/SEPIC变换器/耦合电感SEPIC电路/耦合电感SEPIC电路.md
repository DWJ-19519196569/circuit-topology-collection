# 耦合电感 SEPIC 电路

## 拓扑描述
电路由绕于同一磁芯的耦合电感（含输入绕组 L1 与第二绕组 L2）、耦合电容 Cs、开关管 S、二极管 D 与输出电容 C 组成。关键节点如下：输入节点 $V_{in}$ 接耦合电感输入绕组 L1 的同名端（入端）；开关节点 SW 由 L1 的异名端（出端）、开关管 S 的漏极与耦合电容 Cs 的上端相连而成；中间节点由 Cs 的下端、二极管 D 的阳极与第二绕组 L2 的入端相连而成；输出节点 $V_{out}$ 由二极管 D 的阴极与输出电容 C 的上端相连并接负载，输出电容 C 的下端与 L2 的出端、开关管 S 的源极一并接地。

各元件管脚连接：耦合电感输入绕组 L1 一端接输入节点、另一端接开关节点；第二绕组 L2 一端接中间节点、另一端接地（两绕组同名端方向需按纹波抵消要求匹配）；开关管 S 的漏极接开关节点、源极接地、栅极 G 接控制信号；耦合电容 Cs 一端接开关节点、另一端接中间节点；二极管 D 的阳极接中间节点、阴极接输出节点；输出电容 C 一端接输出节点、另一端接地。

就组态而言，这是把 SEPIC 的两个独立电感合并为耦合电感的耦合电感 SEPIC 电路，通过磁耦合使两个绕组电流纹波相互抵消，保持升降压与输出同极性的同时减小体积、改善纹波与 EMI。

## 工作原理
开关管导通时输入绕组储能，耦合电容经开关管向第二绕组放电；关断时两绕组电流经二极管向输出释放能量。由于两绕组磁耦合，其电流纹波相位相反、部分抵消，输入纹波电流显著减小，甚至接近零纹波。

## 关键计算公式

- 理想电压增益（CCM）：
$$V_{out} = \frac{D}{1-D} V_{in}$$

- 耦合系数：
$$k = \frac{M}{\sqrt{L_1 L_2}}$$

- 输入纹波电流（耦合后大幅减小，理想 k=1 且匝比合适时趋近零）：
$$\Delta I_{in} \approx \frac{V_{in}D}{f_s L_1}(1-k)$$

- 输出纹波电压：
$$\Delta V_{out} = \frac{I_{out} D}{f_s C}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $L_1$ | 输入绕组电感 | H |
| $L_2$ | 第二绕组电感 | H |
| $M$ | 互感 | H |
| $k$ | 耦合系数 | — |
| $C$ | 输出电容 | F |
| $I_{out}$ | 输出电流 | A |

## 元件调整影响
- **k↑（耦合更紧）** → 输入纹波电流减小，EMI 更小。
- **L1、L2↑** → 各绕组纹波电流减小。
- **匝比 N（L2/L1）↑** → 影响电流均衡与纹波抵消程度，需与占空比匹配。
- **Cs↑** → 耦合电容纹波减小。
- **C↑** → 输出电压纹波减小。

## 典型参数示例
- 取 $V_{in}=5\ \text{V}$、$D=0.5$：$V_{out} = \dfrac{0.5}{1-0.5}\times5 = 5\ \text{V}$。
- 取 $f_s=500\ \text{kHz}$、$L_1=10\ \mu\text{H}$、$V_{in}=5\ \text{V}$、$D=0.5$、$k\approx1$：$\Delta I_{in} \approx \dfrac{5\times0.5}{500\times10^3\times10\times10^{-6}}\times(1-0.99) \approx 5\ \text{mA}$。

## 常见器件型号
- 开关管：SI2302、CSD17570、IRF7401。
- 二极管：SS34、MBR0520、SS56。
- 控制 IC：LM3478、LT3757、TPS61170。
- 耦合电感：常用：按需选型（如 Coilcraft、Würth 耦合电感）。

## 注意事项
- 耦合电感的同名端方向必须正确，否则纹波抵消失效甚至恶化。
- 绕组耐流需满足各自支路电流，避免磁芯饱和。
- 匝比与耦合系数对纹波抵消影响敏感，需在目标工况下验证。
- 其余设计要点与 SEPIC 相同，含右半平面零点需注意补偿。
