# SEPIC 升降压电路

## 拓扑描述
电路由两个电感 L1、L2，耦合电容（储能电容）Cs，开关管 S，二极管 D 与输出电容 C 共六个元件组成。关键节点如下：输入节点 $V_{in}$ 接输入电感 L1 的入端；开关节点 SW 由 L1 的出端、开关管 S 的漏极与耦合电容 Cs 的上端相连而成；中间节点由 Cs 的下端、二极管 D 的阳极与第二电感 L2 的入端相连而成；输出节点 $V_{out}$ 由二极管 D 的阴极与输出电容 C 的上端相连并接负载，输出电容 C 的下端与 L2 的出端、开关管 S 的源极一并接地。

各元件管脚连接：输入电感 L1 一端接输入节点、另一端接开关节点；开关管 S 的漏极接开关节点、源极接地、栅极 G 接控制信号；耦合电容 Cs 一端接开关节点、另一端接中间节点；二极管 D 的阳极接中间节点、阴极接输出节点；第二电感 L2 一端接中间节点、另一端接地；输出电容 C 一端接输出节点、另一端接地。

就组态而言，这是以两电感与耦合电容实现升降压的 SEPIC 变换器，输出电压与输入同极性，既可升压又可降压，且输入电流连续适合输入波动大的场合。

## 工作原理
开关管导通时输入电感储能、耦合电容经开关管向第二电感放电；关断时两电感分别经二极管向输出释放能量。通过两电感的连续电流与耦合电容的电荷平衡，实现输出电压既可高于也可低于输入电压的稳定变换，输出极性不变。

## 关键计算公式

- 理想电压增益（CCM）：
$$V_{out} = \frac{D}{1-D} V_{in}$$

- 占空比与电压关系：
$$D = \frac{V_{out}}{V_{in}+V_{out}}$$

- 电感纹波电流（L1、L2 相同形式）：
$$\Delta I_L = \frac{V_{in} D}{f_s L}$$

- 耦合电容纹波电压：
$$\Delta V_{Cs} = \frac{I_{out} D}{f_s C_s}$$

- 输出电压纹波：
$$\Delta V_{out} = \frac{I_{out} D}{f_s C}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压（同极性） | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $L$ | 电感（两次相同或独立） | H |
| $C_s$ | 耦合电容 | F |
| $C$ | 输出电容 | F |
| $I_{out}$ | 输出电流 | A |

## 元件调整影响
- **D↑** → 输出电压升高；D<0.5 降压、D>0.5 升压。
- **L1、L2↑** → 电感纹波电流减小，输入输出更平滑。
- **Cs↑** → 耦合电容纹波减小，传能更平稳。
- **C↑** → 输出电压纹波减小。
- L1 与 L2 可用耦合电感实现，减小体积并改善纹波。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$D=0.6$：$V_{out} = \dfrac{0.6}{1-0.6}\times12 = 18\ \text{V}$。
- 取 $f_s=500\ \text{kHz}$、$L=10\ \mu\text{H}$、$V_{in}=12\ \text{V}$、$D=0.6$：$\Delta I_L = \dfrac{12\times0.6}{500\times10^3\times10\times10^{-6}} = 1.44\ \text{A}$。

## 常见器件型号
- 开关管：IRF540N、SI2302、CSD17570。
- 二极管：SS34、MBR0520、SS56。
- 控制 IC：LM3478、LT3757、TPS61170、MAX668。

## 注意事项
- 耦合电容 Cs 需承受较大纹波电流，选用低 ESR 电容并注意耐压。
- 输入端电感连续使输入电流平滑，适合电池等输入波动大的场合。
- 开关管需承受输入加输出的电压应力，选型时留足耐压余量。
- SEPIC 含右半平面零点，补偿带宽需限制以保证稳定。
