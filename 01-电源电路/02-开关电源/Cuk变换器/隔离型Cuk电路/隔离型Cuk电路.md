# 隔离型 Cuk 电路

## 拓扑描述
电路由输入电感 L1、开关管 S、隔离变压器 T、副边整流二极管 D、输出电感 L2 与输出电容 C2 六个元件组成。关键节点如下：输入节点 $V_{in}$ 接输入电感 L1 的入端；原边节点 A 由 L1 的出端与变压器 T 初级同名端相连而成；原边开关节点 B 由变压器 T 初级异名端与开关管 S 的漏极相连而成；原边地 GND_pri 为开关管 S 源极；副边整流节点 C 由变压器 T 次级异名端与二极管 D 的阳极相连而成；中间节点 E 由二极管 D 的阴极与输出电感 L2 的入端相连而成；输出节点（负极性）$V_{out}$ 由 L2 的出端与输出电容 C2 的上端相连并接负载；副边地 GND_sec 由变压器 T 次级同名端、输出电容 C2 的下端相连而成。

各元件管脚连接：输入电感 L1 一端接输入节点 $V_{in}$、另一端接原边节点 A；变压器 T 初级同名端接原边节点 A、初级异名端接原边开关节点 B，次级同名端接副边地 GND_sec、次级异名端接副边整流节点 C；开关管 S 的漏极接原边开关节点 B、源极接原边地 GND_pri、栅极 G 接 PWM 控制信号；整流二极管 D 的阳极接副边整流节点 C、阴极接中间节点 E；输出电感 L2 一端接中间节点 E、另一端接输出节点 $V_{out}$；输出电容 C2 上端接输出节点 $V_{out}$、下端接副边地 GND_sec；负载跨接 $V_{out}$ 与 GND_sec。

就组态而言，这是把基本 Cuk 的耦合电容替换为隔离变压器形成的隔离型 Cuk 变换器：原边 L1 与变压器初级串联后再经开关管接地，副边经二极管整流、输出电感平滑后向负载供电，通过变压器实现原副边电气隔离，保留升降压与输出反相特性。

## 工作原理
开关管导通时输入电感储能，变压器原边激磁电流建立；关断时变压器副边感应出反向电压，经二极管整流、输出电感平滑后向负载供电。变压器的变比与占空比共同决定输出电压，原副边地之间实现隔离。

## 关键计算公式

- 理想电压增益（CCM）：
$$V_{out} = -\frac{ND}{1-D} V_{in}$$

- 占空比与电压关系：
$$D = \frac{V_{out}}{V_{out} - N V_{in}}$$

- 输入电感纹波电流：
$$\Delta I_{L1} = \frac{V_{in} D}{f_s L_1}$$

- 输出电感纹波电流：
$$\Delta I_{L2} = \frac{N V_{in} D}{f_s L_2}$$

- 输出电压纹波：
$$\Delta V_{out} = \frac{I_{out} D}{f_s C_2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压（负极性） | V |
| $N$ | 变压器匝比（副边/原边） | — |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $L_1$ | 输入电感 | H |
| $L_2$ | 输出电感 | H |
| $C_2$ | 输出电容 | F |
| $I_{out}$ | 输出电流 | A |

## 元件调整影响
- **N↑** → 输出等效电压升高，可在较低 D 下获得所需输出。
- **D↑** → 输出电压绝对值升高，与匝比共同决定增益。
- **L1↑** → 输入纹波电流减小。
- **L2↑** → 输出纹波电流减小。
- **变压器漏感↑** → 开关管关断时电压尖峰增大，需加钳位/吸收。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$D=0.4$、$N=2$：$V_{out} = -\dfrac{2\times0.4}{1-0.4}\times12 = -16\ \text{V}$。
- 取 $f_s=200\ \text{kHz}$、$L_2=100\ \mu\text{H}$、$N=2$、$V_{in}=12\ \text{V}$、$D=0.4$：$\Delta I_{L2} = \dfrac{2\times12\times0.4}{200\times10^3\times100\times10^{-6}} = 0.48\ \text{A}$。

## 常见器件型号
- 开关管：IRF540N、STP60NF06。
- 整流二极管：SS34、MBR20100、UF4007。
- 控制 IC：可选用带隔离反馈的控制器，如 UC3843 + 光耦，或 LT3800 系列。

## 注意事项
- 变压器需满足伏秒平衡，避免磁芯饱和。
- 输出电压极性取决于变压器同名端方向，接线时需核对。
- 需采用隔离反馈（光耦或变压器反馈）来稳定输出。
- 变压器漏感导致电压尖峰，应加 RC/RCD 钳位吸收。
