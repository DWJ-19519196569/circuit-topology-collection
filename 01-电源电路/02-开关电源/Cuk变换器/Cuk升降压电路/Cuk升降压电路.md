# Cuk 升降压电路

## 拓扑描述
电路由输入电感 L1、储能/耦合电容 C1、开关管 S、二极管 D、输出电感 L2 与输出电容 C2 共六个元件组成。关键节点如下：输入节点 $V_{in}$ 接输入电感 L1 的入端；开关节点 SW 由 L1 的出端、开关管 S 的漏极与耦合电容 C1 的上端相连而成；中间节点由 C1 的下端、二极管 D 的阳极与输出电感 L2 的入端相连而成；输出节点（负极性）$V_{out}$ 由二极管 D 的阴极与输出电容 C2 的上端相连并接负载，其输出为负，输出电容 C2 的下端与 L2 的出端、开关管 S 的源极一并接到地节点 GND。

各元件管脚连接：输入电感 L1 一端接输入节点、另一端接开关节点；开关管 S 的漏极接开关节点、源极接地、栅极 G 接 PWM 控制信号；耦合电容 C1 一端接开关节点、另一端接中间节点；二极管 D 的阳极接中间节点、阴极接输出节点（负输出）；输出电感 L2 一端接中间节点、另一端接地；输出电容 C2 一端接输出节点（负输出）、另一端接地。

就组态而言，这是以两个电感和一个耦合电容实现能量升降压的 Cuk 变换器，输出电压极性与输入相反，既可升压又可降压，且输入、输出电流均连续。

## 工作原理
开关管导通时输入电感储能、耦合电容经开关管向输出电感放电；关断时两电感电流分别经二极管续流并给耦合电容与输出充电。借助两个电感的连续电流与耦合电容的电荷平衡，实现能量的升降压传输。

## 关键计算公式

- 理想电压增益（CCM）：
$$V_{out} = -\frac{D}{1-D} V_{in}$$

- 占空比与电压关系：
$$D = \frac{V_{out}}{V_{out}-V_{in}}$$

- 输入电感纹波电流：
$$\Delta I_{L1} = \frac{V_{in} D}{f_s L_1}$$

- 输出电感纹波电流：
$$\Delta I_{L2} = \frac{V_{in} D}{f_s L_2}$$

- 输出电压纹波：
$$\Delta V_{out} = \frac{I_{out} D}{f_s C_2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压（负极性） | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $L_1$ | 输入电感 | H |
| $L_2$ | 输出电感 | H |
| $C_2$ | 输出电容 | F |
| $I_{out}$ | 输出电流 | A |

## 元件调整影响
- **D↑** → 输出电压的绝对值升高；当 D>0.5 时升压、D<0.5 时降压。
- **L1↑** → 输入纹波电流减小，输入侧更平滑。
- **L2↑** → 输出纹波电流减小，输出侧更平滑。
- **C1↑** → 耦合电容纹波减小，稳态更稳；C1 过小会限制传能。
- **C2↑** → 输出电压纹波减小。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$D=0.5$：$V_{out} = -\dfrac{0.5}{1-0.5}\times12 = -12\ \text{V}$。
- 取 $f_s=200\ \text{kHz}$、$L_1=100\ \mu\text{H}$、$V_{in}=12\ \text{V}$、$D=0.5$：$\Delta I_{L1} = \dfrac{12\times0.5}{200\times10^3\times100\times10^{-6}} = 0.30\ \text{A}$。

## 常见器件型号
- 开关管：IRF540N、SI2312。
- 二极管：SS34、MBR1045。
- 控制 IC：常见的 Cuk 控制器有 LT3580、MC34063（可配置为反相）。

## 注意事项
- 输出电压为负，需严格区分输入输出地，避免接反。
- 耦合电容 C1 承受较高纹波电流，需选用低 ESR 电容并注意极性。
- 输入输出电流均连续，但开关管需承受输入加输出的电压应力。
- Cuk 电路传递函数含右半平面零点，环路补偿难度较大。
