# 半桥 LLC 谐振电路

## 拓扑描述
电路由两个开关管 Q1、Q2 构成的半桥桥臂、谐振电感 Lr、谐振电容 Cr、励磁电感 Lm、隔离变压器 T，以及副边整流二极管 D1、D2 与输出滤波电容 C 构成。关键节点如下：输入节点 $V_{in}$ 接上管 Q1 的漏极；半桥中点（开关节点）由 Q1 的源极与 Q2 的漏极相连而成，并经谐振网络接变压器初级；下管 Q2 的源极接地（原边地）；谐振网络由 Lr、Cr 串联且与 Lm（并接于变压器初级）构成，变压器初级一端经谐振网络接半桥中点、另一端接原边地；变压器次级采用中心抽头，中心抽头接副边地，两端分别经二极管 D1、D2 整流后汇于输出节点，输出电容 C 一端接输出节点、另一端接副边地并接负载。

各元件管脚连接：上管 Q1 的漏极接输入节点、源极接半桥中点、栅极 G 接驱动信号；下管 Q2 的漏极接半桥中点、源极接原边地、栅极接与 Q1 互补的驱动信号；谐振电感 Lr 一端接半桥中点、另一端接谐振电容 Cr；谐振电容 Cr 一端接 Lr、另一端接变压器初级一端（或原边地）；励磁电感 Lm 并在变压器初级两端；变压器 T 的初级并接 Lm，次级中心抽头接副边地，次级两端分别接二极管 D1、D2 的阳极；二极管 D1、D2 的阴极并接输出节点；输出电容 C 一端接输出节点、另一端接副边地。

就组态而言，这是由半桥臂驱动 Lr-Cr-Lm 谐振网络、经带中心抽头的变压器全波整流的半桥 LLC 谐振变换器，利用谐振实现软开关，实现高效率的隔离降压输出。

## 工作原理
半桥以接近谐振频率的方波驱动，谐振网络在开关管两端形成正弦电流，使开关管在零电压开通（ZVS）。变压器的励磁电感参与谐振，副边整流二极管零电流关断，从而大幅降低开关损耗与 EMI，实现高效隔离变换。

## 关键计算公式

- 谐振频率：
$$f_r = \frac{1}{2\pi\sqrt{L_r C_r}}$$

- 第二谐振频率（含励磁电感）：
$$f_m = \frac{1}{2\pi\sqrt{(L_r+L_m) C_r}}$$

- 归一化电感比：
$$k = \frac{L_m}{L_r}$$

- 品质因数：
$$Q = \frac{1}{R_o}\sqrt{\frac{L_r}{C_r}}$$

- 直流电压增益（近似，n 为副边/原边匝比 $n=N_s/N_p$）：
$$V_{out}=V_{in}\cdot\frac{nM}{2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L_r$ | 谐振电感 | H |
| $C_r$ | 谐振电容 | F |
| $L_m$ | 磁化电感 | H |
| $f_r$ | 谐振频率 | Hz |
| $f_m$ | 第二谐振频率 | Hz |
| $R_o$ | 折合到原边的负载电阻 | Ω |
| $Q$ | 品质因数 | — |
| $M$ | 谐振网络电压增益 | — |
| $n$ | 变压器匝比（副边/原边） | — |

## 元件调整影响
- **Lr↑ 或 Cr↑** → 谐振频率 $f_r$ 下降，工作频率需相应降低。
- **Lm↑** → 励磁电流减小、损耗降低，但增益调节范围变窄。
- **Q↑**（负载变重或 Lr/Cr 比增大）→ 增益峰变陡，环路更易振荡。
- **工作频率 f_s 相对 f_r 的位置**：过高则增益下降、过低进入容性区失去 ZVS。
- **k↑** → 增益曲线更平缓，但谐振电流与关断损耗减小。

## 典型参数示例
- 取 $L_r=100\ \mu\text{H}$、$C_r=22\ \text{nF}$：$f_r = \dfrac{1}{2\pi\sqrt{100\times10^{-6}\times22\times10^{-9}}} \approx 107\ \text{kHz}$。
- 取 $L_m=500\ \mu\text{H}$、$L_r=100\ \mu\text{H}$：$f_m = \dfrac{1}{2\pi\sqrt{600\times10^{-6}\times22\times10^{-9}}} \approx 43.8\ \text{kHz}$。

## 常见器件型号
- 开关管：IRFP460、STP20NM60、IPP60R190P6。
- 整流二极管：MBR20100、STPS20H100、SR5100。
- 控制 IC：UCC25600、L6599、NCP1396（半桥 LLC 控制器）。

## 注意事项
- 需在容性区之外运行，保证开关管始终实现 ZVS。
- 谐振电容 Cr 承受高压与高频大电流，需选用低损耗、高耐压薄膜电容。
- 变压器漏感可充当 Lr，但需精确控制，避免参数漂移。
- 空载或短路时增益失控，需限制工作频率或加保护。
