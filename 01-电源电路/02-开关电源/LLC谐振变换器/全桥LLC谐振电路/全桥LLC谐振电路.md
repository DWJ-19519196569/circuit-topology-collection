# 全桥 LLC 谐振电路

## 拓扑描述
电路由四个开关管 Q1~Q4 组成的全桥桥臂、谐振电感 Lr、谐振电容 Cr、励磁电感 Lm、隔离变压器 T 以及副边整流二极管与输出滤波电容 C 构成。关键节点如下：输入节点 $V_{in}$ 接上桥臂两管 Q1、Q3 的漏极；两个桥臂中点（开关节点）A、B 分别由 Q1/Q2 与 Q3/Q4 的源极-漏极连接点引出，并分别接谐振网络两端；谐振网络由 Lr、Cr 与 Lm（与变压器初级并联）串联构成；变压器初级经谐振网络跨接于 A、B 之间；副边经整流及滤波电容 C 形成输出节点 $V_{out}$ 并接负载，下桥臂 Q2、Q4 的源极接原边地。

各元件管脚连接：Q1、Q3 的漏极接输入节点、源极分别接桥臂中点 A、B；Q2、Q4 的漏极分别接 A、B、源极接原边地；各管栅极 G 接互补驱动信号；谐振电感 Lr 一端接桥臂中点 A、另一端接谐振电容 Cr 与变压器初级的一个端子；谐振电容 Cr 一端接 Lr、另一端接桥臂中点 B（或变压器初级另一端子）；励磁电感 Lm 并在变压器初级两端；变压器 T 的初级并接 Lm、次级接副边整流二极管，二极管整流输出接滤波电容 C，输出电容 C 一端接输出节点、另一端接副边地（副边采用中心抽头加两二极管的全波整流或桥式整流）。

就组态而言，这是由全桥逆变臂驱动 Lr-Cr-Lm 谐振网络、经变压器隔离整流的全桥 LLC 谐振变换器，通过谐振实现开关管零电压开通与大功率隔离直流变换。

## 工作原理
全桥以两路互补方波驱动，在谐振网络两端产生幅度接近输入电压的方波激励，谐振电流呈正弦状，使开关管实现零电压开通（ZVS），副边二极管实现零电流关断。其工作原理与半桥 LLC 相同，但输入桥臂电压幅值更高、承载功率更大。

## 关键计算公式

- 谐振频率：
$$f_r = \frac{1}{2\pi\sqrt{L_r C_r}}$$

- 第二谐振频率（含励磁电感）：
$$f_m = \frac{1}{2\pi\sqrt{(L_r+L_m) C_r}}$$

- 归一化电感比：
$$k = \frac{L_m}{L_r}$$

- 品质因数：
$$Q = \frac{1}{R_o}\sqrt{\frac{L_r}{C_r}}$$

- 直流电压增益（近似，n 为副边/原边匝比 $n=N_s/N_p$）：
$$V_{out}=V_{in}\cdot nM$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L_r$ | 谐振电感 | H |
| $C_r$ | 谐振电容 | F |
| $L_m$ | 磁化电感 | H |
| $f_r$ | 谐振频率 | Hz |
| $f_m$ | 第二谐振频率 | Hz |
| $R_o$ | 折合到原边的负载电阻 | Ω |
| $Q$ | 品质因数 | — |
| $M$ | 谐振网络电压增益 | — |
| $n$ | 变压器匝比（副边/原边） | — |

## 元件调整影响
- **Lr↑ 或 Cr↑** → 谐振频率 $f_r$ 下降，工作频率需降低。
- **Lm↑** → 励磁电流减小、损耗降低，但增益调节范围变窄。
- **Q↑** → 增益峰变陡，负载大范围变化下环路更难稳定。
- **工作频率 f_s 相对 f_r**：过高增益下降，过低进入容性区失去 ZVS。
- 全桥较半桥多一倍开关管，但每个开关管承受的电压为输入电压而非半桥的 $V_{in}$（取决于拓扑），导通损耗分布更优。

## 典型参数示例
- 取 $L_r=50\ \mu\text{H}$、$C_r=100\ \text{nF}$：$f_r = \dfrac{1}{2\pi\sqrt{50\times10^{-6}\times100\times10^{-9}}} \approx 71.2\ \text{kHz}$。
- 取 $L_m=250\ \mu\text{H}$、$L_r=50\ \mu\text{H}$：$f_m = \dfrac{1}{2\pi\sqrt{300\times10^{-6}\times100\times10^{-9}}} \approx 29.1\ \text{kHz}$。

## 常见器件型号
- 开关管：STW48N60M2、IPW60R099P7、IXFH60N60。
- 整流二极管：MBR40250、DSEP30-06、STPS40H100。
- 控制 IC：UCC28950、UCC25600（可扩展）、NCP1397（配外部驱动）。

## 注意事项
- 需严格保证上下桥臂驱动不重叠，防止直通短路。
- 四个开关管参数需匹配，减小桥臂不平衡与损耗。
- 运行应保持在感性区，全程实现 ZVS，避免容性区硬开关。
- 高频大电流下需优化 PCB 布局，减小寄生电感与环路面积。
