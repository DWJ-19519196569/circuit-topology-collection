# 并联谐振电路

## 拓扑描述
并联谐振（Parallel Resonant Converter, PRC）电路由 **谐振电感 $L$** 与 **谐振电容 $C$** 并联构成 LC 谐振网络，配合 **变换器开关级** 与 **负载（或经整流/变压器耦合的负载）**。电路关键节点：**节点① 谐振槽路上端（开关级输出节点）A**（电感 $L$ 一端、电容 $C$ 一端、开关级输出一端、负载/整流输入一端相连）；**节点② 谐振槽路下端（公共/地）B**（电感 $L$ 另一端、电容 $C$ 另一端、开关级返回端、负载返回端相连）。

各元件管脚连接：**电感 $L$** 一端接节点 A、另一端接节点 B；**电容 $C$** 一端接节点 A、另一端接节点 B（与 $L$ 并联）；**变换器开关级**输出端接节点 A、返回端接节点 B；**负载**（或经整流/变压器的负载）上端接节点 A、下端接节点 B，从而与并联谐振槽路并联。

由此构成"电感与电容并联、谐振频率处总阻抗最大、呈现高阻抗"的并联谐振（PRC）槽路，谐振网络与负载并联，通过变频使开关管实现零电压/零电流软开关，常见于谐振型开关电源。

## 工作原理
并联谐振网络在谐振频率 $f_0$ 处导纳的虚部为零，LC 并联支路对外呈现纯电阻性的高阻抗。变换器中，开关级输出的方波电流或电压激励谐振槽路，在接近谐振频率工作时电压电流相位接近，实现软开关，降低开关损耗与 EMI。

## 关键计算公式

- 谐振频率：
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 谐振角频率：
$$\omega_0 = \frac{1}{\sqrt{LC}}$$

- 特征阻抗：
$$Z_0 = \sqrt{\frac{L}{C}}$$

- 品质因数（负载并联时）：
$$Q = R_L \sqrt{\frac{C}{L}} = \frac{R_L}{Z_0}$$

- 并联谐振阻抗（谐振时）：
$$Z_{res} = Q^2 R_L \quad(\text{理想})$$

- 带宽：
$$BW = \frac{f_0}{Q}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L$ | 谐振电感 | H |
| $C$ | 谐振电容 | F |
| $f_0$ | 谐振频率 | Hz |
| $\omega_0$ | 谐振角频率 | rad/s |
| $Z_0$ | 特征阻抗 | Ω |
| $Q$ | 品质因数 | — |
| $R_L$ | 负载电阻 | Ω |

## 元件调整影响
- **L 或 C 增大** → 谐振频率 $f_0$ 下降。
- **L 增大 且 C 减小（保持 $f_0$ 不变）** → 特征阻抗 $Z_0$ 增大，谐振槽路电压增益提高。
- **负载电阻 $R_L$ 增大** → 品质因数 $Q$ 增大，谐振峰值变尖锐、输出电压对负载变化更敏感。
- **品质因数 $Q$ 降低** → 通带变宽，谐振特性减弱，软开关范围收窄。

## 典型参数示例
- 取 $L=100\ \mu\text{H}$、$C=10\ \text{nF}$：$f_0 = \dfrac{1}{2\pi\sqrt{100\times10^{-6}\times10\times10^{-9}}} \approx 159\ \text{kHz}$。
- 取 $L=100\ \mu\text{H}$、$C=10\ \text{nF}$：$Z_0 = \sqrt{\dfrac{100\times10^{-6}}{10\times10^{-9}}} = 100\ \Omega$。

## 常见器件型号
- 谐振电容：C0G/NP0 贴片电容、金属化聚丙烯薄膜电容（如 941C 系列）。
- 谐振电感：铁氧体磁芯绕制（PQ、RM 磁芯系列）。
- 谐振控制芯片：L6599、UCC25600。

## 注意事项
- 并联谐振槽路在谐振点阻抗极高，轻载时谐振峰值电压很高，需校核器件耐压。
- 负载变化会显著改变 $Q$ 与增益，需结合变频控制维持稳定输出。
- 电容需选用低损耗、温度稳定的介质（C0G 或聚丙烯），避免发热漂移。
- 谐振电感需考虑磁芯损耗与饱和，预留足够气隙。
