# 半桥驱动电路

## 拓扑描述
半桥驱动电路用于驱动由 **上、下两个功率开关管**（高侧 $Q_H$ 与低侧 $Q_L$，通常为 MOSFET 或 IGBT）组成的桥臂，并配 **驱动芯片（半桥驱动 IC）**、**自举电容 $C_{boot}$**、**自举二极管 $D_{boot}$**。电路关键节点：**节点① 母线正端 $+V_{bus}$**（上管 $Q_H$ 漏极/集电极相连）；**节点② 地 GND**（下管 $Q_L$ 源极/发射极相连）；**节点③ 开关节点 A（桥臂中点输出）**（上管源极/发射极、下管漏极/集电极、自举电容下端 $V_S$、输出负载相连）；**节点④ 自举浮空节点 $V_B$**（自举电容上端、自举二极管阴极、上管栅驱浮空电源相连）；**节点⑤ 驱动电源 $V_{CC}$**（自举二极管阳极、下管栅驱供电相连）。

各元件管脚连接：**上管 $Q_H$** 漏极（集电极）接 $+V_{bus}$、源极（发射极）接开关节点 A、栅极（基极）经驱动接 $V_B$ 浮空电源；**下管 $Q_L$** 漏极（集电极）接开关节点 A、源极（发射极）接地、栅极（基极）接驱动；**$C_{boot}$** 上端接 $V_B$、下端接开关节点 A（$V_S$）；**$D_{boot}$** 阳极接 $V_{CC}$、阴极接 $V_B$；驱动芯片高侧输出接上管栅极、低侧输出接下管栅极，并接收 PWM 与死区控制信号。

由此构成"两桥臂开关交替把直流母线在桥臂中点斩成方波、自举电路为上管提供浮空栅极电源"的半桥功率级驱动接口，是半桥逆变/变换器功率级的控制界面。

## 工作原理
驱动芯片接收低电压 PWM 信号，产生带死区时间的两路互补栅极驱动。下管导通期间自举电容通过自举二极管被充电至上管驱动电源电压，待下管关断、上管导通时，自举电容"举起"上管驱动级的电位，从而保证上管栅源电压始终满足开通条件。

## 关键计算公式

- 自举电容容量（每周期允许的电压跌落）：
$$C_{boot} = \frac{Q_g + I_{qbs}t_{on}}{\Delta V_{boot}}$$

- 自举二极管反向耐压：
$$V_{R,diode} \ge V_{bus}$$

- 死区时间（防止直通）：
$$t_{dead} \ge t_{off(max)} - t_{on(min)}$$

- 驱动平均电流（两路栅极）：
$$I_{drv} = f_{sw}(Q_{gH} + Q_{gL})$$

- 栅极峰值电流：
$$I_{g,peak} = \frac{V_{DD}}{R_{g(on)} + R_{g(int)}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_{boot}$ | 自举电容容量 | F |
| $Q_g$ | 上管栅极总电荷 | C |
| $I_{qbs}$ | 驱动芯片静态电流 | A |
| $t_{on}$ | 上管导通时间 | s |
| $\Delta V_{boot}$ | 允许的自举电压跌落 | V |
| $V_{bus}$ | 母线电压 | V |
| $f_{sw}$ | 开关频率 | Hz |
| $R_g$ | 栅极电阻 | Ω |

## 元件调整影响
- **自举电容 $C_{boot}$ 增大** → 电压跌落 $\Delta V_{boot}$ 减小，但充电时间变长，低频大占空比场合需要更大容量。
- **栅极电阻 $R_g$ 增大** → 开关速度变慢、开关损耗增大，但可抑制振铃与 EMI。
- **死区时间 $t_{dead}$ 增大** → 直通风险降低，但低占空比/高频下输出有效占空比损失增大。
- **自举二极管反向耐压不足** → 自举电容无法正确充电，上管驱动失效。

## 典型参数示例
- 取 $Q_g = 60\ \text{nC}$、$I_{qbs}=0.1\ \text{mA}$、$t_{on}=10\ \mu\text{s}$、$\Delta V_{boot}=1\ \text{V}$：$C_{boot} = \dfrac{60\times10^{-9} + 0.1\times10^{-3}\times10\times10^{-6}}{1} \approx 61\ \text{nF}$（实际选取 100 nF～1 μF）。
- 取 $f_{sw}=100\ \text{kHz}$、$Q_{gH}+Q_{gL}=120\ \text{nC}$：$I_{drv}=100\times10^3\times120\times10^{-9}=12\ \text{mA}$。

## 常见器件型号
- 半桥驱动芯片：IR2104、IR2110、UCC27714、NCP51820。
- 自举二极管：UF4007、MURA160（快恢复/超快恢复）。
- 功率开关管：IRF540、IRFZ44N、IPP65R045C7。

## 注意事项
- 上下管必须保证死区时间，否则发生直通烧毁功率管。
- 自举电容需靠近驱动芯片与上管放置，走线尽量短以减少寄生电感。
- 上管占空比接近 100% 时自举电容无法充电，需采用电荷泵或隔离电源供电。
- 驱动回路（栅极—源极—驱动芯片）面积要尽量小，抑制寄生电感引起的栅极振铃。
