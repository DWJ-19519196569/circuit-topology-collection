# 串联谐振电路

## 拓扑描述
电路由谐振电感 L 与谐振电容 C 串联构成 LC 谐振网络，通常串接在开关级（逆变臂）输出与负载（经变压器）之间。关键节点如下：谐振网络入端接逆变桥臂（开关级）的输出节点，入端即电感 L 的一端；谐振网络中间节点由电感 L 的另一端与电容 C 的一端相连而成；谐振网络出端为电容 C 的另一端，接变压器初级或负载的一端，回路另一端经负载折合电阻回到开关级，构成谐振电流环路；开关级输出与负载折合电阻 R 为回路提供激励与耗能。

各元件管脚连接：谐振电感 L 一端接谐振网络入端（开关级输出）、另一端接谐振网络中间节点；谐振电容 C 一端接中间节点、另一端接谐振网络出端（变压器初级或负载）；电感与电容作为二端元件按上述顺序串联，变压器次级接整流及负载，负载的等效电阻 R 折合进谐振回路与 LC 槽路串联。

就组态而言，这是由电感与电容串联构成的串联谐振（SRC）槽路，在谐振频率处感抗与容抗相抵、回路阻抗降为纯电阻使电流最大，用于实现软开关的谐振变换。

## 工作原理
在谐振频率 $f_0$ 处，电感感抗 $X_L = \omega L$ 与电容容抗 $X_C = \frac{1}{\omega C}$ 大小相等、符号相反，相互抵消。串联槽路的阻抗降为回路的纯电阻，激励电压与回路电流同相，电流达到最大；开关管在电流自然换向时通断，实现零电流开关（ZCS）或零电压开关（ZVS）。

## 关键计算公式

- 谐振频率：
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 谐振角频率：
$$\omega_0 = \frac{1}{\sqrt{LC}}$$

- 特征阻抗：
$$Z_0 = \sqrt{\frac{L}{C}}$$

- 品质因数（串联回路）：
$$Q = \frac{Z_0}{R} = \frac{1}{R}\sqrt{\frac{L}{C}}$$

- 谐振时回路电流：
$$I_{res} = \frac{V_{in}}{R}$$

- 容抗/感抗在谐振点：
$$X_L = X_C = Z_0 = \omega_0 L = \frac{1}{\omega_0 C}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L$ | 谐振电感 | H |
| $C$ | 谐振电容 | F |
| $f_0$ | 谐振频率 | Hz |
| $Z_0$ | 特征阻抗 | Ω |
| $Q$ | 品质因数 | — |
| $R$ | 回路等效电阻 | Ω |
| $I_{res}$ | 谐振点电流 | A |

## 元件调整影响
- **L 或 C 增大** → 谐振频率 $f_0$ 下降。
- **负载电阻 $R$ 减小** → 品质因数 $Q$ 增大，谐振电流增大、谐振曲线变尖。
- **L 增大 且 C 减小（保持 $f_0$ 不变）** → 特征阻抗 $Z_0$ 增大，谐振电流减小。
- **工作点偏离谐振频率** → 槽路呈现感性或容性，软开关条件与增益随之改变。

## 典型参数示例
- 取 $L=100\ \mu\text{H}$、$C=10\ \text{nF}$：$f_0 = \dfrac{1}{2\pi\sqrt{100\times10^{-6}\times10\times10^{-9}}} \approx 159\ \text{kHz}$。
- 取 $L=100\ \mu\text{H}$、$C=10\ \text{nF}$、$R=10\ \Omega$：品质因数 $Q = \dfrac{1}{10}\sqrt{\dfrac{100\times10^{-6}}{10\times10^{-9}}} = 10$。

## 常见器件型号
- 谐振电容：C0G/NP0 贴片电容、金属化聚丙烯薄膜电容。
- 谐振电感：铁氧体磁芯绕制（PQ、RM 磁芯系列）。
- 谐振控制芯片：L6599、UCC25600、FSFR2100。

## 注意事项
- 串联谐振槽路在谐振点附近电流很大，需选择能承受谐振峰值的器件。
- 电容需低损耗、耐压足，谐振时电容峰值电压可能是输入电压的数倍。
- 轻载时串联谐振难以维持软开关，需结合其他控制策略（如 LLC 的磁化电感辅助）。
- 谐振电感与电容需精确匹配，受温度、容差影响会漂移 $f_0$。
