# 电流模式控制 Buck 电路

## 拓扑描述
电路由高侧开关管 Q1、续流二极管（或低侧同步整流开关管 Q2）D、储能电感 L、输出电容 C 与电流采样电阻 $R_{sense}$ 构成，配合电流模式控制（CMC）环路。关键节点如下：输入节点 $V_{in}$ 接 Q1 的漏极与采样电阻（或采样元件）上游；开关节点 SW 由 Q1 的源极、二极管 D 的阴极（或 Q2 的漏极）与电感 L 的入端相连而成；输出节点 $V_{out}$ 由电感 L 的出端与输出电容 C 的上端相连并接负载，输出电容 C 的下端、二极管 D 的阳极（或 Q2 的源极）及采样电阻下游一并接到地节点 GND。

各元件管脚连接：高侧开关管 Q1 的漏极接输入节点，栅极 G 接 PWM 控制信号，源极接开关节点 SW；续流二极管 D 的阴极接开关节点、阳极接地；若用低侧开关管 Q2，则 Q2 的漏极接 SW、源极接地、栅极接互补驱动信号；电感 L 一端接开关节点、另一端接输出节点；输出电容 C 一端接输出节点、另一端接地；电流采样电阻 $R_{sense}$ 一端接地、另一端接二极管阳极（或 Q2 源极）以取出电感电流检测信号。

就组态而言，这是一个降压（Buck）功率级叠加电压外环与电感电流内环的电流模式控制（CMC），用开关管峰值电流或电感平均电流作为内环反馈并经斜坡补偿生成占空比，兼具降压稳压、快速瞬态响应与逐周期限流功能。

## 工作原理
电压误差放大器输出 $V_c$ 作为电流内环的给定，控制器将实际电感电流与 $V_c$ 比较，决定开关管导通时刻与关断时刻（峰值电流模式在每个周期内直接限流）。因引入电流反馈，功率级由二阶 LC 特性退化为近似一阶，环路补偿更简单，逐周期限流响应快；但占空比 > 50% 时需斜坡补偿以防次谐波振荡。

## 关键计算公式

- 稳态输出电压（Buck）：
$$V_o = V_{in} D$$

- 电感电流纹波：
$$\Delta I_L = \frac{V_o(1-D)}{L f_{sw}}$$

- 峰值电流内环给定（峰值电流模式）：
$$I_{pk} = I_{L,avg} + \frac{\Delta I_L}{2}$$

- 斜坡补偿斜率（稳定性所需）：
$$m_c \geq \frac{m_2}{2} = \frac{V_o}{2L}$$

- 次谐波振荡判据（补偿后斜率比）：
$$\frac{m_c}{m_2} \geq 0.5$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_o$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $L$ | 电感 | H |
| $f_{sw}$ | 开关频率 | Hz |
| $I_{L,avg}$ | 电感平均电流 | A |
| $I_{pk}$ | 峰值电流给定 | A |
| $m_c$ | 补偿斜率 | A/s |
| $m_2$ | 关断期电感电流下降斜率 | A/s |

## 元件调整影响
- **电流采样电阻 $R_{sense}$ ↑** → 采样信噪比升高但导通损耗增大，需在精度与损耗间权衡。
- **斜坡补偿斜率 $m_c$ ↑** → 抑制次谐波更强，但过补偿会削弱电流内环带宽、趋向电压模式。
- **$L$ ↑** → 纹波 $\Delta I_L$ 减小，内环给定更平稳，环路更易稳定。
- **占空比 D 增大** → 峰值电流模式在 D>0.5 后必须补偿，否则次谐波振荡。
- **电流环增益** → 提高可加快负载响应，但噪声敏感度上升。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$V_o=3.3\ \text{V}$：$D=3.3/12=0.275$。
- 取 $I_{L,avg}=3\ \text{A}$、$L=10\ \mu\text{H}$、$V_o=3.3\ \text{V}$、$f_{sw}=500\ \text{kHz}$：$\Delta I_L=\frac{3.3\times(1-0.275)}{10\times10^{-6}\times5\times10^{5}}\approx0.478\ \text{A}$，$I_{pk}=3+0.48/2=3.24\ \text{A}$。

## 常见器件型号
- 常用：按需选型
- 电流模式 Buck 控制器：UC3843、LM5119、TPS5430（峰值电流模式）。

## 注意事项
- D > 50% 时必须加斜坡补偿，否则出现次谐波振荡与不稳定。
- 电流采样走线需开尔文接法，减小寄生电阻与噪声影响。
- 峰值电流模式对噪声敏感，采样点附近易误触发，需加前沿消隐。
- 轻载断续模式（DCM）下内环行为变化，补偿设计需覆盖全工况。
