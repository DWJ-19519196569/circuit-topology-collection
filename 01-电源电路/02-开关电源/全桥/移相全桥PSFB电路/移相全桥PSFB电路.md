# 移相全桥 PSFB 电路

## 拓扑描述
移相全桥（Phase-Shifted Full-Bridge）由 **四个开关管（$Q_1$~$Q_4$）组成的全桥**、**一个高频隔离变压器 $T$**、变压器原边的 **谐振电感 $L_r$**、以及副边的整流与输出滤波（$L_o$、$C_o$）构成。电路关键节点：**节点① 输入正端 $+V_{in}$**（$Q_1$ 与 $Q_3$ 的漏极相连）；**节点② 左桥臂开关节点 A**（$Q_1$ 源极、$Q_2$ 漏极、$L_r$ 一端相连）；**节点③ 右桥臂开关节点 B**（$Q_3$ 源极、$Q_4$ 漏极、变压器初级一端相连）；**节点④ 谐振—变压器初级节点 P**（$L_r$ 另一端、变压器初级另一端相连）；**节点⑤ 地 GND**（$Q_2$ 与 $Q_4$ 的源极相连）；**节点⑥ 输出正端 $+V_o$**（$L_o$ 输出侧与 $C_o$ 上端相连）。

各元件管脚连接：**$Q_1$** 漏极接 $+V_{in}$、源极接开关节点 A、栅极接驱动；**$Q_2$** 漏极接开关节点 A、源极接地、栅极接驱动；**$Q_3$** 漏极接 $+V_{in}$、源极接开关节点 B、栅极接驱动；**$Q_4$** 漏极接开关节点 B、源极接地、栅极接驱动；**$L_r$** 一端接开关节点 A、另一端接节点 P；**变压器 $T$** 初级一端接节点 P、另一端接开关节点 B，次级接副边整流；副边整流管（全波或倍流/中心抽头整流）接输出滤波电感 $L_o$ 与输出电容 $C_o$，$L_o$ 一端接整流输出、另一端接输出正端 $+V_o$，$C_o$ 跨接在输出正端与地之间，负载接 $+V_o$。

由此构成固定占空比约 50%、仅改变超前臂与滞后臂之间相位差来调节输出电压的移相全桥 ZVS 变换器，广泛用于中大功率、需要隔离的 DC-DC 变换场合。

## 工作原理
把全桥的两条桥臂分为超前臂与滞后臂，改变二者的相位差即可调节变压器原边电压的有效占空比；谐振电感与开关管输出电容发生谐振，使开关管在零电压下开通，从而降低开关损耗、提高效率。

## 关键计算公式

- 输出电压：
$$V_o = \frac{N_s}{N_p} D_{eff} V_{in}$$

- 有效占空比：
$$D_{eff} = D - \Delta D$$

- 占空比损失：
$$\Delta D = \frac{2 L_r I_o}{N V_{in} T_{sw}}$$

- 实现 ZVS 所需谐振电感：
$$L_r \geq \frac{2 C_{oss} V_{in}^2}{I_{pri}^2}$$

- 变压器匝比：
$$N = \frac{N_p}{N_s}$$

- 最大占空比：
$$D_{max} \approx 0.8 \sim 0.9$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_o$ | 输出电压 | V |
| $V_{in}$ | 输入电压 | V |
| $N_p, N_s$ | 原、副边匝数 | — |
| $D_{eff}$ | 有效占空比 | — |
| $L_r$ | 谐振电感 | H |
| $C_{oss}$ | 开关管输出电容 | F |
| $I_{pri}$ | 原边电流 | A |
| $T_{sw}$ | 开关周期 | s |

## 元件调整影响
- **$L_r$ 增大** → 更易实现 ZVS，但占空比损失 $D_{eff}$ 减小、有效输出下降。
- **$f_{sw}$ 增大** → 减小变压器与电感体积，但 ZVS 能量需求与开关损耗上升。
- **匝比 $N$ 增大** → 输出电压按比例增大，但副边整流管反向耐压增加。
- **$C_{oss}$ 减小 / $I_{pri}$ 增大** → 更易实现 ZVS。

## 典型参数示例
- 取 $V_{in}=400\ \text{V}$、$N=N_p/N_s=4:1$（即 $N_s/N_p=1/4$）、$D_{eff}=0.85$：$V_o = 0.85\times400/4 = 85\ \text{V}$。
- 取 $L_r=7\ \mu\text{H}$、$I_{pri}=8\ \text{A}$、$V_{in}=400\ \text{V}$、$T_{sw}=10\ \mu\text{s}$：$V_{in}/L_r = 5.7\times 10^{7}$，$T_{sw}I_{pri}/2 = 4\times10^{-5}$，$\Delta D = \frac{2\times7\times10^{-6}\times8}{4\times400\times10\times10^{-6}} = 0.07$，占空比损失 7%。

## 常见器件型号
- 开关管：英飞凌 CoolMOS IPL60R 系列、STW70N60、IRFP460。
- 控制器：UCC28950、UCC3895、TPS7A（TI）、NCP1397（半桥）。
- 输出整流：MBR20200、STPS30 系列肖特基二极管。
- 变压器/电感：定制高频磁芯 PQ3220、EE4220。

## 注意事项
- ZVS 仅在负载较大时成立，轻载可能失去软开关而增大损耗。
- 副边占空比损失随 $L_r$ 与负载电流增大，需折中取值。
- 原边电流与变压器需按峰值电流设计，避免饱和。
- 需精确控制超前/滞后臂的移相时序，防止直通。
