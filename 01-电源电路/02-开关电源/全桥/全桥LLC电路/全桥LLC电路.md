# 全桥 LLC 电路

## 拓扑描述
由 **四个功率开关管 $Q_1$~$Q_4$**（全桥 H 桥）、**谐振电感 $L_r$**、**谐振电容 $C_r$**、**激磁电感 $L_m$**（常与变压器 $T$ 集成）、**变压器 $T$** 与 **副边整流滤波** 组成。电路关键节点：**节点① 输入正端 $+V_{in}$**（$Q_1$ 与 $Q_3$ 的漏极相连）；**节点② 左桥臂开关节点 A**（$Q_1$ 源极、$Q_2$ 漏极、$L_r$ 一端相连）；**节点③ 右桥臂开关节点 B**（$Q_3$ 源极、$Q_4$ 漏极、变压器初级另一端与 $L_m$ 另一端相连）；**节点④ 谐振节点 C（$L_r$-$C_r$ 之间）**（$L_r$ 另一端与 $C_r$ 一端相连）；**节点⑤ 谐振—变压器初级并联节点 P**（$C_r$ 另一端、变压器初级一端、$L_m$ 一端相连）；**节点⑥ 地 GND**（$Q_2$ 与 $Q_4$ 的源极相连）。

各元件管脚连接：**$Q_1$** 漏极接 $+V_{in}$、源极接开关节点 A、栅极接驱动；**$Q_2$** 漏极接开关节点 A、源极接地、栅极接驱动；**$Q_3$** 漏极接 $+V_{in}$、源极接开关节点 B、栅极接驱动；**$Q_4$** 漏极接开关节点 B、源极接地、栅极接驱动；**$L_r$** 一端接开关节点 A、另一端接谐振节点 C；**$C_r$** 一端接谐振节点 C、另一端接节点 P；**变压器 $T$** 初级一端接节点 P、另一端接开关节点 B，次级接副边整流；**$L_m$** 一端接节点 P、另一端接开关节点 B（与变压器初级并联）；副边整流二极管与输出电容构成整流滤波，输出端接负载。

由此构成"全桥施加方波、$L_r$/$C_r$/$L_m$ 组成 LLC 谐振网络、副边整流输出直流"的隔离谐振变换器，通过调频改变增益并全程实现零电压开关（ZVS），用于中大功率高效率隔离电源（AC-DC、DC-DC）。

## 工作原理
全桥输出方波激励谐振网络，工作在谐振频率附近时，其基波经 $L_r$-$C_r$ 谐振传输能量；通过调频（PFM）改变开关频率、进而改变谐振网络增益来调节输出电压，功率管借助谐振实现 ZVS。

## 关键计算公式

- 双谐振频率（$L_r$-$C_r$ 决定串联谐振点）：
$$f_r = \frac{1}{2\pi\sqrt{L_r C_r}}$$

- 低频谐振点（$L_r$、$L_m$ 与 $C_r$）：
$$f_m = \frac{1}{2\pi\sqrt{(L_r + L_m) C_r}}$$

- 归一化电感比与品质因数：
$$k = \frac{L_m}{L_r},\quad Q = \frac{\sqrt{L_r/C_r}}{R_{ac}}$$

- 等效交流负载电阻（变压器变比 n 时）：
$$R_{ac} = \frac{8 n^2}{\pi^2} R_L$$

- 电压增益（基波近似，第一谐振极点处近似为 1）：
$$M = \frac{V_o}{V_{in}} = \frac{1}{n}\cdot\left|\frac{j\omega L_m \parallel R_{ac}}{j\omega L_r + \frac{1}{j\omega C_r} + j\omega L_m \parallel R_{ac}}\right|$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L_r$、$L_m$ | 谐振电感、激磁电感 | H |
| $C_r$ | 谐振电容 | F |
| $f_r$、$f_m$ | 高、低谐振频率 | Hz |
| $Q$ | 品质因数 | — |
| $n$ | 变压器原副匝比（$N_p/N_s$） | — |
| $R_L$ | 负载电阻 | Ω |

## 元件调整影响
- **$f_s = f_r$** → 增益≈1 且效率最高，为最佳工作点。
- **$f_s < f_r$**（略低）→ 增益 >1（升压），可实现 ZVS 与副边二极管 ZCS。
- **$f_s > f_r$** → 增益 <1（降压），仍保持 ZVS。
- **$L_m$ ↓ / $k$ ↓** → 增益峰值变陡、调压范围增大，但激磁电流增大、损耗上升。
- **$Q$ ↑**（负载变重）→ 可用增益范围变窄，需增大 $L_m$ 补偿。

## 典型参数示例
- 取 $L_r=100\ \mu\text{H}$、$C_r=22\ \text{nF}$：$f_r = \dfrac{1}{2\pi\sqrt{100\times10^{-6}\times 22\times10^{-9}}} \approx 107\ \text{kHz}$。
- 取 $L_m=500\ \mu\text{H}$（$k=5$）：$f_m = \dfrac{1}{2\pi\sqrt{(100+500)\times10^{-6}\times22\times10^{-9}}} \approx 43.8\ \text{kHz}$。

## 常见器件型号
- LLC 控制器：UCC25600、UCC25640、L6599（ST）、FSFR2100。
- 功率 MOSFET 与驱动：IR2110、IR2153 系列，超结 MOSFET（如 IPW60R）。
- 谐振电容：CBB / 金属膜电容、高质量 NP0 电容。

## 注意事项
- 增益曲线随负载变化大，需在全负载范围校验调频范围。
- 需设计可靠 ZVS 所需的最小死区时间与磁化电流。
- 谐振电容须选低损耗、高频、耐压足够并考虑耐流的型号。
- 空载或轻载时频率会升得较高，需限制最大频率与控制稳定性。
