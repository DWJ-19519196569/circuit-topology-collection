# Boost 型 PFC 电路

## 拓扑描述
电路由整流桥 BR、升压电感 L、开关管 S、升压二极管 D 与输出电容 C 共五个元件构成的有源功率因数校正电路。关键节点如下：整流桥 BR 的交流输入端接市电，其正输出端接升压电感 L 的入端、负输出端接地；开关节点 SW 由电感 L 的出端、开关管 S 的漏极与二极管 D 的阳极相连而成；输出节点 $V_{out}$ 由二极管 D 的阴极与输出电容 C 的上端相连并接负载（后级 DC-DC），输出电容 C 的下端与开关管 S 的源极一并接整流桥负输出端（地）。

各元件管脚连接：整流桥 BR 的两个交流输入脚接市电火线/零线，正极输出脚接电感入端、负极输出脚接地；升压电感 L 一端接整流桥正极输出、另一端接开关节点；开关管 S 的漏极接开关节点、源极接地、栅极 G 接 PFC 控制信号；升压二极管 D 的阳极接开关节点、阴极接输出节点；输出电容 C 一端接输出节点、另一端接地。

就组态而言，这是由桥式整流加 Boost 升压单元构成的有源 PFC 电路，通过控制电感电流跟随整流后正弦包络实现高功率因数与低谐波畸变，并将输出电压升压到稳定直流。

## 工作原理
控制开关管使电感电流的平均值按整流后正弦包络变化，从而让电网输入电流与输入电压同相、近似正弦。在连续导电或临界导电模式下，电感储能与释放交替，使输入功率因数接近 1，同时将输出电压升压到稳定直流值。

## 关键计算公式

- 输出电压与占空比（CCM）：
$$V_{out} = \frac{V_{in}}{1-D}$$

- 升压电感（CCM）：
$$L = \frac{V_{in} D}{f_s \Delta I_L}$$

- 输出电容（纹波限制）：
$$C \ge \frac{P_{out}}{4\pi f_{line}\, V_{out}\, \Delta V_{out}}$$

- 功率因数：
$$PF = \frac{I_{1(rms)}}{I_{rms}}$$

- 输出电压纹波（双倍工频）：
$$\Delta V_{out} = \frac{I_{out}}{2\pi (2f_{line}) C}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 整流后输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $f_{line}$ | 电网频率 | Hz |
| $L$ | 升压电感 | H |
| $C$ | 输出电容 | F |
| $P_{out}$ | 输出功率 | W |
| $I_{1(rms)}$ | 基波电流有效值 | A |
| $I_{rms}$ | 总电流有效值 | A |

## 元件调整影响
- **L↑** → 电感纹波电流减小、更易进入 CCM，但体积增大。
- **C↑** → 输出纹波减小，但维持时间与体积增大。
- **D↑** → 输出电压升高；输出电压不可低于输入峰值。
- **f_s↑** → 电感体积减小，但开关损耗增大。
- 电感偏置下饱和会导致电流失控，需保证其在大电流下不失磁。

## 典型参数示例
- 取 $V_{in}=311\ \text{V}$（市电 220V 峰值）、要求 $V_{out}=400\ \text{V}$：$D = 1-\dfrac{311}{400} = 0.2225$。
- 取 $P_{out}=300\ \text{W}$、$V_{out}=400\ \text{V}$、$f_{line}=50\ \text{Hz}$、$\Delta V_{out}=10\ \text{V}$：$C \ge \dfrac{300}{4\pi\times50\times400\times10} \approx 119\ \mu\text{F}$。

## 常见器件型号
- 开关管：SPW20N60C3、STP20NM60、IPA60R180P7。
- 升压二极管（快恢复）：STTH8R06、MUR860、BYV29-600。
- 控制 IC：UCC28070、L6562、NCP1654、ICE2PCS01。

## 注意事项
- 输出电压必须高于输入交流峰值，否则无法正常工作。
- 输出电容需承受双倍工频纹波，应选用低 ESR、耐纹波的电解电容。
- 使用升压二极管时注意反向恢复，临界模式宜选超快恢复或 SiC 二极管。
- 需加 EMI 滤波，满足谐波与传导发射标准。
