# 无桥 PFC 电路

## 拓扑描述
电路由两个升压电感 L1、L2，两个开关管 S1、S2，两个续流二极管 D1、D2 与输出电容 C 构成的无整流桥功率因数校正拓扑。关键节点如下：交流输入两线分别接升压电感 L1、L2 的入端；开关节点 SW1 由 L1 的出端、开关管 S1 的漏极与二极管 D1 的阳极相连而成，开关节点 SW2 由 L2 的出端、开关管 S2 的漏极与二极管 D2 的阳极相连而成；输出节点 $V_{out}$ 由二极管 D1、D2 的阴极与输出电容 C 的上端相连并接负载；开关管 S1、S2 的源极与输出电容 C 的下端一并接输出负端（地）。

各元件管脚连接：升压电感 L1 一端接交流输入一相、另一端接 SW1；升压电感 L2 一端接交流输入另一相、另一端接 SW2；开关管 S1 的漏极接 SW1、源极接输出负端、栅极接驱动信号；开关管 S2 的漏极接 SW2、源极接输出负端、栅极接驱动信号；续流二极管 D1 的阳极接 SW1、阴极接输出节点；续流二极管 D2 的阳极接 SW2、阴极接输出节点；输出电容 C 一端接输出节点、另一端接输出负端。

就组态而言，这是省去整流桥、由两路对称 Boost 支路在正负半周交替工作的无桥 PFC 电路，任意半周仅两个半导体器件导通，输入电流控制成与电压同相的正弦，实现高功率因数与升压稳压。

## 工作原理
市电正半周时，一个开关管与对侧二极管构成升压回路；负半周时由另一组器件工作，对称地完成升压与回流。电感电流被控制成与输入电压同相的正弦，实现功率因数接近 1，同时将交流升压为稳定直流供后级使用。

## 关键计算公式

- 输出电压与占空比（CCM）：
$$V_{out} = \frac{V_{in}}{1-D}$$

- 升压电感（CCM）：
$$L = \frac{V_{in} D}{f_s \Delta I_L}$$

- 输出电压纹波（双倍工频）：
$$\Delta V_{out} = \frac{I_{out}}{2\pi (2f_{line}) C}$$

- 输出电容下限：
$$C \ge \frac{P_{out}}{4\pi f_{line}\, V_{out}\, \Delta V_{out}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $f_{line}$ | 电网频率 | Hz |
| $L$ | 升压电感 | H |
| $C$ | 输出电容 | F |
| $P_{out}$ | 输出功率 | W |
| $\Delta I_L$ | 电感纹波电流 | A |

## 元件调整影响
- **L1、L2↑** → 电感纹波电流减小、更易进入 CCM。
- **C↑** → 输出纹波减小。
- **D↑** → 输出电压升高；输出电压须高于输入峰值。
- **f_s↑** → 电感体积减小但开关损耗增大。
- 两电感分置两端有助于减小共模噪声，但器件数量较 Boost 型更多。

## 典型参数示例
- 取 $V_{in}=311\ \text{V}$、$V_{out}=390\ \text{V}$：$D = 1-\dfrac{311}{390} \approx 0.2026$。
- 取 $P_{out}=400\ \text{W}$、$V_{out}=390\ \text{V}$、$f_{line}=50\ \text{Hz}$、$\Delta V_{out}=10\ \text{V}$：$C \ge \dfrac{400}{4\pi\times50\times390\times10} \approx 163\ \mu\text{F}$。

## 常见器件型号
- 开关管：SPW20N60C3、STP25NM60N、IPW60R099P7。
- 续流二极管：STTH8R06、MUR860、BYV29-600。
- 控制 IC：UCC28070、L6562、NCP1654。

## 注意事项
- 无整流桥，交流直接接功率级，需注意浪涌与雷击防护。
- 输出电压须始终高于输入峰值，否则无法升压。
- 对称拓扑要求两个电感与两个开关管参数匹配，减小不平衡电流。
- 输出电容需耐双倍工频纹波电流与电压。
