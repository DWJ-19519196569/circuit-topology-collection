# 图腾柱 PFC 电路

## 拓扑描述
电路由升压电感 L、高频图腾柱上管 S1 与下管 S2、两个低频二极管（或同步整流 MOSFET）D1、D2 与输出电容 C 构成的无桥功率因数校正拓扑。关键节点如下：交流输入端一相接升压电感 L 的入端；高频桥臂中点（开关节点）由电感 L 的出端、上管 S1 的源极与下管 S2 的漏极相连而成；直流输出节点 $V_{out}$ 由上管 S1 的漏极与输出电容 C 的上端相连并接负载；输出电容 C 的下端与下管 S2 的源极、低频二极管 D1、D2 的一端相连并接输出负端；低频二极管 D1、D2 的另一端分别接交流输入两线，构成低频整流支路。

各元件管脚连接：升压电感 L 一端接交流输入一相、另一端接高频桥臂中点；上管 S1 的漏极接输出节点、源极接高频桥臂中点、栅极接高频驱动信号；下管 S2 的漏极接高频桥臂中点、源极接输出负端（地）、栅极接与 S1 互补的高频驱动；低频二极管 D1、D2 的阳极分别接交流输入两线、阴极并接输出节点（或经电流路径回到输出负端），在正负半周交替导通形成整流与回流路径；输出电容 C 一端接输出节点、另一端接输出负端。

就组态而言，这是省去整流桥、以高频图腾柱桥臂与低频二极管臂构成的无桥 PFC 电路，通过高频开关与工频换相使输入电流近似正弦、功率因数接近 1，并把交流升压为稳定直流。

## 工作原理
高频图腾柱桥臂以开关频率交替导通，使电感电流按正弦包络变化，输入电流与输入电压同相；低频桥臂按电网工频在正负半周切换导通，形成整流与回流路径。整个电路使输入电流接近正弦、功率因数接近 1，同时把交流升压为稳定直流。

## 关键计算公式

- 输出电压与占空比（CCM 等效）：
$$V_{out} = \frac{V_{in}}{1-D}$$

- 升压电感（CCM）：
$$L = \frac{V_{in} D}{f_s \Delta I_L}$$

- 输出电压纹波（双倍工频）：
$$\Delta V_{out} = \frac{I_{out}}{2\pi (2f_{line}) C}$$

- 输出电容下限：
$$C \ge \frac{P_{out}}{4\pi f_{line}\, V_{out}\, \Delta V_{out}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $f_{line}$ | 电网频率 | Hz |
| $L$ | 升压电感 | H |
| $C$ | 输出电容 | F |
| $P_{out}$ | 输出功率 | W |
| $\Delta I_L$ | 电感纹波电流 | A |

## 元件调整影响
- **L↑** → 电感纹波电流减小、更易进入 CCM，但体积增大。
- **C↑** → 输出纹波减小。
- **D↑** → 输出电压升高；输出电压必须高于输入峰值。
- **f_s↑** → 电感减小但开关损耗增大。
- 低频桥臂采用同步整流 MOSFET 可进一步降低导通损耗，但增加驱动复杂度。

## 典型参数示例
- 取 $V_{in}=311\ \text{V}$、$V_{out}=400\ \text{V}$：$D = 1-\dfrac{311}{400} \approx 0.2225$。
- 取 $P_{out}=500\ \text{W}$、$V_{out}=400\ \text{V}$、$f_{line}=50\ \text{Hz}$、$\Delta V_{out}=10\ \text{V}$：$C \ge \dfrac{500}{4\pi\times50\times400\times10} \approx 199\ \mu\text{F}$。

## 常见器件型号
- 高频 MOSFET：IPW65R041CFD、STW70N60DM2、IMZA65R048M1H。
- 低频 MOSFET（同步整流）：IPA60R099P7、STW48N60M2。
- 控制 IC：UCC28070、TEA19162、NCP1680。

## 注意事项
- 高频与低频桥臂换相瞬间需防止直通，加入死区控制。
- 高频 MOSFET 需承受关断时的反向恢复应力，选用低反向恢复体二极管或 SiC/GaN 器件。
- 输出电容需耐双倍工频纹波，选用低 ESR 电解电容。
- 需加强 EMI 滤波，图腾柱整流共模噪声较传统桥更复杂。
