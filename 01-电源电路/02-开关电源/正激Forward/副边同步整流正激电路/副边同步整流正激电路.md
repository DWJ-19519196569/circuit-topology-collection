# 副边同步整流正激电路

## 拓扑描述
电路在单管正激变换器基础上，由主开关管 Q、隔离变压器 T、副边同步整流 MOSFET $Q_{SR1}$、续流同步整流 MOSFET $Q_{SR2}$、滤波电感 L 与输出电容 C 组成。关键节点如下：输入节点 $V_{in}$ 接主开关 Q 的漏极；原边开关节点由 Q 的源极与变压器初级同名端相连而成，初级异名端接地；副边同名端接 $Q_{SR1}$ 的源极作为整流输入，$Q_{SR1}$ 的漏极与 $Q_{SR2}$ 的漏极、滤波电感 L 的入端相连于中间节点；$Q_{SR2}$ 的源极接副边地；输出节点 $V_{out}$ 由电感 L 的出端与输出电容 C 的上端相连并接负载，输出电容 C 的下端与变压器次级异名端一并接副边地。

各元件管脚连接：主开关 Q 的漏极接输入节点、源极接原边开关节点、栅极接 PWM 信号；变压器初级同名端接原边开关节点、初级异名端接地，次级同名端接整流同步管 $Q_{SR1}$ 的源极、次级异名端接副边地；整流同步管 $Q_{SR1}$ 的漏极接中间节点、栅极接同步整流驱动；续流同步管 $Q_{SR2}$ 的漏极接中间节点、源极接副边地、栅极接与 $Q_{SR1}$ 互补的同步整流驱动；滤波电感 L 一端接中间节点、另一端接输出节点；输出电容 C 一端接输出节点、另一端接副边地。

就组态而言，这是以两只 MOS 同步整流管取代副边整流与续流二极管的单管正激变换器，通过与主开关时序配合、以 MOSFET 低导通压降承担整流续流，用于低压大电流的隔离电源以显著降低导通损耗。

## 工作原理
主开关 $Q$ 导通、变压器副边感应电压为正半周时，$Q_{SR1}$ 开通（作为整流管）、$Q_{SR2}$ 关断，能量经 $Q_{SR1}$ 传给负载；主开关关断、反压半周时，$Q_{SR2}$ 开通续流、$Q_{SR1}$ 关断，电感经 $Q_{SR2}$ 续流维持输出电流。

## 关键计算公式

- 输出电压：
$$V_o = \frac{N_s}{N_p} D V_{in} - V_{SR(on)}$$

- 同步整流管导通损耗：
$$P_{cond} = I_{rms}^2 R_{DS(on)}$$

- 同步管电流有效值：
$$I_{rms} = I_o \sqrt{D}$$

- 副边整流/续流两管的导通压降：
$$V_{SR} = I_o R_{DS(on)} \quad (\text{远小于二极管 } V_F)$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_o$ | 输出电压 | V |
| $D$ | 主开关占空比 | — |
| $N_p, N_s$ | 原、副边匝数 | — |
| $R_{DS(on)}$ | 同步管导通电阻 | Ω |
| $I_o$ | 输出电流 | A |
| $I_{rms}$ | 同步管电流有效值 | A |

## 元件调整影响
- **$R_{DS(on)}$ 减小** → 导通损耗与压降减小，效率提高、发热降低。
- **$I_o$ 增大** → 导通损耗随 $I_o^2 R_{DS(on)}$ 上升，同步整流优势越明显。
- **$D$ 增大** → 输出电压增大，整流管导通时间与有效电流增大。
- 同步整流在较大电流时相对二极管整流优势显著，小电流时收益有限。

## 典型参数示例
- 取 $I_o=20\ \text{A}$、$R_{DS(on)}=2\ \text{mΩ}$、$D=0.5$：$I_{rms} = 20\times\sqrt{0.5} \approx 14.14\ \text{A}$，$P_{cond} = 14.14^2\times0.002 \approx 0.4\ \text{W}$。
- 对比二极管（$V_F=0.5\ \text{V}$）整流损耗 $P = I_o V_F = 20\times0.5 = 10\ \text{W}$，同步整流损耗低一个数量级。

## 常见器件型号
- 同步整流 MOSFET：IRF7822、SiS468、BSC010N04、CSD18501。
- 同步整流控制器：UCC24610、NCP4306、IR1167。
- 主开关：IRF540N、IPB 系列。
- 变压器：定制高频低漏感磁芯。

## 注意事项
- 需精确控制同步管的开通关断时序，防止两管同时导通导致环流短路。
- 轻载或高频时驱动损耗可能超过节约的导通损耗，需整体权衡。
- 需设死区并注意同步管体二极管的续流与反向恢复。
- 同步管栅极驱动需与主开关时序严格同步。
