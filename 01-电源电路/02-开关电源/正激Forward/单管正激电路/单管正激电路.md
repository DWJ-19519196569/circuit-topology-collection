# 单管正激电路

## 拓扑描述
电路由功率开关管 Q、隔离变压器 T（含复位绕组）、整流二极管 $D_r$、续流二极管 $D_f$、滤波电感 L 与输出电容 C 六个元件组成。关键节点如下：输入节点 $V_{in}$ 接开关管 Q 的漏极；原边开关节点由 Q 的源极与变压器初级同名端相连而成，变压器初级异名端接地；复位绕组与初级同极性连接，用于磁通复位；副边正端由变压器次级同名端接整流二极管 $D_r$ 的阳极；中间节点由 $D_r$ 的阴极、续流二极管 $D_f$ 的阴极（此处 $D_f$ 阳极接地构成续流路径）与滤波电感 L 的入端相连而成，实际为 $D_r$ 阴极与电感入端相连、$D_f$ 阴极接该点；输出节点 $V_{out}$ 由电感 L 的出端与输出电容 C 的上端相连并接负载，输出电容 C 的下端与 $D_f$ 的阳极、变压器次级异名端一并接副边地。

各元件管脚连接：开关管 Q 的漏极接输入节点、源极接原边开关节点、栅极 G 接 PWM 控制信号；变压器初级同名端接原边开关节点、初级异名端接地，复位绕组一端接地或经复位二极管接电源、另一端与初级同名端极性相反接法以便复位，次级同名端接整流二极管 $D_r$ 的阳极、次级异名端接副边地；整流二极管 $D_r$ 的阳极接次级同名端、阴极接中间节点（电感入端）；续流二极管 $D_f$ 的阳极接副边地、阴极接中间节点；滤波电感 L 一端接中间节点、另一端接输出节点；输出电容 C 一端接输出节点、另一端接副边地。

就组态而言，这是以单开关管、隔离变压器加复位绕组、副边整流续流与 LC 滤波构成的单管正激变换器，导通期直接经变压器向副边传能、关断期续流，实现降压型隔离直流变换。

## 工作原理
开关导通时变压器原边励磁、副边感应电压使 $D_r$ 导通，能量传递到负载并给电感储能；开关关断时 $D_r$ 截止、$D_f$ 续流，电感放电维持输出。与反激不同，正激在导通期间直接向负载传能。

## 关键计算公式

- 输出电压（连续模式，不计压降）：
$$V_o = \frac{N_s}{N_p} D V_{in}$$

- 最小输出电感（维持连续模式）：
$$L_{min} = \frac{V_o (1-D)}{2 f_{sw} I_{o(min)}}$$

- 输出电流纹波：
$$\Delta I_L = \frac{V_o (1-D)}{L f_{sw}}$$

- 开关管电压应力（无复位绕组时需外加复位）：
$$V_{DS(off)} = V_{in} + V_{reset}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_o$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $N_p, N_s$ | 原、副边匝数 | — |
| $L$ | 输出滤波电感 | H |
| $f_{sw}$ | 开关频率 | Hz |
| $I_{o(min)}$ | 最小负载电流 | A |

## 元件调整影响
- **$D$ 增大** → 输出电压增大，但磁芯伏秒增加、复位要求提高。
- **输出电感 $L$ 增大** → 电流纹波与最小连续负载电流减小，动态响应变慢。
- **$f_{sw}$ 增大** → 电感与变压器可缩小，但开关损耗增大。
- **匝比 $N$ 增大** → 输出电压升高、副边整流二极管耐压升高。

## 典型参数示例
- 取 $V_{in}=48\ \text{V}$、$N_p:N_s=10:2$、$D=0.45$：$V_o = (2/10)\times0.45\times48 = 4.32\ \text{V}$。
- 取 $V_o=5\ \text{V}$、$D=0.45$、$f_{sw}=100\ \text{kHz}$、$I_{o(min)}=1\ \text{A}$：$L_{min} = 5\times0.55/(2\times10^{5}\times1) = 13.75\ \mu\text{H}$。

## 常见器件型号
- 开关管：IRF540N、STP10NK60、IPB 系列。
- 控制器：UC3842、UC3844、NCP1251。
- 输出二极管：MBR 系列肖特基、MUR 系列快恢复。
- 变压器：定制 EE/EF 铁氧体磁芯，需复位绕组。

## 注意事项
- 变压器必须设复位绕组或复位电路，防止磁芯单向磁化饱和。
- 无软开关时开关管开关损耗与电压尖峰较大，需吸收回路。
- 输出侧为降压 LC 滤波，纹波较反激小。
- 电感需按最小负载电流设计，轻载可能进入断续模式。
