# 交错并联 Buck 电路

## 拓扑描述
电路由两路（或多路）结构相同的 Buck 降压单元并联组成，每路含一个开关管、一个续流二极管（或同步整流管）与一个输出电感，共享同一输入与输出。以两路为例，元件为开关管 Q1、Q2，续流二极管（或同步整流管）D1、D2，输出电感 L1、L2 与输出电容 C。关键节点如下：公共输入节点 $V_{in}$ 同时接两路开关管 Q1、Q2 的漏极；每路的开关节点 SW1、SW2 分别由开关管源极、二极管阴极（或同步管漏极）与电感入端相连而成；公共输出节点 $V_{out}$ 由两路电感 L1、L2 的出端与输出电容 C 的上端相连并接负载，输出电容 C 的下端与两路二极管 D1、D2 的阳极（或同步管源极）一并接地。

各元件管脚连接：开关管 Q1、Q2 的漏极接公共输入节点、源极各接本路开关节点、栅极接相位交错的驱动信号（两路相差 180°）；续流二极管 D1、D2 的阴极各接本路开关节点、阳极接地（若用同步整流管则其漏极接开关节点、源极接地、栅极接互补驱动）；输出电感 L1、L2 一端各接本路开关节点、另一端并接公共输出节点；输出电容 C 一端接公共输出节点、另一端接地。

就组态而言，这是多相 Buck 单元交错并联、开关管相位错开 180° 的交错并联 Buck 电路，通过各相电感电流纹波相互抵消减小输出电流纹波、提高等效纹波频率，用于低压大电流供电。

## 工作原理
各 Buck 单元的开关管按相位依次错开导通，使各相电感电流在输出电容处叠加时纹波相互抵消。总输出电流纹波比单路显著减小，等效纹波频率提高到 $N \times f_{sw}$（$N$ 为相数），从而可用更小的输出电容与电感，改善瞬态响应与散热。

## 关键计算公式

- 单相占空比（CCM 稳态）：
$$V_{out} = D V_{in} \quad\Rightarrow\quad D = \frac{V_{out}}{V_{in}}$$

- 单相电感值：
$$L = \frac{(V_{in}-V_{out})D}{f_{sw}\Delta I_L}$$

- 相电流纹波消减比（$N$ 相，$0 \le D \le 1$，$m=\lfloor ND\rfloor$）：
$$K = \frac{\Delta I_{out}}{\Delta I_L} = \frac{(m+1-ND)(ND-m)}{N D (1-D)}$$

> 当 $ND$ 为整数时 $K=0$，各相输出纹波完全抵消。

- 等效纹波频率：
$$f_{ripple} = N f_{sw}$$

- 总输出电流：
$$I_{out} = N \times \bar{I}_L$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 单相占空比 | — |
| $L$ | 单相电感 | H |
| $\Delta I_L$ | 单相电感纹波电流 | A |
| $\Delta I_{out}$ | 叠加后输出纹波电流 | A |
| $f_{sw}$ | 单相开关频率 | Hz |
| $N$ | 相数 | — |

## 元件调整影响
- **占空比 $D$ 增大（输出电压升高）** → 输出升高，电感纹波先增后减（在 $D$ 接近 0.5 时最大）。
- **相数 $N$ 增多** → 输出纹波减小、等效频率升高、开关应力分散，但控制与成本增加。
- **单相电感 $L$ 增大** → 相电流纹波减小，瞬态响应变慢。
- **开关频率 $f_{sw}$ 升高** → 电感与电容可小型化，开关损耗增大。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$V_{out}=1.2\ \text{V}$：单相占空比 $D = \dfrac{1.2}{12} = 0.1$。
- 取 $V_{in}=12\ \text{V}$、$V_{out}=1.2\ \text{V}$、$D=0.1$、$f_{sw}=500\ \text{kHz}$、$\Delta I_L=2\ \text{A}$：$L = \dfrac{(12-1.2)\times0.1}{500\times10^3\times2} = 1.08\ \mu\text{H}$。

## 常见器件型号
- 多相 Buck 控制芯片：TPS53659、ISL68137、LTC3855、IR35201。
- 功率开关管 / DrMOS：CSD95378、FDMF6820、IR35401。
- 功率电感：铁氧体功率电感（如 XAL、IHLP 系列）。

## 注意事项
- 各相需精确均流，相电流不平衡会导致部分电感/开关过热。
- 相移不准确会削弱纹波抵消效果，选择支持精确相位交错的控制 IC。
- 输出电容按合成后的纹波与瞬态要求选择低 ESR、大容量电容。
- 多相布局需对称，避免各相寄生参数差异带来电流不均与振荡。
