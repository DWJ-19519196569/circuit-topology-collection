# 交错并联 Boost 电路

## 拓扑描述
电路由两路（或多路）结构相同的 Boost 升压单元并联组成，每路含一个升压电感、一个开关管与一个续流二极管，共享同一输入与输出。以两路为例，元件为升压电感 L1、L2，开关管 S1、S2，续流二极管 D1、D2 与输出电容 C。关键节点如下：公共输入节点 $V_{in}$ 同时接两路电感 L1、L2 的入端；每路的开关节点 SW1、SW2 分别由电感出端、开关管漏极与二极管阳极相连而成；公共输出节点 $V_{out}$ 由两路二极管 D1、D2 的阴极与输出电容 C 的上端相连并接负载，输出电容 C 的下端与两路开关管 S1、S2 的源极一并接地。

各元件管脚连接：电感 L1、L2 的一端分别接公共输入节点、另一端各接本路开关节点；开关管 S1、S2 的漏极各接本路开关节点、源极接地、栅极接相位交错的驱动信号（两路相差 180°）；续流二极管 D1、D2 的阳极各接本路开关节点、阴极并接公共输出节点；输出电容 C 一端接公共输出节点、另一端接地。

就组态而言，这是多路 Boost 单元交错并联、开关管相位错开 180° 的交错并联 Boost 电路，通过纹波相互抵消减小输入电流纹波、提高等效纹波频率，实现大功率升压与 PFC。

## 工作原理
各 Boost 单元的开关管按相位依次错开导通，使各单元的电感电流纹波在输出端相互叠加时部分抵消。总输入电流纹波比单路明显减小，等效纹波频率提高为 $N \times f_{sw}$（$N$ 为并联路数），从而可用更小的滤波电容与电感，改善 EMI 和散热分布。

## 关键计算公式

- 单路占空比（CCM 稳态）：
$$V_{out} = \frac{V_{in}}{1-D} \quad\Rightarrow\quad D = 1 - \frac{V_{in}}{V_{out}}$$

- 单路电感值（连续导通模式）：
$$L \ge \frac{V_{in} D}{f_{sw} \Delta I_L}$$

- 输入电流纹波抵消因子（$N$ 路交错，$m=\lfloor ND\rfloor$）：
$$K = \frac{\Delta I_{in}}{\Delta I_L} = \frac{(m+1-ND)(ND-m)}{N D (1-D)}$$

> 当 $ND$ 为整数（$D=m/N$）时 $K=0$，各相纹波完全抵消；单相纹波 $\Delta I_L=\dfrac{V_{in}D}{L f_{sw}}$。

- 等效纹波频率：
$$f_{ripple} = N f_{sw}$$

- 单路峰值电流：
$$I_{L(peak)} = \frac{I_{in}}{N} + \frac{\Delta I_L}{2}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 单路占空比 | — |
| $L$ | 单路升压电感 | H |
| $\Delta I_L$ | 单路电感纹波电流 | A |
| $f_{sw}$ | 单路开关频率 | Hz |
| $N$ | 并联路数 | — |
| $I_{in}$ | 总输入电流 | A |

## 元件调整影响
- **占空比 $D$ 增大（输入降低或输出升高）** → 升压比增大，电感储能增加。
- **单路电感 $L$ 增大** → 电流纹波减小，但动态响应变慢、体积增大。
- **并联路数 $N$ 增多** → 总纹波减小、等效频率升高、功率扩展，但成本与控制复杂度增加。
- **开关频率 $f_{sw}$ 升高** → 电感与输出电容可减小，开关损耗增大。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$V_{out}=24\ \text{V}$：单路占空比 $D = 1 - \dfrac{12}{24} = 0.5$。
- 取 $V_{in}=12\ \text{V}$、$D=0.5$、$f_{sw}=200\ \text{kHz}$、$\Delta I_L=1\ \text{A}$：$L \ge \dfrac{12\times0.5}{200\times10^3\times1} = 30\ \mu\text{H}$。

## 常见器件型号
- Boost 控制芯片：UCC28070（交错 PFC）、LM5122、LT3757、TPS43060。
- 功率开关管：IRF3205、CSD19531、IPA60R280（高压场合）。
- 续流二极管：MBR20100、STPS20M100（或同步整流 MOSFET）。

## 注意事项
- 各相占空比需精确均流，否则各相电感电流不均、部分器件过热。
- 交错相位偏差会削弱纹波抵消效果，需控制器支持严格相移。
- 输出电容需按合成后的纹波电流选择低 ESR 电容。
- 占空比 $D$ 接近 1 时升压比剧增、效率下降，需限制最小输入电压范围。
