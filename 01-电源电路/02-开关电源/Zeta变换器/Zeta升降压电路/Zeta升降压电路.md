# Zeta 升降压电路

## 拓扑描述
电路由开关管 S、耦合/储能电容 Cs、电感 L1、电感 L2、二极管 D 与输出电容 C 六个元件组成。关键节点如下：输入节点 $V_{in}$ 接开关管 S 的漏极；耦合节点由开关管 S 的源极、耦合电容 Cs 的上端相连而成；中间节点由 Cs 的下端、电感 L1 的入端与二极管 D 的阳极相连而成；输出节点 $V_{out}$ 由电感 L1 的出端与输出电容 C 的上端相连并接负载，输出电容 C 的下端与电感 L2 的入端、二极管 D 的阴极一并接地（电感 L2 的出端也接地）。

各元件管脚连接：开关管 S 的漏极接输入节点、源极接耦合节点、栅极 G 接控制信号；耦合电容 Cs 一端接耦合节点、另一端接中间节点；电感 L1 一端接中间节点、另一端接输出节点；二极管 D 的阳极接中间节点、阴极接地；电感 L2 一端接中间节点（或与二极管阳极同点）、另一端接地（L2 与 L1 可绕成耦合电感）；输出电容 C 一端接输出节点、另一端接地。

就组态而言，这是结构与 SEPIC 互为对偶的 Zeta 升降压变换器，输出与输入同极性、既能升压又能降压，输入电流断续而输出电流连续。

## 工作原理
开关管导通时输入经耦合电容向电感 L1 储能并直接向负载供能；关断时电感 L1 经二极管续流、电感 L2 向耦合电容回馈能量。通过耦合电容的电荷平衡实现稳定变换，输出极性保持不变。

## 关键计算公式

- 理想电压增益（CCM）：
$$V_{out} = \frac{D}{1-D} V_{in}$$

- 占空比与电压关系：
$$D = \frac{V_{out}}{V_{in}+V_{out}}$$

- 电感纹波电流：
$$\Delta I_{L1} = \frac{V_{in} D}{f_s L_1}$$

- 输出电压纹波：
$$\Delta V_{out} = \frac{I_{out} D}{f_s C}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $f_s$ | 开关频率 | Hz |
| $L_1$ | 输出侧电感 | H |
| $C_s$ | 耦合电容 | F |
| $C$ | 输出电容 | F |
| $I_{out}$ | 输出电流 | A |

## 元件调整影响
- **D↑** → 输出电压升高；D<0.5 降压、D>0.5 升压。
- **L1↑** → 输出侧电感纹波电流减小，输出更平滑。
- **Cs↑** → 耦合电容纹波减小，传能平稳。
- **C↑** → 输出电压纹波减小。
- L1、L2 采用耦合电感可减小体积，但需注意匝比与同名端。

## 典型参数示例
- 取 $V_{in}=12\ \text{V}$、$D=0.4$：$V_{out} = \dfrac{0.4}{1-0.4}\times12 = 8\ \text{V}$。
- 取 $f_s=400\ \text{kHz}$、$L_1=10\ \mu\text{H}$、$V_{in}=12\ \text{V}$、$D=0.4$：$\Delta I_{L1} = \dfrac{12\times0.4}{400\times10^3\times10\times10^{-6}} = 1.2\ \text{A}$。

## 常见器件型号
- 开关管：IRF540N、SI2302、CSD17570。
- 二极管：SS34、MBR0520、SS56。
- 控制 IC：LM3478、LT3757、MAX668（可配置）。

## 注意事项
- 输入电流断续，输入侧需加电容滤波以减小纹波。
- 开关管与耦合电容承受较高电压应力，需留足耐压余量。
- 耦合电容需用低 ESR、无极性电容并承受高频纹波。
- 含右半平面零点，环路补偿带宽需限制以保证稳定。
