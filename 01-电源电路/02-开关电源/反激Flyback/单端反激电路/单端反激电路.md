# 单端反激电路

## 拓扑描述
单端反激（Flyback）变换器由 **一个功率开关管 $Q$**、**一个高频变压器 $T$**（实为带气隙的耦合电感，含原边绕组与副边绕组）、**输入电容 $C_{in}$**、**副边整流二极管 $D_o$**、**输出滤波电容 $C_o$** 组成。电路关键节点：**节点① 输入正端 $+V_{in}$**（$C_{in}$ 一端、变压器初级同名端相连）；**节点② 开关节点 A（漏极节点）**（变压器初级另一端、$Q$ 漏极相连）；**节点③ 地 GND**（$Q$ 源极、$C_{in}$ 另一端相连）；**节点④ 输出正端 $+V_o$**（$D_o$ 阴极、$C_o$ 上端相连）；**节点⑤ 副边地 $GND_{sec}$**（变压器次级同名端、$C_o$ 下端相连）。

各元件管脚连接：**$Q$** 漏极接开关节点 A、源极接地、栅极接驱动；**变压器 $T$** 初级同名端接 $+V_{in}$、初级另一端接开关节点 A，次级非同名端接 $D_o$ 阳极、同名端接副边地 $GND_{sec}$；**$D_o$** 阳极接次级非同名端、阴极接输出正端 $+V_o$；**$C_{in}$** 一端接 $+V_{in}$、另一端接地；**$C_o$** 上端接 $+V_o$、下端接副边地；负载跨接 $+V_o$ 与 $GND_{sec}$。

由此构成开关导通时输入电压加在原边储能、关断时副边经 $D_o$ 释放电能的单端反激（Flyback）组态，结构简单、成本低，是 AC-DC 与隔离 DC-DC 应用最广泛的拓扑之一。

## 工作原理
开关导通时，输入电压加在变压器原边，电流线性上升、能量以磁场形式储存在气隙与磁芯中，此时副边二极管反偏截止、由输出电容向负载供电。开关关断时，变压器原边电流被截断，副边感应电压反向，使副边二极管导通，储存的能量释放到负载并给输出电容充电。

## 关键计算公式

- 占空比（连续导通模式 CCM）：
$$V_{out} = \frac{D}{1-D}\ \frac{N_s}{N_p}\ V_{in} \quad\Rightarrow\quad D = \frac{V_{out}}{V_{out} + n V_{in}}$$

- 变压器（电感）储能：
$$E = \frac{1}{2} L_p I_p^2$$

- 原边电流纹波（峰峰值）：
$$\Delta I_p = \frac{V_{in}D}{L_p f_{sw}}$$

- 匝比（反射电压法）：
$$n = \frac{N_s}{N_p} = \frac{V_{out} + V_F}{V_{OR}}$$

- 开关管耐压（忽略漏感尖峰）：
$$V_{DS} = V_{in(max)} + V_{OR} = V_{in(max)} + \frac{N_p}{N_s}(V_{out}+V_F)$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $V_{in}$ | 输入电压 | V |
| $V_{out}$ | 输出电压 | V |
| $D$ | 占空比 | — |
| $N_p, N_s$ | 原/副边匝数 | — |
| $L_p$ | 原边电感量 | H |
| $I_p$ | 原边峰值电流 | A |
| $\Delta I_p$ | 原边电流纹波（峰峰值）；CCM 峰值电流 $I_{p,pk}=I_{p,avg}+\Delta I_p/2$ | A |
| $f_{sw}$ | 开关频率 | Hz |
| $V_{OR}$ | 反射电压 | V |
| $V_F$ | 二极管正向压降 | V |

## 元件调整影响
- **占空比 $D$ 增大** → 输出电压升高，但开关导通时间变长、原边储能与峰值电流增大。
- **原边电感 $L_p$ 增大** → 相同功率下峰值电流减小，但可能进入占空比受限区域需更大磁芯。
- **匝比 $n$ 增大（副边更多匝）** → 反射电压 $V_{OR}$ **减小**、开关管耐压需求降低，但副边二极管反向应力增大。
- **开关频率 $f_{sw}$ 升高** → 变压器可小型化，但开关损耗与漏感尖峰增大。

## 典型参数示例
- 取 $V_{in}=100\ \text{V}$、$V_{out}=12\ \text{V}$、$N_s/N_p=0.1$（即 $n=0.1$）：$$D = \frac{12}{12+0.1\times100}\approx54.5\%$$。
- 取 $V_{in}=300\ \text{V}$、$D=0.4$、$L_p=1\ \text{mH}$、$f_{sw}=65\ \text{kHz}$：$\Delta I_p = \dfrac{300\times0.4}{1\times10^{-3}\times65\times10^3} \approx 1.85\ \text{A}$。

## 注意事项
- 变压器漏感会在开关管关断瞬间产生高压尖峰，必须加 RCD 钳位或 TVS 吸收，否则损坏开关管。
- 变压器需开气隙以存储能量并防止饱和，CCM 与 DCM 需分别校验磁芯。
- 输出电容需承受大的纹波电流，选用低 ESR 电解/固态电容。
- 反激功率密度有限，通常适用于几十瓦以内的应用，大功率需改选正激或全桥。
