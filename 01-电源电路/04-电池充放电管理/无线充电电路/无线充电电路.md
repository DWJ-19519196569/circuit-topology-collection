# 无线充电电路

## 拓扑描述
本电路分为发射端与接收端两部分。发射端由半桥/全桥逆变器（功率 MOSFET Q1～Q4 或 Q1、Q2）、发射线圈 $L_1$（编号 Ltx）与谐振电容 $C_1$（编号 Ctx），以及发射控制 IC（编号 IC1）组成；接收端由接收线圈 $L_2$（编号 Lrx）、谐振电容 $C_2$（编号 Crx）、整流桥（二极管 D1～D4 或同步整流）与接收/充电管理 IC（编号 IC2）组成。关键节点有：发射端直流供电节点 VIN、发射谐振节点（线圈与电容连接端）、发射地 GND；接收端接收谐振节点（接收线圈与电容连接端）、整流输出节点 VRECT、充电输出节点 VBAT 与接收地。

各元件管脚连接：发射端各级联构成桥式逆变，上管（如 Q1）漏极接 VIN、源极接一个发射谐振半桥节点，下管（如 Q2）漏极接该半桥节点、源极接 GND，两管栅极由 IC1 驱动；发射线圈 $L_1$ 的一端接半桥中点、另一端与谐振电容 $C_1$ 串联构成谐振回路。接收线圈 $L_2$ 与谐振电容 $C_2$ 串联（或并联）构成接收谐振回路，其两端接整流桥 D1～D4 的交流输入端；整流桥正输出接节点 VRECT、负输出接接收地，再经接收管理 IC2 稳压后由节点 VBAT 对电池充电。发射端与接收端之间无电气连接，仅靠两线圈间的磁场耦合隔空传递能量。

组态上这是一个"发射逆变 + 谐振耦合 + 接收谐振整流"的电磁感应/磁共振无线充电组态，直流经逆变转高频交流激励发射线圈，接收线圈感应出交流再整流稳压对电池充电，典型基于 Qi 标准。

## 工作原理
发射端把直流经逆变器转换为高频交流，驱动发射线圈产生交变磁场；接收线圈感应出同频交流电压，经整流、稳压后对电池充电，实现无电气接触的能量传输。

## 关键计算公式

- 谐振频率：
$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

- 互感耦合电压（互感 $M$）：
$$V_{ind} = j\omega M I_1$$

- 耦合系数：
$$k = \frac{M}{\sqrt{L_1 L_2}}$$

- 传输效率（粗略）：
$$\eta = \frac{P_{out}}{P_{in}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $L, C$ | 谐振电感、电容 | H, F |
| $f_0$ | 谐振频率 | Hz |
| $M$ | 互感 | H |
| $I_1$ | 发射线圈电流 | A |
| $k$ | 耦合系数 | —（无量纲） |
| $\eta$ | 效率 | — |

## 元件调整影响
- 电感或电容增大 → 谐振频率降低；反之升高。
- 线圈间距离加大或错位 → 耦合系数 $k$ 下降，效率降低。
- 发射功率 / 电压抬升 → 接收端感应电压升高。
- 谐振失配会明显降低传输效率与充电距离。

## 典型参数示例
- 发射线圈 $L=24\ \mu\text{H}$、谐振电容 $C=100\ \text{nF}$：$f_0=\dfrac{1}{2\pi\sqrt{24\times10^{-6}\times100\times10^{-9}}}\approx 103\ \text{kHz}$。
- 接收线圈 $L=11\ \mu\text{H}$、$C=200\ \text{nF}$：$f_0\approx107\ \text{kHz}$，与发射端接近实现谐振耦合。

## 常见器件型号
- 无线充电接收 IC：BQ51013B、BQ51050B。
- 无线充电发射 IC：BQ500212A、XKT 系列。
- 功率管：IRF540N、AO3400；整流用肖特基。

## 注意事项
- 收发两端谐振频率需匹配（通常在 100~200 kHz 附近）。
- 线圈对位与间距对效率影响显著，金属异物会发热甚至损坏。
- 需关注异物检测（FOD）、过温与过压保护。
- 电磁兼容（EMC）与电磁辐射应符合相关标准。
