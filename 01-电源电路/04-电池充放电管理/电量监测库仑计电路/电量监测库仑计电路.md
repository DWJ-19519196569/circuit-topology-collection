# 电量监测库仑计电路

## 拓扑描述
本电路由检流（采样）电阻 $R_{sense}$（编号 Rs）、库仑计/电量计 IC（编号 IC1）及少量辅助滤波元件组成。关键节点有：电池（或充电器）电流输入节点 IN、检流电阻另一端的输出节点 OUT（接负载或电池），以及 IC1 的两路差分采样节点 S+、S-（分别跨接在检流电阻两端）。检流电阻 Rs 串联在电池主回路中，所有电流都从节点 IN 经 Rs 流向节点 OUT。

各元件管脚连接：检流电阻 Rs 一端接输入节点 IN、另一端接输出节点 OUT，其两端分别引出 Kelvin 四线接到 IC1 的电流检测正端（IN+，接节点 IN）与负端（IN-，接节点 OUT）。电量计 IC（IC1）的电源端接系统电源、地端接 GND，其电压检测端并联在电池两端以同时读电池电压，温度检测端外接热敏电阻用于温补，输出端（I²C/SMBus 或状态指示）接主控 MCU。由此 IC1 对 Rs 两端压降对应的电流做时间积分，并结合电压、温度参数估算剩余电量 SOC。

组态上这是一个"检流电阻 + 库仑计 IC"的电流积分型电量监测组态，检流电阻串接主回路、IC 对电流积分并换算荷电状态，用于电池剩余电量的计量与显示。

## 工作原理
电流流过检流电阻产生压降 $V=I·R_{sense}$，库仑计对该压降对应的电流做时间积分得到累计电荷量（库仑），再配合满充容量、自放电与温度补偿模型换算出荷电状态 SOC。

## 关键计算公式

- 检流电阻压降：
$$V_{sense} = I \cdot R_{sense}$$

- 累计电荷（库仑计核心）：
$$Q = \int i(t)\,dt$$

- 荷电状态：
$$SOC = \frac{Q_{available}}{Q_{rated}} \times 100\%$$

- 库仑计分辨率（ADC 位数 $n$、量程 $V_{FS}$）：
$$\Delta V_{LSB} = \frac{V_{FS}}{2^n}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I$ / $i(t)$ | 电流 | A |
| $R_{sense}$ | 检流电阻 | Ω |
| $V_{sense}$ | 检流电阻压降 | V |
| $Q$ | 累计电荷 | C |
| $Q_{available}$ | 可用容量 | C |
| $Q_{rated}$ | 额定容量 | C |
| $SOC$ | 荷电状态 | % |

## 元件调整影响
- $R_{sense}$ 增大 → 信噪比与精度提高，但压降损耗和发热增大。
- $R_{sense}$ 减小 → 损耗降低，但小电流时测量精度下降。
- ADC 位数越高 / 采样累积越频繁 → 计算精度越高。
- 温度补偿模型越准确 → 不同温度下 SOC 估算越准。

## 典型参数示例
- 检流电阻 $R_{sense}=10\ \text{mΩ}$、电流 $I=1\ \text{A}$：$V_{sense}=1\times0.01=10\ \text{mV}$。
- 额定容量 $Q_{rated}=2\ \text{Ah}=7200\ \text{C}$，已放出 $Q_{used}=1800\ \text{C}$：$SOC=\dfrac{7200-1800}{7200}\times100\%=75\%$。

## 常见器件型号
- 电量计 / 库仑计 IC：BQ27421、BQ34Z100、MAX17048、LTC2941。
- 检流电阻：合金采样电阻（1 mΩ ~ 20 mΩ，4 端子）。
- 配套 MCU 或电池管理 AFE。

## 注意事项
- 检流电阻两端需 Kelvin 四线连接，避免走线电阻混入采样误差。
- 库仑计会累积误差，需定期用满充 / 满放校准基准点。
- 大电流与小电流并存时，兼顾量程与分辨率的 ADC 选择很关键。
- 避免检流电阻过热导致温漂，影响测量长期精度。
