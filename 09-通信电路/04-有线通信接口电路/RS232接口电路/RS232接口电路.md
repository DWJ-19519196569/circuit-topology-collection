# RS232 接口电路

## 拓扑描述
由 **RS232 收发器 A1**（电平转换芯片，如 MAX232、MAX3232）、**电荷泵升压电容 $C_1$~$C_4$（$C_+$、$C_-$、$C_{V+}$、$C_{V-}$）**、**电源去耦电容** 与 **DB9 连接器 J1** 组成。电路共有 7 个关键节点：**节点① UART 发送**（MCU 的 TXD 与 A1 的 T1IN 相连）；**节点② UART 接收**（MCU 的 RXD 与 A1 的 R1OUT 相连）；**节点③ RS232 发送线 TXD**（A1 的 T1OUT 与 J1 的 3 脚相连）；**节点④ RS232 接收线 RXD**（A1 的 R1IN 与 J1 的 2 脚相连）；**节点⑤ 电荷泵正电压 $V_+$**；**节点⑥ 电荷泵负电压 $V_-$**；**节点⑦ 数字电源**（VCC，5 V 或 3.3 V）与 **节点⑧ 地**（GND）。

各器件管脚连接：**A1** 的 T1IN 接节点①、R1OUT 接节点②、T1OUT 接节点③、R1IN 接节点④、V$+$ 接节点⑤、V$-$ 接节点⑥、VCC 接节点⑦、GND 接节点⑧；双路型号的 T2IN/R2OUT/T2OUT/R2IN 可类似接第二路串口。**电荷泵电容**：$C_1$（约 0.1 μF）跨接 A1 的 $C_+$ 与 $C_-$（倍压泵电容），$C_2$ 接在 V$+$（节点⑤）与地之间、$C_3$ 接在 V$-$（节点⑥）与地之间、$C_4$ 接在 VCC（节点⑦）与地之间的储能/泵电容，把 VCC 倍压并反相得到 $\pm(5\sim 15)$ V；去耦电容接在 VCC 与 GND 间靠近芯片放置。**J1** 按标准 DTE 接法：3 脚（TxD 发送）接节点③、2 脚（RxD 接收）接节点④、5 脚（GND）接系统地，其余信号脚（DTR/DSR/RTS/CTS、DCD）按应用接 A1 与 MCU 的流控脚或悬空。

由此构成"UART 经收发器做 TTL 与 RS232 电平双向转换、电荷泵升压到 ±（5~15 V）、单端点对点连接 DB9"的异步串行接口，逻辑 1 为负电平、逻辑 0 为正电平，用于较短距离（一般 ≤15 m）数据传输。

## 工作原理
RS232 用单端电压传输：逻辑 1（MARK）为 -3～-15 V，逻辑 0（SPACE）为 +3～+15 V，以正负电平区分而非差动。UART 数据按起始位、数据位、校验位、停止位成帧收发，收发器负责 TTL 正逻辑与 RS232 负逻辑/电平之间的双向转换。

## 关键计算公式

- 单个符号比特率（$t_{bit}$ 位时间）：
$$R_b = \frac{1}{t_{bit}}$$

- 最大波特率与线缆长度关系（经验，$C_{cable}$ 电缆电容）：
$$R_{b,max} \approx \frac{1}{2\pi R_{driver} C_{cable}}$$

- 帧效率（$N_{data}$ 数据位、$N_{overhead}$ 起止/校验位）：
$$\eta = \frac{N_{data}}{N_{data} + N_{overhead}}$$

- 有效数据率：
$$R_{data} = R_b \times \eta$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_b$ | 波特率 | bit/s |
| $t_{bit}$ | 位时间 | s |
| $R_{driver}$ | 驱动器输出阻抗 | Ω |
| $C_{cable}$ | 电缆电容 | F |
| $\eta$ | 帧效率 | — |

## 元件调整影响
- **波特率增大** → 传输速率提高，但线缆长度受限、误码率上升。
- **电荷泵电容减小** → 输出电压幅度不足，可能跌破 ±5 V 规范下限。
- **线缆电容增大（线变长）** → 波形边沿变缓，高波特率下无法可靠通信。
- **驱动器摆率/供电电压提高** → 输出幅度大、抗扰增强，但 EMI 略增。
- **收/发双方波特率不一致** → 采样错位，出现误码。

## 典型参数示例
- 取 $R_b = 9600\ \text{bit/s}$：$t_{bit} = 1/9600 \approx 104\ \mu\text{s}$。
- 取 8N1 帧格式：$N_{data}=8$、$N_{overhead}=2$（起始+停止）：$\eta = 8/10 = 0.8$，$R_{data} = 9600\times0.8 = 7680\ \text{bit/s}$。

## 常见器件型号
- 电平转换：MAX232（5 V）、MAX3232（3.3 V）、SP3232。
- 连接器：DB9（9 针 D-sub）。
- 隔离（可选）：ADuM1201 + 串口隔离。

## 注意事项
- RS232 为单端非差动，抗共模干扰能力弱，距离一般 ≤15 m。
- 需区分 TTL 电平与 RS232 电平，直接连接 MCU 与 RS232 线会损坏器件。
- 电荷泵电容需按数据手册选取并靠近芯片放置，保证输出电压合规。
- RS232 与 RS485/422 不兼容，需用对应转换器桥接。
- 3.3 V 系统应选用 MAX3232 等低压版本以避免电平不匹配。
