# LoRa 收发电路

## 拓扑描述
由 **LoRa 射频收发芯片（如 SX1276/SX1278）U1**、**晶振 Y1**、**天线阻抗匹配网络**、**收发切换开关（RF Switch）K1** 以及少量 **电源滤波电容** 组成，按功能分为射频收发、时钟、天线切换与去耦四类。芯片内部集成调制解调器、功率放大器（PA）和低噪声放大器（LNA），外部晶振提供参考时钟，天线经 π 型匹配网络接入 RF 引脚。电路共有 7 个关键节点：**节点① 天线节点**（天线与匹配网络相连）；**节点② 匹配网络节点**（匹配网络与 K1 的公共端相连）；**节点③ 发射节点**（K1 的 PA 通路接 U1 的发射输出脚）；**节点④ 接收节点**（K1 的 LNA 通路接 U1 的接收输入脚）；**节点⑤ 参考时钟节点**（Y1 与 U1 的时钟脚相连）；**节点⑥ 电源节点 +VCC**；**节点⑦ 地节点 GND**。

各元件管脚连接：**天线**的馈电端接节点①；**匹配网络**（通常为 π 型）一端接节点①、另一端接节点②；**K1** 的公共端 RF 接节点②，发射支路脚 TX 接节点③、接收支路脚 RX 接节点④，控制脚 CTRL 接 U1 的开关控制输出；**U1** 的发射输出脚（PA_OUT）接节点③、接收输入脚（RF_IN）接节点④，时钟脚（XTAL）接节点⑤，电源脚 VDD 接节点⑥、地脚 GND 接节点⑦；**Y1**（如 32 MHz TCXO）两端分别接节点⑤与负载电容（或地）；**电源滤波电容**跨接在节点⑥与⑦之间，抑制发射瞬间电流波动。

由此构成"基带数据经芯片内 CSS 扩频调制、PA 放大后经收发开关与匹配网络辐射，接收时经开关切至 LNA 放大并解调"的 Sub-GHz 低功耗远距离扩频收发组态。

## 工作原理
发射时芯片将数字基带数据做 CSS 扩频调制并经 PA 放大后由天线辐射；接收时信号经 LNA 放大、下变频和扩频解调还原成数据。扩频增益用于换取接收灵敏度，实现远距离低码率传输。

## 关键计算公式

- 链路预算：
$$\text{Link Budget (dB)} = P_{tx} + G_{tx} + G_{rx} - \text{Path Loss} - L_{margin}$$

- 自由空间路径损耗（Friis 公式，$d$ 为距离，$\lambda$ 为波长）：
$$PL = 20\log_{10}(d_{km}) + 20\log_{10}(f_{MHz}) + 32.44$$

- 接收灵敏度近似：
$$S = -174 + 10\log_{10}(BW) + NF + SNR_{min}$$

- 波特率与码片率关系（SF 为扩频因子）：
$$R_c = R_b \cdot 2^{SF}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $P_{tx}$ | 发射功率 | dBm |
| $PL$ | 路径损耗 | dB |
| $BW$ | 接收带宽 | Hz |
| $NF$ | 噪声系数 | dB |
| $SF$ | 扩频因子 | — |
| $R_b$、$R_c$ | 数据率、码片率 | bit/s |

## 元件调整影响
- **SF 增大** → 接收灵敏度提高、抗干扰增强，但数据率下降、空中占用时间变长。
- **BW 增大** → 数据率提高，但灵敏度下降、抗噪能力减弱。
- **发射功率增大** → 通信距离增加，但功耗显著上升。
- **晶振频率偏差增大** → 频偏导致接收灵敏度和邻道抑制能力下降。
- **天线匹配网络失配** → 反射损耗增大，有效辐射功率下降，距离缩短。

## 典型参数示例
- 取 $f = 868\ \text{MHz}$、$d = 1\ \text{km}$：$PL = 20\log_{10}(868) + 20\log_{10}(1) + 32.44 \approx 91.2\ \text{dB}$。
- 取 $BW = 125\ \text{kHz}$、$NF = 6\ \text{dB}$、$SNR_{min} = -20\ \text{dB}$：$S = -174 + 10\log_{10}(125000) + 6 - 20 \approx -137\ \text{dBm}$。

## 常见器件型号
- 收发芯片：SX1276、SX1278、SX1262、LLCC68。
- 射频开关：PE4259、SKY13317。
- 晶振：32 MHz TCXO（±2.5 ppm）。

## 注意事项
- 需遵守当地法规对频率、发射功率和占空比的限制。
- 天线匹配与布局对性能影响大，RF 走线尽量短、做 50 Ω 阻抗控制。
- 晶振精度直接影响链路性能，建议采用 TCXO。
- 供电需足够去耦，发射瞬间电流较大，注意电源纹波。
