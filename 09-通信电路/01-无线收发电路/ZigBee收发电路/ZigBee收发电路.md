# ZigBee 收发电路

## 拓扑描述
由 **ZigBee 无线 SoC/模组（如 CC2530、CC2538、EFR32MG）U1**、**晶振 Y1**、**天线及匹配网络（巴伦 Balun）**、**电源滤波** 组成，按功能分为射频、时钟、电源与网络四类。SoC 内部集成 8051/ARM 内核、IEEE 802.15.4 射频收发机和 MAC，外接天线即可组网，工作在 2.4 GHz / 915 / 868 MHz 频段。电路共有 6 个关键节点：**节点① 天线射频节点**（天线与匹配网络相连）；**节点② 巴伦单端节点**（匹配网络与巴伦单端脚相连）；**节点③ 差分射频节点**（巴伦差分支路接 U1 的差分射频脚）；**节点④ 参考时钟节点**（Y1 与 U1 的晶振脚相连）；**节点⑤ 电源节点 +VCC**；**节点⑥ 地节点 GND**。

各元件管脚连接：**天线**的馈电端接节点①；**匹配网络**一端接节点①、另一端接节点②；**巴伦**的单端脚接节点②、两个差分脚接节点③，且差分走线保持对称；**U1** 的差分射频脚（RF+/RF−）接节点③，晶振脚（XTAL）接节点④，电源脚（VDD、AVDD）接节点⑤、地脚 GND 接节点⑥；**Y1** 两端分别接节点④与负载电容（或地）；**去耦电容**跨接在节点⑤与⑥之间。

由此构成"数据经 SoC 内 DSSS/O-QPSK 调制、经巴伦与匹配网络辐射 2.4 GHz 信号，接收时反向解调"的 IEEE 802.15.4 低功耗自组织网状网络收发组态。

## 工作原理
节点采用直接序列扩频（DSSS）与 O-QPSK 调制，按 IEEE 802.15.4 规范以固定成帧格式收发短数据包。网络层通过协调器组建 PAN，节点以网状（mesh）拓扑多跳转发数据，非活动期进入休眠省电。

## 关键计算公式

- 数据率与符号率关系（4 bit/符号）：
$$R_b = R_{sym} \times 4$$

- 接收灵敏度：
$$S = -174 + 10\log_{10}(BW) + NF + SNR_{min}$$

- 自由空间路径损耗：
$$PL = 20\log_{10}(d_{km}) + 20\log_{10}(f_{MHz}) + 32.44$$

- 平均功耗：
$$P_{avg} = \frac{T_{tx}P_{tx} + T_{rx}P_{rx} + T_{sleep}P_{sleep}}{T_{total}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_b$ | 数据率 | bit/s |
| $R_{sym}$ | 符号率 | symbol/s |
| $S$ | 接收灵敏度 | dBm |
| $PL$ | 路径损耗 | dB |
| $P_{avg}$ | 平均功耗 | W |

## 元件调整影响
- **发射功率增大** → 单跳距离增大，但功耗上升、网络干扰增加。
- **休眠占空比增大** → 功耗降低，但成为路由节点时的转发响应变慢。
- **晶振频偏增大** → 符号定时误差增大，误包率上升。
- **天线匹配失配** → 灵敏度与发射效率下降，网络路由不稳定。
- **巴伦（Balun）与差分走线失配** → 共模抑制变差，辐射性能下降。

## 典型参数示例
- 取 $f = 2.4\ \text{GHz}$（即 $2400\ \text{MHz}$）、$d = 30\ \text{m}$（即 $0.03\ \text{km}$）：$PL = 20\log_{10}(2400)+20\log_{10}(0.03)+32.44 \approx 69.6\ \text{dB}$。
- 取 $R_{sym} = 62.5\ \text{kSymbol/s}$：$R_b = 62.5\times10^3 \times 4 = 250\ \text{kbit/s}$。

## 常见器件型号
- 芯片/模组：CC2530、CC2538、CC2652R、EFR32MG21。
- 天线：2.4 GHz PCB 天线、倒 F 天线（IFA）。

## 注意事项
- 2.4 GHz 频段与 WiFi、蓝牙共用，需做信道规划与干扰规避。
- 网状网络的节点深度与路由数量影响时延，需控制单 PAN 规模。
- 天线净空区需参考芯片参考布局，金属外壳会显著衰减信号。
- 电池供电设备需精确控制休眠唤醒时序以降低平均功耗。
