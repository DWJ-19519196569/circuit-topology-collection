# WiFi 收发电路

## 拓扑描述
由 **WiFi 芯片/模组（如 ESP32、ESP8266，或带射频前端的 SoC）U1**、**晶振 Y1**、**天线及匹配网络**、**电源滤波** 组成，按功能分为射频、时钟、电源与接口四类。模组内部集成基带、射频收发机、PA/LNA 和介质访问控制（MAC），外接 2.4 GHz（或 5 GHz）天线即可实现无线局域网通信。电路共有 6 个关键节点：**节点① 天线射频节点**（天线与匹配网络相连）；**节点② 单端射频节点**（匹配网络与 U1 的射频脚相连）；**节点③ 参考时钟节点**（Y1 与 U1 的晶振脚相连）；**节点④ 接口/数据节点**（U1 的 UART/SPI/SDIO 接口与主控相连）；**节点⑤ 电源节点 +VCC**；**节点⑥ 地节点 GND**。

各元件管脚连接：**天线**的馈电端接节点①；**匹配网络**一端接节点①、另一端接节点②，且尽量贴近 U1 的射频脚；**U1** 的射频脚（RF）接节点②，晶振脚（XTAL）接节点③，数据/接口脚（如 UART_TX/RX、SPI 或 SDIO）接节点④，电源脚（VDD、PA 供电）接节点⑤、地脚 GND 接节点⑥；**Y1** 两端分别接节点③与负载电容（或地）；**电源滤波电容**跨接在节点⑤与⑥之间，减小发射时功率波动。

由此构成"数字数据经模组基带 OFDM 调制、上变频放大后经匹配网络辐射出 2.4/5 GHz 信号，接收时反向解调"的 IEEE 802.11 短距离高速无线局域网收发组态。

## 工作原理
芯片采用 OFDM（正交频分复用）把高速数据分配到多个正交子载波上并行传输，配合 MIMO/波束成形提升吞吐量。收发在时分双工（TDD）下共享同一信道，通过 CSMA/CA 机制竞争信道接入。

## 关键计算公式

- 信道数据率（香农容量上界，$BW$ 带宽、$SNR$ 信噪比）：
$$C = BW \cdot \log_2(1 + SNR)$$

- 自由空间路径损耗：
$$PL = 20\log_{10}(d_{km}) + 20\log_{10}(f_{MHz}) + 32.44$$

- 接收灵敏度：
$$S = -174 + 10\log_{10}(BW) + NF + SNR_{min}$$

- 发射功率与 EIRP 关系：
$$EIRP = P_{tx} - L_{cable} + G_{ant}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C$ | 信道容量 | bit/s |
| $BW$ | 信道带宽 | Hz |
| $SNR$ | 信噪比 | 无量纲（线性） |
| $EIRP$ | 等效全向辐射功率 | dBm |
| $G_{ant}$ | 天线增益 | dBi |

## 元件调整影响
- **信道带宽增大（20→40/80 MHz）** → 吞吐量提升，但灵敏度下降、抗干扰变差。
- **天线增益增大** → 有效辐射功率与接收能力提升，但需满足 EIRP 法规限制。
- **晶振精度变差** → 频偏增大，OFDM 子载波正交性被破坏，误码率上升。
- **匹配网络失配** → 反射损耗增大，距离缩短、发热增加。
- **模块供电纹波大** → 发射时功率波动，出现丢包。

## 典型参数示例
- 取 $BW = 20\ \text{MHz}$、$SNR = 100$（20 dB）：$C = 20\times10^{6} \times \log_2(101) \approx 133\ \text{Mbit/s}$。
- 取 $f = 2.4\ \text{GHz}$（即 $2400\ \text{MHz}$）、$d = 10\ \text{m}$（即 $0.01\ \text{km}$）：$PL = 20\log_{10}(0.01) + 20\log_{10}(2400) + 32.44 \approx 60\ \text{dB}$。

## 常见器件型号
- 模组/芯片：ESP32、ESP8266、CC3235、MT7688。
- 天线：2.4 GHz 陶瓷天线、PCB 天线、外置 SMA 天线。

## 注意事项
- 天线布局需参考模组参考设计，保持净空区，避免金属遮挡。
- 2.4 GHz 与 5 GHz 频段共存干扰需在信道规划上规避。
- PCB 走线需做 50 Ω 阻抗匹配，匹配网络贴近射频引脚。
- 关注发射时的功耗与散热，避免持续满功率导致过热。
