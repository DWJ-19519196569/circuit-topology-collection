# 蓝牙收发电路

## 拓扑描述
由 **蓝牙芯片/模组（如 nRF52832、CC2541、ESP32，集成基带与射频收发机）U1**、**晶振 Y1**、**天线及匹配网络（含巴伦 Balun）**、**电源滤波** 组成，按功能分为射频、时钟、电源与接口四类。模组内部集成 2.4 GHz 射频前端与协议栈，外接天线即可建立蓝牙连接。电路共有 6 个关键节点：**节点① 天线射频节点**（天线与匹配网络相连）；**节点② 巴伦单端节点**（匹配网络与巴伦单端脚相连）；**节点③ 差分射频节点**（巴伦差分支路接 U1 的差分射频脚）；**节点④ 参考时钟节点**（Y1 与 U1 的晶振脚相连）；**节点⑤ 电源节点 +VCC**；**节点⑥ 地节点 GND**。

各元件管脚连接：**天线**的馈电端接节点①；**匹配网络**一端接节点①、另一端接节点②；**巴伦**的单端脚接节点②、两个差分脚接节点③；**U1** 的差分射频脚（RF+/RF−）接节点③，晶振脚（XTAL）接节点④，电源脚（VDD、AVDD）接节点⑤、地脚 GND 接节点⑥；**Y1** 两端分别接节点④与负载电容（或地）；**去耦电容**跨接在节点⑤与⑥之间。

由此构成"数据经模组内 GFSK 调制、经巴伦与匹配网络辐射 2.4 GHz 信号并按跳频收发，接收时反向解调"的 Bluetooth 短距离无线通信收发组态。

## 工作原理
蓝牙采用高斯频移键控（GFSK）等调制，在全 80 个 1 MHz 信道（BLE）上进行跳频，配合时分双工在主从之间交换数据包。跳频扩展频谱降低了同频干扰，提升抗干扰能力。

## 关键计算公式

- 数据率与符号率关系（BLE GFSK 1 bit/符号）：
$$R_b = R_{sym}$$

- 接收灵敏度：
$$S = -174 + 10\log_{10}(BW) + NF + SNR_{min}$$

- 自由空间路径损耗：
$$PL = 20\log_{10}d + 20\log_{10}f + 32.44$$

- OTA 空中数据率（含协议开销 $\eta$）：
$$R_{app} = R_b \times \eta$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $R_b$ | 数据率 | bit/s |
| $S$ | 接收灵敏度 | dBm |
| $PL$ | 路径损耗 | dB |
| $\eta$ | 协议效率 | — |
| $R_{app}$ | 应用层数据率 | bit/s |

## 元件调整影响
- **发射功率增大** → 通信距离增大，功耗与射频干扰增加。
- **连接间隔缩短** → 数据吞吐提升、延迟降低，但功耗上升。
- **晶振精度变差（>±40 ppm）** → 连接保持困难，稳定性下降。
- **匹配网络失配** → 灵敏度下降、误包率上升，掉线概率增大。
- **广播间隔缩短** → 可连接性提升，但平均功耗增大。

## 典型参数示例
- 取 $BW = 1\ \text{MHz}$、$NF = 5\ \text{dB}$、$SNR_{min} = 8\ \text{dB}$：$S = -174 + 10\log_{10}(10^6) + 5 + 8 \approx -101\ \text{dBm}$。
- 取 $R_b = 1\ \text{Mbit/s}$、$\eta = 0.7$：$R_{app} = 1\times10^6 \times 0.7 = 700\ \text{kbit/s}$。

## 常见器件型号
- 芯片/模组：nRF52832、nRF52840、CC2541、ESP32。
- 天线：2.4 GHz PCB 天线、片上天线、陶瓷天线。

## 注意事项
- 2.4 GHz 与 WiFi 共频，注意信道共存与射频准入控制。
- 天线净空区与地平面完整性对链路预算影响显著。
- 注意协议栈 RAM/Flash 占用，选型时确认内存资源。
- 低功耗应用需合理配置广播与连接参数以平衡功耗与响应。
