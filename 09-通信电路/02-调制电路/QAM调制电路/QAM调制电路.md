# QAM 调制电路

## 拓扑描述
由 **串并转换器 U1**、**两个正交载波振荡器 OSC1/OSC2（同频相差 90°）**、**两个乘法器 M1/M2**、**加法器 A1** 组成，按功能分为比特分流、正交调制与合成三类。电路共有 8 个关键节点：**节点① 串行数据节点**（比特流输入串并转换）；**节点② I 路符号节点**（U1 的 I 支路输出接 M1）；**节点③ Q 路符号节点**（U1 的 Q 支路输出接 M2）；**节点④ 同相载波节点**（OSC1 输出 $\cos\omega_c t$ 接 M1）；**节点⑤ 正交载波节点**（OSC2 输出 $\sin\omega_c t$ 接 M2）；**节点⑥ I 路乘积节点**（M1 输出接加法器）；**节点⑦ Q 路乘积节点**（M2 输出接加法器）；**节点⑧ 已调输出节点**（加法器输出为 QAM 信号）。

各元件管脚连接：**U1（串并转换器）** 的串行输入脚接节点①、I 路输出脚接节点②、Q 路输出脚接节点③；**OSC1** 的输出脚接节点④；**OSC2** 的输出脚接节点⑤（由本振经 90° 移相得到）；**M1** 的基带（I 路）输入脚接节点②、载波（本振）输入脚接节点④、输出脚接节点⑥；**M2** 的基带（Q 路）输入脚接节点③、载波输入脚接节点⑤、输出脚接节点⑦；**A1（加法器）** 的两个输入脚分别接节点⑥与节点⑦、输出脚接节点⑧；各单元电源脚接 +VCC、地脚接 GND。

由此构成"比特流分为 I/Q 两路分别调制正交载波后相加"的联合幅度与相位（QAM）数字调制组态，每个符号携带 $\log_2 M$ bit。

## 工作原理
每个符号携带 $\log_2 M$ bit，映射到 I/Q 星座图上的一个点，I 路与 Q 路分别乘以 $\cos$ 与 $\sin$ 载波后相加。星座点间距决定抗噪能力，$M$ 越大频带利用率越高但对信噪比要求越高。

## 关键计算公式

- QAM 已调波（$I_k$、$Q_k$ 为符号映射的 I/Q 幅度）：
$$s(t) = I_k\cos(\omega_c t) + Q_k\sin(\omega_c t)$$

- 主瓣带宽（$R_s$ 符号率）：
$$BW = 2R_s = \frac{2R_b}{\log_2 M}$$

- 频谱效率：
$$\eta = \log_2 M\ \text{bit/s/Hz}$$

- 符号速率：
$$R_s = \frac{R_b}{\log_2 M}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $M$ | 调制阶数 | — |
| $R_b$ | 码率 | bit/s |
| $R_s$ | 符号率 | symbol/s |
| $BW$ | 带宽 | Hz |
| $\eta$ | 频谱效率 | bit/s/Hz |

## 元件调整影响
- **调制阶数 M 增大（16→64→256-QAM）** → 频谱效率提高，但星座点间距变小，对 SNR 与线性度要求更高。
- **符号率 $R_s$ 增大** → 数据率提高，占用带宽增大。
- **I/Q 幅度或相位不平衡增大** → 星座点失真，误码率上升。
- **本振相位噪声增大** → 星座点旋转/展宽，性能恶化。
- **功放线性度不足** → 星座压缩与互调失真，高阶 QAM 尤为敏感。

## 典型参数示例
- 取 $M = 64$、$R_b = 54\ \text{Mbit/s}$：$R_s = 54/6 = 9\ \text{Msymbol/s}$，$\eta = 6\ \text{bit/s/Hz}$。
- 取 $R_s = 5\ \text{Msymbol/s}$：$BW = 2\times5\times10^6 = 10\ \text{MHz}$。

## 常见器件型号
- 正交调制器：ADL5375、LTC5599、TRF3703。
- 数字上变频：AD9957、AD9361（集成收发）。
- 载波源：晶振 + PLL 频率合成器。

## 注意事项
- 高阶 QAM 需严格平衡 I/Q 两路增益、直流偏置与正交相位。
- 星座图非恒包络，功放线性度与峰均比要求高。
- 接收端需要精确信道估计与均衡以对抗衰落与相位旋转。
- 实际系统中需结合编码（如 LDPC/TCM）补偿高阶调制带来的灵敏度损失。
