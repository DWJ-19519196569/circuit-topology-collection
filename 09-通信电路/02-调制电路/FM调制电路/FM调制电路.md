# FM 调制电路

## 拓扑描述
由 **压控振荡器（VCO）U1** 与 **调制信号输入回路** 组成，按功能分为调制信号输入与频率调制两类，也可通过变容二极管接入 LC 振荡回路实现。电路共有 5 个关键节点：**节点① 调制信号输入节点**（调制信号 $m(t)$ 经输入回路送入 VCO 的调制输入端）；**节点② 振荡/谐振节点**（VCO 内部 LC/变容谐振回路与调制输入耦合处）；**节点③ 输出节点**（U1 输出已调频波）；**节点④ 电源节点 +VCC**；**节点⑤ 地节点 GND**。

各元件管脚连接：**U1（VCO）** 的调制输入脚（如 VAR/MOD 脚）接节点①，输出脚 OUT 接节点③，电源脚 VCC 接节点④、地脚 GND 接节点⑤；**变容二极管 D1**（若采用）的阳极接射频地/节点⑤（交流地），阴极接节点②谐振回路，调制信号经输入回路加到其两端以改变反偏电容；**输入回路中的耦合/隔直电容**一端接节点①、另一端接调制源（或地），用于把调制信号耦合进谐振回路并隔离直流。

由此构成"调制信号经输入回路控制 VCO 瞬时频率、输出恒包络调频波"的直接调频组态，频偏与调制信号幅度成正比，幅度保持恒定。

## 工作原理
瞬时频率围绕中心频率 $f_c$ 随调制信号偏移，频偏大小与调制信号幅度成正比，与频率无关。已调波为恒包络信号，抗幅度干扰能力强，带宽由卡森公式估算。

## 关键计算公式

- 调频波瞬时频率：
$$f(t) = f_c + k_f m(t)$$

- 峰值频偏：
$$\Delta f = k_f |m(t)|_{max}$$

- 调频指数：
$$\beta = \frac{\Delta f}{f_m}$$

- 卡森带宽：
$$BW = 2(\Delta f + f_m) = 2f_m(1 + \beta)$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_c$ | 中心频率 | Hz |
| $k_f$ | 调频灵敏度 | Hz/V |
| $\Delta f$ | 峰值频偏 | Hz |
| $f_m$ | 调制信号频率 | Hz |
| $\beta$ | 调频指数 | — |
| $BW$ | 信号带宽 | Hz |

## 元件调整影响
- **调制信号幅度增大（$k_f$ 增大）** → 频偏与带宽增大，抗噪能力增强但占用频谱变宽。
- **VCO 中心频率提高** → 工作频段上移，需相应调整谐振回路。
- **变容二极管反向偏压改变** → 改变 VCO 中心频率与调频灵敏度。
- **调制信号频率升高** → $\beta$ 减小（频偏不变时），带宽略增。

## 典型参数示例
- 取 $\Delta f = 75\ \text{kHz}$、$f_m = 15\ \text{kHz}$：$\beta = 75/15 = 5$，$BW = 2(75+15) = 180\ \text{kHz}$（调频广播单声道标称）。
- 取 $k_f = 50\ \text{kHz/V}$、$m(t)_{max} = 1\ \text{V}$：$\Delta f = 50\ \text{kHz}$。

## 常见器件型号
- VCO：MC1648、MAX2606、NE564（含 VCO）。
- 变容二极管：BB910、1SV149。
- 晶体振荡器：可用于窄带 FM 的温补晶振。

## 注意事项
- 恒包络特性使其对幅度噪声不敏感，但需注意 VCO 频率稳定度与漂移。
- 宽带 FM 占用频带较宽，需符合频谱法规对带宽和频偏的限制。
- 变容二极管非线性会引入失真，需限制频偏或做线性化。
- VCO 中心频率受温度影响，广播级应用常配合 AFC 环路稳频。
