# 天线匹配电路

## 拓扑描述
天线匹配电路由 **匹配电感 $L$ 与匹配电容 $C$** 组成的 **L 型、π 型或 T 型无源网络**（含串联臂电抗 $X_s$ 与并联臂电抗 $X_p$）构成，接在 **发射机/接收机输出端（源 $V_s$，特征阻抗 $Z_0=50\ \Omega$）与天线输入阻抗（负载 $Z_L$）** 之间。电路共有 4 个关键节点：**节点① 源端**（射频驱动/输入，$Z_0$ 侧）；**节点② 串联臂与并联臂交点（中间节点）**；**节点③ 负载端**（天线，$Z_L$ 侧）；**节点④ 地**（GND）。

各元件管脚连接：L 型网络中，**串联电抗元件**（$L_s$ 或 $C_s$）一端接节点①、另一端接节点②；**并联电抗元件**（$C_p$ 或 $L_p$）一端接节点②、另一端接地（节点④），节点② 即变换后的阻抗接入点。π 型在节点① 与节点③ 各有一个并联臂，公共中间节点② 连接两个并联臂并经串联臂接负载；T 型在节点① 与节点③ 各有一个串联臂，自公共中间节点② 分出一并联臂接地。源 $Z_0$ 在节点①、负载 $Z_L$ 在节点③，L、C 取值把 $Z_L$ 共轭变换到 $Z_0$，使反射系数 $\Gamma=\dfrac{Z_L-Z_0}{Z_L+Z_0}$ 趋近 0（VSWR 趋近 1）。

由此构成"串联/并联 L、C 无源网络把天线复阻抗共轭匹配到 50 Ω 源阻抗"的阻抗匹配组态，实现最大功率传输并兼作谐波滤波，广泛用于射频前端馈线匹配。

## 工作原理
通过 L、C 网络把天线的复阻抗（如 30+j20 Ω）变换到源阻抗（50 Ω），或反向变换，使源与负载阻抗匹配、反射最小。匹配元件同时构成谐振/滤波结构，可抑制带外谐波。

## 关键计算公式

- 反射系数：
$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$

- 回波损耗：
$$RL = -20\log_{10}|\Gamma|\ (\text{dB})$$

- 电压驻波比：
$$VSWR = \frac{1+|\Gamma|}{1-|\Gamma|}$$

- 阻抗与匹配元件关系（L 型，感性/容性换算由工作频率决定）：
$$Z_{in} = jX_L + \frac{1}{j\omega C + 1/Z_L}\ (\text{示例拓扑})$$

- 失配功率损耗：
$$P_{lost} = P_{in}\left(1-|\Gamma|^2\right)$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $Z_L, Z_0$ | 负载/源阻抗 | Ω |
| $\Gamma$ | 反射系数 | — |
| $RL$ | 回波损耗 | dB |
| $VSWR$ | 电压驻波比 | — |
| $P$ | 功率 | W |

## 元件调整影响
- **串/并联电感电容取值变化** → 改变变换比与谐振点，匹配点偏移，VSWR 升高。
- **工作频率 ↑** → 同一元件阻抗改变，匹配网络需重新设计。
- **元件 Q 值/损耗** → 决定匹配网络插入损耗，高 Q 元件损耗更低、带宽更窄。
- **匹配网络拓扑（L/π/T）** → 影响带宽与谐波抑制，π/T 型可独立调带宽。

## 典型参数示例
- 取 $Z_L=30+j20\ \Omega$、$Z_0=50\ \Omega$：适当 L、C 组合可将负载匹配到 50 Ω，使回波损耗 >10 dB（VSWR <2）。
- 取 $|\Gamma|=0.05$：$RL=-20\log_{10}(0.05)=26$ dB，反射功率仅 $0.05^2=0.25\%$。

## 常见器件型号
- 常用：高频贴片电感/电容（Murata LQW、ATC 系列），按需选型。
- 集成匹配/调谐：天线调谐开关与可调电容（如 Skyworks 天线调谐器）。

## 注意事项
- 匹配目标是功率传输最大，源阻抗与负载需共轭匹配。
- 匹配网络兼滤波作用时需兼顾谐波抑制与带宽。
- 实际天线阻抗随频率/环境变化，匹配带宽内允许一定 VSWR。
- 元件含寄生参数，高频需用精确模型或 EM 仿真。
