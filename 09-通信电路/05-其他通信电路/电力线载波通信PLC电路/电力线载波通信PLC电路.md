# 电力线载波通信 PLC 电路

## 拓扑描述
由 **PLC 调制解调/基带处理器芯片 A1**、**线路耦合单元（耦合电容 $C_{couple}$ + 耦合变压器 T）**、**带通滤波器** 与 **电源线接口（火线 L、零线 N）** 组成。电路共有 6 个关键节点：**节点① 芯片调制输出 TX**；**节点② 芯片解调输入 RX**；**节点③ 变压器初级（芯片侧）**；**节点④ 变压器次级（电力线侧）**；**节点⑤ 电力线（火线 L/零线 N）**；**节点⑥ 芯片电源**（VCC）与 **节点⑦ 地**（GND）。

各器件管脚连接：**A1** 的调制输出（节点①）经带通滤波器与驱动级耦合到 $C_{couple}$ 与变压器 T 初级（节点③）；T 次级（节点④）接到电力线（节点⑤），把高频载波注入工频线路；**接收端** 从电力线取信号，经 T 反向耦合、$C_{couple}$ 隔断工频电压、带通滤波器滤除工频与杂波后送入 A1 的解调输入（节点②）。$C_{couple}$ 必须耐高压并选用安规 X 电容，保证工频隔离安全，其高通截止 $f_c=\dfrac{1}{2\pi R C_{couple}}$ 应低于载波频率；T 的匝比按 $\dfrac{Z_{line}}{Z_{chip}}=\left(\dfrac{N_p}{N_s}\right)^2$ 匹配线路与芯片阻抗。芯片电源 VCC 与地 GND（节点⑥/⑦）去耦。

由此构成"调制器把数据调制成远高于工频的载波、耦合电容隔断工频电压、耦合变压器阻抗折算后注入/提取电力线信号"的电力线载波通信链路，实现利用既有电力线（工频与载波频分复用）传输数据。

## 工作原理
发送端把数据调制到远高于工频（50/60 Hz）的载波（窄带几十 kHz 或宽带 2~30 MHz），经耦合电容隔断工频电压、由耦合变压器阻抗原边折算后注入火线/零线；接收端反向完成耦合与解调。工频与载波频分复用互不干扰。

## 关键计算公式

- 高通耦合网络截止频率：
$$f_c = \frac{1}{2\pi R C_{couple}}$$

- 耦合变压器阻抗匹配：
$$\frac{Z_{line}}{Z_{chip}} = \left(\frac{N_p}{N_s}\right)^2$$

- 载波注入损耗（含线路衰减）：
$$P_{recv} = P_{tx} - L_{coupler} - L_{line}$$

- 工频隔离（耦合电容容抗）：
$$X_C = \frac{1}{2\pi f_{AC} C_{couple}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $C_{couple}$ | 耦合电容 | F |
| $R$ | 等效负载电阻 | Ω |
| $f_c$ | 截止频率 | Hz |
| $Z$ | 阻抗 | Ω |
| $L$ | 损耗 | dB |

## 元件调整影响
- **耦合电容 ↑** → 低频与工频隔离变差、漏电流增大；**↓** → 载波注入损耗增大。
- **耦合变压器匝比** → 调节线路阻抗与芯片阻抗匹配，失配则功率传输下降。
- **带通滤波器带宽** → 决定可用载波带宽，需滤除工频及谐波干扰。
- **载波频率 ↑** → 线路衰减增大、但受窄带干扰影响减小。

## 典型参数示例
- 取 $R=50\ \Omega$、$C_{couple}=100\ \text{nF}$：高通 $f_c=\dfrac{1}{2\pi\times50\times100\times10^{-9}}\approx 31.8\ \text{kHz}$，低于载波频率即可通过。
- 窄带 PLC（如 G3-PLC）载波约 35~90 kHz，宽带 HomePlug 约 2~30 MHz。

## 常见器件型号
- 窄带 PLC：ST7580、MAX2990、PL3180。
- 宽带 PLC：QCA6410、QCA7000、INT6400。
- 耦合变压器：按需选型（工频隔离型高频耦合变压器）。

## 注意事项
- 耦合电容必须耐高压并选用安规 X 电容，确保工频隔离安全。
- PLC 信号受电网噪声、负载变化与多径干扰影响很大，需强纠错与自适应。
- 变压器需能承受工频电压并保证载波频段低损耗。
- 多节点组网需考虑阻抗变化与信号衰减，必要时加中继。
