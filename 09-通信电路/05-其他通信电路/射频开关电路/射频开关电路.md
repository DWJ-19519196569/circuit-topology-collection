# 射频开关电路

## 拓扑描述
射频开关由 **PIN 二极管 D1、D2**（或 FET、MEMS 型开关元件）、**偏置网络（限流电阻 $R_{bias}$ + 隔直/射频扼流电感 $L_{RFC}$）** 与 **隔直电容 $C_{block}$** 组成，在发射/接收或不同频段之间切换信号路径，多采用串-并联二极管或吸收式结构。电路共有 6 个关键节点：**节点① 射频公共端（RFC 输入）**；**节点② 第一射频输出端**（如 TX 路径）；**节点③ 第二射频输出端**（如 RX 路径）；**节点④ 偏置控制端（Vctrl）**；**节点⑤ 隔直后射频通道**；**节点⑥ 地**（GND）。

各元件管脚连接：**隔直电容 $C_{block}$** 串在射频通道上，使 $X_C=\dfrac{1}{2\pi f C}\ll Z_0$，阻断直流进入射频端；**串臂 PIN 二极管** 阳极经 $L_{RFC}$ 接偏置端（节点④）、阴极接射频通道节点，并联 PIN 二极管阳极接射频通路、阴极接地（节点⑥），构成"串导/并断 或 串断/并导"的通断切换。**限流电阻 $R_{bias}$** 串在 Vctrl 与二极管之间设定正向偏置电流 $I_F$（决定导通电阻 $R_S$ 与插入损耗）；**$L_{RFC}$** 对射频呈高阻（$X_L=2\pi f L\gg Z_0$），把偏置电流注入而隔离射频。FET 型开关以栅极 G 接控制偏置、源极 S 接地、漏极 D 接射频通道，靠栅压控制沟道导通/夹断。

由此构成"直流偏置控制 PIN/FET 开关的通断、隔直电容与扼流电感隔离射频与偏置、串并联结构切换信号路径"的射频开关，用于收发切换（T/R）与多频段前端，隔离度与插入损耗由偏置电流与器件类型决定。

## 工作原理
PIN 二极管在正向偏置时呈现很低阻抗（导通，RF 通过），在反偏时呈现高阻抗（截止，RF 隔离），通过直流偏置控制 RF 通断。FET 型则靠栅压控制沟道导通/夹断实现开关。

## 关键计算公式

- 开关隔离度：
$$Iso = 10\log_{10}\left(\frac{P_{off}}{P_{on}}\right)\ (\text{dB})$$

- 插入损耗：
$$IL = 10\log_{10}\left(\frac{P_{in}}{P_{out}}\right)$$

- PIN 二极管导通电阻与偏置电流近似：
$$R_S \approx \frac{W^2}{(\mu_n+\mu_p)\,\tau\, I_F}$$

- 射频扼流电感阻抗（需远大于射频阻抗）：
$$X_L = 2\pi f L \gg Z_0$$

- 隔直电容容抗（需远小于 $Z_0$）：
$$X_C = \frac{1}{2\pi f C} \ll Z_0$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $IL$ | 插入损耗 | dB |
| $Iso$ | 隔离度 | dB |
| $R_S$ | 导通电阻 | Ω |
| $I_F$ | PIN 正向偏置电流 | A |
| $Z_0$ | 特征阻抗 | Ω |

## 元件调整影响
- **偏置电流 I_F ↑** → PIN 导通电阻减小、插入损耗降低，但偏置功耗与直流泄漏增加。
- **反偏电压 ↑** → 隔离度提高，但需低于器件击穿。
- **扼流电感 ↓ / 隔直电容不当** → 射频信号泄漏到偏置或直流支路，性能恶化。
- **开关切换速度** → 由 PIN 少数载流子寿命或 FET 栅驱动决定。

## 典型参数示例
- 取有 PIN 开关导通电阻 $R_S=1\ \Omega$、隔离态阻抗 $R_{off}>1\ \text{kΩ}$（1 GHz），隔离度达约 30 dB 以上。
- 取 $f=1$ GHz、$C=100$ pF：$X_C=\dfrac{1}{2\pi\times10^9\times100\times10^{-12}}\approx 1.6\ \Omega \ll 50\ \Omega$，满足隔直。

## 常见器件型号
- PIN 二极管：BAP64、BAR64、SMP1320、HSMP-3814。
- 集成射频开关：SKY13350、PE4259、ADG918（FET 型）。
- 常用：Mini-Circuits 射频开关模块（按需选型）。

## 注意事项
- 需在开关前后加隔直电容，防止直流偏置进入射频端。
- 高功率开关关注 1 dB 压缩点与峰值耐压，避免击穿。
- 偏置电路（扼流圈/电阻）要保证对射频无影响。
- FET 开关注意栅极偏置与开关速度、功率容量。
