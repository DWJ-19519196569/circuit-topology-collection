# 频率合成器电路

## 拓扑描述
频率合成器由 **参考晶振 XTAL**（基准频率）、**鉴相器/鉴频鉴相器 PFD**、**环路滤波器**、**压控振荡器 VCO** 与 **分频器 ÷N** 组成负反馈环路（PLL 型），或由 **直接数字合成 DDS**（相位累加器 + 正弦查找表 + DAC）实现。电路共有 6 个关键节点：**节点① 参考频率输入 $f_{ref}$**；**节点② 分频反馈输入**；**节点③ PFD 误差输出**；**节点④ 环路滤波器输出（$V_{tune}$）**；**节点⑤ VCO 输出 $f_{out}$**；**节点⑥ 电源**（VCC）与 **节点⑦ 地**（GND）。

各器件管脚连接：**晶振 XTAL** 输出接节点①（参考输入）；**PFD** 的参考脚接节点①、反馈脚接节点②，输出接节点③；**环路滤波器** 的 R、C 接在节点③ 与节点④ 之间；**VCO** 控制端接节点④、输出接节点⑤；节点⑤ 经 **分频器 ÷N** 分频到节点② 形成反馈，同时作为频率输出，得 $f_{out}=N\cdot f_{ref}$。**DDS 型**：时钟 $f_{clk}$ 驱动相位累加器按频率控制字 $FTW$ 步进，累加器输出地址查正弦表经 DAC 输出，得 $f_{out}=\dfrac{FTW}{2^M}\cdot f_{clk}$，频率分辨 $\Delta f=\dfrac{f_{clk}}{2^M}$。电源 VCC 与地 GND（节点⑥/⑦）按各自去耦，VCO/DDS 供电需低噪声。

由此构成"参考基准经 PLL 分频反馈（或 DDS 数字累加查表）产生一系列稳定可调频率"的频率合成器，$f_{out}=N\cdot f_{ref}$（PLL 型）或 $f_{out}=\dfrac{FTW}{2^M}f_{clk}$（DDS 型），是无线电收发与时钟系统的核心。

## 工作原理
PLL 型：VCO 输出经 N 分频后与参考频率鉴相，相位差经环路滤波器平滑后调谐 VCO，环路锁定后 $f_{out}=N\cdot f_{ref}$。DDS 型：相位累加器按频率控制字步进，查正弦表经 DAC 直接合成输出频率。

## 关键计算公式

- PLL 输出频率：
$$f_{out} = N \cdot f_{ref}$$

- 分频比（小数分频）：
$$N = \frac{f_{out}}{f_{ref}}$$

- DDS 输出频率：
$$f_{out} = \frac{FTW}{2^{M}} \cdot f_{clk}$$

- 环路自然频率/带宽（二阶近似，与环路滤波器 R、C 相关）。

- 频率分辨率（DDS）：
$$\Delta f = \frac{f_{clk}}{2^M}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $f_{out}$ | 输出频率 | Hz |
| $f_{ref}$ | 参考频率 | Hz |
| $N$ | 分频比 | — |
| $FTW$ | 频率控制字 | — |
| $f_{clk}$ | 时钟频率 | Hz |
| $M$ | 相位累加器位宽 | bit |

## 元件调整影响
- **分频比 N ↑** → 输出频率升高，但环路增益与相位噪声放大（×N）。
- **参考频率 f_ref ↑** → 频率分辨率变粗，但允许更宽环路带宽。
- **环路滤波器带宽 ↑** → 锁定加快、相位噪声抑制差；**↓** → 锁定慢、杂散与近端噪声改善。
- **VCO 调谐灵敏度** → 决定环路增益与频率稳定度，需与滤波器配合。

## 典型参数示例
- 取 $f_{ref}=10$ MHz、$N=100$：$f_{out}=100\times10=1000$ MHz（1 GHz）。
- DDS 取 $f_{clk}=1$ GHz、$M=32$：$\Delta f=\dfrac{10^9}{2^{32}}\approx 0.233$ Hz。

## 常见器件型号
- PLL 频率合成器：ADF4351、LMX2594、Si5351、HMC832。
- DDS：AD9834、AD9851、AD9910。
- VCO：MAX2606、HMX 系列 VCO。

## 注意事项
- 参考晶振的相位噪声直接影响输出近端相位噪声。
- 环路滤波器参数需按锁相环稳定判据设计，避免失锁/振荡。
- 小数分频会引入量化杂散，需用 Σ-Δ 调制抑制。
- 输出需关注相位噪声、杂散与频率切换时间等指标。
