# 电流舵型 DAC 电路

## 拓扑描述
由 **二进制加权或温度计编码的恒流源阵列 $I_0,I_1,\dots,I_{N-1}$**、**差分开关对 $SW_0,\dots,SW_{N-1}$** 与 **输出负载/阻抗网络 $R_L$**（常配合外接电阻或运放）组成。电路共有 6 个关键节点：**节点① 数字码节点**（$N$ 位码 $D$ 送各差分开关控制端）；**节点② 正输出节点**（$I_{out+}$，各开关的正触点汇入）；**节点③ 负输出节点**（$I_{out-}$，各开关的负触点汇入）；**节点④ 公共电源节点**（各恒流源公共端接 $V_{DD}$）；**节点⑤ 参考/地节点**（恒流源基准设定端与负载下端接 GND）；**节点⑥ 输出电压节点**（总电流经负载 $R_L$ 得到的 $V_{out}$）。

各管脚连接：**$SW_k$**（$k=0,\dots,N-1$）的控制端接节点①中对应位、公共端接恒流源 $I_k$、正触点接节点②（$I_{out+}$）、负触点接节点③（$I_{out-}$）；**$I_k$** 一端接 $SW_k$ 公共端、另一端接节点④（$V_{DD}$），其基准设定端接节点⑤；**$R_L$** 一端接节点②（$I_{out+}$）、另一端接节点⑤（GND），总电流在此转成 $V_{out}=I_{out}R_L$；若外接运放转电压，则其反相输入接节点②、同相输入接节点⑤（GND）、输出接节点⑥。

由此构成"各位恒流源由差分开关舵向正或负输出、各单元电流在输出节点按权重求和、再经负载电阻转成电压"的电流舵型 DAC 组态，输出 $I_{out}=I_{LSB}\cdot D$，是高速 DAC 的主要结构。

## 工作原理
每一位对应的恒流单元由一对差分开关把电流切换到 $I_{out+}$ 或 $I_{out-}$。所有单元的电流在输出节点按权重求和，经输出电阻或运放转换为与数字码成正比的电压/电流。

## 关键计算公式

- 输出电流：
$$I_{out} = I_{LSB}\cdot D$$

- 单位电流：
$$I_{LSB} = \frac{I_{FS}}{2^N}$$

- 输出电压（外接负载电阻 $R_L$）：
$$V_{out} = I_{out}\cdot R_L$$

- 满量程电流：
$$I_{FS} = I_{LSB}(2^N-1)$$

- 输出摆率（大信号建立）：
$$SR = \frac{\Delta I_{out}}{C_{load}}$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I_{out}$ | 输出电流 | A |
| $I_{LSB}$ | 单位（LSB）电流 | A |
| $I_{FS}$ | 满量程电流 | A |
| $D$ | 数字输入码 | — |
| $N$ | 位数 | bit |
| $R_L$ | 负载电阻 | Ω |
| $C_{load}$ | 负载电容 | F |

## 元件调整影响
- **单位电流 $I_{LSB}$ 增大** → 输出幅度增大、速度提升，但功耗与噪声增大。
- **负载电阻 $R_L$ 增大** → 电压输出幅度增大，但输出摆幅受限、速度变慢。
- **负载电容 $C_{load}$ 减小** → 建立时间缩短，工作速度提高。
- **位数 N 增多** → 分辨率提高，但电流源匹配与版图要求急剧上升。
- 温度计码分段减少毛刺，但所需单元数增加。

## 典型参数示例
- 取 $N=8$、$I_{FS}=20\ \text{mA}$：$I_{LSB}=\dfrac{20}{256}\times10^{-3}\approx78.1\ \mu\text{A}$。
- 取 $R_L=50\ \Omega$、$D$ 满量程：$V_{out}=20\times10^{-3}\times50=1\ \text{V}$。

## 常见器件型号
- 高速电流舵 DAC：AD9779（16 位 GHz 级）、AD9744、MAX5885。
- 视频/通信 DAC：DAC5672。

## 注意事项
- 电流源输出阻抗与匹配决定线性度，需版图对称设计。
- 输出为电流型，接运放转电压时注意带宽与噪声。
- 开关切换毛刺（glitch）影响 SFDR，常采用温度计编码或退化处理。
