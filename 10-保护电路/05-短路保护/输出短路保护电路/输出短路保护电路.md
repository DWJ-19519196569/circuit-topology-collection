# 输出短路保护电路

## 拓扑描述
该电路由受控开关 Q1（MOSFET 或三极管）、采样电阻 $R_{sense}$（编号 R1）与比较/检测环节 IC1（限流检测比较器，可内置于稳压器）组成，串接在稳压器输出端。关键节点定义如下：稳压器输出节点 $V_{reg}$ 是稳压器 VO 引脚与采样电阻 $R_{sense}$ 一端的公共点；检测节点 $N_{sense}$ 是 $R_{sense}$ 另一端与开关 Q1 输入端（MOSFET 漏极 D / BJT 集电极 C）的公共点，同时送给检测环节 IC1 采样；被保护输出节点 $V_{out}$ 接开关 Q1 的输出端（MOSFET 源极 S / BJT 发射极 E），直接连到负载；地节点 GND 是稳压器与检测环节的公共参考地。

各元件管脚连接：采样电阻 $R_{sense}$ 一端接稳压器输出节点 $V_{reg}$，另一端接检测节点 $N_{sense}$（即开关 Q1 的漏极 D 或集电极 C）；检测环节 IC1 的电流检测输入跨接在 $R_{sense}$ 两端（或经分压），其输出端接开关 Q1 的栅极 G（或基极 B），供电端接电源 / 稳压器辅助供电、地端接 GND；开关 Q1（以 MOSFET 为例）漏极 D 接检测节点 $N_{sense}$，源极 S 接被保护输出节点 $V_{out}$，栅极 G 接检测环节 IC1 的输出。

由此构成"串联受控开关 + 输出电流采样 + 比较关断"的限流/打嗝保护组态，输出短路时检测环节立即关断 Q1 切断输出，保护稳压器与线路。

## 工作原理
输出电流经采样电阻产生压降，检测环节实时监视。正常恒流输出时开关保持导通；当输出短路使电流超过设定上限，比较器立即关断开关或使稳压器进入限流 / 打嗝（hiccup）模式，限制短路电流并周期性重试，待故障排除后自动恢复输出。

## 关键计算公式

- 短路保护阈值：
$$I_{limit} = \frac{V_{th}}{R_{sense}}$$

- 输出短路时瞬时功耗（开关管）：
$$P_{diss} = V_{in}\,I_{limit}$$

- 打嗝模式平均功率：
$$P_{avg} = P_{diss}\,\frac{t_{on}}{t_{on}+t_{off}}$$

- 采样电阻取值：
$$R_{sense} = \frac{V_{th}}{I_{limit}}$$

- 限流时输出电压：
$$V_{out} \approx 0\ (\text{短路时})$$

| 符号 | 含义 | 单位 |
|------|------|------|
| $I_{limit}$ | 限流 / 保护电流 | A |
| $V_{th}$ | 阈值电压 | V |
| $R_{sense}$ | 采样电阻 | Ω |
| $V_{in}$ | 输入电压 | V |
| $P_{diss}$ | 开关管耗散功率 | W |
| $t_{on},\ t_{off}$ | 打嗝导通 / 关断时间 | s |

## 元件调整影响
- **$R_{sense}$ 增大** → 限流阈值降低、保护更早，但正常输出压降和损耗增大。
- **阈值 $V_{th}$ 提高** → 允许更大短路电流，保护变迟，器件承受应力增大。
- **打嗝周期占空比 $t_{on}/(t_{on}+t_{off})$ 越小** → 平均功耗越低、发热小，但短路自恢复变慢。
- **开关管耐压 / 散热不足** → 短路时瞬时功耗 $V_{in}I_{limit}$ 很大，易过温损坏。
- **采样点接近输出端** → 能包含线路压降，保护更真实，但要兼顾负载瞬态裕量。

## 典型参数示例
- 取 $R_{sense}=0.1\ \text{Ω}$、$V_{th}=0.2\ \text{V}$：$I_{limit}=\dfrac{0.2}{0.1}=2\ \text{A}$。
- 输入 $V_{in}=12\ \text{V}$、短路限流 2 A：开关瞬时功耗 $P_{diss}=12\times2=24\ \text{W}$；采用打嗝模式、$t_{on}=10\ \mu\text{s}$、$t_{off}=1\ \text{ms}$，平均功耗 $P_{avg}=24\times\dfrac{10\times10^{-6}}{10\times10^{-6}+0.001}\approx0.24\ \text{W}$。

## 常见器件型号
- 集成限流稳压器：LM317（自带过流保护）、78xx 系列、TPS 系列。
- 电源保护开关：TI TPS25200 系列、USB 限流开关（如 APL3551、TPS2051）。
- 采样电阻：低阻合金 / 四端子电阻。
- 开关管：N 沟道 MOSFET（如 AO3400、IRLML6344）。

## 注意事项
- 短路瞬间输出电流与功率可能远超额定，必须靠硬件限流 / 打嗝，不能只依赖软件。
- 恒定限流模式会让开关管长期承受 $V_{in}I_{limit}$，需核算功耗与散热或采用打嗝降低平均损耗。
- 采样电阻的温漂与寄生电感会引入误差与尖峰，选低 TCR 器件并做好布局。
- 保护阈值要高于最大正常负载电流与启动冲击，否则易误触发。
